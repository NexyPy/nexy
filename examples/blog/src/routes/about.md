# About

This is an example blog for [Nexy](https://github.com/NexyPy/nexy), a Python framework for web
applications. This page is a plain Markdown file, `src/routes/about.md`: Nexy serves it inside the
layout of the site, with no template to write.

The source of the whole blog is in
[examples/blog](https://github.com/NexyPy/nexy/tree/main/examples/blog). Copy it, replace the posts
in `content/posts/`, and it is yours.
