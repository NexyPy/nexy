# Internationalisation (i18n)

Nexy ne traduit pas votre candidature. Il n'a pas de middleware de paramètres régionaux, pas d'assistant `trans` et pas de fichiers de paramètres régionaux : une application choisit la bibliothèque i18n qui lui convient, comme elle choisit un ORM.

La ligne de commande (`nx`) est traduite ; voir [la CLI](../reference/cli.md).

## Dans un gestionnaire

Un gestionnaire lit ce dont il a besoin dans la requête. Celui-ci répond dans la langue de l'en-tête `Accept-Language` :

```python filename="src/routes/bonjour.py"
from nexy.http import Header

MESSAGES = {"en": "Hello", "fr": "Bonjour"}


async def GET(accept_language: str = Header("en")):
    language = accept_language.split(",")[0].split("-")[0].lower()
    return {"message": MESSAGES.get(language, MESSAGES["en"])}
```

## Dans une page

Utilisez la bibliothèque de votre frontend pour les pages acheminées par le client (par exemple `i18next`, `vue-i18n` ou une boutique Svelte), et votre bibliothèque Python (`gettext` de la bibliothèque standard, ou Babel) pour les pages `.nexy`. Définissez `<html lang>` dans la disposition racine.
