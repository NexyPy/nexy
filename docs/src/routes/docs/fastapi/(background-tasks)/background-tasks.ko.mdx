# 백그라운드 작업

로깅, 알림, 캐시 워밍 등을 위해 응답을 보낸 *후* 코드를 실행합니다.
```python
from fastapi import BackgroundTasks
```
---

## 단일 작업
```python
---
from fastapi import BackgroundTasks

def write_log(message: str):
    with open("app.log", "a") as f:
        f.write(message + "\n")

def GET(tasks: BackgroundTasks):
    tasks.add_task(write_log, "Page visited")
    return {"status": "ok"}
---
```

## 종속성이 있는 작업
```python
---
from fastapi import BackgroundTasks, Depends
from src.db import get_db

def cleanup_old_records(db=Depends(get_db)):
    db.query(Log).delete()

def GET(tasks: BackgroundTasks):

    return {"status": "cleaning"}
```

## 중요

- 응답이 전송된 **후** 작업이 실행됩니다. 클라이언트는 기다리지 않습니다.
- 동일한 프로세스에서 실행됩니다. 긴 작업은 이벤트 루프를 차단합니다.
- 작업량이 많은 경우 작업 대기열(Celery, ARQ, RQ 등)을 사용합니다.
- 작업 오류는 자동으로 처리됩니다. 작업 함수 내부에 try/Exception을 추가하세요.
- 작업은 변경 가능한 개체의 **사본**을 수신합니다. 돌연변이는 응답에 영향을 미치지 않습니다.
