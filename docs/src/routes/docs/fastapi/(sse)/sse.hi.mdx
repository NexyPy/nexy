# सर्वर-भेजे गए इवेंट (एसएसई)

HTTP पर सर्वर से क्लाइंट तक वास्तविक समय की घटनाओं को स्ट्रीम करें।

## स्थापित करना
```bash
pip install sse-starlette
```
---

## समापन बिंदु
```python
---
import asyncio
from sse_starlette.sse import EventSourceResponse

async def event_generator():
    for i in range(10):
        await asyncio.sleep(1)
        yield {"event": "ping", "data": str(i)}

async def GET():
    return EventSourceResponse(event_generator())
---
```
```python
from nexy.decorators import Controller
from sse_starlette.sse import EventSourceResponse
import asyncio

"@Controller("/events")
class EventsController:
    async def GET(self):
        async def gen():
            for i in range(10):
                await asyncio.sleep(1)
                yield {"event": "ping", "data": str(i)}
        return EventSourceResponse(gen())
```
## ग्राहक
```javascript
const evtSource = new EventSource("/events");

    console.log(e.data);
});
```

## गतिशील घटना धारा

स्ट्रीम को अनुकूलित करने के लिए एक क्वेरी पैरामीटर पास करें:
```python
---
import asyncio
from sse_starlette.sse import EventSourceResponse

async def GET(count: int = 5, interval: float = 0.5):
    async def gen():
        for i in range(count):
            await asyncio.sleep(interval)
            yield {"event": "tick", "data": str(i)}
    return EventSourceResponse(gen())
---
```
```python
from nexy.decorators import Controller
from sse_starlette.sse import EventSourceResponse
import asyncio

"@Controller("/ticks")
class TickController:
    async def GET(self, count: int = 5, interval: float = 0.5):
        async def gen():
            for i in range(count):
                await asyncio.sleep(interval)
                yield {"event": "tick", "data": str(i)}
        return EventSourceResponse(gen())
```
## सीमाएँ

- SSE **यूनिडायरेक्शनल** है (सर्वर → क्लाइंट) - द्विदिशात्मक के लिए WebSocket का उपयोग करें
- `sse-starlette` डिफ़ॉल्ट रूप से शामिल नहीं है - `pip install sse-starlette`
- प्रत्येक कनेक्शन में एक खुला HTTP कनेक्शन होता है - अपने सर्वर की सीमाओं की निगरानी करें
