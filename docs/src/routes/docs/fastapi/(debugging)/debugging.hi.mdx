# डिबगिंग

नेक्सी ऐप्स मानक पायथन हैं - अपने सामान्य डिबगिंग टूल का उपयोग करें।

## `breakpoint()`

अपने रूट हैंडलर में कहीं भी `breakpoint()` डालें:

```python
def GET():
    x = 42
    breakpoint()  # drops into pdb
    return {"x": x}
```

`nx dev` चलाएँ और रूट पर जाएँ - टर्मिनल `pdb` में गिर जाता है।

## वीएस कोड

1. गटर पर क्लिक करके वीएस कोड में ब्रेकप्वाइंट सेट करें
2. `.vscode/launch.json` बनाएँ:

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Nexy Dev",
            "type": "debugpy",
            "request": "launch",
            "module": "nexy.cli",
            "args": ["dev"],
            "jinja": true
        }
    ]
}
```

3. डिबगिंग शुरू करने के लिए `F5` दबाएँ - ब्रेकप्वाइंट `.nexy` फ्रंटमैटर और `.py` फ़ाइलों में काम करते हैं।

## प्रिंट डिबगिंग

```python
---
print(f"Request params: {params}")  # appears in the terminal
---
```

## कंसोल लॉगिंग

नेक्सी डिफ़ॉल्ट रूप से सभी अनुरोधों को टर्मिनल पर लॉग करता है। अपने स्वयं के लॉग जोड़ें:

```python
import logging
logger = logging.getLogger("nexy")

def GET():
    logger.info("Home page loaded")
    return {"ok": True}
```

## यूविकॉर्न पुनः लोड

`nx dev` `--reload` के साथ यूविकॉर्न चलाता है - `.py`, `.nexy`, `.mdx` फ़ाइलों में परिवर्तन एक स्वचालित पुनरारंभ को ट्रिगर करता है।

## सामान्य मुद्दे

| लक्षण | संभावित कारण |
|---------|-----------------|
| रूट रिटर्न 405 | ग़लत HTTP विधि या अनुपलब्ध `python-multipart` |
| शरीर `None` है | पाइडेंटिक मॉडल या टाइप एनोटेशन गुम |
| 422 सत्यापन त्रुटि | पथ/क्वेरी पैरामीटर में बेमेल टाइप करें |
| मॉड्यूल नहीं मिला | वीएफएस कैश पुराना - `nx dev` पुनः आरंभ करें |
