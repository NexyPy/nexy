# デバッグ

Nexy アプリは標準の Python です。通常のデバッグ ツールを使用してください。

## `breakpoint()`

ルート ハンドラーの任意の場所に `breakpoint()` を挿入します。

```python
def GET():
    x = 42
    breakpoint()  # drops into pdb
    return {"x": x}
```

`nx dev` を実行してルートに到達すると、ターミナルは `pdb` に入ります。

## VS コード

1. ガターをクリックして VS Code にブレークポイントを設定します
2. `.vscode/launch.json` を作成します。

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Nexy Dev",
            "type": "debugpy",
            "request": "launch",
            "module": "nexy.cli",
            "args": ["dev"],
            "jinja": true
        }
    ]
}
```

3. `F5` を押してデバッグを開始します。ブレークポイントは `.nexy` フロントマッター ファイルと `.py` ファイルで機能します。

## 印刷デバッグ

```python
---
print(f"Request params: {params}")  # appears in the terminal
---
```

## コンソールのロギング

Nexy は、デフォルトですべてのリクエストを端末に記録します。独自のログを追加します。

```python
import logging
logger = logging.getLogger("nexy")

def GET():
    logger.info("Home page loaded")
    return {"ok": True}
```

## ユビコーンのリロード

`nx dev` は、`--reload` で uvicorn を実行します。`.py`、`.nexy`、`.mdx` ファイルに変更を加えると、自動再起動がトリガーされます。

## よくある問題

|症状 |考えられる原因 |
|----------|---------------|
|ルートは 405 を返します | HTTP メソッドが間違っているか、`python-multipart` がありません |
|本文は `None` | Pydantic モデルまたは型の注釈がありません |
| 422 検証エラー |パス/クエリパラメータの型が一致しません。
|モジュールが見つかりません | VFS キャッシュが古い — `nx dev` を再起動します |
