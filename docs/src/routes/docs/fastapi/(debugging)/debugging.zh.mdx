# 调试

Nexy 应用程序是标准 Python - 使用常用的调试工具。

## `breakpoint()`

在路由处理程序中的任意位置插入 `breakpoint()`：

```python
def GET():
    x = 42
    breakpoint()  # drops into pdb
    return {"x": x}
```

运行 `nx dev` 并命中路线 — 终点站落入 `pdb`。

## VS 代码

1. 通过单击边线在 VS Code 中设置断点
2. 创建`.vscode/launch.json`：

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Nexy Dev",
            "type": "debugpy",
            "request": "launch",
            "module": "nexy.cli",
            "args": ["dev"],
            "jinja": true
        }
    ]
}
```

3. 按 `F5` 开始调试 — 断点在 `.nexy` frontmatter 和 `.py` 文件中工作。

## 打印调试

```python
---
print(f"Request params: {params}")  # appears in the terminal
---
```

## 控制台日志记录

Nexy 默认将所有请求记录到终端。添加您自己的日志：

```python
import logging
logger = logging.getLogger("nexy")

def GET():
    logger.info("Home page loaded")
    return {"ok": True}
```

## uvicorn 重新加载

`nx dev` 使用 `--reload` 运行 uvicorn — 对 `.py`、`.nexy`、`.mdx` 文件的更改会触发自动重新启动。

## 常见问题

|症状|可能的原因 |
|---------|-------------|
|路线返回 405 | HTTP 方法错误或缺少 `python-multipart` |
|身体是`None` |缺少 Pydantic 模型或类型注释 |
| 422 验证错误 |路径/查询参数中的类型不匹配 |
|找不到模块 | VFS 缓存过时 — 重新启动 `nx dev` |
