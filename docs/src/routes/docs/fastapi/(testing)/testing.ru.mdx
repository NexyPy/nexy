# Тестирование

Приложения Nexy — это приложения FastAPI — протестируйте их с помощью `TestClient` от Starlette.

```bash
pip install httpx pytest-anyio  # httpx for TestClient, anyio for async tests
```

## Тестовая установка

```python
# tests/test_app.py
from fastapi.testclient import TestClient
from nexy.app import app

client = TestClient(app)

def test_home():
    response = client.get("/")
    assert response.status_code == 200
    assert response.json() == {"Hello": "World"}
```

## Тестовые маршруты

```python
def test_create_user():
    response = client.post("/users", json={"name": "Alice", "email": "a"@b.com"})
    assert response.status_code == 201
    data = response.json()
    assert data["name"] == "Alice"
```

## Тестирование с авторизацией

```python
def test_protected_route():
    response = client.get("/admin", headers={"Authorization": "Bearer test-token"})
    assert response.status_code == 200
```

## Фикстуры с pytest

```python
# conftest.py
import pytest
from fastapi.testclient import TestClient
from nexy.app import app

"@pytest.fixture
def client():
    return TestClient(app)

# test_users.py
def test_list_users(client):
    resp = client.get("/users")
    assert resp.status_code == 200
```

## Тестирование WebSocket

```python
def test_ws():
    with client.websocket_connect("/ws") as ws:
        ws.send_json({"type": "ping"})
        data = ws.receive_json()
        assert data["type"] == "pong"
```

## Асинхронные тесты

```python
import pytest

"@pytest.mark.anyio
async def test_async_route():
    async with AsyncClient(app=app, base_url="http://test") as ac:
        response = await ac.get("/")
        assert response.status_code == 200
```

## Советы

- Используйте `TestClient` в качестве менеджера контекста, если в вашем приложении есть события жизненного цикла.
- Имитируйте внешние сервисы с помощью `httpx.MockTransport` или `responses`.
- Запустите тесты с помощью `pytest tests/ -v` (специальная команда Nexy не требуется)
- TestClient использует `httpx` внутри — тот же API, что и `requests`.
