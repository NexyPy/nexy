# ライフスパンイベント

アプリの提供を開始する前、またはアプリのシャットダウン時にコードを実行します。

## `nexy.app` を使用する

```python
# In any file loaded at startup (e.g., nexyconfig.py, src/events.py)
from nexy import app

"@app.on_event("startup")
async def startup():
    print("App starting...")
    await db.connect()

"@app.on_event("shutdown")
async def shutdown():
    print("App shutting down...")
    await db.disconnect()
```

## コンテキスト マネージャーの有効期間 (FastAPI 3.0 以降)

```python
from contextlib import asynccontextmanager
from nexy import app

"@asynccontextmanager
async def lifespan():
    print("Startup")
    await db.connect()
    yield
    print("Shutdown")
    await db.disconnect()

app.router.lifespan_context = lifespan
```

## ライフスパン イベントを使用する場合

|使用例 |イベント |
|----------|----------|
|データベース接続プール | `startup` |
|キャッシュのウォーミング | `startup` |
| ML モデルをロードする | `startup` |
|接続を閉じる | `shutdown` |
|キューをフラッシュする | `shutdown` |

## 複数のイベント ハンドラー

```python
"@app.on_event("startup")
async def first():
    ...

"@app.on_event("startup")
async def second():
    ...
```

## 注意

- ライフスパン イベントはリクエストごとではなく**、アプリの開始/停止時に 1 回実行されます。
- 開発中 (`nx dev`)、リロードのたびにイベントが実行されます
- 本番環境には `nx start` を使用します — イベントは起動時に 1 回実行されます
