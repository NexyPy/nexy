# 수명 이벤트

앱이 서비스를 시작하기 전이나 종료될 때 코드를 실행합니다.

## `nexy.app` 사용

```python
# In any file loaded at startup (e.g., nexyconfig.py, src/events.py)
from nexy import app

"@app.on_event("startup")
async def startup():
    print("App starting...")
    await db.connect()

"@app.on_event("shutdown")
async def shutdown():
    print("App shutting down...")
    await db.disconnect()
```

## 컨텍스트 관리자 수명(FastAPI 3.0+)

```python
from contextlib import asynccontextmanager
from nexy import app

"@asynccontextmanager
async def lifespan():
    print("Startup")
    await db.connect()
    yield
    print("Shutdown")
    await db.disconnect()

app.router.lifespan_context = lifespan
```

## 수명 이벤트를 사용해야 하는 경우

| 사용 사례 | 이벤트 |
|----------|-------|
| 데이터베이스 연결 풀 | `startup` |
| 캐시 워밍업 | `startup` |
| ML 모델 로드 | `startup` |
| 연결 닫기 | `shutdown` |
| 대기열 플러시 | `shutdown` |

## 다중 이벤트 핸들러

```python
"@app.on_event("startup")
async def first():
    ...

"@app.on_event("startup")
async def second():
    ...
```

## 참고

- 수명 이벤트는 요청별로 **아님** — 앱 시작/중지 시 한 번 실행됩니다.
- 개발 중(`nx dev`)에서는 다시 로드할 때마다 이벤트가 실행됩니다.
- 프로덕션에 `nx start` 사용 — 이벤트는 출시 시 한 번 실행됩니다.
