# Eventos ao longo da vida

Execute o código antes que o aplicativo comece a ser veiculado ou quando ele for encerrado.

## Usando `nexy.app`

```python
# In any file loaded at startup (e.g., nexyconfig.py, src/events.py)
from nexy import app

"@app.on_event("startup")
async def startup():
    print("App starting...")
    await db.connect()

"@app.on_event("shutdown")
async def shutdown():
    print("App shutting down...")
    await db.disconnect()
```

## Vida útil do gerenciador de contexto (FastAPI 3.0+)

```python
from contextlib import asynccontextmanager
from nexy import app

"@asynccontextmanager
async def lifespan():
    print("Startup")
    await db.connect()
    yield
    print("Shutdown")
    await db.disconnect()

app.router.lifespan_context = lifespan
```

## Quando usar eventos de ciclo de vida

| Caso de uso | Evento |
|----------|-------|
| Conjunto de conexões de banco de dados | `startup` |
| Aquecimento de cache | `startup` |
| Carregar modelos de ML | `startup` |
| Fechar conexões | `shutdown` |
| Liberar filas | `shutdown` |

## Vários manipuladores de eventos

```python
"@app.on_event("startup")
async def first():
    ...

"@app.on_event("startup")
async def second():
    ...
```

## Nota

- Os eventos de vida útil **não** são realizados por solicitação: eles são executados uma vez na inicialização/parada do aplicativo
- Em desenvolvimento (`nx dev`), eventos são executados a cada recarga
- Use `nx start` para produção — os eventos são executados uma vez no lançamento
