# События продолжительности жизни

Запускайте код до того, как приложение начнет работать или когда оно закроется.

## Использование `nexy.app`

```python
# In any file loaded at startup (e.g., nexyconfig.py, src/events.py)
from nexy import app

"@app.on_event("startup")
async def startup():
    print("App starting...")
    await db.connect()

"@app.on_event("shutdown")
async def shutdown():
    print("App shutting down...")
    await db.disconnect()
```

## Срок службы контекстного менеджера (FastAPI 3.0+)

```python
from contextlib import asynccontextmanager
from nexy import app

"@asynccontextmanager
async def lifespan():
    print("Startup")
    await db.connect()
    yield
    print("Shutdown")
    await db.disconnect()

app.router.lifespan_context = lifespan
```

## Когда использовать события продолжительности жизни

| Вариант использования | Событие |
|----------|-------|
| Пул соединений с базой данных | `startup` |
| Потепление кэша | `startup` |
| Загрузить модели машинного обучения | `startup` |
| Тесные связи | `shutdown` |
| Очистить очереди | `shutdown` |

## Несколько обработчиков событий

```python
"@app.on_event("startup")
async def first():
    ...

"@app.on_event("startup")
async def second():
    ...
```

## Примечание

– События продолжительности жизни **не** выполняются по каждому запросу — они запускаются один раз при запуске/остановке приложения.
- В разработке (`nx dev`) события запускаются при каждой перезагрузке.
- Используйте `nx start` для производства — события запускаются один раз при запуске.
