# أحداث العمر

قم بتشغيل التعليمات البرمجية قبل أن يبدأ التطبيق في العرض أو عند إيقاف تشغيله.

## استخدام `nexy.app`

```python
# In any file loaded at startup (e.g., nexyconfig.py, src/events.py)
from nexy import app

"@app.on_event("startup")
async def startup():
    print("App starting...")
    await db.connect()

"@app.on_event("shutdown")
async def shutdown():
    print("App shutting down...")
    await db.disconnect()
```

## عمر مدير السياق (FastAPI 3.0+)

```python
from contextlib import asynccontextmanager
from nexy import app

"@asynccontextmanager
async def lifespan():
    print("Startup")
    await db.connect()
    yield
    print("Shutdown")
    await db.disconnect()

app.router.lifespan_context = lifespan
```

## متى تستخدم أحداث العمر

| حالة الاستخدام | الحدث |
|----------|-------|
| تجمع اتصال قاعدة البيانات | `startup` |
| تسخين ذاكرة التخزين المؤقت | `startup` |
| تحميل نماذج ML | `startup` |
| اتصالات وثيقة | `shutdown` |
| طوابير دافق | `shutdown` |

## معالجات أحداث متعددة

```python
"@app.on_event("startup")
async def first():
    ...

"@app.on_event("startup")
async def second():
    ...
```

## ملاحظة

- أحداث العمر ** ليست ** لكل طلب — فهي تعمل مرة واحدة عند بدء/إيقاف التطبيق
- في مرحلة التطوير (`nx dev`)، يتم تشغيل الأحداث عند كل عملية إعادة تحميل
- استخدم `nx start` للإنتاج — يتم تشغيل الأحداث مرة واحدة عند الإطلاق
