# Interface utilisateur de Docs personnalisée

Nexy utilise Swagger UI et ReDoc par défaut. Personnalisez-les ou auto-hébergez-les.

## Configurer l'interface utilisateur de Swagger

```python
from nexy import app

app.swagger_ui_parameters = {
    "docExpansion": "none",        # collapse all sections
    "defaultModelsExpandDepth": -1, # hide schemas section
    "tryItOutEnabled": True,
}
```

## Interface utilisateur Swagger auto-hébergée

```python
from nexy import app
from fastapi.openapi.docs import (
    get_swagger_ui_html,
    get_swagger_ui_oauth2_redirect_html,
)

"@app.get("/docs", include_in_schema=False)
async def custom_swagger_ui():
    return get_swagger_ui_html(
        openapi_url=app.openapi_url,
        title="My API",
        swagger_js_url="/static/swagger-ui-bundle.js",
        swagger_css_url="/static/swagger-ui.css",
    )
```

## OpenAPI conditionnelle

Désactivez OpenAPI en production :

```python
import os

"@app.get("/openapi.json", include_in_schema=False)
async def openapi():
    if os.getenv("ENV") == "production":
        return {"openapi": "3.1.0", "info": {"title": "My API", "version": "1.0.0"}}
```

## Contrôler les URL des documents

Configurez les points de terminaison des documents dans [nexyconfig.py](/docs/config/nexy) — voir les champs `useDocs`, `useDocsUrl`, `useRedocsUrl`.
