# Behind a Proxy

When running behind Nginx, Caddy, Cloudflare, or a load balancer, configure Nexy to trust forwarded headers.

## Forwarded headers

```python
# nexyconfig.py
from nexy.core.models import NexyConfigModel

class NexyConfig(NexyConfigModel):
    useTrustedHost = {
        "allowed_hosts": ["*"],
    }
```

## Uvicorn

When running with `nx start` or directly with uvicorn, pass the `--proxy-headers` flag:

```bash
nx start --proxy-headers

# or
uvicorn nexy.app:app --proxy-headers --forwarded-allow-ips="*"
```

## Root path

If your app is mounted at a sub-path (e.g., `https://example.com/myapp/`):

```python
# nexyconfig.py
from nexy import app

app.root_path = "/myapp"
```

## Nginx example

```nginx
server {
    listen 80;
    server_name example.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## Effects

When configured correctly:
- `request.url` reflects the original URL, not the internal one
- Redirects use the correct scheme (https)
- Rate limiting and client IP detection use the real client IP
- OpenAPI docs URLs are generated correctly
