# Anforderungstext

Empfangen Sie JSON-Anfragetexte mithilfe von Pydantic-Modellen.

---

## Grundmodell
```python
---
from pydantic import BaseModel

class Item(BaseModel):
    name: str
    price: float
    is_offer: bool | None = None

def POST(item: Item):
    return {"name": item.name, "price": item.price}
---
```
```python
from pydantic import BaseModel
from nexy.decorators import Controller

class Item(BaseModel):
    name: str
    price: float
    is_offer: bool | None = None

"@Controller("/items")
class ItemsController:
    def post(self, item: Item):
        return {"name": item.name, "price": item.price}
```
## Body-Feld mit `embed`

Überschreiben Sie den Feldnamen oder fügen Sie zusätzliche JSON-Felder ein:
```python
---
from fastapi import Body
from pydantic import BaseModel

class Item(BaseModel):
    name: str
    price: float

def POST(
    item: Item,
    important: str = Body(embed=True),
):
    # Expects: {"item": {...}, "important": "x"}
    ...
---
```
```python
from fastapi import Body
from pydantic import BaseModel
from nexy.decorators import Controller

class Item(BaseModel):
    name: str
    price: float

"@Controller("/items")
class ItemsController:
    def post(self, item: Item, important: str = Body(embed=True)):
        # Expects: {"item": {...}, "important": "x"}
        ...
```
## Mehrere Körperparameter

Übergeben Sie mehrere Modelle – FastAPI verschachtelt sie unter ihren Parameternamen:
```python
---
def POST(item: Item, user: User):
    # Expects: {"item": {...}, "user": {...}}
    ...
---
```
```python
"@Controller("/orders")
class OrderController:
    def post(self, item: Item, user: User):
        # Expects: {"item": {...}, "user": {...}}
        ...
```
## Verschachtelte Modelle

Modelle können andere Modelle, Listen und optionale Felder enthalten:
```python
from pydantic import BaseModel

class Image(BaseModel):
    url: str
    alt: str | None = None

class Item(BaseModel):
    name: str
    tags: list[str] = []
    image: Image | None = None
```
Router-agnostisch – die gleichen Pydantic-Modelle funktionieren sowohl in FBR als auch in Modular.

## Einschränkungen

- Der Körper wird automatisch analysiert, wenn Sie einen Pydantic-Modellparameter mit Anmerkungen versehen
- FastAPI übernimmt die Validierung und gibt bei ungültiger Eingabe 422 zurück
- Kein `"@Body()` Dekorator erforderlich – Standard-FastAPI-Verhalten
