# リクエストボディ

Pydantic モデルを使用して JSON リクエスト本文を受信します。

---

## 基本モデル
```python
---
from pydantic import BaseModel

class Item(BaseModel):
    name: str
    price: float
    is_offer: bool | None = None

def POST(item: Item):
    return {"name": item.name, "price": item.price}
---
```
```python
from pydantic import BaseModel
from nexy.decorators import Controller

class Item(BaseModel):
    name: str
    price: float
    is_offer: bool | None = None

"@Controller("/items")
class ItemsController:
    def post(self, item: Item):
        return {"name": item.name, "price": item.price}
```
## `embed` の本文フィールド

フィールド名をオーバーライドするか、追加の JSON フィールドを挿入します。
```python
---
from fastapi import Body
from pydantic import BaseModel

class Item(BaseModel):
    name: str
    price: float

def POST(
    item: Item,
    important: str = Body(embed=True),
):
    # Expects: {"item": {...}, "important": "x"}
    ...
---
```
```python
from fastapi import Body
from pydantic import BaseModel
from nexy.decorators import Controller

class Item(BaseModel):
    name: str
    price: float

"@Controller("/items")
class ItemsController:
    def post(self, item: Item, important: str = Body(embed=True)):
        # Expects: {"item": {...}, "important": "x"}
        ...
```
## 複数のボディパラメータ

いくつかのモデルを渡します — FastAPI はそれらをパラメーター名の下にネストします。
```python
---
def POST(item: Item, user: User):
    # Expects: {"item": {...}, "user": {...}}
    ...
---
```
```python
"@Controller("/orders")
class OrderController:
    def post(self, item: Item, user: User):
        # Expects: {"item": {...}, "user": {...}}
        ...
```
## ネストされたモデル

モデルには、他のモデル、リスト、およびオプションのフィールドを含めることができます。
```python
from pydantic import BaseModel

class Image(BaseModel):
    url: str
    alt: str | None = None

class Item(BaseModel):
    name: str
    tags: list[str] = []
    image: Image | None = None
```
ルーターに依存しない — 同じ Pydantic モデルが FBR とモジュラーの両方で動作します。

## 制限事項

- Pydantic モデルパラメータに型アノテーションを付けると、本文が自動的に解析されます
- FastAPI は検証を処理し、無効な入力に対して 422 を返します。
- `"@Body()` デコレータは不要 - 標準の FastAPI 動作
