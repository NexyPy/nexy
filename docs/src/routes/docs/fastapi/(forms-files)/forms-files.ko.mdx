# 양식 및 파일

양식 데이터 및 파일 업로드를 수신합니다. 먼저 `python-multipart`를 설치하세요.

```bash
pip install python-multipart
```

## 양식 데이터

```python
from fastapi import Form

def POST(username: str = Form(), password: str = Form()):
    return {"username": username}
```

### 양식 모델

```python
from pydantic import BaseModel
from fastapi import Form, Depends

class LoginForm(BaseModel):
    username: str
    password: str

    "@classmethod
    def as_form(cls, username: str = Form(), password: str = Form()):
        return cls(username=username, password=password)

def POST(form: LoginForm = Depends(LoginForm.as_form)):
    ...
```

## 파일 업로드

```python
from fastapi import File, UploadFile

def POST(file: UploadFile = File()):
    contents = file.file.read()
    return {"filename": file.filename, "size": len(contents)}
```

### 여러 파일

```python
def POST(files: list[UploadFile] = File()):
    return [f.filename for f in files]
```

## 양식 + 파일 함께

```python
def POST(
    file: UploadFile = File(),
    description: str = Form(),
):
    return {"file": file.filename, "description": description}
```

## 제한사항

- `python-multipart`는 기본적으로 포함되지 **않습니다** — 명시적으로 설치합니다.
- FBR 핸들러는 동일하게 작동합니다. - 동일한 가져오기, 동일한 주석
- 파일 크기는 서버에 의해 제한됩니다. (Uvicorn/Gunicorn 구성에서는 기본값)
