# 응답(모듈식)

컨트롤러의 응답 직렬화, 상태 코드 및 응답 유형을 제어합니다.

## Pydantic 응답 모델

```python
from nexy.decorators import Controller
from pydantic import BaseModel

class UserOut(BaseModel):
    id: int
    name: str
    email: str

"@Controller("/users")
class UsersController:
    def GET(self) -> list[UserOut]:
        return [UserOut(id=1, name="Alice", email="alice"@example.com")]
```

## 목록 응답

```python
"@Controller("/users")
class UsersController:
    def GET(self) -> list[UserOut]:
        return [UserOut(id=1, name="Alice")]
```

## HTML응답

```python
from fastapi.responses import HTMLResponse
from nexy.decorators import Controller

"@Controller("/page")
class PageController:
    def GET(self) -> HTMLResponse:
        return HTMLResponse("<h1>Hello</h1>")
```

## 스트리밍응답

```python
from fastapi.responses import StreamingResponse
from nexy.decorators import Controller
import io

"@Controller("/export")
class ExportController:
    def GET(self) -> StreamingResponse:
        return StreamingResponse(io.StringIO("data..."), media_type="text/csv")
```

## 사용자 정의 상태를 통한 직접 응답

```python
from fastapi.responses import JSONResponse
from nexy.decorators import Controller, UseResponse

"@Controller("/items")
class ItemsController:
    "@UseResponse(status_code=201)
    def post(self, item: Item):
        return {"created": True}
```

## 지원되는 응답 유형

| 수업 | 콘텐츠 유형 | 사용 사례 |
|-------|-------------|---------|
| `JSONResponse` | `application/json` | JSON 데이터(기본값) |
| `HTMLResponse` | `text/html` | HTML 문자열 |
| `PlainTextResponse` | `text/plain` | 원시 텍스트 |
| `RedirectResponse` | — | 리디렉션 |
| `StreamingResponse` | 다양하다 | 데이터 스트리밍 |
| `FileResponse` | 다양하다 | 파일 다운로드 |

상태 코드 옵션은 ["@UseResponse](/docs/decorators/useresponse)를 참조하세요.
