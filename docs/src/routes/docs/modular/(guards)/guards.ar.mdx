#حراس

يحدد الحراس ما إذا كان يجب أن يصل الطلب إلى معالج المسار أم لا. يتم تنفيذها **قبل طريقة التحكم** — وهي مثالية للمصادقة والترخيص وتحديد المعدل والتحكم في الوصول.

حراس Nexy هم **تبعيات FastAPI**. إنها قابلة للاستدعاء (فئات ذات `__call__` أو وظائف مستقلة) تتلقى الطلب وتقوم إما بتمرير أو رفع HTTPException.

## لماذا الحرس؟

بدون حراس، يمكنك التحقق من المصادقة في كل طريقة تحكم:

```python
class AdminController:
    def GET(self):
        if not is_authenticated(request):
            raise HTTPException(401)
        return {"role": "admin"}

    def delete(self, id: int):
        if not is_authenticated(request):
            raise HTTPException(401)
        return None
```

يستخرج الحارس هذا إلى قابل للاستدعاء قابل لإعادة الاستخدام:

```python
class AuthGuard:
    async def __call__(self, request: Request):
        token = request.headers.get("Authorization")
        if not token:
            raise HTTPException(401)
```

يتم تطبيقه مرة واحدة، ويحمي كل مسار في وحدة التحكم:

```python
"@Controller("/admin")
"@UseGuard(AuthGuard())
class AdminController:
    def GET(self):
        return {"role": "admin"}
```

## إنشاء الحرس

الحارس هو أمر قابل للاستدعاء ويأخذ `Request` ويعيد `None` أو يرفع:

```python
from starlette.exceptions import HTTPException
from starlette.requests import Request

class AuthGuard:
    async def __call__(self, request: Request):
        token = request.headers.get("Authorization")
        if not token or not token.startswith("Bearer "):
            raise HTTPException(401, "Missing or invalid token")
```

يقوم الحارس برفع `HTTPException` لمنع الطلب. إذا عاد بشكل طبيعي، يستمر الطلب.

**مسكتك**: يمكن أن يكون `__call__` متزامنًا أو غير متزامن — حيث يتعامل جهاز التوجيه مع كليهما. استخدم المزامنة عندما يحتاج حارسك إلى الاتصال بقاعدة بيانات أو واجهة برمجة تطبيقات خارجية.

## تطبيق الحراس

### مستوى وحدة التحكم — يحمي جميع المسارات

```python
from nexy.decorators import Controller, UseGuard

"@Controller("/admin")
"@UseGuard(AuthGuard())
class AdminController:
    def GET(self):
        return {"role": "admin"}

    def delete(self, id: int):
        return None
```

### مستوى الطريقة — يحمي مسارات محددة

```python
"@Controller("/users")
class UsersController:
    "@UseGuard(AuthGuard())
    def GET(self):
        return {"email": "user"@example.com"}

    # No guard on public routes
    def post(self, data: dict):
        return {"message": "No auth required"}
```

### حراس متعددون – يجب أن يمروا جميعًا

```python
"@Controller("/admin")
"@UseGuard(AuthGuard(), RateLimitGuard())
class AdminController:
    ...
```

يقوم الحراس بتنفيذ الأمر بالترتيب المذكور في القائمة. إذا تم رفع `AuthGuard`، فلن يتم تشغيل `RateLimitGuard` أبدًا.

**مسكتك**: يتم تشغيل الحراس على مستوى الطريقة بعد الحراس على مستوى وحدة التحكم - وفقط في حالة مرور الحراس على مستوى وحدة التحكم.

## الحراس مع المعلمات

إنشاء مصنع حراسة للحراس ذوي المعلمات:

```python
class RoleGuard:
    def __init__(self, required_role: str):
        self.required_role = required_role

    async def __call__(self, request: Request):
        user_role = request.headers.get("X-Role", "guest")
        if user_role != self.required_role:
            raise HTTPException(403, f"Requires {self.required_role} role")
```

تنطبق مع الحجج:

```python
"@Controller("/admin")
"@UseGuard(RoleGuard("admin"))
class AdminController:
    def GET(self):
        return {"role": "admin"}
```

## الحراس كوظائف

يمكن أن تكون الحراسة البسيطة وظائف مستقلة:

```python
async def rate_limit(request: Request):
    client_ip = request.client.host if request.client else "unknown"
    if is_rate_limited(client_ip):
        raise HTTPException(429, "Too many requests")

"@Controller("/api")
"@UseGuard(rate_limit)
class ApiController:
    def GET(self):
        return {"data": [...]}
```

## سياق الحراسة

يتلقى الحراس كائن Starlette `Request` الكامل، مما يتيح الوصول إلى الرؤوس ومعلمات الاستعلام والجلسة والمزيد.

قم بتعيين حالة الطلب في حارس للاستخدام النهائي:

```python
class AuthGuard:
    async def __call__(self, request: Request):
        token = request.headers.get("Authorization", "").removeprefix("Bearer ")
        user = await verify_token(token)
        if not user:
            raise HTTPException(401)
        request.state.user = user

# In the controller:
class UsersController:
    def GET(self, request: Request):
        return {"user": request.state.user}
```

## الحرس مقابل البرمجيات الوسيطة

| الجانب | الحرس | الوسيطة |
|--------|-------|------------|
| ينفذ | قبل المعالج، بعد الوسيطة | قبل الحراس والمعالج |
| الغرض | المصادقة والترخيص والتحكم في الوصول | التسجيل، معالجة الرأس، CORS |
| العودة | `None` أو رفع `HTTPException` | `None` أو رفع `HTTPException` |
| طلب الوصول | كامل عبر المعلمة `Request` | كامل عبر المعلمة `Request` |

**متى يتم اختيار برنامج حماية مقابل برنامج وسيط**: إذا كان المنطق يحدد "هل يجب متابعة هذا الطلب؟" (المصادقة، التحقق من الدور، حد المعدل)، استخدم حارسًا. إذا كان المنطق يعدل الطلب/الاستجابة بغض النظر عن (التسجيل، CORS)، فاستخدم البرامج الوسيطة.

## أفضل الممارسات

1. **حارس واحد لكل اهتمام** — `AuthGuard`، `RoleGuard`، `RateLimitGuard`. ليس `SecurityGuard` الذي يفعل كل شيء.
2. **استخدم رموز الحالة الوصفية** — 401 للمصادقة المفقودة/غير الصالحة، 403 للأذونات غير الكافية، 429 لتحديد المعدل.
3. **تجنب الآثار الجانبية** — يجب على الحراس التحقق من الأذونات، وليس تعديل الحالة (باستثناء `request.state`).
4. **فحوصات باهظة الثمن لذاكرة التخزين المؤقت** — مثيلات حماية مفردة تحتوي على ذاكرة تخزين مؤقت في الذاكرة.
5. **اختبر الحراس بشكل معزول** — أنشئ نموذجًا وهميًا `Request`، واستدعاء الحارس، وأكد أنه يرفع أو يمرر.
