# 경비원

가드는 요청이 경로 처리기에 도달해야 하는지 여부를 결정합니다. **컨트롤러 메서드 이전에** 실행되므로 인증, 권한 부여, 속도 제한 및 액세스 제어에 적합합니다.

Nexy의 가드는 **FastAPI 종속성**입니다. 요청을 수신하고 HTTPException을 전달하거나 발생시키는 콜러블(`__call__` 또는 독립 실행형 함수가 있는 클래스)입니다.

## 왜 경비원인가?

가드가 없으면 모든 컨트롤러 메서드에서 인증을 확인해야 합니다.

```python
class AdminController:
    def GET(self):
        if not is_authenticated(request):
            raise HTTPException(401)
        return {"role": "admin"}

    def delete(self, id: int):
        if not is_authenticated(request):
            raise HTTPException(401)
        return None
```

경비원은 이것을 재사용 가능한 호출 가능 항목으로 추출합니다.

```python
class AuthGuard:
    async def __call__(self, request: Request):
        token = request.headers.get("Authorization")
        if not token:
            raise HTTPException(401)
```

한 번 적용하면 컨트롤러의 모든 경로를 보호합니다.

```python
"@Controller("/admin")
"@UseGuard(AuthGuard())
class AdminController:
    def GET(self):
        return {"role": "admin"}
```

## 가드 생성

가드는 `Request`를 취하고 `None`를 반환하거나 다음을 발생시키는 콜러블입니다.

```python
from starlette.exceptions import HTTPException
from starlette.requests import Request

class AuthGuard:
    async def __call__(self, request: Request):
        token = request.headers.get("Authorization")
        if not token or not token.startswith("Bearer "):
            raise HTTPException(401, "Missing or invalid token")
```

경비원은 요청을 차단하기 위해 `HTTPException`를 발생시킵니다. 정상적으로 반환되면 요청이 진행됩니다.

**알겠습니다**: `__call__`는 동기식 또는 비동기식일 수 있습니다. 라우터가 두 가지를 모두 처리합니다. 경비원이 데이터베이스나 외부 API를 호출해야 하는 경우 비동기를 사용하세요.

## 가드 적용

### 컨트롤러 수준 — 모든 경로 보호

```python
from nexy.decorators import Controller, UseGuard

"@Controller("/admin")
"@UseGuard(AuthGuard())
class AdminController:
    def GET(self):
        return {"role": "admin"}

    def delete(self, id: int):
        return None
```

### 메소드 수준 - 특정 경로를 보호합니다.

```python
"@Controller("/users")
class UsersController:
    "@UseGuard(AuthGuard())
    def GET(self):
        return {"email": "user"@example.com"}

    # No guard on public routes
    def post(self, data: dict):
        return {"message": "No auth required"}
```

### 여러 명의 경비원 — 모두 통과해야 함

```python
"@Controller("/admin")
"@UseGuard(AuthGuard(), RateLimitGuard())
class AdminController:
    ...
```

경비원은 나열된 순서대로 실행됩니다. `AuthGuard`가 상승하면 `RateLimitGuard`는 절대 실행되지 않습니다.

**알겠습니다**: 메소드 수준 가드는 컨트롤러 수준 가드 이후에 실행되며 컨트롤러 수준 가드가 통과한 경우에만 실행됩니다.

## 매개변수가 있는 가드

매개변수화된 가드에 대한 가드 팩토리를 만듭니다.

```python
class RoleGuard:
    def __init__(self, required_role: str):
        self.required_role = required_role

    async def __call__(self, request: Request):
        user_role = request.headers.get("X-Role", "guest")
        if user_role != self.required_role:
            raise HTTPException(403, f"Requires {self.required_role} role")
```

인수를 사용하여 적용:

```python
"@Controller("/admin")
"@UseGuard(RoleGuard("admin"))
class AdminController:
    def GET(self):
        return {"role": "admin"}
```

## 기능으로서의 가드

단순 가드는 독립형 기능일 수 있습니다.

```python
async def rate_limit(request: Request):
    client_ip = request.client.host if request.client else "unknown"
    if is_rate_limited(client_ip):
        raise HTTPException(429, "Too many requests")

"@Controller("/api")
"@UseGuard(rate_limit)
class ApiController:
    def GET(self):
        return {"data": [...]}
```

## 가드 컨텍스트

경비원은 전체 Starlette `Request` 개체를 수신하여 헤더, 쿼리 매개변수, 세션 등에 대한 액세스를 제공합니다.

다운스트림 사용을 위해 가드에서 요청 상태를 설정합니다.

```python
class AuthGuard:
    async def __call__(self, request: Request):
        token = request.headers.get("Authorization", "").removeprefix("Bearer ")
        user = await verify_token(token)
        if not user:
            raise HTTPException(401)
        request.state.user = user

# In the controller:
class UsersController:
    def GET(self, request: Request):
        return {"user": request.state.user}
```

## 가드 대 미들웨어

| 측면 | 가드 | 미들웨어 |
|---------|---------|------------|
| 실행 | 핸들러 전, 미들웨어 후 | 경비원 및 핸들러 전 |
| 목적 | 인증, 권한 부여, 접근 제어 | 로깅, 헤더 조작, CORS |
| 반품 | `None` 또는 `HTTPException` 인상 | `None` 또는 `HTTPException` 인상 |
| 액세스 요청 | `Request` 매개변수를 통해 전체 | `Request` 매개변수를 통해 전체 |

**가드와 미들웨어를 선택하는 경우**: 로직이 "이 요청을 계속 진행해야 할까요?"를 결정하는 경우 (인증, 역할 확인, 속도 제한) 가드를 사용하세요. 로직이 (로깅, CORS) 관계없이 요청/응답을 수정하는 경우 미들웨어를 사용하세요.

## 모범 사례

1. **문제당 하나의 경비원** — `AuthGuard`, `RoleGuard`, `RateLimitGuard`. 모든 일을 하는 `SecurityGuard`는 아닙니다.
2. **설명이 포함된 상태 코드 사용** — 인증 누락/잘못의 경우 401, 권한 부족의 경우 403, 속도 제한의 경우 429입니다.
3. **부작용 방지** — 경비원은 상태를 수정하지 말고 권한을 확인해야 합니다(`request.state` 제외).
4. **캐시 비용이 많이 드는 검사** — 메모리 내 캐시가 있는 싱글톤 가드 인스턴스입니다.
5. **격리된 가드 테스트** — 모의 `Request`를 생성하고 가드를 호출하고 레이즈 또는 패스를 선언합니다.
