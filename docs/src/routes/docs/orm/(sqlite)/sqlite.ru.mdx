# SQLite

SQLite — это база данных по умолчанию для разработки Nexy — нулевая конфигурация, файловая база данных, идеальная для прототипирования.

## Соединение

По умолчанию: `sqlite:///dev.db`

```python
DATABASE_URL = "sqlite:///dev.db"
```

## С ORM

| ОРМ | Водитель | Строка подключения |
|-----|--------|------------------|
| SQLМодель/SQLАлхимия | `aiosqlite` | `sqlite+aiosqlite:///dev.db` |
| Черепаха-ОРМ | `aiosqlite` | `sqlite://dev.db` |

## Ограничения

- Нет одновременной записи (не подходит для производства с высоким трафиком)
- Нет управления пользователями или разрешений
- Ограничено одним файлом

SQLite отлично подходит для разработки и небольших проектов. Переключитесь на PostgreSQL для работы.
