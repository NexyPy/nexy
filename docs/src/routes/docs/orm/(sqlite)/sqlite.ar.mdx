# سكليتي

SQLite هي قاعدة البيانات الافتراضية لتطوير Nexy - تكوين صفري، قائم على الملفات، مثالي للنماذج الأولية.

## اتصال

الافتراضي: `sqlite:///dev.db`

```python
DATABASE_URL = "sqlite:///dev.db"
```

## مع ORMs

| أو آر إم | سائق | سلسلة الاتصال |
|-----|--------|------------------|
| SQLModel / SQLAlchemy | `aiosqlite` | `sqlite+aiosqlite:///dev.db` |
| السلحفاة-ORM | `aiosqlite` | `sqlite://dev.db` |

## القيود

- لا توجد عمليات كتابة متزامنة (غير مناسبة للإنتاج عالي الحركة)
- لا توجد إدارة المستخدم أو الأذونات
- يقتصر على ملف واحد

يعد SQLite رائعًا للتطوير والمشاريع الصغيرة. قم بالتبديل إلى PostgreSQL للإنتاج.
