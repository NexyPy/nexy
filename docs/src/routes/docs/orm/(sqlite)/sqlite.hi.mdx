# SQLite

नेक्सी विकास के लिए SQLite डिफ़ॉल्ट डेटाबेस है - शून्य कॉन्फ़िगरेशन, फ़ाइल-आधारित, प्रोटोटाइप के लिए बिल्कुल सही।

## कनेक्शन

डिफ़ॉल्ट: `sqlite:///dev.db`

```python
DATABASE_URL = "sqlite:///dev.db"
```

## ओआरएम के साथ

| ओआरएम | ड्राइवर | कनेक्शन स्ट्रिंग |
|----|--------|------------------|
| SQLModel / SQLAlchemy | `aiosqlite` | `sqlite+aiosqlite:///dev.db` |
| कछुआ-ओआरएम | `aiosqlite` | `sqlite://dev.db` |

## सीमाएँ

- कोई समवर्ती लेखन नहीं (उच्च-यातायात उत्पादन के लिए उपयुक्त नहीं)
- कोई उपयोगकर्ता प्रबंधन या अनुमति नहीं
- एक फ़ाइल तक सीमित

SQLite विकास और छोटी परियोजनाओं के लिए बहुत अच्छा है। उत्पादन के लिए PostgreSQL पर स्विच करें।
