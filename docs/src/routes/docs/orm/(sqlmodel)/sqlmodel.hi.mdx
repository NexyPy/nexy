# SQLमॉडल

SQLModel नई Nexy परियोजनाओं के लिए अनुशंसित ORM है - Pydantic मॉडल डेटाबेस मॉडल के रूप में दोगुने हैं।

---

## स्थापित करना

```bash
uv add sqlmodel
```

```python
from sqlmodel import create_engine, Session

DATABASE_URL = "sqlite:///dev.db"
engine = create_engine(DATABASE_URL)
```

---

## मॉडल

```python
from sqlmodel import SQLModel, Field

class User(SQLModel, table=True):
    id: int = Field(default=None, primary_key=True)
    name: str
    email: str

class Hero(SQLModel, table=True):
    id: int | None = Field(default=None, primary_key=True)
    name: str
    secret_name: str
    age: int | None = None
```

---

## मार्गों में उपयोग

```python
# src/routes/users.py
from fastapi import Depends
from sqlmodel import Session, select
from src.models import User
from src.database import engine

def get_session():
    with Session(engine) as session:
        yield session

def GET(db=Depends(get_session)):
    users = db.exec(select(User)).all()
    return users

def POST(user: User, db=Depends(get_session)):
    db.add(user)
    db.commit()
    db.refresh(user)
    return user
```

## प्रवास

एलेम्बिक का उपयोग करें (मैन्युअल रूप से या `nx migrate` के माध्यम से कॉन्फ़िगर किया गया):

```bash
nx migrate --init    # Initialize Alembic (first time)
nx migrate           # Create migration
nx migrate --upgrade # Apply
```
