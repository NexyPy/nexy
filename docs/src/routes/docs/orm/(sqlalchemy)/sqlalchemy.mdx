# SQLAlchemy

**SQLAlchemy** is the mature, full-featured ORM for Python. Use it when you need complex queries, multiple databases, or existing SQLAlchemy projects.

## Configuration

```python
# configs/database.py
from sqlalchemy.ext.asyncio import create_async_engine

engine = create_async_engine("sqlite+aiosqlite:///dev.db")
```

## Example

```python
from sqlalchemy import Column, Integer, String
from sqlalchemy.orm import DeclarativeBase

class Base(DeclarativeBase):
    pass

class User(Base):
    __tablename__ = "users"
    id = Column(Integer, primary_key=True)
    name = Column(String)
    email = Column(String)
```

## Migrations

Use Alembic (configured via `nx migrate`):

```bash
nx migrate --init    # Initialize Alembic (first time)
nx migrate           # Create migration
nx migrate --upgrade # Apply
```

SQLAlchemy gives you full control over queries, relationships, and connection pooling.
