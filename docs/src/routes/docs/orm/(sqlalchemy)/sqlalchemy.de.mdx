# SQLAlchemy

**SQLAlchemy** ist das ausgereifte ORM mit vollem Funktionsumfang für Python. Verwenden Sie es, wenn Sie komplexe Abfragen, mehrere Datenbanken oder bestehende SQLAlchemy-Projekte benötigen.

## Konfiguration

```python
# configs/database.py
from sqlalchemy.ext.asyncio import create_async_engine

engine = create_async_engine("sqlite+aiosqlite:///dev.db")
```

## Beispiel

```python
from sqlalchemy import Column, Integer, String
from sqlalchemy.orm import DeclarativeBase

class Base(DeclarativeBase):
    pass

class User(Base):
    __tablename__ = "users"
    id = Column(Integer, primary_key=True)
    name = Column(String)
    email = Column(String)
```

## Migrationen

Verwenden Sie Alembic (konfiguriert über `nx migrate`):

```bash
nx migrate --init    # Initialize Alembic (first time)
nx migrate           # Create migration
nx migrate --upgrade # Apply
```

SQLAlchemy gibt Ihnen die volle Kontrolle über Abfragen, Beziehungen und Verbindungspooling.
