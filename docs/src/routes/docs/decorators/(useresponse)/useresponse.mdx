# "@UseResponse

Set response metadata on a handler method — status code, response model, response class, etc.
```python
from nexy.decorators import UseResponse, Controller
from fastapi.responses import HTMLResponse

"@Controller("/users")
class UsersController:
    "@UseResponse(status_code=201, response_model=dict)
    def post(self, data: dict) -> dict:
        return {"created": True}

    "@UseResponse(response_class=HTMLResponse)
    def GET(self) -> str:
        return "<h1>Users</h1>"
```
## Signature
```python
UseResponse(
    status_code: int | None = None,
    response_class: type[Response] | None = None,
    response_model: type[Any] | None = None,
    responses: dict[int | str, Any] | None = None,
    response_description: str | None = None,
    response_model_include: AbstractSet[str] | Mapping[str, Any] | None = None,
    response_model_exclude: AbstractSet[str] | Mapping[str, Any] | None = None,
    response_model_by_alias: bool | None = None,
    response_model_exclude_unset: bool | None = None,
    response_model_exclude_defaults: bool | None = None,
    response_model_exclude_none: bool | None = None,
) -> Callable
```
## All parameters

| Param | Type | Description |
|-------|------|-------------|
| `status_code` | `int` | HTTP status code |
| `response_class` | `type[Response]` | Custom response class (e.g. `HTMLResponse`) |
| `response_model` | `type` | Pydantic model for response serialization |
| `responses` | `dict` | Additional OpenAPI responses |
| `response_description` | `str` | Response description in OpenAPI |
| `response_model_include` | set/mapping | Fields to include in response |
| `response_model_exclude` | set/mapping | Fields to exclude from response |
| `response_model_by_alias` | `bool` | Use alias names in response |
| `response_model_exclude_unset` | `bool` | Exclude unset fields |
| `response_model_exclude_defaults` | `bool` | Exclude default-valued fields |
| `response_model_exclude_none` | `bool` | Exclude None-valued fields |
