# "@Módulo

Ensambla controladores, proveedores y submódulos en una FastAPI `APIRouter`.
```python
from nexy.decorators import Module, Controller

"@Controller("/users")
class UsersController:
    def GET(self) -> list[dict]:
        return [{"id": 1}]

"@Module(prefix="/api")
class AppModule:
    controllers = [UsersController]
    providers = [DatabaseService]
    imports = [AuthModule]
    exports = [UsersController]
```
## Firma
```python
Module(prefix: str = "") -> Callable[[type], APIRouter]
```
## Atributos de clase

| Atributo | Tipo | Requerido | Descripción |
|-----------|------|----------|-------------|
| `controllers` | `list[type]` | Sí | Clases de controlador para registrarse |
| `providers` | `list[type]` | No | Servicios inyectables para registrar en el contenedor DI |
| `imports` | `list[APIRouter]` | No | Submódulos (devueltos por `"@Module`) para incluir |
| `exports` | `list[type]` | No | Proveedores para exportar para su uso en la importación de módulos |

## Cómo funciona

1. Los proveedores se crean instancias a través de `Container.resolve()`
2. Los submódulos importados se incluyen en el enrutador principal.
3. Las exportaciones se almacenan en `router.__module_exports__`
4. Los métodos de cada controlador se registran como rutas.

## Ejemplo con importaciones/exportaciones
```python
from nexy.decorators import Injectable, Module

"@Injectable()
class SharedService:
    def get_data(self) -> str:
        return "shared"

"@Module(prefix="/shared")
class SharedModule:
    controllers = [SharedController]
    providers = [SharedService]
    exports = [SharedService]

"@Module(prefix="/api")
class AppModule:
    controllers = [AppController]
    imports = [SharedModule]  # SharedModule router included
```
