#“@UseGuard

将守卫可调用对象应用于控制器类或单个处理程序方法。

## 守卫合同

守卫可以用 `__call__(self, request)` 调用。它接收 FastAPI `Request` 对象。提高 `HTTPException` 阻止，返回 `None` 允许。
```python
from fastapi import HTTPException

class RoleGuard:
    def __init__(self, role: str):
        self.role = role

    def __call__(self, request) -> None:
        if request.user.role != self.role:
            raise HTTPException(403)
```
