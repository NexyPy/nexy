# "@UseGuard

Wenden Sie Guard-Callables auf eine Controller-Klasse oder eine einzelne Handler-Methode an.

## Wachvertrag

Ein Wächter kann mit `__call__(self, request)` aufgerufen werden. Es empfängt das FastAPI-Objekt `Request`. Erhöhen Sie `HTTPException` zum Blockieren, geben Sie `None` zurück, um es zuzulassen.
```python
from fastapi import HTTPException

class RoleGuard:
    def __init__(self, role: str):
        self.role = role

    def __call__(self, request) -> None:
        if request.user.role != self.role:
            raise HTTPException(403)
```

## Unterschrift
```python
UseGuard(*guards: Callable[..., Any]) -> Callable[[Any], Any]
```
## Bestellung

Wächter auf Klassenebene werden vor Wächtern auf Methodenebene ausgeführt. Alle laufen als FastAPI `Depends`.
