# "@UseRoute

Set OpenAPI metadata on a handler method — name, summary, description, tags, etc.
```python
from nexy.decorators import UseRoute, Controller

"@Controller("/users")
class UsersController:
    "@UseRoute(
        summary="List all users",
        description="Returns paginated list of users",
        deprecated=False,
        tags=["users"],
    )
    def GET(self) -> list[dict]:
        ...
```
## Signature
```python
UseRoute(
    name: str | None = None,
    tags: list[str] | None = None,
    summary: str | None = None,
    description: str | None = None,
    deprecated: bool | None = None,
    include_in_schema: bool | None = None,
    operation_id: str | None = None,
    openapi_extra: dict[str, Any] | None = None,
) -> Callable
```
## All parameters

| Param | Type | Description |
|-------|------|-------------|
| `name` | `str` | Route name (defaults to `ClassName.method_name`) |
| `tags` | `list[str]` | OpenAPI tags (overrides controller tags) |
| `summary` | `str` | OpenAPI summary |
| `description` | `str` | OpenAPI description |
| `deprecated` | `bool` | Mark as deprecated in OpenAPI |
| `include_in_schema` | `bool` | Hide from OpenAPI schema |
| `operation_id` | `str` | OpenAPI operationId |
| `openapi_extra` | `dict` | Additional OpenAPI fields |

## Alias
```python
from nexy.decorators import useRoute  # lowercase alias, identical API
```
