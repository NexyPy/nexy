# "@UseRoute

قم بتعيين بيانات تعريف OpenAPI على طريقة المعالج - الاسم والملخص والوصف والعلامات وما إلى ذلك.
```python
from nexy.decorators import UseRoute, Controller

"@Controller("/users")
class UsersController:
    "@UseRoute(
        summary="List all users",
        description="Returns paginated list of users",
        deprecated=False,
        tags=["users"],
    )
    def GET(self) -> list[dict]:
        ...
```
## إمضاء
```python
UseRoute(
    name: str | None = None,
    tags: list[str] | None = None,
    summary: str | None = None,
    description: str | None = None,
    deprecated: bool | None = None,
    include_in_schema: bool | None = None,
    operation_id: str | None = None,
    openapi_extra: dict[str, Any] | None = None,
) -> Callable
```
## جميع المعلمات

| بارام | اكتب | الوصف |
|-------|------|-------------|
| `name` | `str` | اسم المسار (الافتراضي هو `ClassName.method_name`) |
| `tags` | `list[str]` | علامات OpenAPI (تتجاوز علامات وحدة التحكم) |
| `summary` | `str` | ملخص OpenAPI |
| `description` | `str` | وصف OpenAPI |
| `deprecated` | `bool` | وضع علامة مهملة في OpenAPI |
| `include_in_schema` | `bool` | إخفاء من مخطط OpenAPI |
| `operation_id` | `str` | معرف عملية OpenAPI |
| `openapi_extra` | `dict` | حقول OpenAPI الإضافية |

## الاسم المستعار
```python
from nexy.decorators import useRoute  # lowercase alias, identical API
```
