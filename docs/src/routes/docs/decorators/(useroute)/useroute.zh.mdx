#“@UseRoute

在处理程序方法上设置 OpenAPI 元数据 - 名称、摘要、描述、标签等。
```python
from nexy.decorators import UseRoute, Controller

"@Controller("/users")
class UsersController:
    "@UseRoute(
        summary="List all users",
        description="Returns paginated list of users",
        deprecated=False,
        tags=["users"],
    )
    def GET(self) -> list[dict]:
        ...
```
＃＃ 签名
```python
UseRoute(
    name: str | None = None,
    tags: list[str] | None = None,
    summary: str | None = None,
    description: str | None = None,
    deprecated: bool | None = None,
    include_in_schema: bool | None = None,
    operation_id: str | None = None,
    openapi_extra: dict[str, Any] | None = None,
) -> Callable
```
## 所有参数

|参数|类型 |描述 |
|--------|------|-------------|
| `name` | `str` |路线名称（默认为`ClassName.method_name`）|
| `tags` | `list[str]` | OpenAPI 标签（覆盖控制器标签）|
| `summary` | `str` | OpenAPI 总结 |
| `description` | `str` | OpenAPI说明|
| `deprecated` | `bool` |在 OpenAPI 中标记为已弃用 |
| `include_in_schema` | `bool` |从 OpenAPI 架构中隐藏 |
| `operation_id` | `str` | OpenAPI 操作Id |
| `openapi_extra` | `dict` |其他 OpenAPI 字段 |

## 别名
```python
from nexy.decorators import useRoute  # lowercase alias, identical API
```
