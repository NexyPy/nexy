# Введение

**Nexy** (произносится как `nek:si`) — это полнофункциональная веб-платформа Python, построенная на основе **FastAPI** и **Starlette**. Он переносит в Python опыт разработки современных фреймворков, таких как Next.js и NestJS.

Название происходит от: **N**new **Ex**perience for P**y**thon — новый подход к созданию веб-приложений на Python.

> Nexy не изобретает велосипед. Это радикально упрощает веб-разработку на Python, сохраняя при этом мощь FastAPI.

---

## Два маршрутизатора, один фреймворк

Nexy предлагает **две стратегии маршрутизации** — выберите ту, которая подходит для вашего проекта:

### Маршрутизатор (маршрутизация на основе файлов)

Маршруты определяются вашим файловым деревом — каждый файл `.nexy`, `.mdx` или `.py` в `src/routes/` автоматически становится HTTP-маршрутом.

```text
src/routes/

├── index.nexy          →  /

├── about.nexy          →  /about

├── blog/

│   ├── index.nexy      →  /blog

│   └── [slug].nexy     →  /blog/{slug}

└── api/

    └── users.py        →  /api/users (GET, POST, etc.)
```

**Наилучший вариант**: простые сайты, документация, MVP, проекты, использующие только API, команды, которые предпочитают соглашения, а не настройку.

Узнать больше: [File-Based Routing →](/docs/fbrouters)

### Модульный маршрутизатор (на основе декоратора)

Маршруты определяются с помощью декораторов Python — организуйте код в **Контроллеры**, **Поставщики** и **Модули** в соответствии с шаблоном NestJS.

```python
from nexy.decorators import Controller

"@Controller("/users")

class UsersController:

    def __init__(self, service: UserService):

        self.service = service

    def GET(self):

        return self.service.find_all()
```

**Наилучший вариант**: большие приложения, проектирование на основе предметной области, проекты, которые выигрывают от внедрения зависимостей и строгой организации кода.

Узнать больше: [Modular Router →](/docs/modular/overview)

> Используйте **селектор маршрутизатора** в верхней части боковой панели для переключения между видами документации для каждого маршрутизатора.

## FastAPI — это движок

Точно так же, как Next.js **является React** под капотом, Nexy **является FastAPI** под капотом. Каждый маршрут, каждый ответ, каждое промежуточное программное обеспечение проходит через FastAPI и Starlette.

```python
# FastAPI patterns that work unchanged in Nexy

from fastapi import Request, Depends

from fastapi.responses import JSONResponse, HTMLResponse

from pydantic import BaseModel

class UserOut(BaseModel):

    id: int

    name: str

    email: str

def GET(request: Request, db=Depends(get_db)):

    return db.query(User).all()
```

**Что осталось прежним:** `Request`, `Depends`, `HTTPException`, `BaseModel`, `JSONResponse`, `HTMLResponse`, `RedirectResponse`, `WebSocket`, `UploadFile`, `Form`, `Header`, `Cookie`, `Query`, `status` — все из `fastapi`.

**Что добавляет Nexy:** Файлы `.nexy`/`.mdx` → скомпилированы в маршруты FastAPI, `"@Action` → автоматически генерируемые маршруты POST, `"@Controller`/`"@Module` → построители FastAPI `APIRouter`, перехватчики → помощники по запросу поверх `Request` FastAPI.

Поскольку Nexy является FastAPI, каждый маршрут автоматически создает **документы OpenAPI** в `/docs` (Swagger UI) и `/redoc`.

## Почему Некси?

- **FastAPI под капотом** — асинхронность, автоматическая документация OpenAPI, типобезопасность, проверено в боевых условиях.
- **Пользовательский интерфейс на основе компонентов** — пишите компоненты с помощью шаблонов Python + Jinja2 или используйте React/Vue/Svelte/Solid/Preact.
- **Файловая И модульная маршрутизация** — выберите правильный инструмент для своего проекта.
- **Нулевой шаблон** — нет ручной регистрации маршрута, нет файлов конфигурации для подключения.
- **Встроенный i18n, HMR, промежуточное ПО, средства защиты** — готовность к работе с первого дня

---

## Некси для тебя?

Используйте Nexy, если хотите:

- Создайте полнофункциональное приложение Python так же быстро, как Next.js или Laravel.
- Создайте REST API со структурой NestJS, но с простотой Python.
- Используйте компоненты React/Vue/Svelte из серверной части Python.
- Прекратить проекты реструктуризации и установку шаблонных пакетов.
