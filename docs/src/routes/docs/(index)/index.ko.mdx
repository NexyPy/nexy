# 소개

**Nexy**(`nek:si`로 발음)는 **FastAPI** 및 **Starlette**를 기반으로 구축된 전체 스택 Python 웹 프레임워크입니다. Next.js 및 NestJS와 같은 최신 프레임워크의 개발자 경험을 Python에 제공합니다.

이름의 유래: **N**ew **Ex**perience for P**y**thon — Python으로 웹 애플리케이션을 구축하는 새로운 접근 방식입니다.

> 넥시는 바퀴를 재발명하지 않습니다. FastAPI의 성능을 유지하면서 Python 웹 개발을 근본적으로 단순화합니다.

---

## 두 개의 라우터, 하나의 프레임워크

Nexy는 **두 가지 라우팅 전략**을 제공합니다. 귀하의 프로젝트에 적합한 전략을 선택하세요.

### 경로 라우터(파일 기반 라우팅)

경로는 파일 트리에 의해 정의됩니다. `src/routes/`의 모든 `.nexy`, `.mdx` 또는 `.py` 파일은 자동으로 HTTP 경로가 됩니다.

```text
src/routes/

├── index.nexy          →  /

├── about.nexy          →  /about

├── blog/

│   ├── index.nexy      →  /blog

│   └── [slug].nexy     →  /blog/{slug}

└── api/

    └── users.py        →  /api/users (GET, POST, etc.)
```

**최적의 대상**: 간단한 사이트, 문서, MVP, API 전용 프로젝트, 구성보다 규칙을 선호하는 팀.

자세히 알아보기: [File-Based Routing →](/docs/fbrouters)

### 모듈형 라우터(데코레이터 기반)

경로는 Python 데코레이터를 통해 정의됩니다. 코드를 NestJS 패턴에 따라 **컨트롤러**, **공급자** 및 **모듈**로 구성합니다.

```python
from nexy.decorators import Controller

"@Controller("/users")

class UsersController:

    def __init__(self, service: UserService):

        self.service = service

    def GET(self):

        return self.service.find_all()
```

**최적의 용도**: 대규모 애플리케이션, 도메인 중심 설계, 종속성 주입 및 엄격한 코드 구성의 이점을 누리는 프로젝트.

자세히 알아보기: [Modular Router →](/docs/modular/overview)

> 사이드바 상단에 있는 **라우터 선택기**를 사용하여 각 라우터에 대한 문서 보기 간에 전환합니다.

## FastAPI는 엔진입니다

Next.js가 내부적으로 **React**인 것처럼 Nexy는 내부적으로 **FastAPI**입니다. 모든 경로, 모든 응답, 모든 미들웨어는 FastAPI 및 Starlette를 통해 실행됩니다.

```python
# FastAPI patterns that work unchanged in Nexy

from fastapi import Request, Depends

from fastapi.responses import JSONResponse, HTMLResponse

from pydantic import BaseModel

class UserOut(BaseModel):

    id: int

    name: str

    email: str

def GET(request: Request, db=Depends(get_db)):

    return db.query(User).all()
```

**동일하게 유지되는 사항:** `Request`, `Depends`, `HTTPException`, `BaseModel`, `JSONResponse`, `HTMLResponse`, `RedirectResponse`, `WebSocket`, `UploadFile`, `Form`, `Header`, `Cookie`, `Query`, `status` — 모두 출처 `fastapi`.

**Nexy가 추가하는 내용:** `.nexy`/`.mdx` 파일 → FastAPI 경로로 컴파일됨, `"@Action` → 자동 생성된 POST 경로, `"@Controller`/`"@Module` → FastAPI `APIRouter` 빌더, 후크 → FastAPI의 `Request` 위에 요청 범위 헬퍼.

Nexy는 FastAPI이기 때문에 모든 경로는 `/docs`(Swagger UI) 및 `/redoc`에서 자동으로 **OpenAPI 문서**를 생성합니다.

## 왜 넥시인가?

- **FastAPI 내부** — 비동기, 자동 OpenAPI 문서, 유형 안전, 전투 테스트 완료
- **구성 요소 기반 UI** — Python + Jinja2 템플릿을 사용하여 구성 요소를 작성하거나 React/Vue/Svelte/Solid/Preact를 사용합니다.
- **파일 기반 및 모듈식 라우팅** — 프로젝트에 적합한 도구 선택
- **상용구 없음** — 수동 경로 등록이 없고 연결할 구성 파일이 없습니다.
- **내장 i18n, HMR, 미들웨어, 가드** — 첫날부터 생산 가능

---

## 넥시는 당신인가요?

다음과 같은 경우 Nexy를 사용하세요.

- Next.js 또는 Laravel만큼 빠르게 전체 스택 Python 앱을 구축하세요.
- NestJS의 구조를 가지면서도 Python의 단순성을 가지고 REST API를 만들어 보세요.
- Python 백엔드에서 React/Vue/Svelte 구성 요소 사용
- 프로젝트 구조 조정 및 상용구 패키지 설치 중지

---

## 무엇을 배울 것인가

- Nexy 프로젝트 생성 및 구성
- 두 가지 라우팅 전략을 모두 이해합니다.
- 구체적인 예제를 통해 첫 번째 애플리케이션 구축
- 프로덕션 배포에 대한 모범 사례를 따릅니다.
