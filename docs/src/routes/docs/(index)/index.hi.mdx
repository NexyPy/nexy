#परिचय

**नेक्सी** (उच्चारण `nek:si`) एक पूर्ण-स्टैक पायथन वेब फ्रेमवर्क है जो **FastAPI** और **Starlette** के शीर्ष पर बनाया गया है। यह Next.js और NestJS जैसे आधुनिक फ्रेमवर्क के डेवलपर अनुभव को Python में लाता है।

नाम इस प्रकार आता है: **N**ew **Ex**perience for P**y**thon - पायथन में वेब एप्लिकेशन बनाने का एक नया तरीका।

> नेक्सी पहिए का दोबारा आविष्कार नहीं करता है। यह फास्टएपीआई की शक्ति को बनाए रखते हुए पायथन वेब विकास को मौलिक रूप से सरल बनाता है।

---

## दो राउटर, एक ढांचा

नेक्सी **दो रूटिंग रणनीतियों** की पेशकश करती है - वह चुनें जो आपके प्रोजेक्ट के लिए उपयुक्त हो:

### रूट राउटर (फ़ाइल-आधारित रूटिंग)

रूट आपके फ़ाइल ट्री द्वारा परिभाषित होते हैं - `src/routes/` में प्रत्येक `.nexy`, `.mdx`, या `.py` फ़ाइल स्वचालित रूप से एक HTTP रूट बन जाती है।

```text
src/routes/

├── index.nexy          →  /

├── about.nexy          →  /about

├── blog/

│   ├── index.nexy      →  /blog

│   └── [slug].nexy     →  /blog/{slug}

└── api/

    └── users.py        →  /api/users (GET, POST, etc.)
```

**इसके लिए सर्वश्रेष्ठ**: सरल साइटें, दस्तावेज़ीकरण, एमवीपी, एपीआई-केवल परियोजनाएं, टीमें जो कॉन्फ़िगरेशन के बजाय कन्वेंशन को प्राथमिकता देती हैं।

और जानें: [File-Based Routing →](/docs/fbrouters)

### मॉड्यूलर राउटर (डेकोरेटर-आधारित)

मार्गों को पायथन डेकोरेटर्स के माध्यम से परिभाषित किया गया है - NestJS पैटर्न का पालन करते हुए कोड को **नियंत्रक**, **प्रदाता**, और **मॉड्यूल** में व्यवस्थित करें।

```python
from nexy.decorators import Controller

"@Controller("/users")

class UsersController:

    def __init__(self, service: UserService):

        self.service = service

    def GET(self):

        return self.service.find_all()
```

**इसके लिए सर्वश्रेष्ठ**: बड़े एप्लिकेशन, डोमेन-संचालित डिज़ाइन, परियोजनाएं जो निर्भरता इंजेक्शन और सख्त कोड संगठन से लाभान्वित होती हैं।

और जानें: [Modular Router →](/docs/modular/overview)

> प्रत्येक राउटर के दस्तावेज़ीकरण दृश्यों के बीच स्विच करने के लिए साइडबार के शीर्ष पर **राउटर चयनकर्ता** का उपयोग करें।

## फास्टएपीआई इंजन है

जैसे नेक्स्ट.जेएस ** हुड के नीचे रिएक्ट** है, वैसे ही नेक्सी ** हुड के नीचे फास्टएपीआई ** है। प्रत्येक मार्ग, प्रत्येक प्रतिक्रिया, प्रत्येक मिडलवेयर फास्टएपीआई और स्टारलेट के माध्यम से चलता है।

```python
# FastAPI patterns that work unchanged in Nexy

from fastapi import Request, Depends

from fastapi.responses import JSONResponse, HTMLResponse

from pydantic import BaseModel

class UserOut(BaseModel):

    id: int

    name: str

    email: str

def GET(request: Request, db=Depends(get_db)):

    return db.query(User).all()
```

**क्या समान रहता है:** `Request`, `Depends`, `HTTPException`, `BaseModel`, `JSONResponse`, `HTMLResponse`, `RedirectResponse`, `WebSocket`, `UploadFile`, `Form`, `Header`, `Cookie`, `Query`, `status` - सभी `fastapi` से।

**नेक्सी क्या जोड़ता है:** `.nexy`/`.mdx` फ़ाइलें → फास्टएपीआई मार्गों पर संकलित, `"@Action` → स्वचालित रूप से जेनरेट किए गए पोस्ट रूट, `"@Controller`/`"@Module` → फास्टएपीआई `APIRouter` बिल्डर्स, हुक्स → फास्टएपीआई के शीर्ष पर अनुरोध-स्कोप्ड सहायक `Request`।

क्योंकि नेक्सी फास्टएपीआई है, प्रत्येक रूट स्वचालित रूप से `/docs` (स्वैगर यूआई) और `/redoc` पर **ओपनएपीआई डॉक्स** उत्पन्न करता है।

---

## नेक्सी क्यों?

- ** हुड के नीचे फास्टएपीआई ** - एसिंक, स्वचालित ओपनएपीआई दस्तावेज़, टाइप-सुरक्षित, युद्ध-परीक्षणित
- **घटक-आधारित यूआई** - पायथन + जिंजा2 टेम्पलेट्स के साथ घटक लिखें, या रिएक्ट/व्यू/स्वेल्ट/सॉलिड/प्रीएक्ट का उपयोग करें
- **फ़ाइल-आधारित और मॉड्यूलर रूटिंग** — अपने प्रोजेक्ट के लिए सही टूल चुनें
- **शून्य बॉयलरप्लेट** - कोई मैन्युअल रूट पंजीकरण नहीं, वायर अप करने के लिए कोई कॉन्फ़िगरेशन फ़ाइल नहीं
- **अंतर्निहित i18n, HMR, मिडलवेयर, गार्ड** - पहले दिन से उत्पादन के लिए तैयार

## क्या नेक्सी आपके लिए है?

यदि आप चाहें तो नेक्सी का उपयोग करें:

- नेक्स्ट.जेएस या लारवेल जितनी तेजी से एक फुल-स्टैक पायथन ऐप बनाएं
- NestJS की संरचना लेकिन Python की सरलता के साथ एक REST API बनाएं
- पायथन बैकएंड से रिएक्ट/व्यू/स्वेल्ट घटकों का उपयोग करें
- परियोजनाओं का पुनर्गठन और बॉयलरप्लेट पैकेज स्थापित करना बंद करें

- एक नेक्सी प्रोजेक्ट बनाएं और कॉन्फ़िगर करें
- दोनों रूटिंग रणनीतियों को समझें
- ठोस उदाहरणों के साथ अपना पहला एप्लिकेशन बनाएं
- उत्पादन परिनियोजन के लिए सर्वोत्तम प्रथाओं का पालन करें
