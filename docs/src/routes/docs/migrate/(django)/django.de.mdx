# Von Django nach Nexy migrieren

Django ist im Lieferumfang enthalten. Nexy ist fokussiert und modular – Sie bringen mit, was Sie brauchen.

## Konzeptzuordnung

| Django | Nexy |
|--------|------|
| `views.py` | `.nexy` Dateien (FBR) oder `"@Controller` (Modular) |
| `urls.py` | Dateibaum (FBR) oder `"@Module` (Modular) |
| `models.py` | SQLModel / SQLAlchemy (Ihre Wahl) |
| `admin.py` | OpenAPI-Dokumente unter `/docs` |
| `manage.py` | `nx` CLI |
| `settings.py` | `nexyconfig.py` |
| Django ORM | SQLModel, SQLAlchemy oder Tortoise-ORM |
| Vorlagen (DTL) | Jinja2 (`.nexy` Dateien) |
| Klassenbasierte Ansichten | `"@Controller` (Modular) oder `.nexy` Dateien (FBR) |
| Middleware | `"@Middleware` oder FastAPI-Middleware |
| `request.user` | `request.state.user` oder Wachen |

## Beispiel
```python
# src/routes/users/index.nexy
---
from pydantic import BaseModel

class UserOut(BaseModel):
    id: int
    name: str
    email: str

def GET():
    return {"users": [u.model_dump() for u in User.find_all()]}
---
```
```python
# Nexy Modular
from nexy.decorators import Controller

"@Controller("/users")
class UsersController:
    def GET(self):
        return {"users": [u.model_dump() for u in User.find_all()]}
```
## Migrationsschritte

1. **Gerüst für ein neues Nexy-Projekt** – `nx new my-app`
2. **Port-Modelle** – Django-Modelle in SQLModel/SQLAlchemy übersetzen
3. **Portansichten** – Django-Funktions-/Klassenansichten in `.nexy`-Dateien (FBR) oder `"@Controller` (modular) konvertieren.
4. **Port-URL-Konfigurationen** – `urls.py`-Muster werden zu Dateibaum (FBR) oder `"@Module` (modular)
5. **Port-Vorlagen** – DTL-Vorlagen → Jinja2 in `.nexy`-Dateien
6. **Port-Middleware** – Django-Middleware → Starlette `BaseHTTPMiddleware`

## Warum wechseln

- **Keine monolithischen Einstellungen** – konfigurieren Sie nur das, was Sie verwenden
- **Standardmäßig asynchron** – FastAPI/Starlette unter der Haube
- **OpenAPI-Dokumente** – automatisch, kein `drf-spectacular` erforderlich
- **Komponentenbasierte Benutzeroberfläche** – Mischen Sie Python + Jinja2 in einer Datei
- **Framework-Auswahl** – React, Vue, Svelte, Solid oder Preact für das Frontend
