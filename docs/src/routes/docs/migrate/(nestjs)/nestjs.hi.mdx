# NestJS से Nexy पर माइग्रेट करें

नेक्सी का मॉड्यूलर राउटर NestJS से प्रेरित है - डेकोरेटर, DI, मॉड्यूल, गार्ड, मिडलवेयर। अवधारणाएँ लगभग एक-से-एक स्थानांतरित होती हैं।

## अवधारणाओं का मानचित्रण

| नेस्टजेएस | नेक्सी |
|--------|------|
| `"@Controller()` | `"@Controller()` |
| `"@Injectable()` | `"@Injectable()` |
| `"@Module()` | `"@Module()` |
| `"@Get()` | `def GET(self)` |
| `"@Post()` | `def POST(self)` |
| `"@UseGuards()` | `"@UseGuard()` |
| `"@UseInterceptors()` | `"@Middleware()` |
| `constructor(private svc: Svc)` | `def __init__(self, svc: Svc)` |
| `APP_INTERCEPTOR` | कॉन्फ़िगरेशन में `useMiddlewares` |
| `app.module.ts` | `app_module.py` |

## उदाहरण
```python
# NestJS equivalent
"@Controller("/users")
export class UsersController {
    constructor(private service: UserService) {}
    "@Get()
    findAll() { return this.service.findAll(); }
}

# Nexy
"@Controller("/users")
class UsersController:
    def __init__(self, service: UserService):
        self.service = service

    def GET(self):
        return self.service.find_all()
```
## मुख्य अंतर

- **विधि नाम HTTP क्रियाओं को परिभाषित करते हैं** - कोई `"@Get`/`"@Post`/`"@Put`/`"@Delete` डेकोरेटर नहीं
- **सभी डेकोरेटर एक मॉड्यूल में** — `from nexy.decorators import Controller, Module, Injectable, UseGuard, Middleware`
- **नहीं `"@Global`** - दायरा `Injectable(scope=Scope.SINGLETON)` के माध्यम से नियंत्रित किया जाता है
- **गार्ड और मिडलवेयर कॉल करने योग्य हैं** - विस्तार करने के लिए कोई बेस क्लास नहीं, केवल `__call__(self, request)`
