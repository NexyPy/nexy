# NestJS에서 Nexy로 마이그레이션

Nexy의 Modular Router는 데코레이터, DI, 모듈, 가드, 미들웨어 등 NestJS에서 영감을 받았습니다. 개념은 거의 일대일로 전달됩니다.

## 개념 매핑

| 네스트JS | 넥시 |
|---------|------|
| `"@Controller()` | `"@Controller()` |
| `"@Injectable()` | `"@Injectable()` |
| `"@Module()` | `"@Module()` |
| `"@Get()` | `def GET(self)` |
| `"@Post()` | `def POST(self)` |
| `"@UseGuards()` | `"@UseGuard()` |
| `"@UseInterceptors()` | `"@Middleware()` |
| `constructor(private svc: Svc)` | `def __init__(self, svc: Svc)` |
| `APP_INTERCEPTOR` | 구성의 `useMiddlewares` |
| `app.module.ts` | `app_module.py` |

## 예
```python
# NestJS equivalent
"@Controller("/users")
export class UsersController {
    constructor(private service: UserService) {}
    "@Get()
    findAll() { return this.service.findAll(); }
}

# Nexy
"@Controller("/users")
class UsersController:
    def __init__(self, service: UserService):
        self.service = service

    def GET(self):
        return self.service.find_all()
```
## 주요 차이점

- **메서드 이름은 HTTP 동사를 정의합니다** — `"@Get`/`"@Post`/`"@Put`/`"@Delete` 데코레이터 없음
- **하나의 모듈에 있는 모든 데코레이터** — `from nexy.decorators import Controller, Module, Injectable, UseGuard, Middleware`
- **`"@Global` 없음** — 범위는 `Injectable(scope=Scope.SINGLETON)`를 통해 처리됩니다.
- **가드 및 미들웨어는 호출 가능** — 확장할 기본 클래스가 없으며 `__call__(self, request)`만 가능
