# الترحيل من NestJS إلى Nexy

جهاز التوجيه المعياري الخاص بـ Nexy مستوحى من NestJS - أدوات الديكور، والDI، والوحدات النمطية، والحراس، والبرامج الوسيطة. يتم نقل المفاهيم تقريبًا من واحد إلى واحد.

## رسم خرائط المفاهيم

| نيست جي إس | نكسي |
|--------|-----|
| `"@Controller()` | `"@Controller()` |
| `"@Injectable()` | `"@Injectable()` |
| `"@Module()` | `"@Module()` |
| `"@Get()` | `def GET(self)` |
| `"@Post()` | `def POST(self)` |
| `"@UseGuards()` | `"@UseGuard()` |
| `"@UseInterceptors()` | `"@Middleware()` |
| `constructor(private svc: Svc)` | `def __init__(self, svc: Svc)` |
| `APP_INTERCEPTOR` | `useMiddlewares` في التكوين |
| `app.module.ts` | `app_module.py` |

## مثال
```python
# NestJS equivalent
"@Controller("/users")
export class UsersController {
    constructor(private service: UserService) {}
    "@Get()
    findAll() { return this.service.findAll(); }
}

# Nexy
"@Controller("/users")
class UsersController:
    def __init__(self, service: UserService):
        self.service = service

    def GET(self):
        return self.service.find_all()
```
## الاختلافات الرئيسية

- **أسماء الطرق تحدد أفعال HTTP** — لا توجد أدوات تزيين `"@Get`/`"@Post`/`"@Put`/`"@Delete`
- **جميع أدوات الديكور في وحدة واحدة** — `from nexy.decorators import Controller, Module, Injectable, UseGuard, Middleware`
- **لا يوجد `"@Global`** — يتم التعامل مع النطاق عبر `Injectable(scope=Scope.SINGLETON)`
- **الحراسات والبرامج الوسيطة قابلة للاستدعاء** — لا توجد فئة أساسية لتوسيعها، فقط `__call__(self, request)`
