# फ्लास्क से नेक्सी पर माइग्रेट करें

फ्लास्क न्यूनतम है. नेक्सी भी न्यूनतम है - लेकिन आधुनिक एसिंक्स, प्रकार और ओपनएपीआई के साथ।

## अवधारणाओं का मानचित्रण

| फ्लास्क | नेक्सी |
|------|------|
| `"@app.route("/")` | `src/routes/` या `"@Controller` में फ़ाइल करें |
| `render_template()` | `.nexy` फ़ाइल |
| `request.args` | फ़ंक्शन हस्ताक्षर में क्वेरी पैरामीटर |
| `request.json` | फंक्शन सिग्नेचर में बॉडी परम |
| `g` | `request.state` |
| `flask run` | `nx dev` |
| `config.py` | `nexyconfig.py` |
| ब्लूप्रिंट | `"@Module` या `src/routes/` उपनिर्देशिकाएँ |

## उदाहरण

```python
# Flask
"@app.route("/api/users/<int:id>")
def get_user(id):
    return jsonify({"id": id})

# Nexy FBR: src/routes/api/users/[id].py
async def get(id: int):
    return {"id": id}
```

## आपको क्या हासिल हुआ

- **Async समर्थन** - मूल, हैक के माध्यम से नहीं
- **प्रकार सत्यापन** - पाइडेंटिक, स्वचालित 422 त्रुटियाँ
- **ओपनएपीआई डॉक्स** - कोई `flasgger` की आवश्यकता नहीं है
- **डीआई सिस्टम** - वैश्विक सिंगलटन के बिना सेवाओं को इंजेक्ट करें
- **सीएलआई** - `nx build`, `nx start`, `nx migrate`

## प्रवास के चरण

1. **मचान** — `nx new my-app`
2. **पोर्ट मार्ग** - `"@app.route()` → `src/routes/` या `"@Controller` में फ़ाइल करें
3. **पोर्ट टेम्प्लेट** — फ्लास्क `render_template()` → `.nexy` फ़ाइलें
4. **पोर्ट अनुरोध प्रबंधन** - `request.args`/`request.json` → टाइप किए गए फ़ंक्शन पैरामीटर
5. **पोर्ट ब्लूप्रिंट** → `"@Module` या FBR में उपनिर्देशिकाएँ

## क्या रहता है

सरल मार्ग, न्यूनतम बॉयलरप्लेट, पूर्ण नियंत्रण। बिल्कुल आधुनिक पायथन के साथ।
