#कॉन्फ़िगरेशन

नेक्सी को आपके प्रोजेक्ट रूट पर `nexyconfig.py` फ़ाइल के माध्यम से कॉन्फ़िगर किया गया है। यह फ़ाइल फ़्रेमवर्क के हर पहलू को नियंत्रित करती है - रूटिंग, उपनाम, i18n, CORS, सत्र, और बहुत कुछ।

कॉन्फ़िगरेशन सिस्टम अंतर्निहित सत्यापन के साथ पाइडेंटिक मॉडल का उपयोग करता है। प्रत्येक फ़ील्ड में एक समझदार डिफ़ॉल्ट होता है, इसलिए आपके `nexyconfig.py` को केवल यह निर्दिष्ट करने की आवश्यकता होती है कि आप क्या ओवरराइड करना चाहते हैं।

- [CORS](/docs/config/cors) - क्रॉस-ओरिजिनल संसाधन साझाकरण

- [Session](/docs/config/session) - सत्र मिडलवेयर सेटिंग्स
- [i18n](/docs/config/i18n) — अंतर्राष्ट्रीयकरण विन्यास
