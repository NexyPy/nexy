# Конфигурация

Nexy настраивается через файл `nexyconfig.py` в корне вашего проекта. Этот файл контролирует все аспекты платформы — маршрутизацию, псевдонимы, i18n, CORS, сеансы и многое другое.

Система конфигурации использует модели Pydantic со встроенной проверкой. Каждое поле имеет разумное значение по умолчанию, поэтому в вашем `nexyconfig.py` нужно указать только то, что вы хотите переопределить.
