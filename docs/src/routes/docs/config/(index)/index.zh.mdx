# 配置

Nexy 通过项目根目录下的 `nexyconfig.py` 文件进行配置。该文件控制框架的各个方面——路由、别名、i18n、CORS、会话等等。

配置系统使用带有内置验证的 Pydantic 模型。每个字段都有一个合理的默认值，因此您的 `nexyconfig.py` 只需指定您想要覆盖的内容。
