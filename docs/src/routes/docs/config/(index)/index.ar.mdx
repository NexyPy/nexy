# التكوين

تم تكوين Nexy من خلال ملف `nexyconfig.py` في جذر مشروعك. يتحكم هذا الملف في كل جانب من جوانب إطار العمل - التوجيه، والأسماء المستعارة، وi18n، وCORS، والجلسات، والمزيد.

يستخدم نظام التكوين نماذج Pydantic مع التحقق من الصحة المدمج. يحتوي كل حقل على إعدادات افتراضية معقولة، لذلك يحتاج `nexyconfig.py` فقط إلى تحديد ما تريد تجاوزه.

## روابط سريعة

- [Nexy Config](/docs/config/nexy) — مرجع الإعدادات على مستوى المشروع
- [Vite Config](/docs/config/vite) — تكوين أداة بناء الواجهة الأمامية
- [CORS](/docs/config/cors) — مشاركة الموارد عبر الأصل
- [Aliases](/docs/config/aliases) — استيراد الأسماء المستعارة لمسار
- [Session](/docs/config/session) — إعدادات البرامج الوسيطة للجلسة
- [i18n](/docs/config/i18n) — تكوين التدويل
- [TOC](/docs/config/toc) — إنشاء جدول المحتويات تلقائيًا
