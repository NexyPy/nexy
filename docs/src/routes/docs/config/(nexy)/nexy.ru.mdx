# Конфиг: Некси

Nexy настраивается через `nexyconfig.py` в корне вашего проекта. В файле определяется класс, расширяющий `NexyConfigModel`:

```python
from nexy.core.models import NexyConfigModel

class NexyConfig(NexyConfigModel):
    usePort = 3000
    useTitle = "My App"
```

## Все поля

### Маршрутизатор

| Поле | Тип | По умолчанию | Описание |
|-------|------|---------|-------------|
| `useRouter` | `APIRouter \| None` | `None` | Модульный корневой модуль маршрутизатора. Если установлено, используется модульная маршрутизация. Когда `None`, используется FBR. |
| `excludeDirs` | `list[str]` | `[]` | Каталоги, которые необходимо исключить из сканирования FBR. |

### Сервер

| Поле | Тип | По умолчанию | Описание |
|-------|------|---------|-------------|
| `usePort` | `int` | `3000` | Порт для сервера разработки/производства. |
| `useHost` | `str` | `"0.0.0.0"` | Хост для привязки. |
| `useSslKeyfile` | `str \| None` | `None` | Путь к файлу ключей SSL для HTTPS. |
| `useSslCertfile` | `str \| None` | `None` | Путь к файлу сертификата SSL для HTTPS. |

### Документация OpenAPI

| Поле | Тип | По умолчанию | Описание |
|-------|------|---------|-------------|
| `useDocs` | `bool` | `True` | Включить/отключить документы OpenAPI. |
| `useDocsUrl` | `str` | `"/docs"` | URL-адрес пользовательского интерфейса Swagger. |
| `useRedocsUrl` | `str \| None` | `"/redocs"` | URL-адрес ReDoc. Установите `None` для отключения. |
| `useTitle` | `str` | `"Nexy"` | Название схемы OpenAPI. |

### Фронтенд

| Поле | Тип | По умолчанию | Описание |
|-------|------|---------|-------------|
| `useVite` | `bool` | `False` | Включите объединение Vite для клиентских компонентов. |
| `useViteDevUrl` | `str \| None` | `None` | URL-адрес пользовательского сервера разработки Vite (определяется автоматически, если `None`). |
| `useFF` | `list[FrontendFramework]` | `[]` | Фронтенд-фреймворки для включения (React, Vue, Svelte, Solid, Preact). Автоматически определяется из проекта. |
| `useMarkdownExtensions` | `list[str]` | `[]` | Расширения Python-Markdown для файлов `.mdx`. |

### Промежуточное ПО

| Поле | Тип | По умолчанию | Описание |
|-------|------|---------|-------------|
| `useMiddlewares` | `list[Any]` | `[]` | Пользовательские классы промежуточного программного обеспечения ASGI. |
| `useCORS` | `dict \| None` | `None` | Конфигурация промежуточного программного обеспечения CORS (Starlette `CORSMiddleware` kwargs). |
| `useGZip` | `dict \| None` | `None` | Конфигурация промежуточного программного обеспечения GZip (Starlette `GZipMiddleware` kwargs). |
| `useTrustedHost` | `dict \| None` | `None` | Конфигурация промежуточного программного обеспечения доверенного хоста. |
| `useHTTPSRedirect` | `bool` | `False` | Перенаправить HTTP на HTTPS. |
| `useSession` | `dict \| None` | `None` | Конфигурация промежуточного программного обеспечения сеанса (Starlette `SessionMiddleware` kwargs). |
| `useAuth` | `dict \| None` | `None` | Конфигурация промежуточного программного обеспечения аутентификации. |

### i18n

| Поле | Тип | По умолчанию | Описание |
|-------|------|---------|-------------|
| `useLocales` | `list[str] \| None` | `None` | Доступные локали (например, `["en", "fr"]`). Автоматически определяется из `nexy/i18n/`, если `None`. |
| `useDefaultLocale` | `str` | `"en"` | Локаль по умолчанию. |
| `useLocaleCookieName` | `str` | `"nexy-locale"` | Имя файла cookie для хранения локали. |
| `useLocaleDetection` | `dict[str, bool] \| None` | `None` | Настройки определения локали. |
| `useRTL` | `bool` | `False` | Включите поддержку RTL. |

### Содержание

| Поле | Тип | По умолчанию | Описание |
|-------|------|---------|-------------|
| `useTocDepth` | `str` | `"2-6"` | Уровни заголовков для включения в оглавление (например, `"2-4"` для h2–h4). |
| `useTocTitle` | `str` | `"Table of Contents"` | Название раздела оглавления. |
| `useTocAuto` | `bool` | `True` | Автоматическое создание содержания для страниц `.mdx`. |

## Доступ к приложению FastAPI

Nexy предоставляет базовый экземпляр FastAPI через `nexy.app`. Это полезно для добавления пользовательских маршрутов, промежуточного программного обеспечения или обработчиков событий за пределами системы маршрутизации Nexy.

```python
from nexy import app

"@app.on_event("startup")
async def startup():
    print("Server starting...")

"@app.get("/health")
def health():
    return {"status": "ok"}
```

Объект `app` — это полностью настроенный FastAPI `APIRouter`, который монтируется `AppServer`. Вы можете использовать любую функцию FastAPI/Starlette.
