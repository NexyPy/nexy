# कॉन्फ़िगरेशन: नेक्सी

नेक्सी को आपके प्रोजेक्ट रूट पर `nexyconfig.py` के माध्यम से कॉन्फ़िगर किया गया है। फ़ाइल एक वर्ग को परिभाषित करती है जो `NexyConfigModel` तक विस्तारित होती है:

```python
from nexy.core.models import NexyConfigModel

class NexyConfig(NexyConfigModel):
    usePort = 3000
    useTitle = "My App"
```

## सभी फ़ील्ड

### राउटर

| फ़ील्ड | प्रकार | डिफ़ॉल्ट | विवरण |
|-------|------|------|----|
| `useRouter` | `APIRouter \| None` | `None` | मॉड्यूलर राउटर रूट मॉड्यूल। सेट होने पर, मॉड्यूलर रूटिंग का उपयोग करता है। जब `None`, FBR का उपयोग करता है। |
| `excludeDirs` | `list[str]` | `[]` | FBR स्कैनिंग से बाहर की जाने वाली निर्देशिकाएँ। |

### सर्वर

| फ़ील्ड | प्रकार | डिफ़ॉल्ट | विवरण |
|-------|------|------|----|
| `usePort` | `int` | `3000` | विकास/उत्पादन सर्वर के लिए पोर्ट। |
| `useHost` | `str` | `"0.0.0.0"` | आबद्ध करने के लिए मेज़बान. |
| `useSslKeyfile` | `str \| None` | `None` | HTTPS के लिए SSL कुंजी फ़ाइल पथ। |
| `useSslCertfile` | `str \| None` | `None` | HTTPS के लिए SSL प्रमाणपत्र फ़ाइल पथ। |

### ओपनएपीआई दस्तावेज़

| फ़ील्ड | प्रकार | डिफ़ॉल्ट | विवरण |
|-------|------|------|----|
| `useDocs` | `bool` | `True` | OpenAPI दस्तावेज़ सक्षम/अक्षम करें। |
| `useDocsUrl` | `str` | `"/docs"` | स्वैगर यूआई के लिए यूआरएल। |
| `useRedocsUrl` | `str \| None` | `"/redocs"` | ReDoc के लिए URL. अक्षम करने के लिए `None` पर सेट करें। |
| `useTitle` | `str` | `"Nexy"` | OpenAPI स्कीमा के लिए शीर्षक. |

### फ्रंटेंड

| फ़ील्ड | प्रकार | डिफ़ॉल्ट | विवरण |
|-------|------|------|----|
| `useVite` | `bool` | `False` | क्लाइंट घटकों के लिए वाइट बंडलिंग सक्षम करें। |
| `useViteDevUrl` | `str \| None` | `None` | कस्टम वाइट डेव सर्वर यूआरएल (यदि `None` है तो स्वतः पता लगाया गया)। |
| `useFF` | `list[FrontendFramework]` | `[]` | सक्षम करने के लिए फ्रंटएंड फ्रेमवर्क (रिएक्ट, व्यू, स्वेल्ट, सॉलिड, प्रीएक्ट)। प्रोजेक्ट से स्वतः पता लगाया गया. |
| `useMarkdownExtensions` | `list[str]` | `[]` | `.mdx` फ़ाइलों के लिए पायथन-मार्कडाउन एक्सटेंशन। |

### मिडलवेयर

| फ़ील्ड | प्रकार | डिफ़ॉल्ट | विवरण |
|-------|------|------|----|
| `useMiddlewares` | `list[Any]` | `[]` | कस्टम एएसजीआई मिडलवेयर कक्षाएं। |
| `useCORS` | `dict \| None` | `None` | CORS मिडलवेयर कॉन्फ़िगरेशन (स्टारलेट `CORSMiddleware` kwargs)। |
| `useGZip` | `dict \| None` | `None` | GZip मिडलवेयर कॉन्फ़िगरेशन (स्टारलेट `GZipMiddleware` kwargs)। |
| `useTrustedHost` | `dict \| None` | `None` | विश्वसनीय होस्ट मिडलवेयर कॉन्फ़िगरेशन। |
| `useHTTPSRedirect` | `bool` | `False` | HTTP को HTTPS पर पुनर्निर्देशित करें। |
| `useSession` | `dict \| None` | `None` | सत्र मिडलवेयर कॉन्फ़िगरेशन (स्टारलेट `SessionMiddleware` kwargs)। |
| `useAuth` | `dict \| None` | `None` | प्रमाणीकरण मिडलवेयर कॉन्फ़िगरेशन। |

### i18n

| फ़ील्ड | प्रकार | डिफ़ॉल्ट | विवरण |
|-------|------|------|----|
| `useLocales` | `list[str] \| None` | `None` | उपलब्ध स्थान (उदा. `["en", "fr"]`). `None` होने पर `nexy/i18n/` से स्वतः पता लगाया गया। |
| `useDefaultLocale` | `str` | `"en"` | डिफ़ॉल्ट स्थान. |
| `useLocaleCookieName` | `str` | `"nexy-locale"` | स्थानीय भंडारण के लिए कुकी नाम. |
| `useLocaleDetection` | `dict[str, bool] \| None` | `None` | स्थान पहचान सेटिंग्स. |
| `useRTL` | `bool` | `False` | आरटीएल समर्थन सक्षम करें. |

### सामग्री तालिका

| फ़ील्ड | प्रकार | डिफ़ॉल्ट | विवरण |
|-------|------|------|----|
| `useTocDepth` | `str` | `"2-6"` | टीओसी में शामिल करने के लिए शीर्षक स्तर (उदाहरण के लिए h2-h4 के लिए `"2-4"`)। |
| `useTocTitle` | `str` | `"Table of Contents"` | टीओसी अनुभाग शीर्षक. |
| `useTocAuto` | `bool` | `True` | `.mdx` पृष्ठों के लिए स्वतः TOC जनरेट करें। |

## फास्टएपीआई ऐप तक पहुंचना

नेक्सी `nexy.app` के माध्यम से अंतर्निहित फास्टएपीआई उदाहरण को उजागर करता है। यह नेक्सी के रूटिंग सिस्टम के बाहर कस्टम रूट, मिडलवेयर या इवेंट हैंडलर जोड़ने के लिए उपयोगी है।

```python
from nexy import app

"@app.on_event("startup")
async def startup():
    print("Server starting...")

"@app.get("/health")
def health():
    return {"status": "ok"}
```

`app` ऑब्जेक्ट पूरी तरह से कॉन्फ़िगर किया गया फास्टएपीआई `APIRouter` है जो `AppServer` द्वारा माउंट किया जाता है। आप इस पर किसी भी फास्टएपीआई/स्टारलेट सुविधा का उपयोग कर सकते हैं।
