# サーバーアクション

サーバー アクションを使用すると、クライアントから POST エンドポイントとして Python 関数を呼び出すことができます。ルート登録やシリアル化ボイラープレートは必要ありません。

---

## アクションの定義

任意の関数を `"@Action` で装飾します。

```python
# src/actions/vote.py
from nexy.decorators import Action

"@Action
def vote(post_id: str, direction: int) -> dict:
    return {"success": True, "post_id": post_id, "votes": 42}
```

この関数は、JSON 本体パラメーターをキーワード引数として受け取ります。任意の JSON シリアル化可能な値を返します。

---

## アクションファイルを置く場所

アクションは、プロジェクト内の**任意の場所** (`src/actions/`、`src/routes/`、またはルートに直接) 存在できます。 `ActionEngine` は起動時にプロジェクト ディレクトリ全体をスキャンします。

```text
my-app/
├── src/
│   └── actions/
│       ├── vote.py        ← "@Action
│       └── comment.py     ← "@Action
├── actions/
│   ├── vote.ts            ← Generated TypeScript client
│   └── comment.ts
```

検出とエンドポイント生成の仕組みについては、["@Action reference](/docs/decorators/action) を参照してください。

## 実際の例

### フォームの送信

```python
# src/actions/contact.py
from nexy.decorators import Action
from pydantic import BaseModel, EmailStr

class ContactForm(BaseModel):
    name: str
    email: EmailStr
    message: str

"@Action
def submit_contact(data: ContactForm) -> dict:
    # Save to database, send email, etc.
    return {"ok": True, "name": data.name}
```

```nexy

<form id="contact">

<script>
document.getElementById('contact').onsubmit = async (e) => {

    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(Object.fromEntries(fd))
  });
  const data = await res.json();
  if (data.ok) alert('Message sent!');
};
</script>
```

### データベースアクション

```python
# src/actions/create_user.py
from nexy.decorators import Action
from pydantic import BaseModel
from src.database import get_session
from src.models import User

class CreateUserBody(BaseModel):
    name: str
    email: str

"@Action
def create_user(body: CreateUserBody) -> dict:
    db = next(get_session())
    user = User(name=body.name, email=body.email)
    db.add(user)
    db.commit()
    db.refresh(user)
    return {"id": user.id, "name": user.name}
```

### エラー処理を伴うアクション

```python
# src/actions/delete_item.py
from nexy.decorators import Action
from fastapi import HTTPException
from src.database import get_session

"@Action
def delete_item(item_id: int) -> dict:
    db = next(get_session())
    item = db.get(Item, item_id)
    if not item:
        raise HTTPException(status_code=404, detail="Item not found")
    db.delete(item)
    db.commit()
    return {"deleted": item_id}
```

## 生成された TypeScript クライアント

`nx build` または `nx dev` は、`./actions/` にタイプセーフな TypeScript ラッパーを生成します。

```typescript
// Generated: ./actions/vote.ts
import { transport } from '"@/nexy/client';

export const vote = async (post_id: string, direction: number): Promise<dict> => {
  return await transport.call('/_nx_a1b2c3d4e5f6', { post_id, direction });
};
```

生成された各関数は、適切な TypeScript タイプを使用して Python シグネチャをミラーリングします。

---

## ベストプラクティス

- アクション関数の焦点を絞って冪等にしておく
- アクション内の入力を検証します - 信頼できないものとして扱います
- 複雑なリクエストボディには Pydantic モデルを使用する
- アクションは POST のみです。他の HTTP メソッドの場合は、ルート ハンドラーを使用します。
- 認可にガードまたはミドルウェアを使用する
