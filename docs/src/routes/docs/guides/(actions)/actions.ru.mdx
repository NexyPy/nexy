# Действия сервера

Действия сервера позволяют вызывать функции Python из клиента в качестве конечных точек POST — без регистрации маршрута и без шаблона сериализации.

---

## Определение действия

Украсьте любую функцию `"@Action`:

```python
# src/actions/vote.py
from nexy.decorators import Action

"@Action
def vote(post_id: str, direction: int) -> dict:
    return {"success": True, "post_id": post_id, "votes": 42}
```

Функция получает параметры тела JSON в качестве аргументов ключевого слова. Возвращает любое сериализуемое значение JSON.

---

## Куда поместить файлы действий

Действия могут находиться **где угодно** в вашем проекте — `src/actions/`, `src/routes/` или непосредственно в корне. `ActionEngine` сканирует весь каталог проекта при запуске.

```text
my-app/
├── src/
│   └── actions/
│       ├── vote.py        ← "@Action
│       └── comment.py     ← "@Action
├── actions/
│   ├── vote.ts            ← Generated TypeScript client
│   └── comment.ts
```

См. ["@Action reference](/docs/decorators/action), чтобы узнать, как работают обнаружение и создание конечных точек.

## Практические примеры

### Отправка формы

```python
# src/actions/contact.py
from nexy.decorators import Action
from pydantic import BaseModel, EmailStr

class ContactForm(BaseModel):
    name: str
    email: EmailStr
    message: str

"@Action
def submit_contact(data: ContactForm) -> dict:
    # Save to database, send email, etc.
    return {"ok": True, "name": data.name}
```

```nexy
---
---
<form id="contact">
  <input name="name" required />
  <input name="email" type="email" required />
  <textarea name="message" required></textarea>
  <button type="submit">Send</button>
</form>

<script>
document.getElementById('contact').onsubmit = async (e) => {
  e.preventDefault();
  const fd = new FormData(e.target);
  const res = await fetch('/_nx_a1b2c3d4e5f6', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(Object.fromEntries(fd))
  });
  const data = await res.json();
  if (data.ok) alert('Message sent!');
};
</script>
```

### Действие базы данных

```python
# src/actions/create_user.py
from nexy.decorators import Action
from pydantic import BaseModel
from src.database import get_session
from src.models import User

class CreateUserBody(BaseModel):
    name: str
    email: str

"@Action
def create_user(body: CreateUserBody) -> dict:
    db = next(get_session())
    user = User(name=body.name, email=body.email)
    db.add(user)
    db.commit()
    db.refresh(user)
    return {"id": user.id, "name": user.name}
```

### Действие с обработкой ошибок

```python
# src/actions/delete_item.py
from nexy.decorators import Action
from fastapi import HTTPException
from src.database import get_session

"@Action
def delete_item(item_id: int) -> dict:
    db = next(get_session())
    item = db.get(Item, item_id)
    if not item:
        raise HTTPException(status_code=404, detail="Item not found")
    db.delete(item)
    db.commit()
    return {"deleted": item_id}
```

## Созданный клиент TypeScript

`nx build` или `nx dev` генерирует типобезопасные оболочки TypeScript в `./actions/`:

```typescript
// Generated: ./actions/vote.ts
import { transport } from '"@/nexy/client';

export const vote = async (post_id: string, direction: number): Promise<dict> => {
  return await transport.call('/_nx_a1b2c3d4e5f6', { post_id, direction });
};
```

Каждая сгенерированная функция отражает подпись Python с соответствующими типами TypeScript.

## Лучшие практики

- Сохраняйте функции действия сфокусированными и идемпотентными.
- Проверяйте входные данные внутри действия — рассматривайте их как ненадежные.
- Используйте модели Pydantic для сложных тел запросов.
- Действия выполняются только через POST — для других методов HTTP используйте обработчики маршрутов.
- Используйте охранники или промежуточное программное обеспечение для авторизации.
