# إجراءات الخادم

تتيح لك إجراءات الخادم استدعاء وظائف Python من العميل كنقاط نهاية POST - لا يوجد تسجيل للمسار، ولا يوجد نموذج معياري للتسلسل.

---

## تعريف الإجراء

تزيين أي دالة بـ `"@Action`:

```python
# src/actions/vote.py
from nexy.decorators import Action

"@Action
def vote(post_id: str, direction: int) -> dict:
    return {"success": True, "post_id": post_id, "votes": 42}
```

تتلقى الوظيفة معلمات نص JSON كوسيطات للكلمات الرئيسية. قم بإرجاع أي قيمة قابلة للتسلسل لـ JSON.

---

## مكان وضع ملفات العمل

يمكن أن تكون الإجراءات موجودة **في أي مكان** في مشروعك — `src/actions/`، `src/routes/`، أو مباشرة في الجذر. يقوم `ActionEngine` بفحص دليل المشروع بأكمله عند بدء التشغيل.

```text
my-app/
├── src/
│   └── actions/
│       ├── vote.py        ← "@Action
│       └── comment.py     ← "@Action
├── actions/
│   ├── vote.ts            ← Generated TypeScript client
│   └── comment.ts
```

راجع ["@Action reference](/docs/decorators/action) للتعرف على كيفية عمل الاكتشاف وإنشاء نقطة النهاية.

## أمثلة عملية

### تقديم النموذج

```python
# src/actions/contact.py
from nexy.decorators import Action
from pydantic import BaseModel, EmailStr

class ContactForm(BaseModel):
    name: str
    email: EmailStr
    message: str

"@Action
def submit_contact(data: ContactForm) -> dict:
    # Save to database, send email, etc.
    return {"ok": True, "name": data.name}
```

```nexy

<script>
document.getElementById('contact').onsubmit = async (e) => {
  e.preventDefault();
  const fd = new FormData(e.target);
  const res = await fetch('/_nx_a1b2c3d4e5f6', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(Object.fromEntries(fd))
  });
  const data = await res.json();
  if (data.ok) alert('Message sent!');
};
</script>
```

### عمل قاعدة البيانات

```python
# src/actions/create_user.py
from nexy.decorators import Action
from pydantic import BaseModel
from src.database import get_session
from src.models import User

class CreateUserBody(BaseModel):
    name: str
    email: str

"@Action
def create_user(body: CreateUserBody) -> dict:
    db = next(get_session())
    user = User(name=body.name, email=body.email)
    db.add(user)
    db.commit()
    db.refresh(user)
    return {"id": user.id, "name": user.name}
```

### الإجراء مع معالجة الأخطاء

```python
# src/actions/delete_item.py
from nexy.decorators import Action
from fastapi import HTTPException
from src.database import get_session

"@Action
def delete_item(item_id: int) -> dict:
    db = next(get_session())
    item = db.get(Item, item_id)
    if not item:
        raise HTTPException(status_code=404, detail="Item not found")
    db.delete(item)
    db.commit()
    return {"deleted": item_id}
```

## تم إنشاء عميل TypeScript

`nx build` أو `nx dev` ينشئ أغلفة TypeScript آمنة للنوع في `./actions/`:

```typescript
// Generated: ./actions/vote.ts
import { transport } from '"@/nexy/client';

export const vote = async (post_id: string, direction: number): Promise<dict> => {
  return await transport.call('/_nx_a1b2c3d4e5f6', { post_id, direction });
};
```

تعكس كل وظيفة تم إنشاؤها توقيع Python مع أنواع TypeScript المناسبة.

## أفضل الممارسات

- حافظ على تركيز وظائف العمل وعجزها
- التحقق من صحة المدخلات داخل الإجراء - التعامل معها على أنها غير موثوقة
- استخدام نماذج Pydantic لهيئات الطلب المعقدة
- الإجراءات هي POST فقط - بالنسبة لطرق HTTP الأخرى، استخدم معالجات المسار
- استخدم الحراس أو البرامج الوسيطة للحصول على الترخيص
