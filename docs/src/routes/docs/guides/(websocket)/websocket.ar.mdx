# التواصل في الوقت الحقيقي

يدعم Nexy WebSocket، والأحداث المرسلة من الخادم (SSE)، والاستقصاء الطويل للاتصالات في الوقت الفعلي.

## أي واحد للاستخدام

| ميزة | الأفضل لـ | الاتجاه |
|---------|---------|-----------|
| **ويبسوكيت** | ثنائي الاتجاه، زمن وصول منخفض (الدردشة، الألعاب، التعاون) | العميل ↔ الخادم |
| **سس** | الخادم → أحداث العميل (الإشعارات والموجزات المباشرة) | الخادم → العميل |
| ** الاقتراع الطويل ** | اقتراع بسيط عندما لا يتوفر ما ورد أعلاه | العميل → الخادم |

## ويب سوكيت

اتصال مزدوج الاتجاه عبر اتصال TCP واحد. يقوم Nexy بتعيين اسم الوظيفة/الطريقة `SOCKET` إلى نقطة نهاية Starlette WebSocket.

- [FBR WebSocket](/docs/fbrouters/websocket) — أمثلة التوجيه المستندة إلى الملف
- [Modular WebSocket](/docs/modular/websocket) — أمثلة قائمة على وحدة التحكم مع DI

## الأحداث المرسلة من الخادم (SSE)

خادم أحادي الاتجاه → تدفق العميل عبر HTTP. أخف من WebSocket عندما تحتاج فقط إلى دفع الخادم.

راجع [SSE](/docs/fastapi/sse) للحصول على تفاصيل التنفيذ.

## متى تختار

- **WebSocket**: تطبيقات الدردشة والتعاون المباشر والألعاب والمؤشرات المالية
- **SSE**: الإشعارات المباشرة وتحديثات الموجز وأشرطة التقدم وتدفق السجل
- **الاقتراع الطويل**: خيار احتياطي للبيئات التي تحظر WebSocket (الوكلاء المؤسسيون)
