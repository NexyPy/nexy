# 실시간 소통

Nexy는 실시간 통신을 위해 WebSocket, SSE(Server-Sent Events) 및 롱 폴링을 지원합니다.

## 어느 것을 사용할 것인가

| 기능 | | 방향 |
|---------|----------|------------|
| **웹소켓** | 양방향, 낮은 지연 시간(채팅, 게임, 협업) | 클라이언트 ⇔ 서버 |
| **SSE** | 서버 → 클라이언트 이벤트(알림, 라이브 피드) | 서버 → 클라이언트 |
| **장기 폴링** | 위의 항목을 사용할 수 없는 경우 단순 폴링 | 클라이언트 → 서버 |

## 웹소켓

단일 TCP 연결을 통한 전이중 통신. Nexy는 `SOCKET` 함수/메서드 이름을 Starlette WebSocket 엔드포인트에 매핑합니다.

- [FBR WebSocket](/docs/fbrouters/websocket) — 파일 기반 라우팅 예
- [Modular WebSocket](/docs/modular/websocket) — DI를 사용한 컨트롤러 기반 예제

## 서버에서 보낸 이벤트(SSE)

단방향 서버 → HTTP를 통한 클라이언트 스트리밍. 서버 푸시만 필요한 경우 WebSocket보다 가볍습니다.

구현 세부정보는 [SSE](/docs/fastapi/sse)를 참조하세요.

## 언제 선택해야 할까요?

- **WebSocket**: 채팅 앱, 실시간 협업, 게임, 금융 시세 표시기
- **SSE**: 실시간 알림, 피드 업데이트, 진행률 표시줄, 로그 스트리밍
- **장기 폴링**: WebSocket(기업 프록시)을 차단하는 환경에 대한 대체
