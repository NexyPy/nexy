# Общение в реальном времени

Nexy поддерживает WebSocket, события, отправленные сервером (SSE) и длительный опрос для связи в реальном времени.

## Какой использовать

| Особенность | Лучшее для | Направление |
|---------|----------|-----------|
| **Вебсокет** | Двунаправленный, с низкой задержкой (чат, игры, совместная работа) | Клиент ↔ Сервер |
| **ССЕ** | Сервер → клиентские события (уведомления, прямые трансляции) | Сервер → Клиент |
| **Длительный опрос** | Простой опрос, когда вышеперечисленное недоступно | Клиент → Сервер |

## Вебсокет

Полнодуплексная связь через одно TCP-соединение. Nexy сопоставляет имя функции/метода `SOCKET` с конечной точкой Starlette WebSocket.

- [FBR WebSocket](/docs/fbrouters/websocket) — примеры маршрутизации на основе файлов.
- [Modular WebSocket](/docs/modular/websocket) — примеры на базе контроллера с DI

## События, отправленные сервером (SSE)

Однонаправленный сервер → клиентская потоковая передача по HTTP. Легче, чем WebSocket, когда вам нужен только сервер.

Подробности реализации см. в [SSE](/docs/fastapi/sse).

## Когда выбирать

- **WebSocket**: приложения для чата, совместная работа в реальном времени, игры, финансовые тикеры.
- **SSE**: живые уведомления, обновления каналов, индикаторы выполнения, потоковая передача журналов.
- **Длинный опрос**: запасной вариант для сред, блокирующих WebSocket (корпоративные прокси-серверы).
