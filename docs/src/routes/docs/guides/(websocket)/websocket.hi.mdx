# वास्तविक समय संचार

नेक्सी वास्तविक समय संचार के लिए वेबसॉकेट, सर्वर-सेंटेड इवेंट्स (एसएसई) और लॉन्ग-पोलिंग का समर्थन करता है।

## कौन सा उपयोग करना है

| फ़ीचर | के लिए सर्वश्रेष्ठ | दिशा |
|---------|----------|-------|
| **वेबसॉकेट** | द्विदिश, कम-विलंबता (चैट, गेम, सहयोग) | क्लाइंट ↔ सर्वर |
| **एसएसई** | सर्वर → क्लाइंट इवेंट (सूचनाएं, लाइव फ़ीड) | सर्वर → क्लाइंट |
| **लंबे मतदान** | उपरोक्त उपलब्ध न होने पर सरल मतदान | क्लाइंट → सर्वर |

## वेबसॉकेट

एकल टीसीपी कनेक्शन पर पूर्ण-डुप्लेक्स संचार। नेक्सी `SOCKET` फ़ंक्शन/विधि नाम को स्टारलेट वेबसॉकेट एंडपॉइंट पर मैप करता है।

- [FBR WebSocket](/docs/fbrouters/websocket) — फ़ाइल-आधारित रूटिंग उदाहरण
- [Modular WebSocket](/docs/modular/websocket) - DI के साथ नियंत्रक-आधारित उदाहरण

## सर्वर-भेजे गए इवेंट (एसएसई)

यूनिडायरेक्शनल सर्वर → HTTP पर क्लाइंट स्ट्रीमिंग। जब आपको केवल सर्वर पुश की आवश्यकता हो तो WebSocket से हल्का।

कार्यान्वयन विवरण के लिए [SSE](/docs/fastapi/sse) देखें।

## कब चुनना है

- **वेबसॉकेट**: चैट ऐप्स, लाइव सहयोग, गेमिंग, वित्तीय टिकर
- **एसएसई**: लाइव सूचनाएं, फ़ीड अपडेट, प्रगति बार, लॉग स्ट्रीमिंग
- **लंबे मतदान**: वेबसॉकेट (कॉर्पोरेट प्रॉक्सी) को अवरुद्ध करने वाले वातावरण के लिए फ़ॉलबैक
