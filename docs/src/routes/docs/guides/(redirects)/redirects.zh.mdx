# 重定向

使用 FastAPI 的 `RedirectResponse` 将传入请求重定向到其他 URL。

---

## 基本重定向
```python
---
from fastapi.responses import RedirectResponse

def GET():
    return RedirectResponse("/login")
---
```
```python
from fastapi.responses import RedirectResponse
from nexy.decorators import Controller

"@Controller("/admin")
class AdminController:
    def GET(self):
        return RedirectResponse("/login")
```
## 带状态码
```python
---
from fastapi.responses import RedirectResponse

def GET():
    # 301 — Permanent (tells browsers to cache)
    return RedirectResponse("/new-page", status_code=301)
---
```
```python
from fastapi.responses import RedirectResponse
from nexy.decorators import Controller

"@Controller("/old-path")
class RedirectController:
    def GET(self):
        return RedirectResponse("/new-path", status_code=308)
```
## 有条件重定向
```python
---
from fastapi.responses import RedirectResponse

def GET(request):
    if not request.user.is_authenticated:
        return RedirectResponse("/login")
    return "<h1>Dashboard</h1>"
---
```
```python
from fastapi.responses import RedirectResponse
from nexy.decorators import Controller

"@Controller("/dashboard")
class DashboardController:
    def GET(self, request):
        if not request.user.is_authenticated:
            return RedirectResponse("/login")
        return {"admin": True}
```
## 状态码参考

|代码|名称 |使用案例 |
|------|------|----------|
| 301 | 301永久搬家 |永久 URL 更改 — 浏览器缓存它 |
| 302 | 302找到（默认）|临时重定向 |
| 307 | 307临时重定向 |类似 302 但保留 HTTP 方法 |
| 308 | 308永久重定向 |类似 301 但保留 HTTP 方法 |

## 常见模式

- **身份验证重定向**：未经身份验证的用户 → `/login`
- **旧 URL**：旧路径 → 新路径 (301)
- **提交后重定向**：表单 POST 之后 → 成功页面 (303)
- **区域设置重定向**：`/` → `/{locale}/` 基于浏览器语言
