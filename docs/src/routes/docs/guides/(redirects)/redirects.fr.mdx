# Redirections

Redirigez les requêtes entrantes vers d'autres URL à l'aide du `RedirectResponse` de FastAPI.

---

## Redirection de base
```python
---
from fastapi.responses import RedirectResponse

def GET():
    return RedirectResponse("/login")
---
```
```python
from fastapi.responses import RedirectResponse
from nexy.decorators import Controller

"@Controller("/admin")
class AdminController:
    def GET(self):
        return RedirectResponse("/login")
```
## Avec code d'état
```python
---
from fastapi.responses import RedirectResponse

def GET():
    # 301 — Permanent (tells browsers to cache)
    return RedirectResponse("/new-page", status_code=301)
---
```
```python
from fastapi.responses import RedirectResponse
from nexy.decorators import Controller

"@Controller("/old-path")
class RedirectController:
    def GET(self):
        return RedirectResponse("/new-path", status_code=308)
```
## Redirection conditionnelle
```python
---
from fastapi.responses import RedirectResponse

def GET(request):
    if not request.user.is_authenticated:
        return RedirectResponse("/login")
    return "<h1>Dashboard</h1>"
---
```
```python
from fastapi.responses import RedirectResponse
from nexy.decorators import Controller

"@Controller("/dashboard")
class DashboardController:
    def GET(self, request):
        if not request.user.is_authenticated:
            return RedirectResponse("/login")
        return {"admin": True}
```
## Référence du code d'état

| Codes | Nom | Cas d'utilisation |
|------|------|----------|
| 301 | Déménagé définitivement | Changement d'URL permanent - les navigateurs le mettent en cache |
| 302 | Trouvé (par défaut) | Redirection temporaire |
| 307 | Redirection temporaire | Comme 302 mais préserve la méthode HTTP |
| 308 | Redirection permanente | Comme 301 mais préserve la méthode HTTP |

## Modèles courants

- **Redirection d'authentification** : utilisateurs non authentifiés → `/login`
- **Anciennes URL** : anciens chemins → nouveaux chemins (301)
- **Redirection post-soumission** : après le formulaire POST → page de réussite (303)
- **Redirection locale** : `/` → `/{locale}/` en fonction de la langue du navigateur
