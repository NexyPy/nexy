# स्थिर फ़ाइलें

नेक्सी आपके प्रोजेक्ट रूट पर `public/` निर्देशिका से स्थिर फ़ाइलें परोसता है।

## यह कैसे काम करता है

`public/` में रखी गई कोई भी फ़ाइल रूट URL पथ पर प्रस्तुत की जाती है:

```text
public/
├── logo.svg           →  /logo.svg
├── images/
│   └── hero.jpg       →  /images/hero.jpg
├── fonts/
│   └── inter.woff2    →  /fonts/inter.woff2
└── robots.txt         →  /robots.txt
```

किसी कॉन्फ़िगरेशन की आवश्यकता नहीं है. `public/` में फ़ाइलें स्वचालित रूप से परोसी जाती हैं।

## संपत्ति निर्देशिका

संकलित परिसंपत्तियों (CSS, Vite से JS) के लिए, `assets/` निर्देशिका का उपयोग करें या आउटपुट को `vite.config.ts` में कॉन्फ़िगर करें। नेक्सी इन्हें `/assets/` पर माउंट करता है।

## स्थिर फ़ाइलों का संदर्भ देना

`.nexy` टेम्प्लेट में:

```nexy
<img src="/logo.svg" alt="Logo" />
<link rel="stylesheet" href="/styles/global.css" />
```

पायथन फ्रंटमैटर या रूट हैंडलर में, पथ प्रोजेक्ट रूट से संबंधित होते हैं।

## उत्पादन

`nx build` के दौरान, `public/` निर्देशिका को `__nexy__/public/` में कॉपी किया जाता है। आपका उत्पादन सर्वर इन फ़ाइलों को सीधे परोसता है - किसी संकलन की आवश्यकता नहीं है।
