# Обработка ошибок

Nexy предоставляет встроенные страницы ошибок 404 и 500. Переопределите их с помощью пользовательских файлов `.nexy`.

## Страницы ошибок по умолчанию

Если страница не найдена (404) или возникает необработанная ошибка (500), Nexy возвращает простую HTML-страницу со стилем.

## Пользовательские страницы ошибок

Поместите файлы `error.nexy` или `notfound.nexy` в любой каталог маршрута, чтобы переопределить страницы ошибок для этой области:

```
src/routes/
+-- admin/
|   +-- notfound.nexy   # Custom 404 for /admin/*
|   +-- error.nexy      # Custom 500 for /admin/*
+-- notfound.nexy       # Global custom 404
+-- error.nexy          # Global custom 500
```

### Пример: `notfound.nexy`

```nexy
---
---
<main class="grid min-h-full place-items-center px-6 py-24 sm:py-32">
  <div class="text-center">
    <p class="text-base font-semibold text-yellow-500">404</p>
    <h1 class="mt-4 text-3xl font-bold tracking-tight">Page not found</h1>
    <p class="mt-6 text-base leading-7 text-gray-600">
      Sorry, we couldn't find the page you're looking for.
    </p>
    <a href="/" class="mt-10 text-sm font-semibold text-yellow-500 hover:text-yellow-400">
      Go back home →
    </a>
  </div>
</main>
```

### Пример: `error.nexy`

```nexy
---
---
<main class="grid min-h-full place-items-center px-6 py-24 sm:py-32">
  <div class="text-center">
    <p class="text-base font-semibold text-red-500">500</p>
    <h1 class="mt-4 text-3xl font-bold tracking-tight">Something went wrong</h1>
    <p class="mt-6 text-base leading-7 text-gray-600">
      Please try again later.
    </p>
    <a href="/" class="mt-10 text-sm font-semibold text-yellow-500 hover:text-yellow-400">
      Go back home →
    </a>
  </div>
</main>
```

## Страницы с ошибками области действия

Страницы ошибок, размещенные в подкаталогах, применяются только к маршрутам внутри этого каталога. Это позволяет вам иметь разные страницы ошибок для разных разделов вашего сайта:

```
src/routes/
+-- admin/
|   +-- notfound.nexy   # /admin/* — "Admin page not found"
+-- blog/
|   +-- notfound.nexy   # /blog/* — "Blog post not found"
+-- notfound.nexy       # All other routes
```
