# 데이터 로딩

Nexy는 데이터 로딩을 위한 두 가지 레이어를 제공합니다: `.nexy` 프론트매터의 **컴파일 시간**과 후크를 통한 **요청 시간**.

## 컴파일 타임 데이터(머리말)

`.nexy` 파일의 `---` 블록은 컴파일 타임에 실행되는 Python입니다. 여기에 정의된 변수는 템플릿에서 사용할 수 있습니다.

```nexy
---
import json
from src.data import get_items
items = get_items()
total = len(items)
---
<ul>
{% for item in items %}
  <li>{{ item.name }}</li>
{% endfor %}
</ul>
<p>Total: {{ total }} items</p>
```

JSON 데이터를 직접 가져올 수도 있습니다.

```nexy
---
import "./data.json" as data
---
<pre>{{ data | tojson }}</pre>
```

## 요청 시간 데이터(후크)

후크는 HTTP 요청 중에 실행되며 요청 컨텍스트에 액세스할 수 있습니다.

```python
from nexy import useQuery, useSearchParams, useSession, useCookies

# URL path parameters (from [param] in filename)
id = useQuery("id")

# Query string parameters
params = useSearchParams()  # {"page": "1", "sort": "asc"}

# Session data (requires session middleware)
user = useSession().get("user")

# Cookies
token = useCookies().get("token")
```

## API 경로 핸들러

데이터베이스 또는 외부 API에서 제공되는 데이터의 경우 `.py` 파일에 전용 API 핸들러를 만듭니다.

```python
# src/routes/api/items.py
from myapp.db import get_items

def GET():
    return get_items()

def POST(data: dict):
    # data is parsed from request body automatically
    return {"created": True, "id": data.get("id")}
```

그런 다음 `fetch` 또는 서버측 포함을 통해 페이지에서 호출하세요.

## `useViews`에 동적 포함

요청 시 현재 페이지 내에서 다른 페이지의 구성 요소를 렌더링합니다.

```python
from nexy import useViews
sidebar = useViews("/components/sidebar.nexy", {"active": "docs"})
```

템플릿에 포함할 수 있는 `HTMLResponse`를 반환합니다.
