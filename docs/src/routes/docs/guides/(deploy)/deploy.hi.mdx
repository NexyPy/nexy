#तैनाती

`nx build` आपके ऐप को संकलित करता है, `nx start` इसे उत्पादन में पेश करता है। झंडों के लिए [CLI build](/docs/cli/build) और [CLI start](/docs/cli/start) देखें।

## डॉकर

```dockerfile
FROM python:3.13-slim
WORKDIR /app
COPY . .
RUN pip install nexy && nx build
CMD ["nx", "start"]
```

---

## पर्यावरण चर

| परिवर्तनशील | डिफ़ॉल्ट | विवरण |
|---|---|---|
| `NEXY_PORT` | `3000` | सर्वर पोर्ट |
| `NEXY_HOST` | `0.0.0.0` | बाइंड पता |
| `NEXY_DEBUG` | `false` | डिबग मोड |
| `NEXY_INLINE_CLIENT` | `false` | HTML में इनलाइन CSS/JS |

---

## प्लेटफ़ॉर्म गाइड

### वीपीएस

```bash
uv sync
nx build
nx start --host 0.0.0.0 --port 80
```

### क्लाउड प्रदाता

नेक्सी किसी भी प्लेटफ़ॉर्म पर तैनात है जो पायथन एएसजीआई ऐप्स का समर्थन करता है:

- **रेलवे** - प्रोकफाइल के माध्यम से `nx start` का स्वतः पता लगाता है
- **Fly.io** — Dockerfile में `CMD ["nx", "start"]` का उपयोग करें
- **रेंडर** - स्टार्ट कमांड को `nx start` पर सेट करें
- **हेट्ज़नर / डिजिटलओशन** - डॉकर या सिस्टमडी सेवा

---

## स्थैतिक निर्यात

पूरी तरह से स्थिर साइटों के लिए, नेक्सी निर्माण के दौरान प्रत्येक पृष्ठ को `__nexy__/static/` पर प्री-रेंडर कर सकता है। किसी भी स्थिर फ़ाइल सर्वर (Nginx, Caddy, S3, Cloudflare Pages) के साथ परोसें।
