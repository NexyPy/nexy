#CSS وجافا سكريبت

يمنحك Nexy الحرية الكاملة في التصميم والبرمجة النصية. تعمل كل الأساليب - التجميع المضمن أو المستورد أو المنفعة أولاً أو التجميع المخصص.

## نهج CSS

### 1. قم بتضمين `<style>` في قوالب `.nexy`

قم بإضافة علامة `<style>` مباشرة في قسم القالب. تكون الأنماط عامة بشكل افتراضي - قم بنطاقها يدويًا باستخدام BEM أو سمات البيانات أو فئات الأداة المساعدة.

```nexy
---
---
<div class="card">
  <slot />
</div>

<style>
.card {
  padding: 1rem;
  border: 1px solid #e2e8f0;
  border-radius: 8px;
}
.card-title {
  font-weight: 600;
  font-size: 1.25rem;
}
</style>
```

### 2. استيراد CSS خارجي عبر `__Import`

كل ملف `.nexy` يتوفر تلقائيًا `__Import` (يتم حقنه بواسطة المترجم). استخدمه لتضمين CSS أو JSON أو الصور الخارجية.

```nexy
---
css_block = __Import("/styles/global.css", "", "")()
---
<div class="wrapper">
  {{ css_block }}
  <main>...</main>
</div>
```

`__Import(path, framework, symbol)` عمليات الإرسال بامتداد الملف:

| ملحق | عوائد |
|-----------|--------|
| `.css` | سلسلة `<style>...</style>` مع محتوى الملف المضمن |
| `.png`، `.jpg`، `.svg`، إلخ. | سلسلة URI للبيانات base64 |
| `.json` | بيانات JSON التي تم تحليلها |
| `.tsx`، `.vue`، `.svelte`، إلخ. | مجمّع مكون العميل (علامة `<ncc>`) |

بالنسبة لـ CSS، لا يتم استخدام الوسيطتين الثانية والثالثة - قم بتمرير سلاسل فارغة.

### 3. الريح الخلفية CSS

يتضمن Nexy دعم Tailwind CSS عند تهيئة المشروع. تتم معالجة فئات الأداة المساعدة في القالب الخاص بك بشكل طبيعي.

```nexy
---
padding:prop[str] = "p-4"
---
<div class="rounded-lg shadow-md {{ padding }}">
  <slot />
</div>
```

قم بتكوين Tailwind في `tailwind.config.*` أو `nexyconfig.py`.

### 4. تجميع Vite CSS

عند تمكين Vite (`useVite: true` في التكوين)، يمكنك استيراد ملفات `.css` من مكونات الواجهة الأمامية الخاصة بك وسيتم تجميعها مع مسار Vite - بما في ذلك وحدات PostCSS وCSS وHMR.

## جافا سكريبت من جانب العميل

أضف علامات `<script>` مباشرة في قوالب `.nexy`:

```nexy
---
---
<button id="greet-btn">Greet</button>

<script>
document.getElementById('greet-btn').addEventListener('click', () => {
  alert('Hello from Nexy!')
})
</script>
```

## تايب سكريبت

مع تمكين Vite، يتم تجميع ملفات `.ts` تلقائيًا. قم باستيرادها في مكونات الواجهة الأمامية لديك أو عبر علامات `<script>`.

```typescript
// src/scripts/utils.ts
export function greet(name: string): string {
  return `Hello ${name}`
}
```

يتم تقديم البرامج النصية في `public/` بشكل ثابت. تتم معالجة البرامج النصية في `src/` بواسطة Vite (إذا تم تمكينها) أو يتم تقديمها بشكل أولي في التطوير.

## التجميع

| الوضع | سي اس اس | شبيبة/TS |
|------|-----|-------|
| **تنمية** | يقدم نيئًا أو عبر Vite HMR | يقدم نيئًا أو عبر Vite HMR |
| **الإنتاج (`nexy build`)** | مضمنة أو مجمعة Vite | تم تصغيرها وتجميعها بواسطة Vite |

عند إيقاف تشغيل Vite، يتم تضمين علامات CSS في `<style>` مباشرة في مخرجات HTML. عند تشغيل Vite، تمر جميع الأصول عبر مسار إنشاء Vite للحصول على التجميع الأمثل وتقسيم التعليمات البرمجية.
