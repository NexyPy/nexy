# सीएसएस और जावास्क्रिप्ट

नेक्सी आपको स्टाइलिंग और स्क्रिप्टिंग पर पूरी आजादी देता है। हर दृष्टिकोण काम करता है - इनलाइन, आयातित, उपयोगिता-प्रथम, या कस्टम बंडलिंग।

## सीएसएस दृष्टिकोण

### 1. `.nexy` टेम्पलेट्स में इनलाइन `<style>`

टेम्प्लेट अनुभाग में सीधे `<style>` टैग जोड़ें। शैलियाँ डिफ़ॉल्ट रूप से वैश्विक होती हैं - उन्हें BEM, डेटा विशेषताओं या उपयोगिता वर्गों के साथ मैन्युअल रूप से स्कोप करें।

```nexy
---
---
<div class="card">
  <slot />
</div>

<style>
.card {
  padding: 1rem;
  border: 1px solid #e2e8f0;
  border-radius: 8px;
}
.card-title {
  font-weight: 600;
  font-size: 1.25rem;
}
</style>
```

### 2. `__Import` के माध्यम से बाहरी सीएसएस आयात करें

प्रत्येक `.nexy` फ़ाइल में स्वचालित रूप से `__Import` उपलब्ध होता है (कंपाइलर द्वारा इंजेक्ट किया जाता है)। बाहरी CSS, JSON, या छवियों को इनलाइन करने के लिए इसका उपयोग करें।

```nexy
---
css_block = __Import("/styles/global.css", "", "")()
---
<div class="wrapper">
  {{ css_block }}
  <main>...</main>
</div>
```

फ़ाइल एक्सटेंशन द्वारा `__Import(path, framework, symbol)` प्रेषण:

| विस्तार | रिटर्न |
|----|----|
| `.css` | फ़ाइल सामग्री इनलाइन के साथ एक `<style>...</style>` स्ट्रिंग |
| `.png`, `.jpg`, `.svg`, आदि | एक बेस64 डेटा यूआरआई स्ट्रिंग |
| `.json` | पार्स किया गया JSON डेटा |
| `.tsx`, `.vue`, `.svelte`, आदि | एक क्लाइंट घटक रैपर (`<ncc>` टैग) |

सीएसएस के लिए, दूसरे और तीसरे तर्क अप्रयुक्त हैं - खाली स्ट्रिंग पास करें।

### 3. टेलविंड सीएसएस

नेक्सी में प्रोजेक्ट आरंभीकरण के समय टेलविंड सीएसएस समर्थन शामिल है। आपके टेम्पलेट में उपयोगिता कक्षाएं सामान्य रूप से संसाधित की जाती हैं।

```nexy
---
padding:prop[str] = "p-4"
---
<div class="rounded-lg shadow-md {{ padding }}">
  <slot />
</div>
```

टेलविंड को `tailwind.config.*` या `nexyconfig.py` में कॉन्फ़िगर करें।

### 4. वाइट सीएसएस बंडलिंग

जब Vite सक्षम होता है (कॉन्फ़िगरेशन में `useVite: true`), तो आप अपने फ्रंटएंड घटकों से `.css` फ़ाइलें आयात कर सकते हैं और उन्हें Vite की पाइपलाइन के साथ बंडल किया जाएगा - जिसमें PostCSS, CSS मॉड्यूल और HMR शामिल हैं।

## क्लाइंट-साइड जावास्क्रिप्ट

`<script>` टैग सीधे `.nexy` टेम्प्लेट में जोड़ें:

```nexy
---
---
<button id="greet-btn">Greet</button>

<script>
document.getElementById('greet-btn').addEventListener('click', () => {
  alert('Hello from Nexy!')
})
</script>
```

## टाइपस्क्रिप्ट

Vite सक्षम होने पर, `.ts` फ़ाइलें स्वचालित रूप से संकलित हो जाती हैं। उन्हें अपने फ्रंटएंड घटकों में या `<script>` टैग के माध्यम से आयात करें।

```typescript
// src/scripts/utils.ts
export function greet(name: string): string {
  return `Hello ${name}`
}
```

`public/` में स्क्रिप्ट स्थिर रूप से परोसी जाती हैं। `src/` में स्क्रिप्ट्स को Vite द्वारा संसाधित किया जाता है (यदि सक्षम है) या विकास में कच्ची परोसी जाती है।

## बंडलिंग

| मोड | सीएसएस | जेएस/टीएस |
|------|-----|-------|
| **विकास** | कच्चा या वाइट एचएमआर के माध्यम से परोसा गया | कच्चा या वाइट एचएमआर के माध्यम से परोसा गया |
| **उत्पादन (`nexy build`)** | इनलाइन या वाइट-बंडल | वाइट द्वारा छोटा और बंडल किया गया |

जब Vite बंद होता है, तो `<style>` टैग में CSS सीधे HTML आउटपुट में इनलाइन हो जाता है। जब Vite चालू होता है, तो सभी संपत्तियां इष्टतम बंडलिंग और कोड विभाजन के लिए Vite की बिल्ड पाइपलाइन से गुजरती हैं।
