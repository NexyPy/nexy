# CSS и JavaScript

Nexy дает вам полную свободу в выборе стилей и написании сценариев. Работает каждый подход — встроенный, импортированный, ориентированный на утилиты или индивидуальный пакет.

## CSS-подходы

### 1. Встроенные `<style>` в шаблонах `.nexy`

Добавьте тег `<style>` непосредственно в раздел шаблона. По умолчанию стили являются глобальными — их можно определить вручную с помощью БЭМ, атрибутов данных или служебных классов.

```nexy
---
---
<div class="card">
  <slot />
</div>

<style>
.card {
  padding: 1rem;
  border: 1px solid #e2e8f0;
  border-radius: 8px;
}
.card-title {
  font-weight: 600;
  font-size: 1.25rem;
}
</style>
```

### 2. Импортируйте внешний CSS через `__Import`

В каждом файле `.nexy` автоматически доступен `__Import` (вставленный компилятором). Используйте его для встраивания внешнего CSS, JSON или изображений.

```nexy
---
css_block = __Import("/styles/global.css", "", "")()
---
<div class="wrapper">
  {{ css_block }}
  <main>...</main>
</div>
```

`__Import(path, framework, symbol)` отправляет по расширению файла:

| Расширение | Возврат |
|-----------|---------|
| `.css` | Строка `<style>...</style>` со встроенным содержимым файла |
| `.png`, `.jpg`, `.svg` и т. д. | Строка URI данных base64 |
| `.json` | Проанализированные данные JSON |
| `.tsx`, `.vue`, `.svelte` и т. д. | Обертка клиентского компонента (тег `<ncc>`) |

Для CSS второй и третий аргументы не используются — передайте пустые строки.

### 3. CSS для попутного ветра

Nexy включает поддержку Tailwind CSS при инициализации проекта. Служебные классы в вашем шаблоне обрабатываются нормально.

```nexy
---
padding:prop[str] = "p-4"
---
<div class="rounded-lg shadow-md {{ padding }}">
  <slot />
</div>
```

Настройте Tailwind в `tailwind.config.*` или `nexyconfig.py`.

### 4. Объединение CSS Vite

Когда Vite включен (`useVite: true` в конфигурации), вы можете импортировать файлы `.css` из компонентов внешнего интерфейса, и они будут включены в конвейер Vite, включая PostCSS, модули CSS и HMR.

## Клиентский JavaScript

Добавьте теги `<script>` непосредственно в шаблоны `.nexy`:

```nexy
---
---
<button id="greet-btn">Greet</button>

<script>
document.getElementById('greet-btn').addEventListener('click', () => {
  alert('Hello from Nexy!')
})
</script>
```

## Типскрипт

При включенном Vite файлы `.ts` компилируются автоматически. Импортируйте их в компоненты внешнего интерфейса или с помощью тегов `<script>`.

```typescript
// src/scripts/utils.ts
export function greet(name: string): string {
  return `Hello ${name}`
}
```

Скрипты в `public/` обслуживаются статически. Скрипты в `src/` обрабатываются Vite (если включено) или используются в сыром виде при разработке.

## Объединение

| Режим | CSS | JS/TS |
|------|-----|-------|
| **Разработка** | Подается в сыром виде или через Vite HMR | Подается в сыром виде или через Vite HMR |
| **Производство (`nexy build`)** | Встроенный или в комплекте с Vite | Минимизирован и собран Vite |

Когда Vite отключен, CSS в тегах `<style>` встраивается непосредственно в вывод HTML. Когда Vite включен, все ресурсы проходят через конвейер сборки Vite для оптимального объединения и разделения кода.
