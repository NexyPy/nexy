# usePathname

현재 URL 경로를 문자열로 반환합니다.

```python
from nexy import usePathname

pathname = usePathname()
```

---

## 반환 값

`str` — 현재 요청 URL의 경로 구성 요소(예: `/docs/hooks/usePathname`).

---

## 예

```nexy
---
from nexy import usePathname
path = usePathname()
---
<nav class="breadcrumb">
    {% set segments = path.strip('/').split('/') %}
    {% for seg in segments %}
        <span>/ {{ seg }}</span>
    {% endfor %}
</nav>
```

---

## 사용 참고사항

- `.nexy` 및 `.mdx` 앞부분에서 사용 가능
- `request.url.path`를 통해 `.py` 경로 핸들러에서도 사용 가능
- 경로만 반환 — 쿼리 문자열 없음, 조각 없음
