# 후크

후크는 `.nexy` 구성 요소 및 레이아웃 내부의 요청 컨텍스트 및 브라우저 상태에 대한 액세스를 제공하는 반응 기능입니다. 최신 프런트엔드 프레임워크의 개념을 반영하지만 서버에서 실행됩니다.

모든 후크는 `nexy`에서 가져옵니다.

```python
from nexy import usePathname, useSearchParams, useRouter
```

## 사용 가능한 후크

- [usePathname](/docs/hooks/usePathname) — 현재 URL 경로
- [useSearchParams](/docs/hooks/useSearchParams) — 쿼리 문자열 매개변수
- [useRouter](/docs/hooks/useRouter) — 프로그래밍 방식 탐색
- [useQuery](/docs/hooks/useQuery) — 구문 분석된 쿼리 매개변수
- [useSession](/docs/hooks/useSession) — 세션 데이터 액세스
- [useCookies](/docs/hooks/useCookies) — 쿠키 읽기/쓰기
- [useToc](/docs/hooks/useToc) — 목차 추출
- [useViews](/docs/hooks/useViews) — 컴포저블 뷰 관리
