# useSearchParams

Renvoie les paramètres de requête d'URL actuels sous forme de dictionnaire.

```python
from nexy import useSearchParams

params = useSearchParams()
```

---

## Valeur de retour

`dict` — paramètres de requête à partir de l'URL de la requête (par exemple `{"q": "nexy", "page": "2"}`).

---

## Exemple

```nexy
---
from nexy import useSearchParams
params = useSearchParams()
search = params.get("q", "")
page = int(params.get("page", "1"))
---
<h1>Search: {{ search }}</h1>
<p>Page {{ page }}</p>
```

---

## Méthodes

Le dict renvoyé prend en charge les opérations de dictionnaire standard : `.get(key, default)`, `.keys()`, `.items()`.

---

## Notes d'utilisation

- Toutes les valeurs sont des chaînes — convertissez avec `int()`, `bool()`, etc.
- Pour les gestionnaires d'API, utilisez plutôt l'injection de paramètres natifs de FastAPI
