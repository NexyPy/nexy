# useToc

Generates an HTML table of contents from the current page's headings.

```python
from nexy import useToc

toc_html = useToc()
toc_html = useToc(depth_range="1-4")
```

---

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `depth_range` | `str` | `"2-6"` | Heading levels to include (e.g. `"2-4"` for h2 through h4) |

---

## Return value

`str` — HTML string of the table of contents, or empty string if no headings.

---

## Example

```nexy
---
from nexy import useToc
toc = useToc()
---
<aside class="toc">
    <h3>On this page</h3>
    {{ toc | safe }}
</aside>
```

---

## Usage notes

- Parses markdown headings from the rendered page content
- Returns empty string for pages without headings
- Depth range format: `"2-6"` means h2 through h6, `"1-3"` means h1 through h3
