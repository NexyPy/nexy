#استخدامToc

يقوم بإنشاء جدول محتويات HTML من عناوين الصفحة الحالية.

```python
from nexy import useToc

toc_html = useToc()
toc_html = useToc(depth_range="1-4")
```

---

## المعلمات

| المعلمة | اكتب | الافتراضي | الوصف |
|-----------|------|--------|-------------|
| `depth_range` | `str` | `"2-6"` | مستويات العناوين المراد تضمينها (على سبيل المثال `"2-4"` من h2 إلى h4) |

---

## القيمة المرتجعة

`str` — سلسلة HTML لجدول المحتويات، أو سلسلة فارغة في حالة عدم وجود عناوين.

---

## مثال

```nexy
---
from nexy import useToc
toc = useToc()
---
<aside class="toc">
    <h3>On this page</h3>
    {{ toc | safe }}
</aside>
```

---

## ملاحظات الاستخدام

- يوزع عناوين تخفيض السعر من محتوى الصفحة المقدمة
- إرجاع سلسلة فارغة للصفحات بدون عناوين
- تنسيق نطاق العمق: `"2-6"` يعني h2 إلى h6، `"1-3"` يعني h1 إلى h3
