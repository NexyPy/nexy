# useToc

現在のページの見出しから HTML 目次を生成します。

```python
from nexy import useToc

toc_html = useToc()
toc_html = useToc(depth_range="1-4")
```

---

## パラメータ

|パラメータ |タイプ |デフォルト |説明 |
|----------|------|-----------|---------------|
| `depth_range` | `str` | `"2-6"` |含める見出しレベル (例: h2 ～ h4 の `"2-4"`) |

---

## 戻り値

`str` — 目次の HTML 文字列、または見出しがない場合は空の文字列。

 - -

＃＃ 例

```nexy
---
from nexy import useToc
toc = useToc()
---
<aside class="toc">
    <h3>On this page</h3>
    {{ toc | safe }}
</aside>
```

---

## 使用上の注意

- レンダリングされたページコンテンツからマークダウン見出しを解析します
- 見出しのないページの場合は空の文字列を返します。
- 深度範囲の形式: `"2-6"` は h2 ～ h6 を意味し、`"1-3"` は h1 ～ h3 を意味します
