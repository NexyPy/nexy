# useToc

현재 페이지의 제목에서 HTML 목차를 생성합니다.

```python
from nexy import useToc

toc_html = useToc()
toc_html = useToc(depth_range="1-4")
```

---

## 매개변수

| 매개변수 | 유형 | 기본값 | 설명 |
|------------|------|---------|-------------|
| `depth_range` | `str` | `"2-6"` | 포함할 제목 수준(예: h2에서 h4까지의 경우 `"2-4"`) |

---

## 반환 값

`str` — 목차의 HTML 문자열 또는 제목이 없는 경우 빈 문자열입니다.

---

## 예

```nexy
---
from nexy import useToc
toc = useToc()
---
<aside class="toc">
    <h3>On this page</h3>
    {{ toc | safe }}
</aside>
```

---

## 사용 참고사항

- 렌더링된 페이지 콘텐츠에서 마크다운 제목을 구문 분석합니다.
- 제목이 없는 페이지의 경우 빈 문자열을 반환합니다.
- 깊이 범위 형식: `"2-6"`는 h2~h6을 의미하고, `"1-3"`는 h1~h3을 의미합니다.
