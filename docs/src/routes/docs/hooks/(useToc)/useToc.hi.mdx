# यूज़टोक

वर्तमान पृष्ठ के शीर्षकों से सामग्री की एक HTML तालिका तैयार करता है।

```python
from nexy import useToc

toc_html = useToc()
toc_html = useToc(depth_range="1-4")
```

---

## पैरामीटर्स

| पैरामीटर | प्रकार | डिफ़ॉल्ट | विवरण |
|----|------|------|----|
| `depth_range` | `str` | `"2-6"` | शामिल करने योग्य शीर्षक स्तर (उदा. h2 से h4 के लिए `"2-4"`) |

---

## वापसी मूल्य

`str` - सामग्री तालिका की HTML स्ट्रिंग, या यदि कोई शीर्षक नहीं है तो खाली स्ट्रिंग।

---

## उदाहरण

```nexy
---
from nexy import useToc
toc = useToc()
---
<aside class="toc">
    <h3>On this page</h3>
    {{ toc | safe }}
</aside>
```

---

## उपयोग नोट्स

- प्रस्तुत पृष्ठ सामग्री से मार्कडाउन शीर्षकों को पार्स करता है
- बिना शीर्षक वाले पृष्ठों के लिए खाली स्ट्रिंग लौटाता है
- गहराई सीमा प्रारूप: `"2-6"` का अर्थ है h2 से h6, `"1-3"` का अर्थ है h1 से h3
