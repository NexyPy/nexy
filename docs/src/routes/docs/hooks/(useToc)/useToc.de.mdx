# useToc

Erstellt ein HTML-Inhaltsverzeichnis aus den Überschriften der aktuellen Seite.

```python
from nexy import useToc

toc_html = useToc()
toc_html = useToc(depth_range="1-4")
```

---

## Parameter

| Parameter | Geben Sie | ein Standard | Beschreibung |
|-----------|------|---------|-------------|
| `depth_range` | `str` | `"2-6"` | Einzuschließende Überschriftenebenen (z. B. `"2-4"` für h2 bis h4) |

---

## Rückgabewert

`str` – HTML-Zeichenfolge des Inhaltsverzeichnisses oder leere Zeichenfolge, wenn keine Überschriften vorhanden sind.

---

## Beispiel

```nexy
---
from nexy import useToc
toc = useToc()
---
<aside class="toc">
    <h3>On this page</h3>
    {{ toc | safe }}
</aside>
```

---

## Nutzungshinweise

– Analysiert Markdown-Überschriften aus dem gerenderten Seiteninhalt
– Gibt eine leere Zeichenfolge für Seiten ohne Überschriften zurück
- Tiefenbereichsformat: `"2-6"` bedeutet h2 bis h6, `"1-3"` bedeutet h1 bis h3
