# использоватьТок

Генерирует оглавление в формате HTML из заголовков текущей страницы.

```python
from nexy import useToc

toc_html = useToc()
toc_html = useToc(depth_range="1-4")
```

---

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|-----------|------|---------|-------------|
| `depth_range` | `str` | `"2-6"` | Уровни заголовков, которые необходимо включить (например, `"2-4"` для h2–h4) |

---

## Возвращаемое значение

`str` — HTML-строка оглавления или пустая строка, если нет заголовков.

---

## Пример

```nexy
---
from nexy import useToc
toc = useToc()
---
<aside class="toc">
    <h3>On this page</h3>
    {{ toc | safe }}
</aside>
```

---

## Примечания по использованию

- Анализирует заголовки уценки из отображаемого содержимого страницы.
- Возвращает пустую строку для страниц без заголовков.
- Формат диапазона глубины: `"2-6"` означает h2–h6, `"1-3"` означает h1–h3.
