# Аудио компонент

Встроенный компонент `Audio` позволяет легко добавлять аудиоплееры в ваше приложение.

## Импорт

Импортируйте его напрямую из `nexy`:

```nexy
---
from nexy import Audio
---
```

## Базовое использование 

```nexy
---
from nexy import Audio
---
<Audio src="/music.mp3" />
```

## Реквизит

| Опора | Тип | По умолчанию | Описание |
|------|------|---------|-------------|
| `src` | `str` | **обязательно** | Путь к аудиофайлу |
| `controls` | `bool` | `True` | Показать элементы управления звуком |
| `autoplay` | `bool` | `False` | Автовоспроизведение аудио |
| `loop` | `bool` | `False` | Зациклить аудио |
| `muted` | `bool` | `False` | Отключить звук |
| `preload` | `str` | `"metadata"` | Стратегия предварительной загрузки (`"none"`, `"metadata"`, `"auto"`) |
| `class_name` | `str | None` | `None` | Имена классов CSS |
| `sources` | `list[str] | None` | `None` | Список альтернативных источников звука |
| `**kwargs` | любой | — | Дополнительные атрибуты HTML |

## Несколько источников

Предоставьте несколько аудиоформатов для лучшей совместимости с браузером:

```nexy
---
from nexy import Audio
---
<Audio 
    sources=["/audio.mp3", "/audio.ogg", "/audio.wav"] 
/>
```

## Автозапуск аудио

```nexy
<Audio 
    src="/bgm.mp3" 
    autoplay={True} 
    loop={True} 
    controls={False}
/>
```
