# نظرة عامة على المكونات

المكونات هي اللبنات الأساسية لتطبيق Nexy. المكون هو ملف `.nexy` يجمع منطق Python مع قالب HTML - مثل ملفات `.vue` من Vue أو ملفات `.svelte` من Svelte.

## أنواع المكونات

يحتوي Nexy على فئتين من المكونات:

### 1. مكونات الصفحة (في `src/routes/`)

يصبح كل ملف `.nexy` في `src/routes/` مسارًا. يحدد مسار الملف عنوان URL.

```
src/routes/
├── index.nexy          →  /
├── about.nexy          →  /about
├── blog/
│   ├── index.nexy      →  /blog
│   └── [slug].nexy     →  /blog/:slug
```

يمكن الوصول إلى مكونات الصفحة مباشرة عبر عنوان URL. يمكنهم استخدام الخطافات مثل `useQuery()` و `usePathname()` لأنها تعمل في سياق الطلب.

### 2. المكونات القابلة لإعادة الاستخدام (`src/components/`)

المكونات الموجودة في `src/components/` ليست مسارات — حيث يتم استيرادها واستخدامها بواسطة الصفحات والمكونات الأخرى.

```nexy
---
from "./Card.nexy" import Card
from "./Header.nexy" import Header
---
<Header title="My Site" />
<Card title="Hello">
  <p>Card content</p>
</Card>
```

تقبل هذه المكونات الدعائم، وتستخدم الفتحات، وتغلف منطق HTML + في وحدة قابلة لإعادة الاستخدام.

## تشريح أحد المكونات

يحتوي كل مكون `.nexy` على ثلاثة أقسام محتملة:

```nexy
---
# 1. Frontmatter: Python code
title:prop[str] = "Default"
count = 0
---
<!-- 2. Template: HTML + Jinja2 -->
<div class="card">
  <h2>{{ title }}</h2>
  <p>Count: {{ count }}</p>
  <slot />
</div>

<style>
/* 3. Styles (global) */
.card { border: 1px solid #ddd; padding: 1rem; }
</style>
```

**1. Frontmatter** — كود Python بين المحددات `---`. يعلن عن الدعائم، ويستورد الوحدات، ويشغل الخطافات، ويعالج البيانات.

**2. القالب** — HTML مع تعبيرات Jinja2. إخراج المتغيرات، والتكرار فوق البيانات، وعرض المكونات الفرعية.

**3. الأنماط** — علامات `<style>` (في أي مكان في القالب). الأنماط عالمية وليست محددة النطاق. استخدم BEM أو فئات المرافق للتغليف.

## قواعد المكونات

- **الاسم يجب أن يكون PascalCase**: `BlogCard`، `Header`، `CommentForm`
- **ملف واحد = مكون واحد**: لا توجد عمليات تصدير متعددة لكل ملف
- **الدعائم المعلنة مقدمًا**: `title:prop[str] = "Default"`
- **الواردات في الأعلى**: قبل أي منطق أو خطافات
- **لا توجد آثار جانبية على مستوى الوحدة**: يتم تشغيل المادة الأمامية لكل طلب. لا تفتح الملفات أو تنشئ اتصالات خارج الوظائف

## متى يتم إنشاء مكون

قم بإنشاء مكون عندما:

- يمكنك إعادة استخدام نفس نمط HTML في أماكن متعددة (البطاقة، الزر، الرأس)
- تريد تغليف المنطق بالقالب الخاص به (نموذج التعليق مع التحقق من الصحة)
- تحتاج إلى تمرير البيانات من الصفحة إلى قسم فرعي (الشريط الجانبي مع العنصر النشط)
- تريد مشاركة بنية التخطيط عبر المسارات (التخطيط، الغلاف)

إذا كنت تكتب نفس HTML مرتين، فاستخرجه إلى مكون.
