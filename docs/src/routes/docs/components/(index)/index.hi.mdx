# घटक अवलोकन

घटक नेक्सी एप्लिकेशन के निर्माण खंड हैं। एक घटक एक `.nexy` फ़ाइल है जो पायथन लॉजिक को HTML टेम्पलेट के साथ जोड़ती है - जैसे Vue की `.vue` फ़ाइलें या Svelte की `.svelte` फ़ाइलें।

## घटक प्रकार

नेक्सी में घटकों की दो श्रेणियां हैं:

### 1. पृष्ठ घटक (`src/routes/` में)

`src/routes/` में प्रत्येक `.nexy` फ़ाइल एक रूट बन जाती है। फ़ाइल पथ URL निर्धारित करता है.

```
src/routes/
├── index.nexy          →  /
├── about.nexy          →  /about
├── blog/
│   ├── index.nexy      →  /blog
│   └── [slug].nexy     →  /blog/:slug
```

पृष्ठ घटक सीधे URL के माध्यम से पहुंच योग्य हैं। वे `useQuery()` और `usePathname()` जैसे हुक का उपयोग कर सकते हैं क्योंकि वे अनुरोध संदर्भ में चलते हैं।

### 2. पुन: प्रयोज्य घटक (`src/components/` में)

`src/components/` में घटक मार्ग नहीं हैं - वे पृष्ठों और अन्य घटकों द्वारा आयात और उपयोग किए जाते हैं।

```nexy
---
from "./Card.nexy" import Card
from "./Header.nexy" import Header
---
<Header title="My Site" />
<Card title="Hello">
  <p>Card content</p>
</Card>
```

ये घटक प्रॉप्स स्वीकार करते हैं, स्लॉट का उपयोग करते हैं, और पुन: प्रयोज्य इकाई में HTML + तर्क को समाहित करते हैं।

## एक घटक की शारीरिक रचना

प्रत्येक `.nexy` घटक में तीन संभावित अनुभाग होते हैं:

```nexy
---
# 1. Frontmatter: Python code
title:prop[str] = "Default"
count = 0
---
<!-- 2. Template: HTML + Jinja2 -->
<div class="card">
  <h2>{{ title }}</h2>
  <p>Count: {{ count }}</p>
  <slot />
</div>

<style>
/* 3. Styles (global) */
.card { border: 1px solid #ddd; padding: 1rem; }
</style>
```

**1. फ्रंटमैटर** - `---` डिलीमीटर के बीच पायथन कोड। प्रॉप्स घोषित करता है, मॉड्यूल आयात करता है, हुक चलाता है, डेटा संसाधित करता है।

**2. टेम्प्लेट** - Jinja2 अभिव्यक्तियों के साथ HTML। आउटपुट वेरिएबल, डेटा पर लूप, चाइल्ड घटकों को प्रस्तुत करता है।

**3. शैलियाँ** - `<style>` टैग (टेम्पलेट में कहीं भी)। शैलियाँ वैश्विक हैं, दायरे वाली नहीं। इनकैप्सुलेशन के लिए बीईएम या यूटिलिटी क्लास का उपयोग करें।

## घटक नियम

- **नाम पास्कलकेस होना चाहिए**: `BlogCard`, `Header`, `CommentForm`
- **एक फ़ाइल = एक घटक**: प्रति फ़ाइल कोई एकाधिक निर्यात नहीं
- **प्रॉप्स अग्रिम रूप से घोषित**: `title:prop[str] = "Default"`
- **शीर्ष पर आयात**: किसी भी तर्क या हुक से पहले
- **मॉड्यूल स्तर पर कोई दुष्प्रभाव नहीं**: फ्रंटमैटर अनुरोध के अनुसार चलता है। फ़ंक्शंस के बाहर फ़ाइलें न खोलें या कनेक्शन न बनाएं

## कोई घटक कब बनाना है

एक घटक बनाएं जब:

- आप एक ही HTML पैटर्न का कई स्थानों पर पुन: उपयोग करते हैं (कार्ड, बटन, हेडर)
- आप इसके टेम्पलेट के साथ तर्क को समाहित करना चाहते हैं (सत्यापन के साथ टिप्पणी प्रपत्र)
- आपको एक पृष्ठ से डेटा को एक उप-अनुभाग (सक्रिय आइटम के साथ साइडबार) में पास करने की आवश्यकता है
- आप सभी मार्गों पर लेआउट संरचना साझा करना चाहते हैं (लेआउट, रैपर)

यदि आप एक ही HTML दो बार लिख रहे हैं, तो इसे एक घटक में निकालें।
