# Обзор компонентов

Компоненты — это строительные блоки приложения Nexy. Компонент — это файл `.nexy`, который сочетает в себе логику Python с шаблоном HTML — например, файлы `.vue` Vue или файлы `.svelte` Svelte.

## Типы компонентов

Nexy имеет две категории компонентов:

### 1. Компоненты страницы (в `src/routes/`)

Каждый файл `.nexy` в `src/routes/` становится маршрутом. Путь к файлу определяет URL-адрес.

```
src/routes/
├── index.nexy          →  /
├── about.nexy          →  /about
├── blog/
│   ├── index.nexy      →  /blog
│   └── [slug].nexy     →  /blog/:slug
```

Компоненты страницы доступны напрямую через URL. Они могут использовать такие перехватчики, как `useQuery()` и `usePathname()`, поскольку они выполняются в контексте запроса.

### 2. Многоразовые компоненты (в `src/components/`)

Компоненты в `src/components/` не являются маршрутами — они импортируются и используются страницами и другими компонентами.

```nexy
---
from "./Card.nexy" import Card
from "./Header.nexy" import Header
---
<Header title="My Site" />
<Card title="Hello">
  <p>Card content</p>
</Card>
```

Эти компоненты принимают реквизиты, используют слоты и инкапсулируют логику HTML + в модуль многократного использования.

## Анатомия компонента

Каждый компонент `.nexy` имеет три возможных раздела:

```nexy
---
# 1. Frontmatter: Python code
title:prop[str] = "Default"
count = 0
---
<!-- 2. Template: HTML + Jinja2 -->
<div class="card">
  <h2>{{ title }}</h2>
  <p>Count: {{ count }}</p>
  <slot />
</div>

<style>
/* 3. Styles (global) */
.card { border: 1px solid #ddd; padding: 1rem; }
</style>
```

**1. Frontmatter** — код Python между разделителями `---`. Объявляет реквизиты, импортирует модули, запускает перехватчики, обрабатывает данные.

**2. Шаблон** — HTML с выражениями Jinja2. Выводит переменные, перебирает данные, визуализирует дочерние компоненты.

**3. Стили** — теги `<style>` (в любом месте шаблона). Стили являются глобальными, а не ограниченными. Используйте BEM или служебные классы для инкапсуляции.

## Правила компонента

- **Имя должно быть в PascalCase**: `BlogCard`, `Header`, `CommentForm`
- **Один файл = один компонент**: нет возможности многократного экспорта для каждого файла.
- **Реквизит объявлен заранее**: `title:prop[str] = "Default"`
- **Импорт вверху**: до какой-либо логики или перехватчиков.
- **Нет побочных эффектов на уровне модуля**: заголовок выполняется для каждого запроса. Не открывайте файлы и не создавайте соединения вне функций.

## Когда создавать компонент

Создайте компонент, если:

– Вы повторно используете один и тот же шаблон HTML в нескольких местах (карточка, кнопка, заголовок).
- Вы хотите инкапсулировать логику с помощью ее шаблона (CommentForm с проверкой)
- Вам необходимо передать данные со страницы в подраздел (Боковая панель с активным элементом)
- Вы хотите использовать структуру макета для разных маршрутов (Layout, Wrapper).

Если вы пишете один и тот же HTML дважды, извлеките его в компонент.
