
# घटकों का उपयोग करना

घटक `src/components/` में `.nexy` फ़ाइलें हैं जिन्हें आप पृष्ठों और अन्य घटकों में आयात करते हैं।

## एक घटक बनाना

एक घटक कोई भी `.nexy` फ़ाइल है। सबसे सरल संभव घटक में कोई फ्रंटमैटर नहीं है - केवल HTML:

```nexy
<!-- src/components/Hello.nexy -->
---
---
<h1>Hello Nexy!</h1>
```

लेकिन अधिकांश घटकों में प्रॉप्स, तर्क और एक टेम्पलेट होता है।

## घटकों का आयात करना

नेक्सी के घटक आयात सिंटैक्स का उपयोग करें, जो सापेक्ष पथों और कॉन्फ़िगर किए गए उपनामों का समर्थन करता है:

```nexy
---
from "./Card.nexy" import Card
from "./Header.nexy" import Header
from "@components/Button.nexy" import Button
---
```

आयात पथ वर्तमान फ़ाइल से संबंधित है। `"@/` डिफ़ॉल्ट रूप से `src/` पर मैप करता है (या जो भी आप `useAliases` में कॉन्फ़िगर करते हैं)।

**विशेष सिंटैक्स क्यों?** क्योंकि कंपाइलर को निर्माण के समय यह जानना आवश्यक है कि अज्ञात HTML तत्वों के मुकाबले कौन से पास्कलकेस टैग घटक हैं। सैनिटाइज़र इन आयातों को पायथन के एएसटी पार्सर द्वारा देखे जाने से पहले बदल देता है, इसलिए वे कभी भी सिंटैक्स त्रुटियों का कारण नहीं बनते हैं।

## घटकों का प्रतिपादन

टेम्पलेट में, आयातित नाम को HTML टैग के रूप में उपयोग करें:

```nexy
---
from "./Card.nexy" import Card
---
<Card title="Hello" count={5} />
```

कंपाइलर पास्कलकेस टैग को Jinja2 फ़ंक्शन कॉल में परिवर्तित करता है:

| टेम्पलेट | संकलित आउटपुट |
|---|-----------------|
| `&lt;Card /&gt;` | `{{Card() }}` |
| `&lt;Card title="Hi" /&gt;` | `{{ Card(title="Hi") }}` |
| `&lt;Card count={5} /&gt;` | `{{ Card(count=5) }}` |
| `&lt;Card&gt;content&lt;/Card&gt;` | `{% call Card() %}content{% endcall %}` |

**नामकरण की आवश्यकता**: घटक नाम **बड़े अक्षर से शुरू होने चाहिए**। यदि आप लोअरकेस का उपयोग करते हैं, तो कंपाइलर इसे एक नियमित HTML तत्व के रूप में मानता है और घटक फ़ंक्शन को कॉल नहीं करता है। यह वेब प्लेटफ़ॉर्म कन्वेंशन के अनुरूप है (कस्टम तत्वों में एक हाइफ़न होना चाहिए; पास्कलकेस फ्रेमवर्क घटकों के लिए आरक्षित है)।

## पासिंग प्रॉप्स

```nexy
---
from "./Card.nexy" import Card
---
<!-- Static string -->
<Card title="Hello" />

<!-- Dynamic Jinja2 expression -->
<Card title="{{ page_title }}" />

<!-- Unquoted value (expression, not string) -->
<Card count={5} active={true} items={["a", "b"]} />

<!-- Mixed -->
<Card title="{{ page_title }}" count={items|length} />
```

**विशेषता पारित करने के नियम**:

| सिंटैक्स | मान प्रकार | टेम्प्लेट आउटपुट |
|--------|----|----------------|
| `title="Hello"` | स्ट्रिंग | `Card(title="Hello")` |
| `title="{{ var }}"` | जिंजा2 अभिव्यक्ति | `Card(title=var)` |
| `count={5}` | पायथन अभिव्यक्ति | `Card(count=5)` |
| `active=true` | कीवर्ड (पायथन बूल) | `Card(active=True)` |
| `items={["a"]}` | पायथन अभिव्यक्ति | `Card(items=["a"])` |

गैर-उद्धृत मान जो पायथन शाब्दिक (`true`, `false`, `none`, संख्याएँ) से मेल खाते हैं, वैसे ही पारित कर दिए जाते हैं। बाकी सब एक स्ट्रिंग है.

**समझ गया**: `count={0}` पूर्णांक 0 को पास करता है। `count="0"` स्ट्रिंग `"0"` को पास करता है। Jinja2 टेम्प्लेट में, `{% if count %}`, `0` (झूठा) बनाम `"0"` (सच्चाई) के लिए अलग-अलग मूल्यांकन करता है। जब आपको संख्यात्मक शून्य की आवश्यकता हो तो `{0}` का उपयोग करें।

## स्लॉट / बच्चे

सामग्री को लपेटने वाले घटक यह परिभाषित करने के लिए `<slot />` का उपयोग करते हैं कि बच्चे कहाँ जाते हैं:

```nexy
<!-- Card.nexy -->
---
title:prop[str] = ""
---
<div class="card">
  <h2>{{ title }}</h2>
  <div class="card-body">
    <slot />
  </div>
</div>
```

```nexy
<!-- Usage -->
---
from "./Card.nexy" import Card
---
<Card title="My Card">
  <p>This appears inside the slot.</p>
</Card>
```

**स्लॉट कैसे काम करते हैं**: कंपाइलर बच्चों को `{% call %}` ब्लॉक में लपेटता है। घटक उन्हें `caller` फ़ंक्शन के रूप में प्राप्त करता है। `<slot />` `caller()` को कॉल करता है और परिणाम आउटपुट करता है।

**सीमाएँ**:
- प्रति घटक केवल एक अनाम स्लॉट
- कोई स्कोप्ड स्लॉट नहीं (इसके बजाय प्रॉप्स के रूप में फ़ंक्शन पास करें)
- स्लॉट केवल `.nexy` फ़ाइलों में काम करते हैं, कच्चे Jinja2 टेम्पलेट्स में नहीं

## स्व-समापन बनाम लपेटना

स्व-समापन घटक (कोई बच्चे नहीं):

```nexy
<Header title="Blog" />
<Separator />
<Spacer size={16} />
```

रैपिंग घटक (बच्चों के साथ):

```nexy
<Card title="Post">
  <p>Content here</p>
</Card>

<Layout>
  <Header />
  <main>Page content</main>
  <Footer />
</Layout>
```

कंपाइलर स्व-समापन टैग (`&lt;Card /&gt;`) बनाम बच्चों वाले टैग (`&lt;Card&gt;...&lt;/Card&gt;`) का पता लगाता है और उपयुक्त Jinja2 सिंटैक्स उत्पन्न करता है।

## शीघ्र रिटर्न/सशर्त रेंडरिंग

चूँकि घटक एक पायथन फ़ंक्शन है, आप फ्रंटमैटर में जल्दी लौट सकते हैं:

```nexy
---
title:prop[str] = ""
if not title:
    print("Warning: Card rendered without title")
    # Return early — the template still runs but title is empty
---
<div class="card">
  <h2>{{ title }}</h2>
  <slot />
</div>
```

टेम्पलेट में सशर्त प्रतिपादन के लिए, Jinja2 `{% if %}` का उपयोग करें:

```nexy
---
show_header:prop[bool] = true
---
{% if show_header %}
  <header>
    <slot />
  </header>
{% endif %}
```

## सर्वोत्तम प्रथाएँ

- **प्रति फ़ाइल एक घटक** - स्पष्ट नामकरण, खोजने में आसान
- **टेम्प्लेट को 50 पंक्तियों के नीचे रखें** - यदि यह लंबा है, तो उप-घटकों को निकालें
- **हार्डकोडिंग के बजाय प्रॉप्स का उपयोग करें** - घटकों को पुन: प्रयोज्य बनाता है
- **पास्कलकेस में फ़ाइलों का नाम** — `BlogCard.nexy` नहीं `blog_card.nexy`
- **वैकल्पिक मानों के लिए डिफ़ॉल्ट प्रॉप्स** — `title:prop[str] = ""` नहीं `title:prop[str]`
