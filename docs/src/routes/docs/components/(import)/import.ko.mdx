# 가져오기 도우미

`Import` 기능은 Nexy에서 다양한 유형의 자산을 가져오는 데 도움이 됩니다.

## 가져오기

`nexy`에서 직접 가져옵니다.

```nexy
---
from nexy import Import
---
```

## 지원되는 자산

`Import`는 다음을 처리할 수 있습니다.
- 클라이언트 구성 요소
- JSON 파일
- CSS 파일
- 이미지

## 사용법

JSON 가져오기:
```python
from nexy import Import
data = Import("data.json", "json", "default")
```

CSS 가져오기:
```python
from nexy import Import
styles = Import("styles.css", "css", "default")
```

이미지 가져오기:
```python
from nexy import Import
img_src = Import("image.jpg", "image", "default")
```
