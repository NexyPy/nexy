# 链接组件

内置的 `Link` 组件提供带有预取功能的客户端导航，以获得更好的用户体验。

## 导入

直接从`nexy`导入：

```nexy
---
from nexy import Link
---
```

## 基本用法

```nexy
---
from nexy import Link
---
<Link href="/about">About Us</Link>
```

## 道具

|道具|类型 |默认 |描述 |
|------|------|---------|------------|
| `href` | `str` | **必填** |导航至的 URL |
| `children` | `str` | `""` |链接文字或内容 |
| `class_name` | `str | None` | `None` | CSS 类名 |
| `prefetch` | `bool` | `True` |悬停/触摸时预取页面 |
| `**kwargs` |任何| — |附加 HTML 属性 |

## 预取

默认情况下，`Link` 在用户悬停或触摸页面时预取页面以加快导航速度：

```nexy
<Link href="/blog/my-post" prefetch={True}>Read Post</Link>
```

要禁用特定链接的预取：
```nexy
<Link href="/external" prefetch={False}>External Link</Link>
```

## 链接样式

使用 `class_name` 应用自定义样式：

```nexy
<Link 
    href="/contact" 
    class_name="text-blue-500 hover:text-blue-700 underline"
>Contact Us</Link>
```
