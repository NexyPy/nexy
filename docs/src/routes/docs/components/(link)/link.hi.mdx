# लिंक घटक

अंतर्निहित `Link` घटक बेहतर उपयोगकर्ता अनुभव के लिए प्रीफ़ेचिंग के साथ क्लाइंट-साइड नेविगेशन प्रदान करता है।

## आयात करें

इसे सीधे `nexy` से आयात करें:

```nexy
---
from nexy import Link
---
```

## बुनियादी उपयोग

```nexy
---
from nexy import Link
---
<Link href="/about">About Us</Link>
```

## सहारा

| प्रोप | प्रकार | डिफ़ॉल्ट | विवरण |
|------|------|------|---|
| `href` | `str` | **आवश्यक** | नेविगेट करने के लिए यूआरएल |
| `children` | `str` | `""` | लिंक पाठ या सामग्री |
| `class_name` | `str | None` | `None` | सीएसएस वर्ग के नाम |
| `prefetch` | `bool` | `True` | होवर/टच पर पेज प्रीफ़ेच करें |
| `**kwargs` | कोई भी | — | अतिरिक्त HTML विशेषताएँ |

## प्रीफ़ेचिंग

डिफ़ॉल्ट रूप से, `Link` पेजों को प्रीफ़ेच करता है जब उपयोगकर्ता तेज़ नेविगेशन के लिए उन पर होवर करता है या उन्हें छूता है:

```nexy
<Link href="/blog/my-post" prefetch={True}>Read Post</Link>
```

किसी विशिष्ट लिंक के लिए प्रीफ़ेचिंग अक्षम करने के लिए:
```nexy
<Link href="/external" prefetch={False}>External Link</Link>
```

## स्टाइलिंग लिंक

कस्टम शैलियाँ लागू करने के लिए `class_name` का उपयोग करें:

```nexy
<Link 
    href="/contact" 
    class_name="text-blue-500 hover:text-blue-700 underline"
>Contact Us</Link>
```
