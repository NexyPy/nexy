# Компонент ссылки

Встроенный компонент `Link` обеспечивает навигацию на стороне клиента с предварительной выборкой для лучшего взаимодействия с пользователем.

## Импорт

Импортируйте его напрямую из `nexy`:

```nexy
---
from nexy import Link
---
```

## Базовое использование

```nexy
---
from nexy import Link
---
<Link href="/about">About Us</Link>
```

## Реквизит

| Опора | Тип | По умолчанию | Описание |
|------|------|---------|-------------|
| `href` | `str` | **обязательно** | URL-адрес для перехода |
| `children` | `str` | `""` | Текст или содержание ссылки |
| `class_name` | `str | None` | `None` | Имена классов CSS |
| `prefetch` | `bool` | `True` | Предварительная загрузка страницы при наведении/прикосновении |
| `**kwargs` | любой | — | Дополнительные атрибуты HTML |

## Предварительная выборка

По умолчанию `Link` предварительно загружает страницы, когда пользователь наводит на них курсор или касается их, для более быстрой навигации:

```nexy
<Link href="/blog/my-post" prefetch={True}>Read Post</Link>
```

Чтобы отключить предварительную загрузку для конкретной ссылки:
```nexy
<Link href="/external" prefetch={False}>External Link</Link>
```

## Стилизация ссылок

Используйте `class_name` для применения пользовательских стилей:

```nexy
<Link 
    href="/contact" 
    class_name="text-blue-500 hover:text-blue-700 underline"
>Contact Us</Link>
```
