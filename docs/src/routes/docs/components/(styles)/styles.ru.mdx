# Стили в файлах .nexy

Шаблоны Nexy поддерживают CSS так же, как HTML — через теги `<style>`, внешний импорт или служебные платформы, такие как Tailwind.

## Встроенный тег `<style>`

Самый прямой способ добавления стилей. Добавьте блок `<style>` в любом месте раздела шаблона.

```nexy
---
---
<div class="card">
  <slot />
</div>

<style>
.card {
  padding: 1rem;
  border: 1px solid #e2e8f0;
  border-radius: 8px;
}
</style>
```

Стили **не ограничены** — они применяются глобально. Используйте соглашение об именах (BEM, служебные классы) или атрибуты данных, чтобы избежать коллизий.

## Внешний CSS через `__Import`

В каждом файле `.nexy` автоматически доступен `__Import` (вставленный компилятором). Для файлов CSS он считывает файл и помещает его в тег `<style>`:

```nexy
---
global_css = __Import("/styles/global.css", "", "")()
---
{{ global_css }}
<div class="layout">...</div>
```

`__Import(path, framework, symbol)` принимает три аргумента. В CSS вторая и третья строки не используются — передайте пустые строки. Завершающий `()` немедленно вызывает возвращаемый вызываемый объект, создавая строку `<style>...</style>`.

## CSS попутного ветра

Nexy работает с Tailwind «из коробки». Служебные классы в атрибутах вашего шаблона обрабатываются обычным образом:

```nexy
---
padding:prop[str] = "p-4"
---
<div class="rounded-lg shadow-md {{ padding }}">
  <slot />
</div>
```

Настройте Tailwind в `nexyconfig.py` или `tailwind.config.*`.

## Импорт CSS через Vite

Если Vite включен (`useVite: true`), вы можете использовать стандартные операторы CSS `"@import` или `import` в компонентах внешнего интерфейса. Vite обрабатывает их через PostCSS, модули CSS и любые настроенные плагины.

## Лучшие практики

| Подход | Когда использовать |
|----------|-------------|
| `<style>` в шаблоне | Стили, ориентированные на отдельные компоненты, небольшие проекты |
| `__Import()` внешний CSS | Совместное использование стилей между компонентами |
| CSS попутного ветра | Проектирование, ориентированное на полезность, быстрое прототипирование |
| CSS-конвейер Vite | Полный набор инструментов для сборки, модули CSS, PostCSS |
