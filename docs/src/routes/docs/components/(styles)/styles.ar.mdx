# الأنماط في ملفات .nexy

تدعم قوالب Nexy CSS بنفس الطريقة التي يدعمها HTML — من خلال علامات `<style>`، أو عمليات الاستيراد الخارجية، أو أطر عمل الأدوات المساعدة مثل Tailwind.

## علامة `<style>` مضمنة

الطريقة الأكثر مباشرة لإضافة الأنماط. أضف كتلة `<style>` في أي مكان في قسم القالب.

```nexy
---
---
<div class="card">
  <slot />
</div>

<style>
.card {
  padding: 1rem;
  border: 1px solid #e2e8f0;
  border-radius: 8px;
}
</style>
```

الأنماط **غير محددة النطاق** — فهي تنطبق عالميًا. استخدم اصطلاح التسمية (BEM، فئات المرافق) أو سمات البيانات لتجنب الاصطدامات.

## CSS خارجي عبر `__Import`

كل ملف `.nexy` لديه `__Import` متاح تلقائيًا (يتم حقنه بواسطة المترجم). بالنسبة لملفات CSS، يقرأ الملف ويغلفه في علامة `<style>`:

```nexy
---
global_css = __Import("/styles/global.css", "", "")()
---
{{ global_css }}
<div class="layout">...</div>
```

`__Import(path, framework, symbol)` يأخذ ثلاث وسائط. بالنسبة لـ CSS، لا يتم استخدام الثاني والثالث - قم بتمرير سلاسل فارغة. تستدعي `()` اللاحقة العنصر القابل للاستدعاء على الفور، مما يؤدي إلى إنتاج السلسلة `<style>...</style>`.

## الريح الخلفية CSS

يعمل Nexy مع Tailwind خارج الصندوق. تتم معالجة فئات الأدوات المساعدة في سمات القالب الخاص بك بشكل طبيعي:

```nexy
---
padding:prop[str] = "p-4"
---
<div class="rounded-lg shadow-md {{ padding }}">
  <slot />
</div>
```

قم بتكوين Tailwind في `nexyconfig.py` أو `tailwind.config.*`.

## استيراد CSS عبر Vite

إذا تم تمكين Vite (`useVite: true`)، فيمكنك استخدام عبارات CSS `"@import` أو `import` القياسية في مكونات الواجهة الأمامية لديك. يقوم Vite بمعالجتها من خلال وحدات PostCSS وCSS وأي مكونات إضافية تم تكوينها.

## أفضل الممارسات

| النهج | متى تستخدم |
|----------|------------|
| `<style>` في القالب | الأنماط الخاصة بالمكونات، المشاريع الصغيرة |
| `__Import()` CSS خارجي | مشاركة الأنماط عبر المكونات |
| الريح الخلفية CSS | تصميم المنفعة أولا، النماذج الأولية السريعة |
| خط أنابيب Vite CSS | سلسلة أدوات بناء كاملة، وحدات CSS، PostCSS |
