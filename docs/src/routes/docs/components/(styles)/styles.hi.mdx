# .nexy फ़ाइलों में शैलियाँ

नेक्सी टेम्प्लेट सीएसएस को उसी तरह सपोर्ट करते हैं जैसे HTML करता है - `<style>` टैग, बाहरी आयात, या टेलविंड जैसे उपयोगिता ढांचे के माध्यम से।

## इनलाइन `<style>` टैग

शैलियाँ जोड़ने का सबसे सीधा तरीका. टेम्प्लेट अनुभाग में कहीं भी `<style>` ब्लॉक जोड़ें।

```nexy
---
---
<div class="card">
  <slot />
</div>

<style>
.card {
  padding: 1rem;
  border: 1px solid #e2e8f0;
  border-radius: 8px;
}
</style>
```

शैलियाँ **स्कोप्ड नहीं** हैं - वे विश्व स्तर पर लागू होती हैं। टकराव से बचने के लिए नामकरण परंपरा (बीईएम, उपयोगिता वर्ग) या डेटा विशेषताओं का उपयोग करें।

## बाहरी सीएसएस `__Import` के माध्यम से

प्रत्येक `.nexy` फ़ाइल में `__Import` स्वचालित रूप से उपलब्ध है (कंपाइलर द्वारा इंजेक्ट किया गया)। सीएसएस फ़ाइलों के लिए, यह फ़ाइल को पढ़ता है और इसे `<style>` टैग में लपेटता है:

```nexy
---
global_css = __Import("/styles/global.css", "", "")()
---
{{ global_css }}
<div class="layout">...</div>
```

`__Import(path, framework, symbol)` तीन तर्क लेता है। सीएसएस के लिए, दूसरा और तीसरा अप्रयुक्त हैं - खाली स्ट्रिंग पास करें। अनुगामी `()` तुरंत लौटाए गए कॉल करने योग्य को कॉल करता है, जिससे `<style>...</style>` स्ट्रिंग उत्पन्न होती है।

## टेलविंड सीएसएस

नेक्सी आउट ऑफ द बॉक्स टेलविंड के साथ काम करता है। आपके टेम्पलेट विशेषताओं में उपयोगिता वर्ग सामान्य रूप से संसाधित होते हैं:

```nexy
---
padding:prop[str] = "p-4"
---
<div class="rounded-lg shadow-md {{ padding }}">
  <slot />
</div>
```

टेलविंड को `nexyconfig.py` या `tailwind.config.*` में कॉन्फ़िगर करें।

## वाइट के माध्यम से सीएसएस आयात

यदि Vite सक्षम है (`useVite: true`), तो आप अपने फ्रंटएंड घटकों में मानक CSS `"@import` या `import` स्टेटमेंट का उपयोग कर सकते हैं। Vite उन्हें PostCSS, CSS मॉड्यूल और किसी भी कॉन्फ़िगर किए गए प्लगइन के माध्यम से संसाधित करता है।

## सर्वोत्तम प्रथाएँ

| दृष्टिकोण | कब उपयोग करें |
|---|----|
| टेम्पलेट में `<style>` | घटक-विशिष्ट शैलियाँ, छोटी परियोजनाएँ |
| `__Import()` बाह्य सीएसएस | घटकों में शैलियाँ साझा करना |
| टेलविंड सीएसएस | उपयोगिता-प्रथम डिज़ाइन, रैपिड प्रोटोटाइप |
| वाइट सीएसएस पाइपलाइन | पूर्ण बिल्ड टूलचेन, सीएसएस मॉड्यूल, पोस्टसीएसएस |
