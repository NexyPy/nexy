# घटकों में स्क्रिप्ट

आप मानक <script> टैग का उपयोग करके क्लाइंट-साइड जावास्क्रिप्ट को सीधे अपनी .nexy फ़ाइलों में शामिल कर सकते हैं।

## बुनियादी उपयोग

```nexy
---
---
<button id="myButton">Click Me!</button>
<script>
document.getElementById('myButton').addEventListener('click', function() {
    alert('Hello from Nexy!');
});
</script>
```

## फ्रेमवर्क-विशिष्ट स्क्रिप्ट

फ़्रेमवर्क घटकों (रिएक्ट, Vue, Svelte, Solid, Preact) के लिए, `<script framework="...">` सिंटैक्स का उपयोग करें:

```nexy
---
---
<script framework="react">
import { useState } from 'react';

export default function Counter() {
    const [count, setCount] = useState(0);
    
    return (
        <div>
            <p>Count: {count}</p>
            <button onClick={() => setCount(c => c + 1)}>+</button>
        </div>
    );
}
</script>
```

## हॉट मॉड्यूल रिप्लेसमेंट (एचएमआर)

नेक्सी विकास के दौरान स्क्रिप्ट अपडेट को स्वचालित रूप से संभालता है। जब आप कोई स्क्रिप्ट बदलते हैं, तो संपूर्ण पृष्ठ को रीफ़्रेश किए बिना घटक पुनः लोड हो जाता है।

## बाहरी स्क्रिप्ट

आप बाहरी स्क्रिप्ट का भी संदर्भ ले सकते हैं:

```nexy
---
---
<script src="https://cdn.example.com/script.js"></script>
```
