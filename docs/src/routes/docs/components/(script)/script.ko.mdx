# 구성 요소의 스크립트

표준 <script> 태그를 사용하여 .nexy 파일에 클라이언트 측 JavaScript를 직접 포함할 수 있습니다.

## 기본 사용법

```nexy
---
---
<button id="myButton">Click Me!</button>
<script>
document.getElementById('myButton').addEventListener('click', function() {
    alert('Hello from Nexy!');
});
</script>
```

## 프레임워크별 스크립트

프레임워크 구성 요소(React, Vue, Svelte, Solid, Preact)의 경우 `<script framework="...">` 구문을 사용합니다.

```nexy
---
---
<script framework="react">
import { useState } from 'react';

export default function Counter() {
    const [count, setCount] = useState(0);
    
    return (
        <div>
            <p>Count: {count}</p>
            <button onClick={() => setCount(c => c + 1)}>+</button>
        </div>
    );
}
</script>
```

## 핫 모듈 교체(HMR)

Nexy는 개발 중에 스크립트 업데이트를 자동으로 처리합니다. 스크립트를 변경하면 전체 페이지를 새로 고치지 않고 구성 요소가 다시 로드됩니다.

## 외부 스크립트

외부 스크립트를 참조할 수도 있습니다.

```nexy
---
---
<script src="https://cdn.example.com/script.js"></script>
```
