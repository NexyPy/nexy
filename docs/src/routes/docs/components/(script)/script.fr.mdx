# Scripts dans les composants

Vous pouvez inclure du JavaScript côté client directement dans vos fichiers .nexy à l'aide de balises <script> standard.

## Utilisation de base

```nexy
---
---
<button id="myButton">Click Me!</button>
<script>
document.getElementById('myButton').addEventListener('click', function() {
    alert('Hello from Nexy!');
});
</script>
```

## Scripts spécifiques au framework

Pour les composants du framework (React, Vue, Svelte, Solid, Preact), utilisez la syntaxe `<script framework="...">` :

```nexy
---
---
<script framework="react">
import { useState } from 'react';

export default function Counter() {
    const [count, setCount] = useState(0);
    
    return (
        <div>
            <p>Count: {count}</p>
            <button onClick={() => setCount(c => c + 1)}>+</button>
        </div>
    );
}
</script>
```

## Remplacement du module chaud (HMR)

Nexy gère automatiquement les mises à jour des scripts pendant le développement. Lorsque vous modifiez un script, le composant est rechargé sans actualiser la page entière.

## Scripts externes

Vous pouvez également référencer des scripts externes :

```nexy
---
---
<script src="https://cdn.example.com/script.js"></script>
```
