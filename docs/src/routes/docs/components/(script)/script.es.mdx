# Scripts en Componentes

Puede incluir JavaScript del lado del cliente directamente en sus archivos .nexy utilizando etiquetas <script> estándar.

## Uso básico

```nexy
---
---
<button id="myButton">Click Me!</button>
<script>
document.getElementById('myButton').addEventListener('click', function() {
    alert('Hello from Nexy!');
});
</script>
```

## Scripts específicos del marco

Para los componentes del marco (React, Vue, Svelte, Solid, Preact), use la sintaxis `<script framework="...">`:

```nexy
---
---
<script framework="react">
import { useState } from 'react';

export default function Counter() {
    const [count, setCount] = useState(0);
    
    return (
        <div>
            <p>Count: {count}</p>
            <button onClick={() => setCount(c => c + 1)}>+</button>
        </div>
    );
}
</script>
```

## Reemplazo del módulo activo (HMR)

Nexy maneja automáticamente las actualizaciones de scripts durante el desarrollo. Cuando cambia una secuencia de comandos, el componente se recarga sin actualizar toda la página.

## Guiones externos

También puede hacer referencia a scripts externos:

```nexy
---
---
<script src="https://cdn.example.com/script.js"></script>
```
