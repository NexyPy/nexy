# Scripts in Components

You can include client-side JavaScript directly in your .nexy files using standard <script> tags.

## Basic Usage

```nexy
---
---
<button id="myButton">Click Me!</button>
<script>
document.getElementById('myButton').addEventListener('click', function() {
    alert('Hello from Nexy!');
});
</script>
```

## Framework-Specific Scripts

For framework components (React, Vue, Svelte, Solid, Preact), use the `<script framework="...">` syntax:

```nexy
---
---
<script framework="react">
import { useState } from 'react';

export default function Counter() {
    const [count, setCount] = useState(0);
    
    return (
        <div>
            <p>Count: {count}</p>
            <button onClick={() => setCount(c => c + 1)}>+</button>
        </div>
    );
}
</script>
```

## Hot Module Replacement (HMR)

Nexy automatically handles script updates during development. When you change a script, the component is reloaded without refreshing the entire page.

## External Scripts

You can also reference external scripts:

```nexy
---
---
<script src="https://cdn.example.com/script.js"></script>
```
