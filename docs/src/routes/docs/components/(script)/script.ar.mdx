# البرامج النصية في المكونات

يمكنك تضمين JavaScript من جانب العميل مباشرة في ملفات .nexy باستخدام علامات <script> القياسية.

## الاستخدام الأساسي

```nexy
---
---
<button id="myButton">Click Me!</button>
<script>
document.getElementById('myButton').addEventListener('click', function() {
    alert('Hello from Nexy!');
});
</script>
```

## البرامج النصية الخاصة بالإطار

بالنسبة لمكونات إطار العمل (React، Vue، Svelte، Solid، Preact)، استخدم بناء الجملة `<script framework="...">`:

```nexy
---
---
<script framework="react">
import { useState } from 'react';

export default function Counter() {
    const [count, setCount] = useState(0);
    
    return (
        <div>
            <p>Count: {count}</p>
            <button onClick={() => setCount(c => c + 1)}>+</button>
        </div>
    );
}
</script>
```

## استبدال الوحدة الساخنة (HMR)

يقوم Nexy تلقائيًا بمعالجة تحديثات البرنامج النصي أثناء التطوير. عندما تقوم بتغيير برنامج نصي، تتم إعادة تحميل المكون دون تحديث الصفحة بأكملها.

## البرامج النصية الخارجية

يمكنك أيضًا الرجوع إلى البرامج النصية الخارجية:

```nexy
---
---
<script src="https://cdn.example.com/script.js"></script>
```
