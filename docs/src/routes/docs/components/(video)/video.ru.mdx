# Видеокомпонент

Встроенный компонент `Video` позволяет легко встраивать видеофайлы с помощью встроенных элементов управления.

## Импорт

Импортируйте его напрямую из `nexy`:

```nexy
---
from nexy import Video
---
```

## Базовое использование

```nexy
---
from nexy import Video
---
<Video src="/demo.mp4" />
```

## Реквизит

| Опора | Тип | По умолчанию | Описание |
|------|------|---------|-------------|
| `src` | `str` | **обязательно** | Путь к видеофайлу |
| `width` | `int | None` | `None` | Ширина видео в пикселях |
| `height` | `int | None` | `None` | Высота видео в пикселях |
| `controls` | `bool` | `True` | Показать элементы управления видео |
| `autoplay` | `bool` | `False` | Автовоспроизведение видео |
| `loop` | `bool` | `False` | Зациклить видео |
| `muted` | `bool` | `False` | Выключить звук видео |
| `preload` | `str` | `"metadata"` | Стратегия предварительной загрузки (`"none"`, `"metadata"`, `"auto"`) |
| `class_name` | `str | None` | `None` | Имена классов CSS |
| `sources` | `list[str] | None` | `None` | Список альтернативных видеоисточников |
| `**kwargs` | любой | — | Дополнительные атрибуты HTML |

## Несколько источников

Предоставьте несколько форматов видео для лучшей совместимости с браузером:

```nexy
---
from nexy import Video
---
<Video 
    sources=["/video.mp4", "/video.webm", "/video.ogg"] 
    controls={True}
/>
```

## Автовоспроизведение видео

Примечание. Большинству браузеров для работы автозапуска требуется `muted`:

```nexy
<Video 
    src="/background.mp4" 
    autoplay={True} 
    muted={True} 
    loop={True} 
    controls={False}
/>
```
