# Компонент изображения

Встроенный компонент `Image` позволяет легко добавлять оптимизированные изображения с отложенной загрузкой по умолчанию.

## Импорт

Импортируйте его напрямую из `nexy`:

```nexy
---
from nexy import Image
---
```

## Использование

```nexy
---
from nexy import Image
---
<Image src="/nexy.svg" alt="Nexy Logo" width={200} height={200} />
```

## Реквизит

| Опора | Тип | По умолчанию | Описание |
|------|------|---------|-------------|
| `src` | `str` | **обязательно** | Путь к файлу изображения |
| `alt` | `str` | `""` | Альтернативный текст для доступности |
| `width` | `int | None` | `None` | Ширина изображения в пикселях |
| `height` | `int | None` | `None` | Высота изображения в пикселях |
| `loading` | `str` | `"lazy"` | Стратегия загрузки (`"lazy"` или `"eager"`) |
| `class_name` | `str | None` | `None` | Имена классов CSS |
| `**kwargs` | любой | — | Дополнительные атрибуты HTML |

## Ленивая загрузка

По умолчанию изображения загружаются лениво для повышения производительности:

```nexy
---
from nexy import Image
---
<Image 
    src="/hero.jpg" 
    alt="Hero" 
    loading="lazy" 
    class_name="w-full h-auto"
/>
```

Чтобы загрузить критические изображения:
```nexy
<Image 
    src="/logo.svg" 
    alt="Logo" 
    loading="eager"
/>
```
