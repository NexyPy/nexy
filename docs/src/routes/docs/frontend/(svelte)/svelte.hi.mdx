# सुडौल

अपने `nexyconfig.py` में Svelte जोड़ें:

```python
from nexy.frontend import svelte

class NexyConfig(NexyConfigModel):
    useFF = [svelte()]
```

---

## एक घटक बनाना

`.svelte` एक्सटेंशन वाली फ़ाइलों को Svelte घटकों के रूप में माना जाता है:

```svelte
<!-- src/components/Counter.svelte -->
<script>
  export let initial = 0
  let count = initial
</script>

<div>
  <p>Count: {count}</p>
  <button on:click={() => count += 1}>+</button>
</div>
```

---

## .nexy पेज में उपयोग करना

```nexy
---
from "@components/Counter" import Counter
---
<Counter initial={{42}} />
```

प्रॉप्स को Jinja2 `{{ }}` सिंटैक्स के माध्यम से पारित किया जाता है - JSON मानों के लिए डबल ब्रेसिज़ का उपयोग करें।

---

## बच्चे/स्लॉट सामग्री

नेक्सी चाइल्ड कंटेंट को स्वेल्ट स्लॉट के रूप में पास करती है:

```svelte
<!-- Card.svelte -->
<script>
  export let title
</script>

<div class="card">
  <h2>{title}</h2>
  <slot />
</div>
```

```nexy
<Card title="Hello">
  <p>This content is passed as a slot</p>
</Card>
```

---

## एसएसआर

जब सर्वर में पहले से रेंडर किया गया HTML होता है, तो Svelte घटक `hydrate` का उपयोग करते हैं, या क्लाइंट-केवल रेंडरिंग के लिए `mount` का उपयोग करते हैं।
