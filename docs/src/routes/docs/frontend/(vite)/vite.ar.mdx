# التكامل فيت

تمكين Vite في `nexyconfig.py`:

```python
class NexyConfig(NexyConfigModel):
    useVite = True
```

## وضع التطوير

يبدأ `nexy dev` تلقائيًا خادم Vite dev جنبًا إلى جنب مع خادم Nexy. يوفر فيت:
- استبدال الوحدة الساخنة (HMR)
- تحديث سريع لمكونات الإطار
- تجميع TypeScript وJSX
- المعالجة المسبقة لـ CSS

يعمل وكيل خادم Nexy على عنوان URL الخاص بتطوير Vite بحيث يعمل كل شيء على منفذ واحد.

##الإنتاج

يقوم `nexy build` بتشغيل إصدار إنتاج Vite. يذهب الإخراج إلى `__nexy__/client/`. تقوم الدالة `Vite()` بقراءة البيان وتصدر علامات CSS والبرامج النصية الصحيحة.

## تكوين Vite مخصص

يقوم Nexy بدمج `vite.config.ts` الخاص بك مع الإعدادات الافتراضية الخاصة به. يمكنك إضافة المكونات الإضافية والأسماء المستعارة وخيارات Vite الأخرى بشكل طبيعي.

## مرجع التكوين

| الخيار | اكتب | الافتراضي | الوصف |
|--------|------|---------|-------------|
| `useVite` | `bool` | `False` | تمكين فايت |
| `useViteDevUrl` | `str \| None` | `None` | عنوان URL المخصص لتطوير Vite |
