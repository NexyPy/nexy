# Интеграция с Vite

Включите Vite в `nexyconfig.py`:

```python
class NexyConfig(NexyConfigModel):
    useVite = True
```

## Режим разработки

`nexy dev` автоматически запускает сервер разработки Vite рядом с сервером Nexy. Вите обеспечивает:
- Горячая замена модуля (HMR)
- Быстрое обновление компонентов платформы.
- Компиляция TypeScript и JSX
- Предварительная обработка CSS

Сервер Nexy передает URL-адрес разработчика Vite, поэтому все работает на одном порту.

## Производство

`nexy build` запускает производственную сборку Vite. Вывод поступает в `__nexy__/client/`. Функция `Vite()` считывает манифест и выдает правильные теги CSS и скрипта.

## Пользовательская конфигурация Vite

Nexy объединяет ваш `vite.config.ts` со своими настройками по умолчанию. Вы можете добавлять плагины, псевдонимы и другие параметры Vite обычным способом.

## Справочник по конфигурации

| Вариант | Тип | По умолчанию | Описание |
|--------|------|---------|-------------|
| `useVite` | `bool` | `False` | Включить Vite |
| `useViteDevUrl` | `str \| None` | `None` | Пользовательский URL-адрес для разработчиков Vite |
