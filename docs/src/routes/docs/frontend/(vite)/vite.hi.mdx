# वाइट एकीकरण

`nexyconfig.py` में Vite सक्षम करें:

```python
class NexyConfig(NexyConfigModel):
    useVite = True
```

## देव मोड

`nexy dev` स्वचालित रूप से नेक्सी सर्वर के साथ एक वाइट डेव सर्वर शुरू करता है। वाइट प्रदान करता है:
- हॉट मॉड्यूल रिप्लेसमेंट (एचएमआर)
- फ्रेमवर्क घटकों के लिए तेज़ रिफ्रेश
- टाइपस्क्रिप्ट और JSX संकलन
- सीएसएस प्रीप्रोसेसिंग

नेक्सी सर्वर वाइट के डेव यूआरएल को प्रॉक्सी करता है इसलिए सब कुछ एक ही पोर्ट पर काम करता है।

## उत्पादन

`nexy build` एक वाइट प्रोडक्शन बिल्ड चलाता है। आउटपुट `__nexy__/client/` हो जाता है। `Vite()` फ़ंक्शन मैनिफ़ेस्ट को पढ़ता है और सही CSS और स्क्रिप्ट टैग उत्सर्जित करता है।

## कस्टम वाइट कॉन्फ़िगरेशन

नेक्सी आपके `vite.config.ts` को अपने डिफ़ॉल्ट के साथ मर्ज कर देता है। आप सामान्य रूप से प्लगइन्स, उपनाम और अन्य Vite विकल्प जोड़ सकते हैं।

## कॉन्फ़िग संदर्भ

| विकल्प | प्रकार | डिफ़ॉल्ट | विवरण |
|--------|------|------|----|
| `useVite` | `bool` | `False` | वाइट सक्षम करें |
| `useViteDevUrl` | `str \| None` | `None` | कस्टम वाइट डेव यूआरएल |
