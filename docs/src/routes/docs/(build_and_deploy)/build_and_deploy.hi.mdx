# निर्माण और तैनाती

`nx build` आपके प्रोजेक्ट को उत्पादन के लिए संकलित करता है। `nx start` उत्पादन सर्वर चलाता है।

## निर्माण

```bash
nx build
```

`.nexy`/`.mdx` फ़ाइलें संकलित करता है, फ्रंटएंड संपत्तियों को बंडल करता है, रूट ट्री बनाता है। आउटपुट `__nexy__/` हो जाता है।

झंडे और विकल्पों के लिए [CLI: build](/docs/cli/build) देखें।

## शुरू

```bash
nx start
```

उत्पादन यूविकॉर्न सर्वर लॉन्च किया।

झंडों के लिए [CLI: start](/docs/cli/start) देखें (`--port`, `--host`, `--env`)।

## तैनात करना

डॉकर, वीपीएस, फ्लाई.आईओ, रेलवे, रेंडर - प्लेटफ़ॉर्म-विशिष्ट निर्देशों के लिए [Deploy guide](/docs/guides/deploy) देखें।

## स्थैतिक निर्यात

पूरी तरह से स्थिर साइटों के लिए, निर्माण के दौरान प्रत्येक पृष्ठ को HTML पर पूर्व-रेंडर किया जाता है। किसी भी स्थिर फ़ाइल सर्वर के साथ `__nexy__/static/` परोसें।
