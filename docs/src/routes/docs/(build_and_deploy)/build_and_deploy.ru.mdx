# Сборка и развертывание

`nx build` компилирует ваш проект для производства. `nx start` запускает рабочий сервер.

## Строить

```bash
nx build
```

Компилирует файлы `.nexy`/`.mdx`, объединяет ресурсы внешнего интерфейса, генерирует дерево маршрутов. Вывод поступает в `__nexy__/`.

См. [CLI: build](/docs/cli/build) для флагов и опций.

## Начинать

```bash
nx start
```

Запускает производственный сервер Uvicorn.

См. [CLI: start](/docs/cli/start) для флагов (`--port`, `--host`, `--env`).

## Развертывание

Docker, VPS, Fly.io, Railway, Render — инструкции для конкретной платформы см. в [Deploy guide](/docs/guides/deploy).

## Статический экспорт

Для полностью статических сайтов каждая страница предварительно преобразуется в HTML во время сборки. Обслуживайте `__nexy__/static/` на любом статическом файловом сервере.
