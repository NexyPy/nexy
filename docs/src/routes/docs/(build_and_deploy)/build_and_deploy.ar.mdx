# البناء والنشر

يقوم `nx build` بتجميع مشروعك للإنتاج. يقوم `nx start` بتشغيل خادم الإنتاج.

## يبني

```bash
nx build
```

تجميع ملفات `.nexy`/`.mdx`، وتجميع أصول الواجهة الأمامية، وإنشاء شجرة المسار. يذهب الإخراج إلى `__nexy__/`.

راجع [CLI: build](/docs/cli/build) للتعرف على العلامات والخيارات.

## يبدأ

```bash
nx start
```

إطلاق خادم الإنتاج Uvicorn.

راجع [CLI: start](/docs/cli/start) للأعلام (`--port`، `--host`، `--env`).

## نشر

Docker، VPS، Fly.io، Railway، Render - راجع [Deploy guide](/docs/guides/deploy) للحصول على الإرشادات الخاصة بالمنصة.

## تصدير ثابت

بالنسبة للمواقع الثابتة بالكامل، يتم عرض كل صفحة مسبقًا إلى HTML أثناء الإنشاء. خدمة `__nexy__/static/` مع أي خادم ملفات ثابت.
