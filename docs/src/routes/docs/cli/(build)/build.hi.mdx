# एनएक्स बिल्ड

उत्पादन के लिए परियोजना को संकलित करता है - `.nexy`/`.mdx` संकलन, एसएसजी, और क्लाइंट बंडलिंग।

```bash
nx build
```

---

## यह क्या करता है

1. सभी `.nexy`/`.mdx` फ़ाइलों को `__nexy__/` (समानांतर, बहु-थ्रेडेड) में संकलित करता है
2. एसएसजी पेज (स्थैतिक साइट निर्माण) उत्पन्न करता है - स्थिर मार्गों के लिए HTML को पूर्व-रेंडर करता है
3. क्लाइंट घटकों के लिए वाइट प्रोडक्शन बिल्ड चलाता है (यदि कॉन्फ़िगर किया गया हो)
4. फास्टएपीआई ऐप के लिए संकलित रूट ट्री तैयार करता है

आउटपुट `__nexy__/` पर जाता है:

```text
__nexy__/
├── server/          — Compiled Python routes
├── client/          — Bundled JS/CSS (Vite)
├── static/          — Pre-rendered HTML (SSG)
└── manifest.json    — Build manifest
```

---

## विकल्प

| झंडा | डिफ़ॉल्ट | विवरण |
|------|---------|----------------|
| `--check` | `false` | संकलन के बाद रफ़ + mypy चलाएँ |
| `--static` | `false` | पूर्ण स्थैतिक साइट निर्यात (कोई सर्वर नहीं) |

---

## उदाहरण

```bash
# Build with type checking
nx build --check

# Build as static site
nx build --static
```
