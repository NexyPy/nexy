# nx 빌드

프로덕션용 프로젝트(`.nexy`/`.mdx` 컴파일, SSG 및 클라이언트 번들링)를 컴파일합니다.

```bash
nx build
```

---

## 기능

1. 모든 `.nexy`/`.mdx` 파일을 `__nexy__/`(병렬, 다중 스레드)로 컴파일합니다.
2. SSG 페이지 생성(정적 사이트 생성) — 정적 경로에 대한 HTML을 사전 렌더링합니다.
3. 클라이언트 구성요소에 대한 Vite 프로덕션 빌드 실행(구성된 경우)
4. FastAPI 앱용으로 컴파일된 경로 트리를 생성합니다.

출력은 `__nexy__/`로 이동합니다.

```text
__nexy__/
├── server/          — Compiled Python routes
├── client/          — Bundled JS/CSS (Vite)
├── static/          — Pre-rendered HTML (SSG)
└── manifest.json    — Build manifest
```

---

## 옵션

| 플래그 | 기본값 | 설명 |
|------|---------|-------------|
| `--check` | `false` | 컴파일 후 ruff + mypy 실행 |
| `--static` | `false` | 전체 정적 사이트 내보내기(서버 없음) |

---

## 예

```bash
# Build with type checking
nx build --check

# Build as static site
nx build --static
```
