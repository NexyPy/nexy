# nx-сборка

Компилирует проект для производства — компиляция `.nexy`/`.mdx`, SSG и объединение клиентов.

```bash
nx build
```

---

## Что он делает

1. Компилирует все файлы `.nexy`/`.mdx` в `__nexy__/` (параллельно, многопоточно).
2. Генерирует страницы SSG (генерация статического сайта) — предварительно обрабатывает HTML для статических маршрутов.
3. Запускает производственную сборку Vite для клиентских компонентов (если настроено).
4. Генерирует скомпилированное дерево маршрутов для приложения FastAPI.

Вывод поступает в `__nexy__/`:

```text
__nexy__/
├── server/          — Compiled Python routes
├── client/          — Bundled JS/CSS (Vite)
├── static/          — Pre-rendered HTML (SSG)
└── manifest.json    — Build manifest
```

---

## Опции

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--check` | `false` | Запустите ruff + mypy после компиляции |
| `--static` | `false` | Полный экспорт статического сайта (без сервера) |

---

## Пример

```bash
# Build with type checking
nx build --check

# Build as static site
nx build --static
```
