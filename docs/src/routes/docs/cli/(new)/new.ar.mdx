#نكس جديد

إنشاء مشروع Nexy جديد بشكل تفاعلي. هذه هي الطريقة الموصى بها للبدء.

```bash
nx new
nx new my-app
```

---

## الخيارات

| علم | الوصف |
|------|------------|
| `<name>` | اسم المشروع (وسيطة موضعية، اختيارية - يتم المطالبة بها إذا تم حذفها) |
| `--template`، `-t` | التهيئة من قالب مسجل (استنساخ صامت، بدون مطالبات) |

---

## المطالبات التفاعلية

| خطوة | موجه | خيارات |
|------|--------|---------|
| 1 | اسم المشروع | (إذا لم يتم توفيره كوسيطة) |
| 2 | استخدام جهاز التوجيه القائم على الملف؟ | نعم (FBR) / لا (معياري) |
| 3 | نوع المشروع | الويب (متراصة) / API (RESTful) |
| 4 | استخدام مكون العميل؟ | نعم / لا (الويب فقط) |
| 5 | إطار العميل | رد فعل، Vue، Svelte، Solid، Preact، لا شيء |
| 6 | أو آر إم | SQLModel، SQLAlchemy، Tortoise-ORM، لا شيء |
| 7 | قاعدة بيانات | SQLite وPostgreSQL وMySQL (إذا تم تحديد ORM) |
| 8 | عنوان URL لقاعدة البيانات | (يتم إنشاؤه تلقائيًا بناءً على التحديد) |

```text
├── src/

│   └── layout.nexy
├── public/
└── README.md
```
