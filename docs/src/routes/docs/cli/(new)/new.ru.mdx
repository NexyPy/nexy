# nx новый

Создает новый проект Nexy в интерактивном режиме. Это рекомендуемый способ начать.

```bash
nx new
nx new my-app
```

---

## Опции

| Флаг | Описание |
|------|-------------|
| `<name>` | Имя проекта (позиционный аргумент, необязательно — запрос будет предложен, если опущен) |
| `--template`, `-t` | Инициализировать из зарегистрированного шаблона (автоматическое клонирование, без запросов) |

---

## Интерактивные подсказки

| Шаг | Подсказка | Опции |
|------|--------|---------|
| 1 | Название проекта | (если не указан в качестве аргумента) |
| 2 | Использовать файловый маршрутизатор? | Да (FBR) / Нет (Модульный) |
| 3 | Тип проекта | Веб (монолит)/API (RESTful) |
| 4 | Использовать клиентский компонент? | Да/Нет (только через Интернет) |
| 5 | Клиентская среда | React, Vue, Svelte, Solid, Preact, нет |
| 6 | ОРМ | SQLModel, SQLAlchemy, Tortoise-ORM, нет |
| 7 | База данных | SQLite, PostgreSQL, MySQL (если выбран ORM) |
| 8 | URL-адрес базы данных | (создается автоматически на основе выбора) |

---

## Выход

```text
my-app/
├── nexyconfig.py
├── pyproject.toml
├── src/
│   ├── routes/       (FBR) or apps/ (Modular)
│   └── layout.nexy
├── public/
└── README.md
```
