# एनएक्स नया

इंटरैक्टिव ढंग से एक नया Nexy प्रोजेक्ट बनाता है। यह आरंभ करने का अनुशंसित तरीका है.

```bash
nx new
nx new my-app
```

---

## विकल्प

| झंडा | विवरण |
|------|----||
| `<name>` | प्रोजेक्ट का नाम (स्थितीय तर्क, वैकल्पिक - यदि छोड़ा गया है तो संकेत दिया गया है) |
| `--template`, `-t` | एक पंजीकृत टेम्पलेट से प्रारंभ करें (मूक क्लोन, कोई संकेत नहीं) |

---

## इंटरएक्टिव संकेत

| कदम | शीघ्र | विकल्प |
|------|--------|------|
| 1 | प्रोजेक्ट का नाम | (यदि तर्क के रूप में प्रदान नहीं किया गया है) |
| 2 | फ़ाइल-आधारित राउटर का उपयोग करें? | हाँ (एफबीआर) / नहीं (मॉड्यूलर) |
| 3 | प्रोजेक्ट का प्रकार | वेब (मोनोलिथ) / एपीआई (रेस्टफुल) |
| 4 | क्लाइंट घटक का उपयोग करें? | हाँ/नहीं (केवल वेब) |
| 5 | ग्राहक ढांचा | रिएक्ट, व्यू, स्वेल्ट, सॉलिड, प्रीएक्ट, कोई नहीं |
| 6 | ओआरएम | SQLModel, SQLAlchemy, Tortoise-ORM, कोई नहीं |
| 7 | डेटाबेस | SQLite, PostgreSQL, MySQL (यदि ORM चयनित है) |
| 8 | डेटाबेस यूआरएल | (चयन के आधार पर स्वतः उत्पन्न) |
