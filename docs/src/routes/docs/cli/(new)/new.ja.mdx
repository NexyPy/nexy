# nx 新しい

新しい Nexy プロジェクトを対話的に作成します。これが推奨される開始方法です。

```bash
nx new
nx new my-app
```

---

## オプション

|旗 |説明 |
|------|---------------|
| `<name>` |プロジェクト名 (位置引数、オプション - 省略した場合はプロンプトが表示されます) |
| `--template`、`-t` |登録されたテンプレートから初期化します (サイレント クローン、プロンプトなし)。

---

## 対話型プロンプト

|ステップ |プロンプト |オプション |
|------|--------|----------|
| 1 |プロジェクト名 | (引数として指定されない場合) |
| 2 |ファイルベースのルーターを使用しますか? |はい (FBR) / いいえ (モジュラー) |
| 3 |プロジェクトの種類 | Web (モノリス) / API (RESTful) |
| 4 |クライアントコンポーネントを使用しますか? |はい / いいえ (Web のみ) |
| 5 |クライアントフレームワーク | React、Vue、Svelte、Solid、Preact、なし |
| 6 | ORM | SQLModel、SQLAlchemy、Tortoise-ORM、なし |
| 7 |データベース | SQLite、PostgreSQL、MySQL (ORM が選択されている場合) |
| 8 |データベース URL | (選択に基づいて自動生成) |

---

## 出力

```text
my-app/
├── nexyconfig.py
├── pyproject.toml
├── src/
│   ├── routes/       (FBR) or apps/ (Modular)
│   └── layout.nexy
├── public/
└── README.md
```
