# nx 새로운

새로운 Nexy 프로젝트를 대화형으로 생성합니다. 이것이 권장되는 시작 방법입니다.

```bash
nx new
nx new my-app
```

---

## 옵션

| 플래그 | 설명 |
|------|-------------|
| `<name>` | 프로젝트 이름(위치 인수, 선택 사항 — 생략하면 메시지 표시) |
| `--template`, `-t` | 등록된 템플릿에서 초기화(자동 복제, 프롬프트 없음) |

---

## 대화형 프롬프트

| 단계 | 프롬프트 | 옵션 |
|------|---------|---------|
| 1 | 프로젝트 이름 | (인수로 제공되지 않은 경우) |
| 2 | 파일 기반 라우터를 사용하시겠습니까? | 예(FBR) / 아니요(모듈식) |
| 3 | 프로젝트 유형 | 웹(모놀리스)/API(RESTful) |
| 4 | 클라이언트 구성요소를 사용하시겠습니까? | 예 / 아니요(웹에만 해당) |
| 5 | 클라이언트 프레임워크 | React, Vue, Svelte, Solid, Preact, 없음 |
| 6 | ORM | SQLModel, SQLAlchemy, Tortoise-ORM, 없음 |
| 7 | 데이터베이스 | SQLite, PostgreSQL, MySQL(ORM을 선택한 경우) |
| 8 | 데이터베이스 URL | (선택에 따라 자동 생성) |

---

## 출력

```text
my-app/
├── nexyconfig.py
├── pyproject.toml
├── src/
│   ├── routes/       (FBR) or apps/ (Modular)
│   └── layout.nexy
├── public/
└── README.md
```
