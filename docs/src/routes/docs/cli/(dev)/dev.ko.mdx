# nx 개발자

핫 리로드, Vite HMR 및 VFS 파일 감시를 통해 개발 서버를 시작합니다.

```bash
nx dev
```

---

## 기능

1. `.nexy`/`.mdx` 파일에 대한 **VFS**(가상 파일 시스템) 감시자를 시작합니다.
2. 클라이언트 구성요소용 **Vite** 개발 서버 실행(구성된 경우)
3. `127.0.0.1:3000`에서 자동 재로드로 **uvicorn**을 시작합니다.
4. 즉각적인 브라우저 업데이트를 위해 `/_nexy/hmr`에서 **HMR** WebSocket을 엽니다.

---

## 옵션

| 플래그 | 기본값 | 설명 |
|------|---------|-------------|
| `--port` | `3000` | 서버 포트 |
| `--host` | `127.0.0.1` | 서버 바인드 주소 |
| `--vite-port` | 자동 | Vite 개발 서버 포트 |

---

## 환경 변수

| 변수 | 기본값 | 설명 |
|------------|---------|-------------|
| `NEXY_DEBUG` | `true` | 디버그 모드(개발자에서 자동 설정) |
| `NEXY_PORT` | `3000` | 서버 포트 |
| `NEXY_HOST` | `127.0.0.1` | 주소 바인딩 |

---

## 예

```bash
# Development with custom port
nx dev --port 8080

# Development binding all interfaces (Docker)
nx dev --host 0.0.0.0
```
