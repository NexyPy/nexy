#nx 开发

启动开发服务器，支持热重载、Vite HMR 和 VFS 文件监视。

```bash
nx dev
```

---

## 它的作用

1. 为 `.nexy`/`.mdx` 文件启动 **VFS**（虚拟文件系统）观察程序
2. 为客户端组件启动 **Vite** 开发服务器（如果已配置）
3. 在 `127.0.0.1:3000` 上启动 **uvicorn** 并自动重新加载
4. 在 `/_nexy/hmr` 打开 **HMR** WebSocket 以进行即时浏览器更新

---

## 选项

|旗帜|默认 |描述 |
|------|---------|-------------|
| `--port` | `3000` |服务器端口|
| `--host` | `127.0.0.1` |服务器绑定地址 |
| `--vite-port` |汽车 | Vite开发服务器端口 |

---

## 环境变量

|变量|默认 |描述 |
|----------|---------|-------------|
| `NEXY_DEBUG` | `true` |调试模式（在开发中自动设置）|
| `NEXY_PORT` | `3000` |服务器端口|
| `NEXY_HOST` | `127.0.0.1` |绑定地址 |

 - -

＃＃ 例子

```bash
# Development with custom port
nx dev --port 8080

# Development binding all interfaces (Docker)
nx dev --host 0.0.0.0
```
