# nx-разработчик

Запускает сервер разработки с горячей перезагрузкой, Vite HMR и просмотром файлов VFS.

```bash
nx dev
```

---

## Что он делает

1. Запускает наблюдатель **VFS** (виртуальной файловой системы) для файлов `.nexy`/`.mdx`.
2. Запускает сервер разработки **Vite** для клиентских компонентов (если настроено).
3. Запускает **uvicorn** с автоматической перезагрузкой на `127.0.0.1:3000`.
4. Открывает **HMR** WebSocket по адресу `/_nexy/hmr` для мгновенных обновлений браузера.

---

## Опции

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--port` | `3000` | Порт сервера |
| `--host` | `127.0.0.1` | Адрес привязки сервера |
| `--vite-port` | авто | Порт сервера разработки Vite |

---

## Переменные среды

| Переменная | По умолчанию | Описание |
|----------|---------|-------------|
| `NEXY_DEBUG` | `true` | Режим отладки (автоматически устанавливается в разработке) |
| `NEXY_PORT` | `3000` | Порт сервера |
| `NEXY_HOST` | `127.0.0.1` | Привязать адрес |

---

## Пример

```bash
# Development with custom port
nx dev --port 8080

# Development binding all interfaces (Docker)
nx dev --host 0.0.0.0
```
