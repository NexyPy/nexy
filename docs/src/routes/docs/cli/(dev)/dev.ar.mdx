# نكس ديف

يبدأ خادم التطوير من خلال إعادة التحميل السريع ومشاهدة ملفات Vite HMR وVFS.

```bash
nx dev
```

---

## ماذا يفعل

1. بدء تشغيل مراقب **VFS** (نظام الملفات الافتراضي) لملفات `.nexy`/`.mdx`
2. تشغيل خادم **Vite** dev لمكونات العميل (إذا تم تكوينه)
3. يبدأ **uvicorn** بإعادة التحميل التلقائي على `127.0.0.1:3000`
4. يفتح **HMR** WebSocket على `/_nexy/hmr` للحصول على تحديثات المتصفح الفورية

---

## الخيارات

| علم | الافتراضي | الوصف |
|------|---------|-------------|
| `--port` | `3000` | منفذ الخادم |
| `--host` | `127.0.0.1` | عنوان ربط الخادم |
| `--vite-port` | تلقائي | منفذ خادم Vite dev |

---

## متغيرات البيئة

| متغير | الافتراضي | الوصف |
|----------|--------|-------------|
| `NEXY_DEBUG` | `true` | وضع التصحيح (الضبط التلقائي في التطوير) |
| `NEXY_PORT` | `3000` | منفذ الخادم |
| `NEXY_HOST` | `127.0.0.1` | ربط العنوان |

---

## مثال

```bash
# Development with custom port
nx dev --port 8080

# Development binding all interfaces (Docker)
nx dev --host 0.0.0.0
```
