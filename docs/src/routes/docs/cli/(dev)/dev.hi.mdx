# एनएक्स देव

विकास सर्वर को हॉट रीलोड, वाइट एचएमआर और वीएफएस फ़ाइल देखने के साथ प्रारंभ करता है।

```bash
nx dev
```

---

## यह क्या करता है

1. `.nexy`/`.mdx` फ़ाइलों के लिए **VFS** (वर्चुअल फ़ाइल सिस्टम) वॉचर प्रारंभ करता है
2. क्लाइंट घटकों के लिए **Vite** डेव सर्वर लॉन्च करता है (यदि कॉन्फ़िगर किया गया हो)
3. `127.0.0.1:3000` पर ऑटो-रीलोड के साथ **यूविकॉर्न** शुरू होता है
4. त्वरित ब्राउज़र अपडेट के लिए **HMR** वेबसॉकेट को `/_nexy/hmr` पर खोलता है

---

## विकल्प

| झंडा | डिफ़ॉल्ट | विवरण |
|------|---------|----------------|
| `--port` | `3000` | सर्वर पोर्ट |
| `--host` | `127.0.0.1` | सर्वर बाइंड पता |
| `--vite-port` | ऑटो | वाइट देव सर्वर पोर्ट |

---

## पर्यावरण चर

| परिवर्तनशील | डिफ़ॉल्ट | विवरण |
|---|---|---|
| `NEXY_DEBUG` | `true` | डिबग मोड (देव में स्वतः सेट) |
| `NEXY_PORT` | `3000` | सर्वर पोर्ट |
| `NEXY_HOST` | `127.0.0.1` | बाइंड पता |

---

## उदाहरण

```bash
# Development with custom port
nx dev --port 8080

# Development binding all interfaces (Docker)
nx dev --host 0.0.0.0
```
