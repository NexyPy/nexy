#nx開発

ホットリロード、Vite HMR、および VFS ファイル監視を使用して開発サーバーを起動します。

```bash
nx dev
```

---

## 何をするのか

1. `.nexy`/`.mdx` ファイルの **VFS** (仮想ファイル システム) ウォッチャーを開始します
2. クライアント コンポーネント用の **Vite** 開発サーバーを起動します (構成されている場合)
3. `127.0.0.1:3000` で **uvicorn** を自動リロードで開始します
4. ブラウザーを即時に更新するために、`/_nexy/hmr` で **HMR** WebSocket を開きます

---

## オプション

|旗 |デフォルト |説明 |
|------|--------|---------------|
| `--port` | `3000` |サーバーポート |
| `--host` | `127.0.0.1` |サーバーバインドアドレス |
| `--vite-port` |自動 | Vite 開発サーバー ポート |

---

## 環境変数

|変数 |デフォルト |説明 |
|----------|-----------|---------------|
| `NEXY_DEBUG` | `true` |デバッグ モード (開発時に自動設定) |
| `NEXY_PORT` | `3000` |サーバーポート |
| `NEXY_HOST` | `127.0.0.1` |バインドアドレス |

 - -

＃＃ 例

```bash
# Development with custom port
nx dev --port 8080

# Development binding all interfaces (Docker)
nx dev --host 0.0.0.0
```
