# एनएक्स माइग्रेट

कॉन्फ़िगर किए गए ORM के माइग्रेशन टूल का उपयोग करके डेटाबेस माइग्रेशन प्रबंधित करता है।

```bash
nx migrate
```

---

## यह कैसे काम करता है

नेक्सी `nexyconfig.py` से कॉन्फ़िगर किए गए ORM का पता लगाता है और उपयुक्त टूल को सौंपता है:

| ओआरएम | माइग्रेशन टूल | कॉन्फ़िग फ़ील्ड |
|----|----------------------|----|
| एसक्यूएलकेमी | एलेम्बिक | `useORM` |
| SQLमॉडल | एलेम्बिक | `useORM` |
| कछुआ-ओआरएम | एरीच | `useORM` |

---

## आदेश

| आदेश | विवरण |
|---------|-----------------|
| `nx migrate` | एक नया माइग्रेशन बनाएं (परिवर्तनों का स्वतः पता लगाता है) |
| `nx migrate --init` | इनिशियलाइज़ माइग्रेशन टूल (एलेम्बिक/एरिच) |
| `nx migrate --upgrade` / `-u` | लंबित माइग्रेशन लागू करें |
| `nx migrate -m "message"` | एक संदेश के साथ माइग्रेशन बनाएं |

---

## उदाहरण

```bash
# Initialize Alembic (first time)
nx migrate --init

# Create a migration after model changes
nx migrate -m "add user table"

# Apply to database
nx migrate --upgrade
```
