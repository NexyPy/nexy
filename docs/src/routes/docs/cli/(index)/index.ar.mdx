# واجهة سطر الأوامر

يأتي Nexy مزودًا بـ CLI كامل المواصفات. الثنائي هو `nx` (أو `nexy`) ويكشف عن أوامر التطوير والبناء ودعم المشروع والترحيل.

يقبل كل أمر `--help` للاستخدام التفصيلي.

## روابط سريعة

- [dev](/docs/cli/dev) — ابدأ تشغيل خادم التطوير
- [start](/docs/cli/start) — خادم الإنتاج
- [build](/docs/cli/build) — بناء الإنتاج
- [new](/docs/cli/new) — سقالة مشروع جديد
- [init](/docs/cli/init) — تهيئة Nexy في مشروع موجود
- [migrate](/docs/cli/migrate) — الانتقال من أطر العمل الأخرى
