# Интерфейс командной строки

Nexy поставляется с полнофункциональным интерфейсом командной строки. Двоичный файл — `nx` (или `nexy`) и предоставляет команды для разработки, сборки, формирования проекта и миграции.

Каждая команда принимает `--help` для подробного использования.

## Быстрые ссылки

- [dev](/docs/cli/dev) — запустить сервер разработки
- [start](/docs/cli/start) — рабочий сервер
- [build](/docs/cli/build) — производственная сборка
- [new](/docs/cli/new) — создать новый проект
- [init](/docs/cli/init) — инициализировать Nexy в существующем проекте
- [migrate](/docs/cli/migrate) — миграция с других фреймворков
