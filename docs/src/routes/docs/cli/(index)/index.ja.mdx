# コマンドラインインターフェース

Nexy には、フル機能の CLI が付属しています。バイナリは `nx` (または `nexy`) で、開発、構築、プロジェクトの足場、移行のためのコマンドを公開します。

すべてのコマンドは、詳細な使用法については `--help` を受け入れます。

## クイックリンク

- [dev](/docs/cli/dev) — 開発サーバーを起動します
- [start](/docs/cli/start) — 運用サーバー
- [build](/docs/cli/build) — 本番ビルド
- [new](/docs/cli/new) — 新しいプロジェクトの足場を築く
- [init](/docs/cli/init) — 既存のプロジェクトで Nexy を初期化します
- [migrate](/docs/cli/migrate) — 他のフレームワークから移行
