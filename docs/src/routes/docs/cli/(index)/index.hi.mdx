# कमांड-लाइन इंटरफ़ेस

नेक्सी पूर्ण-विशेषताओं वाले सीएलआई के साथ आता है। बाइनरी `nx` (या `nexy`) है और विकास, निर्माण, प्रोजेक्ट मचान और माइग्रेशन के लिए कमांड को उजागर करता है।

प्रत्येक कमांड विस्तृत उपयोग के लिए `--help` स्वीकार करता है।

## त्वरित लिंक

- [dev](/docs/cli/dev) - विकास सर्वर प्रारंभ करें
- [start](/docs/cli/start) - उत्पादन सर्वर
- [build](/docs/cli/build) - उत्पादन निर्माण
- [new](/docs/cli/new) - एक नई परियोजना का मंच तैयार करें
- [init](/docs/cli/init) - मौजूदा प्रोजेक्ट में नेक्सी को इनिशियलाइज़ करें
- [migrate](/docs/cli/migrate) - अन्य ढाँचों से माइग्रेट करें
