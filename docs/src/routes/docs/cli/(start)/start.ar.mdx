#نإكس البداية

يقوم بتشغيل خادم الإنتاج باستخدام الإخراج المترجم من `nx build`.

```bash
nx start
```

---

## ماذا يفعل

بدء تشغيل خادم **uvicorn** الذي يخدم تطبيق FastAPI المجمّع من `__nexy__/`. لا يوجد إعادة تحميل تلقائي، ولا يوجد خادم Vite dev - إنتاج فقط.

---

## الخيارات

| علم | الافتراضي | الوصف |
|------|---------|-------------|
| `--port` | `3000` | منفذ الخادم |
| `--host` | `127.0.0.1` | عنوان ربط الخادم |

---

## متغيرات البيئة

| متغير | الافتراضي | الوصف |
|----------|--------|-------------|
| `NEXY_PORT` | `3000` | منفذ الخادم |
| `NEXY_HOST` | `127.0.0.1` | ربط العنوان |
| `NEXY_DEBUG` | `false` | تمكين وضع التصحيح |
---

## مثال

```bash
# Production with custom host/port
nx start --host 0.0.0.0 --port 8080
```

---

## الاسم المستعار

`nx s`
