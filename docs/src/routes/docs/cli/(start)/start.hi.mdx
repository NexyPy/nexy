# एनएक्स प्रारंभ

`nx build` से संकलित आउटपुट का उपयोग करके उत्पादन सर्वर चलाता है।

```bash
nx start
```

---

## यह क्या करता है

`__nexy__/` से संकलित फास्टएपीआई ऐप की सेवा देने वाला **यूविकॉर्न** सर्वर प्रारंभ करता है। कोई ऑटो-रीलोड नहीं, कोई वाइट डेव सर्वर नहीं - केवल उत्पादन।

---

## विकल्प

| झंडा | डिफ़ॉल्ट | विवरण |
|------|---------|----------------|
| `--port` | `3000` | सर्वर पोर्ट |
| `--host` | `127.0.0.1` | सर्वर बाइंड पता |

---

## पर्यावरण चर

| परिवर्तनशील | डिफ़ॉल्ट | विवरण |
|---|---|---|
| `NEXY_PORT` | `3000` | सर्वर पोर्ट |
| `NEXY_HOST` | `127.0.0.1` | बाइंड पता |
| `NEXY_DEBUG` | `false` | डिबग मोड सक्षम करें |
---

## उदाहरण

```bash
# Production with custom host/port
nx start --host 0.0.0.0 --port 8080
```
