# начало nx

Запускает рабочий сервер, используя скомпилированные выходные данные `nx build`.

```bash
nx start
```

---

## Что он делает

Запускает сервер **uvicorn**, обслуживающий скомпилированное приложение FastAPI из `__nexy__/`. Никакой автоматической перезагрузки, никакого сервера разработки Vite — только рабочая версия.

---

## Опции

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--port` | `3000` | Порт сервера |
| `--host` | `127.0.0.1` | Адрес привязки сервера |

---

## Переменные среды

| Переменная | По умолчанию | Описание |
|----------|---------|-------------|
| `NEXY_PORT` | `3000` | Порт сервера |
| `NEXY_HOST` | `127.0.0.1` | Привязать адрес |
| `NEXY_DEBUG` | `false` | Включить режим отладки |
---

## Пример

```bash
# Production with custom host/port
nx start --host 0.0.0.0 --port 8080
```
