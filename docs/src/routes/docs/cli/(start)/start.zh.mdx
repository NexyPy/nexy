#nx开始

使用 `nx build` 的编译输出运行生产服务器。

```bash
nx start
```

---

## 它的作用

启动 **uvicorn** 服务器，从 `__nexy__/` 提供已编译的 FastAPI 应用程序。没有自动重新加载，没有 Vite 开发服务器——仅限生产。

---

## 选项

|旗帜|默认 |描述 |
|------|---------|-------------|
| `--port` | `3000` |服务器端口|
| `--host` | `127.0.0.1` |服务器绑定地址 |

---

## 环境变量

|变量|默认 |描述 |
|----------|---------|-------------|
| `NEXY_PORT` | `3000` |服务器端口|
| `NEXY_HOST` | `127.0.0.1` |绑定地址 |
| `NEXY_DEBUG` | `false` |启用调试模式 |
 - -

＃＃ 例子

```bash
# Production with custom host/port
nx start --host 0.0.0.0 --port 8080
```
