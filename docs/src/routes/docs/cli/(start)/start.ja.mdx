#nxスタート

`nx build` からのコンパイルされた出力を使用して実稼働サーバーを実行します。

```bash
nx start
```

---

## 何をするのか

コンパイルされた FastAPI アプリを提供する **uvicorn** サーバーを `__nexy__/` から起動します。自動リロードや Vite 開発サーバーはなく、実稼働のみです。

---

## オプション

|旗 |デフォルト |説明 |
|------|--------|---------------|
| `--port` | `3000` |サーバーポート |
| `--host` | `127.0.0.1` |サーバーバインドアドレス |

---

## 環境変数

|変数 |デフォルト |説明 |
|----------|-----------|---------------|
| `NEXY_PORT` | `3000` |サーバーポート |
| `NEXY_HOST` | `127.0.0.1` |バインドアドレス |
| `NEXY_DEBUG` | `false` |デバッグモードを有効にする |
 - -

＃＃ 例

```bash
# Production with custom host/port
nx start --host 0.0.0.0 --port 8080
```
