# nx 시작

`nx build`에서 컴파일된 출력을 사용하여 프로덕션 서버를 실행합니다.

```bash
nx start
```

---

## 기능

`__nexy__/`에서 컴파일된 FastAPI 앱을 제공하는 **uvicorn** 서버를 시작합니다. 자동 재로드 없음, Vite 개발 서버 없음 - 프로덕션 전용입니다.

---

## 옵션

| 플래그 | 기본값 | 설명 |
|------|---------|-------------|
| `--port` | `3000` | 서버 포트 |
| `--host` | `127.0.0.1` | 서버 바인드 주소 |

---

## 환경 변수

| 변수 | 기본값 | 설명 |
|------------|---------|-------------|
| `NEXY_PORT` | `3000` | 서버 포트 |
| `NEXY_HOST` | `127.0.0.1` | 주소 바인딩 |
| `NEXY_DEBUG` | `false` | 디버그 모드 활성화 |
---

## 예

```bash
# Production with custom host/port
nx start --host 0.0.0.0 --port 8080
```
