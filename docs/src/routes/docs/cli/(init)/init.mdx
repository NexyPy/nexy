# nx init

Initializes Nexy project scaffolding in an existing directory. Use this to add Nexy to an existing Python project.

```bash
nx init
```

---

## What it creates

- `nexyconfig.py` — main configuration file
- `vite.config.ts` — Vite configuration (if client components enabled)
- `__nexy__/` — compiled output directory (added to `.gitignore`)

---

## Notes

- `nx init` is interactive — it prompts you for project settings
- Use `nx new` if you want to specify a project name and options from the start

---

## Example

```bash
# Initialize in the current directory
nx init
```

---

## Alias

`nx i`
