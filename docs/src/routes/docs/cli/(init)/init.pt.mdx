#nx inicialização

Inicializa o scaffolding do projeto Nexy em um diretório existente. Use isto para adicionar Nexy a um projeto Python existente.

```bash
nx init
```

---

## O que isso cria

- `nexyconfig.py` — arquivo de configuração principal
- `vite.config.ts` — Configuração do Vite (se os componentes do cliente estiverem habilitados)
- `__nexy__/` — diretório de saída compilado (adicionado a `.gitignore`)

---

## Notas

- `nx init` é interativo — solicita configurações do projeto
- Use `nx new` se quiser especificar um nome de projeto e opções desde o início

---

## Exemplo

```bash
# Initialize in the current directory
nx init
```

---

## Alias

`nx i`
