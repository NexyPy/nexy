# एनएक्स इनिट

मौजूदा निर्देशिका में नेक्सी प्रोजेक्ट मचान को प्रारंभ करता है। मौजूदा पायथन प्रोजेक्ट में नेक्सी को जोड़ने के लिए इसका उपयोग करें।

```bash
nx init
```

---

## यह क्या बनाता है

- `nexyconfig.py` - मुख्य कॉन्फ़िगरेशन फ़ाइल
- `vite.config.ts` - वाइट कॉन्फ़िगरेशन (यदि क्लाइंट घटक सक्षम हैं)
- `__nexy__/` - संकलित आउटपुट निर्देशिका (`.gitignore` में जोड़ा गया)

---

## नोट्स

- `nx init` इंटरैक्टिव है - यह आपको प्रोजेक्ट सेटिंग्स के लिए संकेत देता है
- यदि आप शुरू से ही प्रोजेक्ट का नाम और विकल्प निर्दिष्ट करना चाहते हैं तो `nx new` का उपयोग करें

---

## उदाहरण

```bash
# Initialize in the current directory
nx init
```

`nx i`
