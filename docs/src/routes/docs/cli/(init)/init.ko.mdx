# nx 초기화

기존 디렉터리에서 Nexy 프로젝트 스캐폴딩을 초기화합니다. 이를 사용하여 기존 Python 프로젝트에 Nexy를 추가합니다.

```bash
nx init
```

---

## 그것이 만들어내는 것

- `nexyconfig.py` — 기본 구성 파일
- `vite.config.ts` — Vite 구성(클라이언트 구성 요소가 활성화된 경우)
- `__nexy__/` — 컴파일된 출력 디렉터리(`.gitignore`에 추가됨)

---

## 메모

- `nx init`는 대화형입니다. 프로젝트 설정을 묻는 메시지를 표시합니다.
- 처음부터 프로젝트 이름과 옵션을 지정하고 싶다면 `nx new`를 사용하세요.

---

## 예

```bash
# Initialize in the current directory
nx init
```

`nx i`
