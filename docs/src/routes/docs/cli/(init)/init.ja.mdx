#nx初期化

既存のディレクトリで Nexy プロジェクト スキャフォールディングを初期化します。これを使用して、既存の Python プロジェクトに Nexy を追加します。

```bash
nx init
```

---

## それが生み出すもの

- `nexyconfig.py` — メイン構成ファイル
- `vite.config.ts` — Vite 構成 (クライアント コンポーネントが有効な場合)
- `__nexy__/` — コンパイルされた出力ディレクトリ (`.gitignore` に追加)

---

## 注意事項

- `nx init` は対話型です - プロジェクト設定を求めるプロンプトが表示されます
- 最初からプロジェクト名とオプションを指定したい場合は、`nx new` を使用します。

---

## 例

```bash
# Initialize in the current directory
nx init
```

---

## エイリアス
