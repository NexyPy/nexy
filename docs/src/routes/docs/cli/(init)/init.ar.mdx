# نكس الحرف الأول

تهيئة سقالات مشروع Nexy في دليل موجود. استخدم هذا لإضافة Nexy إلى مشروع Python موجود.

```bash
nx init
```

---

## ما يخلق

- `nexyconfig.py` — ملف التكوين الرئيسي
- `vite.config.ts` — تكوين Vite (في حالة تمكين مكونات العميل)
- `__nexy__/` — دليل المخرجات المجمع (تمت إضافته إلى `.gitignore`)

---

## ملاحظات

- `nx init` تفاعلي — فهو يطالبك بإعدادات المشروع
- استخدم `nx new` إذا كنت تريد تحديد اسم المشروع وخياراته من البداية

---

## مثال

```bash
# Initialize in the current directory
nx init
```

---

## الاسم المستعار

`nx i`
