# nx init

Initialisiert das Nexy-Projektgerüst in einem vorhandenen Verzeichnis. Verwenden Sie dies, um Nexy zu einem vorhandenen Python-Projekt hinzuzufügen.

```bash
nx init
```

---

## Was es schafft

- `nexyconfig.py` – Hauptkonfigurationsdatei
- `vite.config.ts` – Vite-Konfiguration (wenn Client-Komponenten aktiviert)
- `__nexy__/` – kompiliertes Ausgabeverzeichnis (hinzugefügt zu `.gitignore`)

---

## Notizen

- `nx init` ist interaktiv – es fordert Sie zur Eingabe von Projekteinstellungen auf
- Verwenden Sie `nx new`, wenn Sie von Anfang an einen Projektnamen und Optionen angeben möchten

---

## Beispiel

```bash
# Initialize in the current directory
nx init
```

---

## Alias

`nx i`
