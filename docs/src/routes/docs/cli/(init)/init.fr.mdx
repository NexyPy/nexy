# nx initialisation

Initialise l'échafaudage du projet Nexy dans un répertoire existant. Utilisez-le pour ajouter Nexy à un projet Python existant.

```bash
nx init
```

---

## Ce que cela crée

- `nexyconfig.py` — fichier de configuration principal
- `vite.config.ts` — Configuration Vite (si les composants clients sont activés)
- `__nexy__/` — répertoire de sortie compilé (ajouté à `.gitignore`)

---

## Remarques

- `nx init` est interactif : il vous demande les paramètres du projet
- Utilisez `nx new` si vous souhaitez spécifier un nom de projet et des options dès le début

---

## Exemple

```bash
# Initialize in the current directory
nx init
```

---

## Alias

`nx i`
