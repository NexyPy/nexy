#nx初始化

在现有目录中初始化 Nexy 项目脚手架。使用它将 Nexy 添加到现有的 Python 项目。

```bash
nx init
```

---

## 它创造了什么

- `nexyconfig.py` — 主配置文件
- `vite.config.ts` — Vite 配置（如果启用了客户端组件）
- `__nexy__/` — 编译输出目录（添加到`.gitignore`）

---

## 注释

- `nx init` 是交互式的 — 它会提示您进行项目设置
- 如果您想从一开始就指定项目名称和选项，请使用 `nx new`

---

## 示例

```bash
# Initialize in the current directory
nx init
```

---

## 别名

`nx i`
