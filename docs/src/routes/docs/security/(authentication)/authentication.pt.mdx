# Autenticação

Nexy fornece autenticação baseada em middleware por meio do `AuthenticationMiddleware` da Starlette. Configure-o globalmente em `nexyconfig.py`.

## Autenticação baseada em sessão

```python
# src/auth.py
from starlette.authentication import AuthCredentials, AuthenticationBackend, SimpleUser

class SessionAuthBackend(AuthenticationBackend):
    async def authenticate(self, conn):
        user_id = conn.session.get("user_id")
        if user_id:
            return AuthCredentials(["authenticated"]), SimpleUser(user_id)
        return None
```

```python
# nexyconfig.py
class NexyConfig(NexyConfigModel):
    useSession = {"secret_key": "change-me"}
    useAuth = {"backend": SessionAuthBackend()}
```

## Autenticação baseada em token

```python
class TokenAuthBackend(AuthenticationBackend):
    async def authenticate(self, conn):
        token = conn.headers.get("Authorization", "").removeprefix("Bearer ")
        user = await verify_token(token)
        if user:
            return AuthCredentials(["authenticated"]), SimpleUser(user.id)
        return None
```

## Acessar usuário em manipuladores

```python
def GET(request):
    return {"user": request.user.username}
```

## Referência de configuração

| Campo | Tipo | Padrão | Descrição |
|-------|------|---------|------------|
| `useAuth` | `dict \| None` | `None` | Kwargs encaminhados para `AuthenticationMiddleware` da Starlette |
| `useSession` | `dict \| None` | `None` | Kwargs encaminhados para `SessionMiddleware` da Starlette |
