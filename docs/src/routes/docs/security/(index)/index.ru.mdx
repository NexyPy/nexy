# Обзор безопасности

Nexy предоставляет промежуточное программное обеспечение для аутентификации, защиту маршрутов и поддержку сеансов. Стандартная библиотека Python и сторонние пакеты охватывают шифрование, хеширование, JWT и генерацию идентификаторов.

---

## Матрица функций

| Особенность | Некси API | Бэкэнд |
|---------|----------|---------|
| Аутентификация | Конфигурация `useAuth` + собственный бэкэнд | Старлетка `AuthenticationMiddleware` |
| Защита маршрута | `"@UseGuard(*guards)` | ФастAPI `Depends` |
| Сессии | Конфигурация `useSession` + ловушка `useSession()` | Старлетка `SessionMiddleware` |
| Авторизация | Пользовательские охранники + проверка ролей | FastAPI `Depends` |
| Шифрование/хеширование | Стандартный Питон | `hashlib`, `bcrypt`, `cryptography` |
| ДЖВТ | Сторонние | `PyJWT` |
| УИД | Стандартный Питон | `uuid`, `secrets` |
