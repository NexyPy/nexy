# "@미들웨어(FBR)

미들웨어 호출 가능 항목을 경로 함수에 적용합니다.

## 미들웨어 계약

미들웨어는 `__call__(self, request)`로 호출할 수 있습니다. FastAPI `Request` 객체를 수신하고 핸들러보다 먼저 실행됩니다.

```python
class LoggingMiddleware:
    def __call__(self, request) -> None:
        print(f"Request: {request.method} {request.url}")
```

## 함수에 대한 미들웨어

```python
from nexy.decorators import Middleware

"@Middleware(LoggingMiddleware())
def GET():
    ...
```

## 다중 미들웨어

```python
from nexy.decorators import Middleware

"@Middleware(LoggingMiddleware(), TimerMiddleware())
def GET():
    ...
```

## 서명

```python
Middleware(*middlewares: Callable[..., Any]) -> Callable[[Any], Any]
```

미들웨어는 FastAPI `Depends`로 실행되며 핸들러보다 먼저 실행됩니다. Unlike guards, middleware is intended for side effects (logging, timing), not for blocking requests (though it can raise `HTTPException`).
