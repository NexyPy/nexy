# 웹소켓(FBR)

`async def SOCKET` 함수로 `.py` 파일을 생성하여 WebSocket 엔드포인트를 정의합니다.

---

## 기본 에코

```python
# src/routes/chat.py
from fastapi import WebSocket, WebSocketDisconnect

async def SOCKET(websocket: WebSocket):
    await websocket.accept()
    try:
        while True:
            data = await websocket.receive_text()
            await websocket.send_text(f"Echo: {data}")
    except WebSocketDisconnect:
        pass
```

함수 이름 `SOCKET`(대소문자 구분 안 함)는 Starlette WebSocket 엔드포인트에 매핑됩니다. 파일 경로에 따라 URL이 결정됩니다(이 예에서는 `/chat`).

## 방 패턴

연결된 모든 클라이언트에게 메시지를 브로드캐스트합니다.

```python
# src/routes/chat.py
from fastapi import WebSocket, WebSocketDisconnect

connections: list[WebSocket] = []

async def SOCKET(websocket: WebSocket):
    await websocket.accept()
    connections.append(websocket)
    try:
        while True:
            data = await websocket.receive_text()
            for conn in connections:
                await conn.send_text(data)
    except WebSocketDisconnect:
        connections.remove(websocket)
```

`connections` 목록은 모듈 수준에 있습니다. 모든 클라이언트는 동일한 목록을 공유합니다.

---

## 이름이 지정된 방

룸 이름별로 그룹 연결:

```python
# src/routes/rooms/{room_id}.py
from fastapi import WebSocket, WebSocketDisconnect

rooms: dict[str, list[WebSocket]] = {}

async def SOCKET(websocket: WebSocket, room_id: str):
    await websocket.accept()
    rooms.setdefault(room_id, []).append(websocket)
    try:
        while True:
            data = await websocket.receive_text()
            for conn in rooms.get(room_id, []):
                await conn.send_text(data)
    except WebSocketDisconnect:
        rooms[room_id].remove(websocket)
        if not rooms[room_id]:
            del rooms[room_id]
```

URL 매개변수 `{room_id}`는 파일 이름에서 자동으로 삽입됩니다.

---

## 연결 수명주기

| 이벤트 | 무슨 일이 일어나는가 |
|-------|-------------|
| 클라이언트 연결 | `websocket.accept()` — 먼저 호출되어야 함 |
| 메시지 수신됨 | `receive_text()` / `receive_json()` / `receive_bytes()` |
| 클라이언트 연결 끊김 | `WebSocketDisconnect` 발생 — `except`에서 정리 |
| 서버 종료 | `await websocket.close(code=1000)` |

연결을 정리하려면 항상 메시지 루프를 `try/except WebSocketDisconnect`로 래핑하세요.
