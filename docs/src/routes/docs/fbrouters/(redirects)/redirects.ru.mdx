# Перенаправления (FBR)

Перенаправляйте входящие запросы на другие URL-адреса, используя `RedirectResponse` FastAPI.

## Базовое перенаправление

```python
# src/routes/redirect.py
from fastapi.responses import RedirectResponse

def GET():
    return RedirectResponse("/login")
```

## С кодом состояния

```python
from fastapi.responses import RedirectResponse

def GET():
    return RedirectResponse("/new-page", status_code=301)
```

## Условное перенаправление

```python
from fastapi.responses import RedirectResponse

def GET(request):
    if not request.user.is_authenticated:
        return RedirectResponse("/login")
    return "<h1>Dashboard</h1>"
```

## Ссылка на код состояния

| Код | Имя | Вариант использования |
|------|------|----------|
| 301 | Переехал навсегда | Постоянное изменение URL-адреса |
| 302 | Найдено (по умолчанию) | Временное перенаправление |
| 307 | Временное перенаправление | Сохраняет метод HTTP |
| 308 | Постоянное перенаправление | Сохраняет метод HTTP |

## Общие шаблоны

- Перенаправление аутентификации: неаутентифицированные пользователи → `/login`
– Устаревшие URL-адреса: старые пути → новые пути (301).
- Перенаправление после отправки: после формы POST → страница успеха (303)
- Перенаправление локали: `/` → `/{locale}/` в зависимости от языка браузера.
