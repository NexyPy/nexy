# Redirections (FBR)

Redirigez les requêtes entrantes vers d'autres URL à l'aide du `RedirectResponse` de FastAPI.

## Redirection de base

```python
# src/routes/redirect.py
from fastapi.responses import RedirectResponse

def GET():
    return RedirectResponse("/login")
```

## Avec code d'état

```python
from fastapi.responses import RedirectResponse

def GET():
    return RedirectResponse("/new-page", status_code=301)
```

## Redirection conditionnelle

```python
from fastapi.responses import RedirectResponse

def GET(request):
    if not request.user.is_authenticated:
        return RedirectResponse("/login")
    return "<h1>Dashboard</h1>"
```

## Référence du code d'état

| Codes | Nom | Cas d'utilisation |
|------|------|----------|
| 301 | Déménagé définitivement | Changement d'URL permanent |
| 302 | Trouvé (par défaut) | Redirection temporaire |
| 307 | Redirection temporaire | Préserve la méthode HTTP |
| 308 | Redirection permanente | Préserve la méthode HTTP |

## Modèles courants

- Redirection d'authentification : utilisateurs non authentifiés → `/login`
- Anciennes URL : anciens chemins → nouveaux chemins (301)
- Redirection post-soumission : après le formulaire POST → page de réussite (303)
- Redirection vers les paramètres régionaux : `/` → `/{locale}/` en fonction de la langue du navigateur
