# صفحہ کی منتقلی کیسے کام کرتی ہے؟

Nexy کلائنٹ نیویگیشن کے لیے براؤزر کے View Transitions API کا استعمال کرتا ہے، اس لیے ایک معاون براؤزر صفحہ کی تبدیلی کو متحرک کرتا ہے جب تک کہ وزیٹر کم حرکت کو ترجیح نہ دے۔

## جب ایک منتقلی چلتی ہے۔

پہلی دستاویز ایک عام سرور کا جواب ہے اور اس میں کوئی منتقلی نہیں ہے۔ اس کے بعد سے، کلائنٹ روٹر کے ذریعے سنبھالا جانے والا ہر نیویگیشن صفحہ کو `document.startViewTransition()` کے اندر تبدیل کرتا ہے: کلائنٹ کے روٹ کا لنک، `router.push()` یا `router.replace()`، اور پیچھے اور آگے کے بٹن۔ روٹر پہلے اگلا صفحہ اور اس کے لے آؤٹ کو پیش کرتا ہے، پھر یو آر ایل کو منتقل کرتا ہے، اس لیے نیا صفحہ ظاہر ہونے سے پہلے تیار ہے۔

React، Preact، Solid، Vue اور Svelte ایک ہی راؤٹر کا اشتراک کرتے ہیں، لہٰذا سلوک پانچوں اڈاپٹرز میں ایک جیسا ہے۔ ٹرانزیشن کو فعال کرنے کے لیے کوئی ترتیب نہیں ہے۔

## جب یہ واپس گرے۔

- بغیر `startViewTransition()` کے براؤزر صفحہ کو براہ راست رینڈر کرتا ہے۔
- `prefers-reduced-motion: reduce` کے ساتھ، راؤٹر صفحہ کو براہ راست رینڈر کرتا ہے۔
- نئی نیویگیشن کے ذریعے چھوڑی گئی منتقلی غلطی کو لاگ نہیں کرتی ہے: صفحہ اب بھی درست ہے۔

یو آر ایل، ہسٹری، اسکرول پوزیشن اور `nexy:navigated` ایونٹ منتقلی کے ساتھ یا اس کے بغیر اسی طرح برتاؤ کرتے ہیں۔

## منتقلی کا انداز

Nexy بحری جہاز کوئی حرکت پذیری CSS نہیں ہے۔ براؤزر اپنا ڈیفالٹ کراس فیڈ لاگو کرتا ہے، جسے آپ اپنی اسٹائل شیٹ میں بدل سکتے ہیں:

```css
::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: 250ms;
}
```
