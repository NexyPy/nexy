# صفحات

ایک صفحہ فائل HTML لوٹاتا ہے۔ آپ کس فائل کی قسم کو استعمال کرتے ہیں اس کے پیدا ہونے کے طریقے کو تبدیل کرتے ہیں: دیکھیں [ویوز](../../../views/README.md)۔ یہ سیکشن روٹنگ کے قواعد کا احاطہ کرتا ہے جو ہر صفحے کی شکل پر لاگو ہوتے ہیں۔

| صفحہ | اس میں کیا شامل ہے |
|---|---|
| [متحرک راستے](dynamic-routes.md) | `[slug]`، `[...path]`، روٹ گروپس، ٹائپ شدہ طبقات |
| [خرابی کے صفحات](../errors/README.md) | `notfound.nexy`، `errors.nexy`، API کلائنٹس کے لیے JSON |
| [لے آؤٹس](../layouts/README.md) | ایک صفحہ فی لے آؤٹ فائل کی قسم |
| [وراثت](../inheritance.md) | ترتیب اور انحصار کیسے جمع ہوتے ہیں |

## ایک کم سے کم صفحہ

```nexy filename="src/routes/about.nexy"
---
title: prop[str] = "About"
---
<h1>{{ title }}</h1>
```

یہ `/about` پر پیش کیا جاتا ہے۔ `---` لائنوں کے درمیان فرنٹ میٹر ہے Python; اس کے نیچے مارک اپ Jinja2 ہے۔ دیکھیں [.nexy فائلیں](../../../views/nexy/README.md)۔

## صفحہ کی شکلیں

| موڈ | فائل | پیدا کرتا ہے |
|---|---|---|
| سرور | `.nexy` | سرور سے پیش کردہ HTML Python اور Jinja2 |
| سرور | `.md`، `.mdx` | مواد کے صفحات |
| کلائنٹ | `.tsx`، `.jsx`، `.vue`، `.svelte` | فریم ورک کے اجزاء، براؤزر میں رینڈرڈ اور نیویگیٹ |

دونوں طریقوں کو ایک پروجیکٹ میں نہیں ملایا جا سکتا۔ دیکھیں [سرور موڈ اور کلائنٹ موڈ](../modes.md)۔ کلائنٹ کے اجزاء اب بھی سرور موڈ میں ظاہر ہو سکتے ہیں، جیسا کہ [جزیرے](../../../rendering/islands.md) صفحہ کے اندر `.nexy`۔

## انکریمنٹل کیشنگ

stale-while-revalidate کے ساتھ کیش کرنے کے لیے `revalidate = 60` کو `.nexy` صفحہ میں شامل کریں۔ دیکھیں [ISR](../../../rendering/isr.md)۔
