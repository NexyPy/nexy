# 2.2 میں اپ گریڈ ہو رہا ہے۔

جب آپ 2.1 سے 2.2 پر جاتے ہیں تو موجودہ پروجیکٹ میں کیا تبدیلیاں آتی ہیں، اور اس کے بارے میں کیا کرنا ہے۔ مکمل فہرست [تبدیلیوں کا ریکارڈ](../../CHANGELOG.md) میں ہے۔

```bash
uv add "nexy>=2.2"            # or: uv tool upgrade nexy
nx build
nx test
```

## جو آپ کو تبدیل کرنا پڑ سکتا ہے۔

| تبدیل کریں | یہ کریں |
|---|---|
| **`.mdx` کو Vite نے مرتب کیا ہے۔ صرف** Python مرتب کرنے والا اب اسے رینڈر نہیں کرتا | React یا Preact کو `useFF` میں رکھیں اور `@mdx-js/rollup`، `remark-gfm` اور `@mdx-js/react` کو انسٹال کریں۔ ایک صفحہ جس میں اجزاء نہ ہوں وہ `.md` فائل ہو سکتا ہے |
| **`useBadge` ہے۔ چلا گیا** "Bult with Nexy" ٹیگ اب موجود نہیں ہے | لائن کو `nexyconfig.py` سے حذف کریں۔ ایک بچ جانے والی لائن کو نظر انداز کر دیا جاتا ہے |
| **`nx check` مزید مرتب نہیں کرتا `.mdx`** | کچھ نہیں: Vite تعمیر میں MDX غلطیوں کی اطلاع دیتا ہے |

## جو ویسا ہی رہتا ہے۔

- آپ کے راستے، ترتیب، اعمال اور ترتیب۔
- موجودہ پروجیکٹس اپنے اپنے اسٹارٹر پیجز رکھتے ہیں۔ نیا اسٹارٹر ڈیزائن صرف اپ گریڈ کے بعد بنائے گئے پروجیکٹس پر لاگو ہوتا ہے۔
- ڈویلپمنٹ ٹول بار اور `useDevTools`۔

## 2.2 میں نیا

- **ایجنٹ فائلیں** `nx new` لکھتے ہیں `AGENTS.md`، `CLAUDE.md` اور ایجنٹوں کو کوڈنگ کرنے کی مہارت۔ آپ کے پاس پہلے سے موجود پروجیکٹ کے لیے `nx skills` چلائیں۔ یہ آپ کی لکھی ہوئی فائل کو کبھی بھی اوور رائٹ نہیں کرتا ہے۔ دیکھیں [کوڈنگ ایجنٹس](../guides/ai-agents.md)۔
- **ایک دیو سرور جو رکھتا ہے۔ چل رہا ہے** جب آپ کی درخواست شروع نہیں ہوسکتی ہے، تو `nx dev` کیوں رپورٹ کرتا ہے اور باہر جانے کے بجائے اگلی تبدیلی کا انتظار کرتا ہے۔
- **ایک ہی صفحات اور اجزاء کے ساتھ Tailwind یا UnoCSS میں ہر فریم ورک کے لیے ایک نیا اسٹارٹر**۔
- **UnoCSS سرور پروجیکٹ میں `.nexy` فائلیں** پڑھتا ہے۔ اگر آپ `.nexy` صفحات کے ساتھ UnoCSS استعمال کرتے ہیں، تو `content` بلاک کو شامل کریں جو [ٹربل شوٹنگ](../guides/troubleshooting.md) میں دکھایا گیا ہے۔

## درست دستاویزات

تین صفحات نے کچھ کہا جو کوڈ نہیں کرتا ہے۔ اگر آپ ان کی پیروی کرتے ہیں، تو اپنی فائلیں چیک کریں:

- ایک `.nexy` جزو اپنے بچوں کو `<Slot />` (کیپٹل ایس) کے ساتھ رکھتا ہے، `<slot />` نہیں۔
- ایک `.nexy` اجزاء کی فائل کا نام پاسکل کیس میں رکھا گیا ہے: اسے Python ماڈیول کے طور پر درآمد کیا جاتا ہے، اس لیے ہائفن مرتب نہیں ہوتا ہے۔
- `.mdx` کے لیے، فریم ورک Preact ہے جب فائل درآمد کرتی ہے `preact`، React دوسری صورت میں۔
