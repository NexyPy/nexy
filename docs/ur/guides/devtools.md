# دیو ٹول بار

`nexy dev` ہر HTML صفحہ پر ایک ٹول بار شامل کرتا ہے۔ یہ نیچے بائیں کونے میں بیٹھتا ہے، دکھاتا ہے کہ آپ کس راستے پر ہیں اور سرور نے کتنا وقت لیا، اور ایک پینل میں کھلتا ہے۔ یہ کبھی بھی پیداواری ردعمل کا حصہ نہیں ہوتا ہے۔

| ٹیب | دکھاتا ہے |
|---|---|
| صفحہ | URL، روٹ، ہینڈلر، فائل جس سے یہ آتی ہے (ایک لنک کے ساتھ جو اسے آپ کے ایڈیٹر میں کھولتا ہے)، اسٹیٹس، سرور ٹائم، پہلا بائٹ، پہلا پینٹ، مین مواد، لے آؤٹ شفٹ (گریڈڈ گرین، امبر یا ریڈ)، DOM تیار |
| روٹس | ایپ کا ہر روٹ اس کے طریقوں، ایک فلٹر، اور موجودہ کو نشان زد کرتا ہے۔ ہر ایک اپنی فائل سے لنک کرتا ہے |
| خرابیاں | سرور کی خرابیاں جب سے `nexy dev` شروع ہوئی ہیں اور براؤزر نے جو غلطیاں اٹھائی ہیں |
| ترتیبات | تھیم (صفحہ سے میل کریں، تاریک یا روشنی)، پوزیشن، سائز، چھپائیں، دوبارہ ترتیب دیں |

## اسے منتقل کریں۔

بٹن کو گھسیٹیں: یہ پوائنٹر کی پیروی کرتا ہے اور جب آپ جانے دیتے ہیں تو قریب ترین کونے تک پہنچ جاتا ہے۔ پینل اسکرین کے وسط کی طرف کھلتا ہے جہاں سے بٹن ہوتا ہے۔ پوزیشن اس براؤزر میں رکھی گئی ہے۔ آپ **ترتیبات** میں ایک کونا بھی چن سکتے ہیں۔

`Shift` + `Alt` + `D` ٹول بار کو چھپاتا اور دکھاتا ہے۔ `Esc` پینل کو بند کرتا ہے۔

## غلطیاں

براؤزر میں ایک نہ پکڑی گئی غلطی صفحہ پر پیغام اور اسٹیک کے ساتھ ایک ڈائیلاگ کھولتی ہے۔ کئی غلطیوں کے ساتھ، ان کے ذریعے قدم رکھیں (3 میں سے 1)۔ سرور کی خرابی اسی قسم کے صفحہ کے ساتھ جواب دیتی ہے: غلطی، جہاں اسے اٹھایا گیا تھا اور اس کے ارد گرد کا کوڈ۔

## اسے بند کر دیں۔

```python filename="nexyconfig.py"
class NexyConfig(NexyConfigModel):
    useDevTools = False
```

ٹول بار ایک اسٹائل بلاک اور اسکرپٹ ہے جو `</body>` سے پہلے شامل کیا گیا: کوئی بیرونی درخواست، کوئی انحصار نہیں۔ JSON، فائلیں اور ہر جواب جو HTML نہیں ہے اکیلے رہ گئے ہیں۔
