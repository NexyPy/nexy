# بین الاقوامی کاری (i18n)

Nexy آپ کی درخواست کا ترجمہ نہیں کرتا ہے۔ اس میں کوئی لوکل مڈل ویئر نہیں ہے، کوئی `trans` مددگار نہیں ہے اور کوئی لوکل فائل نہیں ہے: ایک ایپلیکیشن i18n لائبریری کو چنتی ہے جو اس کے مطابق ہوتی ہے، جیسا کہ یہ ایک ORM چنتی ہے۔

کمانڈ لائن (`nx`) کا ترجمہ ہے؛ دیکھیں [CLI](../reference/cli.md)]۔

## ایک ہینڈلر میں

ایک ہینڈلر پڑھتا ہے کہ اسے درخواست سے کیا ضرورت ہے۔ یہ `Accept-Language` ہیڈر کی زبان میں جواب دیتا ہے:

```python filename="src/routes/hello.py"
from nexy.http import Header

MESSAGES = {"en": "Hello", "fr": "Bonjour"}


async def GET(accept_language: str = Header("en")):
    language = accept_language.split(",")[0].split("-")[0].lower()
    return {"message": MESSAGES.get(language, MESSAGES["en"])}
```

## ایک صفحے میں

اپنے فرنٹ اینڈ کی لائبریری کو کلائنٹ روٹ شدہ صفحات کے لیے استعمال کریں (مثال کے طور پر `i18next`، `vue-i18n` یا Svelte اسٹور)، اور اپنی Python لائبریری (`gettext` معیاری لائبریری سے، یا بابل) `.nexy` صفحات کے لیے۔ روٹ لے آؤٹ میں `<html lang>` سیٹ کریں۔
