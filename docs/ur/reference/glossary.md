# لغت

وہ الفاظ جو یہ دستاویزات استعمال کرتے ہیں، ایک ایک سطر، حروف تہجی کی ترتیب میں۔ ایک اصطلاح جس میں ایک لائن سے زیادہ کی ضرورت ہوتی ہے ایک صفحہ ہوتا ہے: لنک پر عمل کریں۔ تصورات ایک ساتھ کیسے فٹ ہوتے ہیں، اس کے لیے [بنیادی تصورات](../getting-started/core-concepts.md) کو پڑھیں۔

## شرائط

| اصطلاح | ایک لائن میں |
|---|---|
| ایکشن | ایک Python فنکشن نشان زد `@Action`، ایک `POST` کے طور پر کام کرتا ہے اور کلائنٹ ([کارروائیاں](../guides/actions.md)) | سے قابل کال ہے۔
| ASGI | انٹرفیس Uvicorn بولتا ہے، FastAPI اور Starlette | کے ذریعہ نافذ کیا جاتا ہے۔
| کلائنٹ موڈ | `useCSR = True`: فریم ورک فائلیں روٹس ہیں اور براؤزر نیویگیٹس ([موڈز](../routing/fbr/modes.md)) |
| جزو | ایک دوبارہ قابل استعمال UI بلڈنگ بلاک جو کسی منظر کو تحریر کرنے کے لیے استعمال کیا جاتا ہے ([views](../views/README.md)]) |
| CSR | کلائنٹ سائیڈ رینڈرنگ: براؤزر پہلی دستاویز کے بعد صفحات پیش کرتا ہے ([CSR](../rendering/csr.md)) |
| انحصار | ایک فنکشن FastAPI ہینڈلر سے پہلے چلتا ہے، فی روٹ یا فی فولڈر ([انحصارات](../routing/fbr/dependencies/README.md)) |
| ایک صفحہ کے ارد گرد دستاویز کا شیل | `<html>`، `<head>` اور `<body>`، قریبی لے آؤٹ یا Nexy ([layouts](../routing/fbr/layouts/README.md)]) |
| اختتامی نقطہ | URL اور HTTP طریقہ کا انوکھا امتزاج ([ملاحظات](../views/README.md)) |
| ایف بی آر | فائل پر مبنی روٹنگ: `src/routes/` کے تحت فائل ایک روٹ ہے ([روٹنگ](../routing/fbr/README.md)) |
| فرنٹ میٹر | ایک `.nexy` یا `.md` فائل کی دو `---` لائنوں کے درمیان Python بلاک ([.nexy فائلز](../views/nexy/README.md)) |
| گارڈز | ایک انحصار جو `HTTPException` ([گارڈز](../routing/modular/guards-and-metadata.md)) | کو بڑھا کر درخواست سے انکار کرتا ہے۔
| ہینڈلر | ایک Python فنکشن جو ایک مخصوص طریقہ کے لیے HTTP درخواست کو ہینڈل کرتا ہے ([ملاحظات](../views/README.md)) |
| HMR | ہاٹ ماڈیول کی تبدیلی: دیو سرور تبدیل شدہ ماڈیولز کو تبدیل کرتا ہے، بغیر مکمل دوبارہ لوڈ کیے ([فرنٹ اینڈ](../guides/frontend.md)) |
| ہائیڈریشن | براؤزر HTML کے ساتھ ایک فریم ورک منسلک کرتا ہے جو سرور نے پہلے سے بھیجا ہے ([جزیرے](../rendering/islands.md)) |
| جزیرہ | سرور کی طرف سے پیش کردہ صفحہ کے اندر نصب ایک کلائنٹ کا جزو ([جزیرے](../rendering/islands.md)) |
| ISR | اضافی جامد تخلیق نو: ایک کیش شدہ صفحہ فی راستہ، پس منظر میں تازہ کیا گیا ([ISR](../rendering/isr.md)) |
| لے آؤٹ | ایک `layout.*` فائل جو اپنے فولڈر کے نیچے صفحات کو سمیٹتی ہے ([لے آؤٹس](../routing/fbr/layouts/README.md)) |
| ماڈیولر راؤٹر | راستوں کا اعلان `@Module` اور `@Controller` کے تحت `src/apps/` ([ماڈیولر](../routing/modular/README.md)) |
| صفحہ | `src/routes/` ([ملاحظات](../views/README.md)]) | کے تحت ایک فائل کے ذریعہ بیان کردہ یو آر ایل ایڈریس ایبل وسیلہ
| پری فیچ | صفحہ کو لنک کے پیچھے لوڈ کرنا اس سے پہلے کہ قاری اس پر کلک کرے ([لنکنگ](../routing/fbr/navigation/linking-and-navigating.md)) |
| پروپس | وہ اقدار جو والدین کسی جزو کو منتقل کرتے ہیں ([.nexy فائلز](../views/nexy/README.md)) |
| دوبارہ تصدیق کرنا | سیکنڈوں کی تعداد جس کے بعد ایک ISR صفحہ پس منظر میں دوبارہ بنایا جاتا ہے ([ISR](../rendering/isr.md)] |
| روٹ | ایک URL پیٹرن، جو روٹ فائل کے راستے سے تیار ہوتا ہے ([روٹنگ](../routing/README.md)) |
| روٹ گروپ | قوسین میں ایک فولڈر جو کسی حصے کو شامل کیے بغیر روٹس کو گروپ کرتا ہے ([متحرک راستے](../routing/fbr/pages/dynamic-routes.md)] |
| روٹ ہینڈلر | `GET`، `POST`، … ایک `.py` روٹ فائل کا فنکشن ([ہینڈلر](../routing/fbr/handlers/README.md)) |
| سرور موڈ | `useCSR = False`، ڈیفالٹ: سرور رینڈر کرتا ہے `.nexy` اور `.md` صفحات ([موڈز](../routing/fbr/modes.md)) |
| مہارت | ایک فولڈر جس میں `SKILL.md` ہے جو کوڈنگ ایجنٹ کو Nexy کا ایک حصہ سکھاتا ہے ([کوڈنگ ایجنٹس](../guides/ai-agents.md)) |
| ایس ایس جی | جامد سائٹ کی نسل؛ **Nexy موڈ نہیں ہے**: وقت سے پہلے بنایا گیا HTML ہمیشہ سرور کے ذریعہ پڑھا جاتا ہے ([رینڈرنگ](../rendering/README.md)) |
| SSR | سرور سائیڈ رینڈرنگ: سرور ہر صفحے کو اپنی درخواست کے لیے پیش کرتا ہے، اور یہ ڈیفالٹ ہے ([SSR](../rendering/ssr.md)) |
| دیکھیں | ایک صفحہ کے لیے رسپانس باڈی تیار کرنے کا عمل ([نظریات](../views/README.md)) |

## فائلیں اور فولڈرز

| نام | ایک لائن میں |
|---|---|
| `__nexy__/` | پیدا شدہ آؤٹ پٹ: مرتب شدہ صفحات، کلائنٹ کا اندراج اور ایکشن کلائنٹ؛ کبھی تدوین نہیں کی، کبھی عہد نہیں کیا |
| `nexyconfig.py` | پروجیکٹ کی ترتیب، `use*` فیلڈز کی ایک کلاس ([config](config.md)] |
| `public/` | فائلیں روٹ پر پیش کی جاتی ہیں، جیسے `public/logo.svg` → `/logo.svg` ([فائل کنونشنز](file-conventions.md)) |
| `src/apps/` | ماڈیولر روٹر کے کنٹرولرز اور ماڈیولز ([ماڈیولر](../routing/modular/README.md)) |
| `src/components/` | صفحات کے ذریعے درآمد شدہ اجزاء کبھی راستے نہیں ([فائل کنونشنز](file-conventions.md)]) |
| `src/routes/` | درخواست کے راستے ([فائل کنونشنز](file-conventions.md)]) |
