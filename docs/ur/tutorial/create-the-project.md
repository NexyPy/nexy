# Nexy کے ساتھ ایک نوٹس ایپ بنائیں، حصہ 1: پروجیکٹ بنائیں

ٹیوٹوریل کا حصہ 1 اس پروجیکٹ کو تخلیق کرتا ہے جسے آپ نوٹ ایپ میں تبدیل کریں گے، اور اسے آپ کے براؤزر میں تقریباً پانچ منٹ میں چلاتے ہیں۔

**شروع کرنے سے پہلے:** [uv](https://docs.astral.sh/uv/) اور Node.js 20 یا اس سے نئے۔ ٹیوٹوریل مینو کے اوپری حصے میں منتخب کردہ راؤٹر کی پیروی کرتا ہے: اسے وہاں سوئچ کریں اور ہر حصہ اس روٹر کی فائلوں کو دکھاتا ہے۔

## جو آپ تعمیر کریں گے۔

ٹیوٹوریل کے اختتام تک، ایپ میں نوٹس، ڈیٹا بیس، اکاؤنٹس، ای میل کے ذریعے اشتراک کردہ نوٹس، لائیو اپ ڈیٹس، ٹیسٹ، اور پروڈکشن کی تعمیر کے لیے صفحات اور JSON API موجود ہے۔ ہر حصہ ایک ایپ کے ساتھ ختم ہوتا ہے جو چلتی ہے، لہذا آپ ان میں سے کسی کے بعد بھی رک سکتے ہیں۔

## پروجیکٹ بنائیں

```bash
uvx nexy new notes
```

سوالات کا جواب اس طرح دیں:

| سوال | جواب دیں۔ |
|---|---|
| فائل پر مبنی روٹر؟ | `Yes` فائل پر مبنی اور کسٹم راؤٹرز کے لیے، `No` ماڈیولر کے لیے |
| پروجیکٹ کی قسم | `Web` |
| کلائنٹ سائیڈ روٹنگ | `No`: سرور صفحات کو رینڈر کرتا ہے۔ |
| کلائنٹ کا فریم ورک | `React`: یہ جزائر کے لیے یونٹ 4 میں واپس آتا ہے۔ |
| انداز | `Tailwind CSS` |
| عرف درآمد کریں۔ | `@` |
| ORM | `No database`: حصہ 5 ایک کا اضافہ کرتا ہے۔ |

کسٹم راؤٹر فائل پر مبنی ایک پلس ایک `APIRouter` ہے جو آپ کے پاس پہلے سے ہے۔ ٹیوٹوریل ایپ کو فائلوں کے ساتھ بناتا ہے۔ [موجودہ FastAPI راؤٹر کو شامل کریں](../routing/custom/README.md) دکھاتا ہے کہ آپ کو ان کے ساتھ کیسے لگانا ہے۔

## اسے چلائیں۔

```bash
cd notes
source .venv/bin/activate    # Windows: .venv\Scripts\activate
nexy dev
```

کھولیں <http://localhost:3000>۔ آپ کو خوش آمدید صفحہ دیکھنا چاہیے۔ `nexy dev` کو چلنا چھوڑ دیں: اب سے، آپ کی محفوظ کردہ ہر فائل براؤزر کو دوبارہ لوڈ کرتی ہے۔

## جو آپ نے سیکھا۔

- `uvx nexy new` ایک پروجیکٹ بناتا ہے اور اس کے Python اور JavaScript پیکجز کو انسٹال کرتا ہے۔
- `nexy dev` اسے سرو کرتا ہے اور سیو پر دوبارہ لوڈ کرتا ہے۔
<!-- router:fbr,custom -->
- صفحات `src/routes/` میں رہتے ہیں: اگلا حصہ ایک کا اضافہ کرتا ہے۔
