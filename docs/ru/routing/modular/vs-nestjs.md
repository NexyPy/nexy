# Некси и NestJS

Модульный маршрутизатор вдохновлен NestJS: контроллеры, модули и внедрение конструктора. Это тонкий слой над FastAPI, поэтому он не пытается воспроизвести весь NestJS. На этой странице перечислены обе стороны.

## Что соответствует

| NestJS | Некси |
|---|---|
| `@Controller('users')` | `@Controller(prefix="/users")` |
| `@Module({ controllers, providers, imports, exports })` | `@Module()` с теми же четырьмя атрибутами класса |
| `@Injectable()` | `@Injectable()` |
| Внедрение в конструктор | `__init__` параметров, разрешенных из аннотаций типов |
| Синглтон, запросы и временные области | `Scope.SINGLETON`, `Scope.REQUEST`, `Scope.TRANSIENT` |
| `@UseGuards(AuthGuard)` | `@UseGuard(guard)` (зависимость FastAPI) |
| `@ApiOperation`, `@ApiResponse` (Сваггер) | `@UseRoute`, `@UseResponse` (OpenAPI, служил в `/docs`) |
| WebSocket шлюзы | `async def SOCKET(...)` на контроллере |
| Проверка DTO (`class-validator`) | Pydantic модели, встроенные в FastAPI |
| Обнаружение циклических зависимостей | `RecursionError` присвоение имени классу |

## Чем отличается

- Обработчики — это методы, названные в честь глагола HTTP (`get`, `post`...), по одному на каждый контроллер.
- Охранники и декораторы промежуточного программного обеспечения — это FastAPI `Depends`, а не классы с `canActivate`.
- Параметры (`@Body`, `@Param`, `@Query`) — это FastAPI параметры: аннотации типов, `Query`, `Path`, `Body`.
- Каналы — это Pydantic проверка и FastAPI зависимости.

## Чего не хватает

| NestJS функция | Статус в Nexy |
|---|---|
| Пользовательские поставщики (`useValue`, `useFactory`, `useClass`, строковые токены) | недоступны: только `@Injectable()` классы |
| Внедрение через интерфейс или абстрактный класс | недоступно |
| Инкапсуляция модуля | не применяется: контейнер распространяется на весь процесс, `exports` контролирует только активное разрешение |
| Динамические и глобальные модули (`forRoot`, `@Global`) | недоступны |
| Перехватчики жизненного цикла (`onModuleInit`, `onApplicationShutdown`) | недоступны |
| Перехватчики | используют промежуточное программное обеспечение ASGI (`useMiddlewares`) или зависимости |
| Фильтры исключений | используют FastAPI обработчики исключений |
| Модуль тестирования с переопределением поставщика | без публичного API; используйте FastAPI `dependency_overrides` и `TestClient` |
| Модуль конфигурации, планирование, очереди, CQRS, микросервисы, кеширование | не являются частью Nexy; использовать Python экосистему |

## Когда выбирать

Выбирайте модульный маршрутизатор, если вам нужна структура на основе классов с внедрением более крупного API. Выбирайте файловый маршрутизатор, если структура URL является принципом организации. Оба созданы `nx new`, запускаются в одном и том же приложении FastAPI и могут сосуществовать.

> [!ПРИМЕЧАНИЕ]
> недостающие элементы выше — это честный пробел. Если вам нужны `useFactory` провайдеры или переопределяемые провайдеры в тестах сегодня, сохраните логику в простых функциях и FastAPI `Depends`, которые компонуются и переопределяются естественным образом.
