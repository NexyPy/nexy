# Страницы

Файл подкачки возвращает HTML. От того, какой тип файла вы используете, зависит способ его создания: см. [представления](../../../views/README.md). В этом разделе описаны правила маршрутизации, применимые к каждому формату страницы.

| Страница | Что она охватывает |
|---|---|
| [Динамические маршруты](dynamic-routes.md) | `[slug]`, `[...path]`, группы маршрутов, типизированные сегменты |
| [Страницы ошибок](../errors/README.md) | `notfound.nexy`, `errors.nexy`, JSON для клиентов API |
| [Макеты](../layouts/README.md) | Одна страница для каждого типа файла макета |
| [Наследование](../inheritance.md) | Как складываются макеты и зависимости |

## Минимальная страница

```nexy filename="источник/маршруты/about.nexy"
---
title: prop[str] = "About"
---
<h1>{{ title }}</h1>
```

Его подают в `/about`. Вступительная часть между строками `---` — Python; разметка под ним — Jinja2. См. файлы [.nexy](../../../views/nexy/README.md).

## Форматы страниц

| Режим | Файл | Производит |
|---|---|---|
| Серверный | `.nexy` | HTML-код, отображаемый на сервере из Python и Jinja2 |
| Сервер | `.md`, `.mdx` | страницы контента |
| Клиентские | `.tsx`, `.jsx`, `.vue`, `.svelte` | компоненты платформы, отображаемые и перемещаемые в браузере |

Эти два режима нельзя смешивать в одном проекте. См. [Режим сервера и режим клиента](../modes.md). Клиентские компоненты по-прежнему могут отображаться в режиме сервера, как [острова](../../../rendering/islands.md) внутри страницы `.nexy`.

## Инкрементальное кэширование

Добавьте `revalidate = 60` на страницу `.nexy`, чтобы кэшировать ее с помощью устаревшей проверки. См. [ISR](../../../rendering/isr.md).

## Чтение запроса

Страница считывает путь, строку запроса, файлы cookie и сеанс через перехватчики. См. [Крючки](../navigation/hooks.md).
