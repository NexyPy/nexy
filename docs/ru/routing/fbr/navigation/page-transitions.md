# Как работают переходы страниц?

Nexy использует View Transitions API браузера для клиентской навигации, поэтому поддерживаемый браузер анимирует переключение страниц, если посетитель не предпочитает замедленное движение.

## Когда выполняется переход

Первый документ представляет собой обычный ответ сервера и не имеет перехода. С этого момента каждая навигация, обрабатываемая клиентским маршрутизатором, меняет местами страницу внутри `document.startViewTransition()`: ссылку на клиентский маршрут, `router.push()` или `router.replace()`, а также кнопки «Назад» и «Вперед». Маршрутизатор сначала отображает следующую страницу и ее макеты, затем перемещает URL-адрес, поэтому новая страница готова до ее отображения.

React, Preact, Solid, Vue и Svelte используют один и тот же маршрутизатор, поэтому поведение одинаково во всех пяти адаптерах. Нет настройки для включения переходов.

## Когда он отступит

- Браузер без `startViewTransition()` отображает страницу напрямую.
- При использовании `prefers-reduced-motion: reduce` маршрутизатор отображает страницу напрямую.
- Переход, пропущенный новой навигацией, не регистрирует ошибку: страница по-прежнему правильна.

URL-адрес, история, позиция прокрутки и событие `nexy:navigated` ведут себя одинаково с переходом или без него.

## Стиль перехода

Nexy не поставляет CSS-анимацию. Браузер применяет плавное затухание по умолчанию, которое вы можете заменить в своей собственной таблице стилей:

```css
::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: 250ms;
}
```
