# Учебник Nexy: шаг за шагом создайте приложение для заметок

Учебное пособие Nexy создает одно приложение для заметок из пустой папки в производственную сборку, по одной части за раз, и каждая часть заканчивается запуском приложения.

Впервые в Некси? [Быстрый запуск](quick-start.md) показывает, что он заработает через три минуты; вернитесь сюда, чтобы узнать, как это работает.

## Как работает учебник

- **Одно приложение, которое растет.** Каждая часть добавляет одну функцию к приложению заметок предыдущей части.
- **Ваш маршрутизатор.** Детали соответствуют маршрутизатору, выбранному в верхней части меню: файловому, модульному или индивидуальному. Переключите его туда, и вместе с ним изменяются файлы каждой части.
- **Код, который работает.** Каждый файл с именем над ним представляет собой целый файл, и набор тестов воспроизводит его части по порядку в новом проекте: что вы копируете, то и запускается.
- **Остановитесь где угодно.** Каждая часть занимает от 10 до 20 минут и заканчивается тем, что нужно проверить в браузере.
