# Создайте приложение для заметок с помощью Nexy, часть 1: создайте проект

В первой части руководства создается проект, который вы превратите в приложение для заметок, и запускаете его в браузере примерно за пять минут.

**Прежде чем начать:** [uv](https://docs.astral.sh/uv/) и Node.js 20 или новее. Учебное пособие следует за маршрутизатором, выбранным в верхней части меню: переключите его туда, и каждая часть покажет файлы этого маршрутизатора.

## Что вы построите

К концу руководства в приложении появятся страницы и API JSON для заметок, база данных, учетные записи, заметки, передаваемые по электронной почте, текущие обновления, тесты и производственная сборка. Каждая часть заканчивается запуском приложения, поэтому вы можете остановиться после любой из них.

## Создать проект

```bash
uvx nexy new notes
```

Ответьте на вопросы следующим образом:

| Вопрос | Ответ |
|---|---|
| Файловый маршрутизатор? | `Yes` для файловых и пользовательских маршрутизаторов, `No` для модульных |
| Тип проекта | `Web` |
| Маршрутизация на стороне клиента | `No`: сервер отображает страницы |
| Клиентская платформа | `React`: оно возвращается в блоке 4, для островов |
| Стиль | `Tailwind CSS` |
| Импортировать псевдоним | `@` |
| ОРМ | `No database`: часть 5 добавляет один |

## Запусти это

```bash
cd notes
source .venv/bin/activate    # Windows: .venv\Scripts\activate
nexy dev
```

Откройте <http://localhost:3000>. Вы должны увидеть страницу приветствия. Оставьте `nexy dev` включенным: с этого момента каждый сохраняемый вами файл будет перезагружать браузер.

## Что вы узнали

- `uvx nexy new` создает проект и устанавливает его пакеты Python и JavaScript.
- `nexy dev` обслуживает его и перезагружается при сохранении.
