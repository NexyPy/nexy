# Создание приложения для заметок с помощью Nexy, часть 10: создайте учетную запись и войдите в нее

Часть 10 позволяет посетителю создать учетную запись с адресом электронной почты и паролем, войти в систему и выйти из нее, а также запомнить, кто выполнил вход, с помощью файла cookie сеанса.

**Прежде чем начать:** приложение из [части 9](paginate-the-notes.md).

## Включить сеансы

Сеанс представляет собой подписанный файл cookie: сервер помещает в него идентификатор вошедшего в систему пользователя и считывает его при каждом запросе. Starlette подписывает его с помощью `itsdangerous`:

```bash
uv add itsdangerous
```

Секрет, которым он подписывается, хранится в `.env` рядом с адресом базы данных:

```bash filename=".env"
DATABASE_URL=sqlite:///dev.db
SESSION_SECRET=change-me-to-a-long-random-string
```

Сделайте настоящий секрет с помощью `python -c "import secrets; print(secrets.token_urlsafe(32))"`. Любой, кто знает это, может подписать файл cookie от имени любого пользователя.

`useSession` включает сеансы, считывая секрет из среды:

## Хэш и проверка пароля

`hashlib.scrypt` из стандартной библиотеки представляет собой хеш, который намеренно замедляется, поэтому угадывание паролей один за другим стоит злоумышленнику годы. Каждый пароль получает свою случайную соль:

<!-- router:fbr,custom -->
```python filename="src/accounts.py"
import hashlib
import hmac
import secrets

from sqlalchemy.exc import IntegrityError
from sqlmodel import Session, select

from src.configs.db import engine
from src.models.user_model import User


def hash_password(password: str) -> str:
    salt = secrets.token_bytes(16)
    digest = hashlib.scrypt(password.encode(), salt=salt, n=2**14, r=8, p=1)
    return f"{salt.hex()}:{digest.hex()}"


def password_matches(password: str, stored: str) -> bool:
    salt, digest = stored.split(":")
    found = hashlib.scrypt(password.encode(), salt=bytes.fromhex(salt), n=2**14, r=8, p=1)
    return hmac.compare_digest(found.hex(), digest)


def create_user(email: str, password: str) -> User | None:
    """The new user, or None when the email already has an account."""
    user = User(email=email, password_hash=hash_password(password))
    with Session(engine) as session:
        session.add(user)
        try:
            session.commit()
        except IntegrityError:
            return None
        session.refresh(user)
    return user


def authenticate(email: str, password: str) -> User | None:
    with Session(engine) as session:
        user = session.exec(select(User).where(User.email == email)).first()
    if user is None or not password_matches(password, user.password_hash):
        return None
    return user
```

`hmac.compare_digest` сравнивается за время, которое не зависит от того, где различаются два хеша, поэтому время ответа ни о чем не говорит злоумышленнику.

## Зарегистрируйтесь, войдите, выйдите

Три действия. Каждый, кому это удалось, записывает сессию или очищает ее:

```python filename="src/actions/accounts.py"
from urllib.parse import urlencode

from nexy import useSession
from nexy.decorators import Action
from nexy.http import RedirectResponse
from src.accounts import authenticate, create_user

MIN_PASSWORD = 8


def go(path: str, error: str = "") -> RedirectResponse:
    query = f"?{urlencode({'error': error})}" if error else ""
    return RedirectResponse(f"{path}{query}", status_code=303)


@Action
async def sign_up(email: str, password: str) -> RedirectResponse:
    email = email.strip().lower()
    if len(password) < MIN_PASSWORD:
        return go("/signup", f"A password has at least {MIN_PASSWORD} characters.")
    user = create_user(email, password)
    if user is None:
        return go("/signup", "This email already has an account.")
    useSession()["user_id"] = user.id
    return go("/notes")


@Action
async def sign_in(email: str, password: str) -> RedirectResponse:
    user = authenticate(email.strip().lower(), password)
    if user is None:
        return go("/signin", "Wrong email or password.")
    useSession()["user_id"] = user.id
    return go("/notes")


@Action
async def sign_out() -> RedirectResponse:
    useSession().clear()
    return go("/")
```

*Неправильный адрес электронной почты или пароль*, ни разу какой: сообщение с надписью «нет учетной записи с этим адресом электронной почты» сообщит любому, на каких адресах электронной почты есть учетная запись.

## Что вы узнали

- `useSession` в `nexyconfig.py` включает подписанный файл cookie сеанса; его секрет живет в `.env`.
- В базе данных хранится медленный хеш пароля, проверенный с помощью `hmac.compare_digest`.
- Действие записывает сеанс с помощью `useSession()`; страница читается одинаково.
