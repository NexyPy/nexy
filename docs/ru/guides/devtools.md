# Панель инструментов разработчика

`nexy dev` добавляет панель инструментов на каждую HTML-страницу. Он находится в левом нижнем углу, показывает маршрут, по которому вы находитесь, и время, которое потребовалось серверу, и открывается в виде панели. Это никогда не является частью производственного ответа.

| Вкладка | Показывает |
|---|---|
| Страница | URL-адрес страницы, маршрут, обработчик, файл, из которого он получен (со ссылкой, которая открывает его в вашем редакторе), статус, время сервера, первый байт, первая отрисовка, основной контент, сдвиг макета (зеленый, желтый или красный), готовность DOM |
| Направляет | каждый маршрут приложения с его методами, фильтром и помеченным текущим маршрутом; каждый ссылается на свой файл |
| Ошибки | ошибки сервера с момента запуска `nexy dev` и ошибки, возникшие в браузере |
| Настройки | тема (соответствие странице, темная или светлая), положение, размер, скрытие, сброс |

## Переместить это

Перетащите кнопку: она следует за указателем и привязывается к ближайшему углу, когда вы ее отпускаете. Панель открывается к середине экрана, где бы ни была кнопка. Позиция сохраняется в этом браузере. Вы также можете выбрать угол в **Настройках**.

`Shift` + `Alt` + `D` скрывает и показывает панель инструментов. `Esc` закрывает панель.

## Ошибки

Необнаруженная ошибка в браузере открывает диалог поверх страницы с сообщением и стеком; при нескольких ошибках пройдите их (1 из 3). Ошибка сервера отвечает страницей того же типа: ошибка, место ее возникновения и код вокруг нее.

## Выключи это

```python filename="nexyconfig.py"
class NexyConfig(NexyConfigModel):
    useDevTools = False
```

Панель инструментов представляет собой блок стилей и скрипт, добавленный до `</body>`: никаких внешних запросов, никаких зависимостей. JSON, файлы и все ответы, кроме HTML, остаются в покое.
