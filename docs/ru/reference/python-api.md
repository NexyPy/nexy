# Python API

Каждое имя Nexy экспортирует в ваш код Python по модулю. Тест проверяет эту страницу на соответствие коду в обоих направлениях: имя, указанное здесь, должно существовать, и имя, экспортируемое кодом, должно быть указано здесь.

## `nexy`

Компоненты для шаблонов `.nexy` и перехватчики запросов.

| Имя | Что это |
|---|---|
| `Audio`, `Video` | родные `<audio>` и `<video>` проигрыватели, см. [компоненты](../views/nexy/components.md) |
| `Image` | и `<img>` который по умолчанию загружается лениво |
| `Link` | клиентская сторона `<a>` с дополнительной предварительной выборкой |
| `Import` | импортируйте клиентский компонент на страницу `.nexy` |
| `Template` | отображают шаблоны Jinja2 и Markdown |
| `Vite` | клиентский тег Vite необходим каждой странице |
| `Form` | заполнитель без поведения: используйте простой `<form>` с [действием](../guides/actions.md) |
| `usePathname` | путь текущего запроса |
| `useSearchParams` | строка запроса в виде словаря |
| `useParams` | параметры динамического пути в виде словаря, например `useParams()` на клиенте |
| `useQuery` | исходное имя `useParams`, сохраненное для существующих страниц (оно не читает строку запроса) |
| `useRequest` | текущий запрос, для чего другие хуки не перекрывают |
| `useHeaders` | заголовки запросов в виде слов с именами в нижнем регистре |
| `useUrl` | полный URL: `.scheme`, `.hostname`, `.path`, `.query` |
| `useIsActive` | указывает ли ссылка на текущую страницу или на одну из ее родительских страниц для панели навигации |
| `useRouter` | `path`, `base_url` и `url_for` текущего запроса |
| `useSession` | запись сеанса, пустая, когда сеансы отключены |
| `useCookies` | файлы cookie запроса как диктовку |
| `useToc` | оглавление текущей страницы в формате HTML |
| `useViews` | визуализировать файл представления, например `about.tsx` из обработчика |
| `setMetadata`, `useMetadata` | назовите теги заголовка и заголовка страницы и запишите их в макете |
| `redirect`, `permanentRedirect` | отправьте посетителя в другое место (307, 308) и остановите запрос |
| `notFound`, `forbidden`, `unauthorized` | ответьте на 404, 403 или 401 из любого места |

Перехватчики работают только внутри запроса: см. [крючки](../routing/fbr/navigation/hooks.md).

## `nexy.http`

HTTP-словарь обработчика. Импортируйте отсюда, а не из FastAPI, поэтому ваши обработчики зависят от контракта Nexy.

| Имя | Что это |
|---|---|
| `Request`, `Response` | входящий запрос и исходящий ответ |
| `HTTPException` | остановите обработчик со статусом и `detail` |
| `status` | именованные коды состояния, например `status.HTTP_404_NOT_FOUND` |
| `Depends` | сначала запустите функцию и передайте ее результат в |
| `Header`, `Cookie`, `Query`, `Path`, `Body` | где параметр берется из |
| `Form`, `File`, `UploadFile` | поля формы и загрузки (нужно `python-multipart`) |
| `BackgroundTasks` | работа, которая запускается после отправки ответа |
| `JSONResponse`, `HTMLResponse`, `PlainTextResponse` | отвечают с фиксированным типом контента |
| `RedirectResponse` | HTTP-перенаправление |
| `redirect`, `permanentRedirect` | вызывают перенаправление (307, 308) со страницы, обработчика, контроллера или охранника |
| `notFound`, `forbidden`, `unauthorized` | поднимите 404, 403 или 401 из тех же мест |
| `FileResponse`, `StreamingResponse` | ответьте файлом или потоком |

## `nexy.decorators`

| Имя | Что это |
|---|---|
| `Action` | превращает функцию в конечную точку `POST`, см. [действия](../guides/actions.md) |
| `revalidate` | сообщите браузеру, на каких страницах действие стало устаревшим |
| `Module`, `Controller` | объявите модуль и контроллер в [модульном маршрутизаторе](../routing/modular/README.md) |
| `Injectable`, `Container`, `Scope` | [внедрение зависимостей](../routing/modular/dependency-injection.md) и время его существования |
| `UseGuard`, `Middleware` | защитите или оберните один обработчик, см. [guards](../routing/modular/guards-and-metadata.md) |
| `UseRoute`, `useRoute`, `RouteMeta` | назовите маршрут и опишите его для OpenAPI |
| `UseResponse`, `ResponseMeta` | описывают ответ маршрута |
| `HTTP_METHODS` | HTTP-методы, которые может определить файл-обработчик |
| `ACTIONS_STORE` | реестр действий, для инструментов и тестов |
