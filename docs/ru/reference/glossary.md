# Глоссарий

Слова, используемые в этих документах, по одной строке в алфавитном порядке. У термина, которому нужно больше, чем строка, есть страница: перейдите по ссылке. О том, как эти понятия соотносятся друг с другом, читайте в [Основные понятия](../getting-started/core-concepts.md).

## Условия

| Термин | В одну строку |
|---|---|
| Действие | функция Python с пометкой `@Action`, служащая как `POST` и вызываемая с клиента ([действия](../guides/actions.md)) |
| ASGI | говорит интерфейс Uvicorn, реализованный FastAPI и Starlette |
| Клиентский режим | `useCSR = True`: файлы фреймворка — это маршруты и навигация браузера ([режимы](../routing/fbr/modes.md)) |
| Компонент | повторно используемый строительный блок пользовательского интерфейса, используемый для составления представления ([представления](../views/README.md)) |
| CSR | рендеринг на стороне клиента: браузер отображает страницы после первого документа ([CSR](../rendering/csr.md)) |
| Зависимость | функция FastAPI выполняется перед обработчиком, для каждого маршрута или для каждой папки ([зависимости](../routing/fbr/dependencies/README.md)) |
| Оболочка документа | `<html>`, `<head>` и `<body>` вокруг страницы, принадлежащей ближайшему макету или Nexy ([макеты](../routing/fbr/layouts/README.md)) |
| Конечная точка | уникальная комбинация URL-адреса и метода HTTP ([представления](../views/README.md)) |
| Маршрутизация на основе файлов FBR |: файл в папке `src/routes/` является маршрутом ([маршрутизация](../routing/fbr/README.md)) |
| Frontmatter | блок Python между двумя строками `---` файла `.nexy` или `.md` ([файлы .nexy](../views/nexy/README.md)) |
| Guard | зависимость, которая отклоняет запрос путем поднятия `HTTPException` ([гарды](../routing/modular/guards-and-metadata.md)) |
| Обработчик | функция Python, которая обрабатывает HTTP-запрос для определенного метода ([представления](../views/README.md)) |
| HMR | горячая замена модулей: сервер разработки меняет местами измененные модули без полной перезагрузки ([фронтенд](../guides/frontend.md)) |
| Гидратация | браузер, прикрепляющий фреймворк к уже отправленному сервером HTML ([острова](../rendering/islands.md)) |
| Остров | клиентский компонент, смонтированный внутри страницы, отображаемой сервером ([острова](../rendering/islands.md)) |
| ISR | инкрементная статическая регенерация: одна кэшированная страница на каждый путь, обновляемая в фоновом режиме ([ISR](../rendering/isr.md)) |
| Макет | файл `layout.*`, в который переплетаются страницы, находящиеся под его папкой ([макеты](../routing/fbr/layouts/README.md)) |
| Маршруты модульного маршрутизатора | объявлены с помощью `@Module` и `@Controller` в `src/apps/` ([модульный](../routing/modular/README.md)) |
| Страница | ресурс с URL-адресом, определенный файлом в папке `src/routes/` ([представления](../views/README.md)) |
| Предварительная выборка | загрузка страницы после ссылки до того, как читатель нажмет на нее ([ссылки](../routing/fbr/navigation/linking-and-navigating.md)) |
| Реквизит | значения, которые родитель передает компоненту ([.nexy файлы](../views/nexy/README.md)) |
| Повторно проверить | количество секунд, после которых страница ISR перестраивается в фоновом режиме ([ISR](../rendering/isr.md)) |
| Маршрутизация | шаблона URL-адреса, созданного путем пути к файлу маршрута ([маршрутизация](../routing/README.md)) |
| Группа маршрутов | папка в скобках, которая группирует маршруты без добавления сегмента ([динамические маршруты](../routing/fbr/pages/dynamic-routes.md)) |
| Обработчик маршрута | функция `GET`, `POST`, … файла маршрута `.py` ([обработчики](../routing/fbr/handlers/README.md)) |
| Режим сервера | `useCSR = False`, по умолчанию: сервер отображает страницы `.nexy` и `.md` ([режимы](../routing/fbr/modes.md)) |
| Навык | папка с `SKILL.md`, которая обучает агента кодирования одной части Nexy ([агенты кодирования](../guides/ai-agents.md)) |
| SSG | создание статического сайта; **не режим Nexy**: заранее созданный HTML всегда считывается сервером ([рендеринг](../rendering/README.md)) |
| SSR | рендеринг на стороне сервера: сервер отображает каждую страницу по его запросу, и это значение по умолчанию ([SSR](../rendering/ssr.md)) |
| Просмотрите | процесс создания тела ответа для страницы ([представления](../views/README.md)) |

## Файлы и папки

| Имя | В одну строку |
|---|---|
| `__nexy__/` | сгенерированный вывод: скомпилированные страницы, запись клиента и клиент действия; никогда не редактировался, никогда не фиксировался |
| `nexyconfig.py` | конфигурация проекта, класс `use*` полей ([конфигурация](config.md)) |
| `public/` | файлы, обслуживаемые в корне, например `public/logo.svg` → `/logo.svg` ([условия файлов](file-conventions.md)) |
| `src/apps/` | контроллеры и модули модульного маршрутизатора ([модульный](../routing/modular/README.md)) |
| `src/components/` | компоненты, импортированные по страницам; никогда не маршрутизирует ([соглашения о файлах](file-conventions.md)) |
| `src/routes/` | маршруты приложения ([соглашения о файлах](file-conventions.md)) |
