# 开发工具栏

`nexy dev` 向每个 HTML 页面添加一个工具栏。它位于左下角，显示您的路线
已开启以及服务器花费了多长时间，并打开一个面板。它从来不是生产的一部分
回应。

| 选项卡 | 显示 |
|---|---|
| 页面 | URL、路由、处理程序、它来自的文件（带有在编辑器中打开它的链接）、状态、服务器时间、第一个字节、第一次绘制、主要内容、布局转换（分级为绿色、琥珀色或红色）、DOM 就绪 |
| 路线 | 应用程序的每条路线及其方法、过滤器和当前标记的路线；每个链接到其文件 |
| 错误 | 自 `nexy dev` 启动以来的服务器错误以及浏览器引发的错误 |
| 设置 | 主题（匹配页面，深色或浅色）、位置、大小、隐藏、重置 |

## 移动它

拖动按钮：它会跟随指针并在您放开时捕捉到最近的角。面板
从按钮所在的位置向屏幕中间打开。位置保持在这个位置
浏览器。您还可以在**设置**中选择一个角。

`Shift` + `Alt` + `D` 隐藏和显示工具栏。 `Esc` 关闭面板。

## 错误

浏览器中未捕获的错误会在页面上打开一个包含消息和堆栈的对话框；与
几个错误，请逐步解决它们（3 个中的第一个）。服务器错误会返回相同类型的页面：
错误、引发错误的位置及其周围的代码。

## 将其关闭

```python filename="nexyconfig.py"
class NexyConfig(NexyConfigModel):
    useDevTools = False
```

工具栏是样式块和`</body>`之前添加的脚本：没有外部请求，没有
依赖性。 JSON、文件和每个非 HTML 的响应都将被保留。
