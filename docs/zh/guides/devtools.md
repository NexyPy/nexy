# 开发工具栏

`nexy dev` 向每个 HTML 页面添加一个工具栏。它位于左下角，显示您所在的路线以及服务器花费的时间，并打开一个面板。它绝不是生产响应的一部分。

| 选项卡 | 显示 |
|---|---|
| 页面 | URL、路由、处理程序、它来自的文件（带有在编辑器中打开它的链接）、状态、服务器时间、第一个字节、第一次绘制、主要内容、布局偏移（分级为绿色、琥珀色或红色）、DOM 就绪 |
| 路由 | 应用程序的每条路由及其方法、过滤器和当前标记的路由；每个链接到其文件 |
| 自 `nexy dev` 启动以来的错误 | 服务器错误以及浏览器引发的错误 |
| 设置 | 主题（匹配页面，深色或浅色）、位置、大小、隐藏、重置 |

## 移动它

拖动按钮：它会跟随指针并在您放开时捕捉到最近的角。面板从按钮所在的位置向屏幕中间打开。该位置保存在该浏览器中。您还可以在 **设置**中选择一个角。

`Shift` + `Alt` + `D` 隐藏和显示工具栏。 `Esc` 关闭面板。

## 错误

浏览器中未捕获的错误会在页面上打开一个包含消息和堆栈的对话框；如果存在多个错误，请逐步解决这些错误（共 3 个错误之一）。服务器错误会以相同类型的页面进行响应：错误、引发错误的位置以及错误周围的代码。

## 将其关闭

```python filename="nexyconfig.py"
class NexyConfig(NexyConfigModel):
    useDevTools = False
```

工具栏是一个样式块和一个在 `</body>`之前添加的脚本：无外部请求，无依赖。 JSON、文件和每个非 HTML 的响应都将被保留。
