# 国际化 (i18n)

Nexy 不会翻译您的申请。它没有语言环境中间件，没有 `trans` 帮助程序，也没有
语言环境文件：应用程序会选择适合它的 i18n 库，就像它选择 ORM 一样。

命令行（`nx`）被翻译；请参阅 [CLI](../reference/cli.md)。

## 在处理程序中

处理程序从请求中读取它需要的内容。这个人用的语言回答
`Accept-Language` 标题：

```python filename="src/routes/hello.py"
from nexy.http import Header

MESSAGES = {"en": "Hello", "fr": "Bonjour"}


async def GET(accept_language: str = Header("en")):
    language = accept_language.split(",")[0].split("-")[0].lower()
    return {"message": MESSAGES.get(language, MESSAGES["en"])}
```

## 在页面中

将前端库用于客户端路由页面（例如 `i18next`、`vue-i18n` 或
Svelte store），以及 `.nexy` 的 Python 库（来自标准库或 Babel 的 `gettext`）
页。在根布局中设置 `<html lang>`。
