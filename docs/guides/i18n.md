# i18n

Nexy resolves a locale per request, exposes it to templates and Python, and generates translation
files.

## Configure locales

```python filename="nexyconfig.py"
from nexy.core.models import NexyConfigModel


class NexyConfig(NexyConfigModel):
    useLocales = ["en", "fr"]
    useDefaultLocale = "en"
    useLocaleCookieName = "nexy-locale"
    useLocalesDir = "locales"            # runtime locale files
    useLocalesSourceDir = "src/locales"  # source for `nx translate`
```

## Locale resolution

For every request, in order:

1. URL prefix `/fr/...` - the locale is stripped from the path before routing;
2. the `nexy-locale` cookie;
3. the `Accept-Language` header;
4. `useDefaultLocale`.

The chosen locale is stored in the cookie and in the `current_locale` context variable for that
request.

## Translate a string

```python
from nexy import current_locale, t, trans, useLocale

trans("hero.title", "Hello")     # dotted key, default, current locale
t("hero.title", "Hello")         # alias of trans
current_locale.get()             # "fr"
useLocale()                      # {"locale", "is_rtl", "available", "default", "trans"}
```

In a template, `trans` is always available:

```html
<h1>{{ trans("hero.title", "Hello") }}</h1>
```

A missing key falls back to the default, then to the key itself.

## Locale files

`useLocalesDir` holds one file per locale, with nested objects matching the dotted keys:

```json filename="locales/fr.json"
{
  "hero": { "title": "Hello" }
}
```

`locales/fr.json`, `locales/en.json`, etc. A `<locale>.py` exporting a `translations` dict works
too; `i18n.py` provides the default locale.

## Translate a class

```python filename="src/locales/home.py"
from nexy.modules.i18n import i18n


@i18n()
class Home:
    title = "Hello"
```

`Home.title` returns the translation of the key `Home.title` when it exists, otherwise the class
default.

`nx translate` scans `@i18n()` classes under `useLocalesSourceDir`, translates them, and writes the
generated packs to `__nexy__/i18n/`.

```bash
nx translate --source en --target fr
```

> **Good to know**: the command uses an online translator. It needs network access.
