# Internationalisierung (i18n)

Nexy übersetzt Ihre Bewerbung nicht. Es gibt keine Locale-Middleware, keinen `trans`-Helfer und keine
Gebietsschemadateien: Eine Anwendung wählt die i18n-Bibliothek aus, die zu ihr passt, während sie ein ORM auswählt.

Die Befehlszeile (`nx`) wird übersetzt; siehe [die CLI](../reference/cli.md).

## In einem Handler

Ein Handler liest aus der Anfrage, was er benötigt. Dieser antwortet in der Sprache der
`Accept-Language` Kopfzeile:

```python filename="src/routes/hello.py"
from nexy.http import Header

MESSAGES = {"en": "Hello", "fr": "Bonjour"}


async def GET(accept_language: str = Header("en")):
    language = accept_language.split(",")[0].split("-")[0].lower()
    return {"message": MESSAGES.get(language, MESSAGES["en"])}
```

## Auf einer Seite

Verwenden Sie die Bibliothek Ihres Frontends für vom Client weitergeleitete Seiten (z. B. `i18next`, `vue-i18n` oder a
Svelte Store) und Ihre Python-Bibliothek (`gettext` aus der Standardbibliothek oder Babel) für `.nexy`
Seiten. Legen Sie `<html lang>` im Root-Layout fest.
