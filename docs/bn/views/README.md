# ভিউ

একটি ফাইল বিন্যাস নির্বাচন করার আগে, Nexy কীভাবে সংস্থানগুলি পরিচালনা করে এবং কীভাবে সেগুলিকে রেন্ডার করে তার মধ্যে পার্থক্য করা গুরুত্বপূর্ণ৷

| মেয়াদ | সংজ্ঞা |
|---|---|
| **পৃষ্ঠা** | অ্যাপ্লিকেশনটির একটি URL-ঠিকানাযোগ্য সংস্থান৷ এটি `src/routes/` এর অধীনে একটি ফাইল দ্বারা সংজ্ঞায়িত করা হয়। |
| **দেখুন** | একটি পৃষ্ঠার জন্য প্রতিক্রিয়া বডি তৈরি করার প্রক্রিয়া। একটি ভিউ যুক্তি ও ডেটাকে HTML বা JSON-এ রূপান্তরিত করে। |
| **উপাদান** | একটি দৃশ্য রচনা করতে ব্যবহৃত একটি পুনঃব্যবহারযোগ্য UI বিল্ডিং ব্লক৷ উপাদানগুলি নেটিভ নেক্সি হেল্পার বা ফ্রেমওয়ার্ক-নির্দিষ্ট (React, Vue, ইত্যাদি) হতে পারে। |
| **রুট হ্যান্ডলার** | একটি Python ফাংশন যা একটি নির্দিষ্ট পদ্ধতির জন্য একটি HTTP অনুরোধ পরিচালনা করে (যেমন, `GET`, `POST`)। |
| **শেষ বিন্দু** | একটি URL এবং একটি HTTP পদ্ধতির অনন্য সমন্বয় যা একজন রুট হ্যান্ডলার উত্তর দেয়। |

**নিশ্চিত নন? একটি `.nexy` লিখুন ফাইল** এটির কোন ক্লায়েন্ট ফ্রেমওয়ার্কের প্রয়োজন নেই এবং আপনি একটি React, Vue, Svelte, Solid বা Preact কম্পোনেন্ট যোগ করতে পারেন পরে, একটি দ্বীপ হিসাবে।

```diagram filename="কোন পৃষ্ঠার জন্য কোন ফাইল"
server logic + HTML          →  .nexy      (Python frontmatter + Jinja2)
prose that changes rarely    →  .md        (GitHub-flavoured Markdown)
prose + components           →  .mdx       (React or Preact)
app-like page, client router →  .tsx .vue .svelte (framework files)
API handler                  →  .py        (GET, POST, …)
```

| `.nexy` | [.nexy ফাইল](nexy/README.md) | Jinja2 + Python যুক্তি, প্রবাহিত | ঐচ্ছিক | নেটিভ নেক্সি পেজ ফরম্যাট |
| `.md` | [Markdown এবং MDX](nexy/markdown.md) | অনুরোধের সময় Markdown | লেআউটের মাধ্যমে ঐচ্ছিক | বিশুদ্ধ Markdown, GFM, বিন্যাস-মোড়ানো |
| `.mdx` | [Markdown এবং MDX](nexy/markdown.md) | ফ্রেমওয়ার্ক এসএসআর | React বা Preact | Markdown উপাদান সহ |
| `.tsx` | [React](react/differences.md), [Solid](solid/differences.md) বা [Preact](preact/differences.md) | ক্লায়েন্ট মোড: ফ্রেমওয়ার্ক, নোডে রেন্ডার করা হয়েছে | React, Solid বা Preact | উপাদান রুট |
| `.vue` | [Vue](vue/differences.md) | ক্লায়েন্ট মোড: ফ্রেমওয়ার্ক, নোডে রেন্ডার করা হয়েছে | Vue | SFC রুট |
| `.svelte` | [Svelte](svelte/differences.md) | ক্লায়েন্ট মোড: ফ্রেমওয়ার্ক, নোডে রেন্ডার করা হয়েছে | Svelte | SFC রুট |

অন্তর্নির্মিত `Image`, `Link`, `Audio`, `Video` এবং `Import` সাহায্যকারী: [উপাদানগুলি](nexy/components.md)।

## মিশ্রণ বিন্যাস

আপনি একই প্রকল্পের মধ্যে বিভিন্ন প্রযুক্তি মিশ্রিত করতে পারেন:
- **দ্বীপপুঞ্জ**: আপনি একটি `.nexy` পৃষ্ঠার ভিতরে একটি React বা Vue উপাদান আমদানি করতে পারেন। সার্ভার শেল রেন্ডার করে এবং ফ্রেমওয়ার্ক ক্লায়েন্টের উপাদানটিকে হাইড্রেট করে।
- **শেয়ার্ড লজিক**: `.py` ফাইলের রুট হ্যান্ডলাররা শেয়ার্ড অ্যাপ্লিকেশন স্টেট বা API কলের মাধ্যমে যেকোনো ফর্ম্যাটে পৃষ্ঠাগুলিতে ডেটা সরবরাহ করতে পারে।

## একটি ফ্রেমওয়ার্ক সক্ষম করুন

নির্ভরতা যোগ করতে `nexyconfig.py`-এ `useFF` সেট করুন এবং `nexy new` চালান:

```python filename="nexyconfig.py"
from nexy.core.models import NexyConfigModel
from nexy.frontend import react


class NexyConfig(NexyConfigModel):
    useFF = react()
```

একটি ফ্রেমওয়ার্ক সক্ষম করে, Vite তার ক্লায়েন্ট বান্ডিলগুলি পরিচালনা করে। ক্লায়েন্ট মোডে এর এক্সটেনশন রুট হয়ে যায়; সার্ভার মোডে একই ফাইলগুলি আপনি দ্বীপ হিসাবে আমদানি করা উপাদান - `src/routes/` এর অধীনে একটি ফ্রেমওয়ার্ক ফাইল সেখানে প্রত্যাখ্যান করা হয়। [সার্ভার মোড এবং ক্লায়েন্ট মোড](../routing/fbr/modes.md) দেখুন।

> [!NOTE]
> [CSR](../rendering/csr.md) মোডে, শুধুমাত্র ফ্রেমওয়ার্ক রুট ফাইলগুলিই ন্যাভিগেবল ক্লায়েন্ট-সাইড।
