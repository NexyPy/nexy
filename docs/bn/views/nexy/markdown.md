# Markdown এবং MDX

বিষয়বস্তু পৃষ্ঠাগুলির জন্য দুটি বিন্যাস: `.md` যখন আপনার শুধুমাত্র প্রয়োজন Markdown, `.mdx` যখন আপনার উপাদানগুলির প্রয়োজন হয়।

## `.md`: খাঁটি Markdown

একটি `.md` ফাইল বিশুদ্ধ বিষয়বস্তু। Nexy এটিকে GitHub-flavored Markdown (টেবিল, টাস্ক লিস্ট, স্ট্রাইকথ্রু, লিঙ্ক) হিসাবে রেন্ডার করে, শিরোনাম আইডি যোগ করে, বিষয়বস্তুর একটি সারণী বের করে এবং এটিকে নিকটতম `layout.*` এ মোড়ানো হয়।

```md filename="src/routes/about.md"
# About

Nexy is a fullstack Python meta-framework.
```

- `.md` মধ্যে ফ্রন্টম্যাটার Python যুক্তি হিসাবে ব্যবহৃত হয় না। আপনার সার্ভার লজিক প্রয়োজন হলে `.nexy` ব্যবহার করুন।
- একটি `.md` পৃষ্ঠায় কাঁচা এইচটিএমএল টেক্সট হিসাবে দেখানো হয়, কখনও চালানো হয় না। আপনার যদি HTML এর প্রয়োজন হয় তবে `.nexy` ব্যবহার করুন।
- লেআউট মোড়ানো, ত্রুটি পৃষ্ঠা এবং গতিশীল বিভাগ অন্যান্য পৃষ্ঠাগুলির মতো একইভাবে কাজ করে।

## `.mdx`: Markdown উপাদান সহ

`.mdx` ফাইলগুলি **Vite**, ফ্রেমওয়ার্ক রুট পাইপলাইন (React বা Preact) দ্বারা সংকলিত হয়। Python শুধুমাত্র পাতলা মোড়ক লেখে যা রুট পরিবেশন করে; এটি কখনই কম্পাইল বা রেন্ডার করে না MDX। উপাদানগুলি ফ্রেমওয়ার্ক দ্বারা রেন্ডার করা হয়, অন্যান্য কম্পোনেন্ট রুটের মতো সার্ভার-রেন্ডার করা হয় এবং `nx build` দ্বারা এইচটিএমএল-এ প্রাক-রেন্ডার করা হয়।

- `useFF` হতে হবে React বা Preact।
- ঐচ্ছিক প্যাকেজ প্রয়োজন `@mdx-js/rollup`, `remark-gfm` এবং `@mdx-js/react` (এবং বিল্ডের জন্য `@mdx-js/esbuild`)। Vite কোনটি অনুপস্থিত তা আপনাকে বলে।
- ফ্রেমওয়ার্কটি আমদানি থেকে স্বয়ংক্রিয়ভাবে সনাক্ত করা হয়: Preact যখন ফাইলটি আমদানি করে `preact`, React অন্যথায়।

> [!NOTE]
> সামনের বস্তুতে Python যুক্তির প্রয়োজন হলে `.nexy` ব্যবহার করুন।
