# শব্দকোষ

এই ডক্স ব্যবহার করে শব্দগুলি, প্রতিটি একটি লাইন, বর্ণানুক্রমিকভাবে। একটি শব্দ যার একটি লাইনের চেয়ে বেশি প্রয়োজন একটি পৃষ্ঠা রয়েছে: লিঙ্কটি অনুসরণ করুন৷ ধারণাগুলি কীভাবে একত্রিত হয় তার জন্য, [মূল ধারণাগুলি](../getting-started/core-concepts.md) পড়ুন।

## শর্তাবলী

| টার্ম | এক লাইনে |
|---|---|
| অ্যাকশন | একটি Python ফাংশন চিহ্নিত `@Action`, একটি `POST` হিসাবে পরিবেশিত এবং ক্লায়েন্ট থেকে কলযোগ্য ([ক্রিয়া](../guides/actions.md)) |
| ASGI | ইন্টারফেস Uvicorn কথা বলে, FastAPI এবং Starlette | দ্বারা বাস্তবায়িত
| ক্লায়েন্ট মোড | `useCSR = True`: ফ্রেমওয়ার্ক ফাইল হল রুট এবং ব্রাউজার নেভিগেট ([মোড](../routing/fbr/modes.md)) |
| কম্পোনেন্ট | একটি পুনর্ব্যবহারযোগ্য UI বিল্ডিং ব্লক যা একটি ভিউ রচনা করতে ব্যবহৃত হয় ([দর্শন](../views/README.md)) |
| CSR | ক্লায়েন্ট-সাইড রেন্ডারিং: ব্রাউজার প্রথম নথির পরে পৃষ্ঠাগুলি রেন্ডার করে ([CSR](../rendering/csr.md)) |
| নির্ভরতা | একটি ফাংশন FastAPI একটি হ্যান্ডলারের আগে চলে, প্রতি রুট বা প্রতি ফোল্ডার ([নির্ভরতা](../routing/fbr/dependencies/README.md)) |
| একটি পৃষ্ঠার চারপাশে ডকুমেন্ট শেল | `<html>`, `<head>` এবং `<body>`, নিকটতম লেআউটের মালিকানাধীন বা Nexy ([লেআউট](../routing/fbr/layouts/README.md)) |
| এন্ডপয়েন্ট | একটি URL এবং একটি HTTP পদ্ধতির অনন্য সমন্বয় ([দর্শন](../views/README.md)) |
| FBR | ফাইল-ভিত্তিক রাউটিং: `src/routes/` এর অধীনে একটি ফাইল হল একটি রুট ([রাউটিং](../routing/fbr/README.md)) |
| ফ্রন্টম্যাটার | একটি `.nexy` বা `.md` ফাইলের দুটি `---` লাইনের মধ্যে Python ব্লক ([.nexy ফাইল](../views/nexy/README.md)) |
| গার্ড | এমন একটি নির্ভরতা যা `HTTPException` ([রক্ষীদের](../routing/modular/guards-and-metadata.md)) | বাড়িয়ে একটি অনুরোধ প্রত্যাখ্যান করে
| হ্যান্ডলার | একটি Python ফাংশন যা একটি নির্দিষ্ট পদ্ধতির জন্য একটি HTTP অনুরোধ পরিচালনা করে ([দর্শন](../views/README.md)) |
| HMR | হট মডিউল প্রতিস্থাপন: ডেভ সার্ভার পরিবর্তিত মডিউলগুলিকে অদলবদল করে, সম্পূর্ণ রিলোড ছাড়াই ([ফ্রন্টেন্ড](../guides/frontend.md)) |
| হাইড্রেশন | ব্রাউজারটি HTML এর সাথে একটি ফ্রেমওয়ার্ক সংযুক্ত করছে যা সার্ভার ইতিমধ্যেই পাঠিয়েছে ([দ্বীপগুলি](../rendering/islands.md)) |
| দ্বীপ | একটি ক্লায়েন্ট উপাদান একটি সার্ভার-রেন্ডার করা পৃষ্ঠার ভিতরে মাউন্ট করা হয়েছে ([দ্বীপগুলি](../rendering/islands.md)) |
| ISR | ক্রমবর্ধমান স্থির পুনর্জন্ম: প্রতি পাথে একটি ক্যাশে পৃষ্ঠা, পটভূমিতে রিফ্রেশ করা হয়েছে ([ISR](../rendering/isr.md)) |
| বিন্যাস | একটি `layout.*` ফাইল যা তার ফোল্ডারের নীচে পৃষ্ঠাগুলিকে মোড়ানো করে ([লেআউটগুলি](../routing/fbr/layouts/README.md)) |
| মডুলার রাউটার | রুট `@Module` এবং `@Controller` `src/apps/` ([মডুলার](../routing/modular/README.md)) | এর অধীনে ঘোষিত।
| পৃষ্ঠা | `src/routes/` ([দর্শন](../views/README.md)) | এর অধীনে একটি ফাইল দ্বারা সংজ্ঞায়িত একটি ইউআরএল-ঠিকানাযোগ্য সংস্থান
| পাঠক এটিতে ক্লিক করার আগে একটি লিঙ্কের পিছনে পৃষ্ঠাটি লোড করা প্রিফেচ | ([লিঙ্কিং](../routing/fbr/navigation/linking-and-navigating.md)) |
| প্রপস | যে মানগুলি অভিভাবক একটি উপাদানে পাস করেন ([.nexy ফাইল](../views/nexy/README.md)) |
| যে সেকেন্ডের পরে একটি ISR পৃষ্ঠা পটভূমিতে পুনর্নির্মিত হয় তার সংখ্যা | পুনরায় যাচাই করুন ([ISR](../rendering/isr.md)) |
| রুট | একটি URL প্যাটার্ন, একটি রুট ফাইলের পাথ দ্বারা উত্পাদিত ([রাউটিং](../routing/README.md)) |
| রুট গ্রুপ | বন্ধনীতে একটি ফোল্ডার যা একটি সেগমেন্ট যোগ না করেই রুটগুলিকে গোষ্ঠীভুক্ত করে ([গতিশীল রুট](../routing/fbr/pages/dynamic-routes.md)) |
| রুট হ্যান্ডলার | `GET`, `POST`, … একটি `.py` রুট ফাইলের ফাংশন ([হ্যান্ডলার](../routing/fbr/handlers/README.md)) |
| সার্ভার মোড | `useCSR = False`, ডিফল্ট: সার্ভার রেন্ডার করে `.nexy` এবং `.md` পৃষ্ঠা ([মোড](../routing/fbr/modes.md)) |
| দক্ষতা | একটি `SKILL.md` সহ একটি ফোল্ডার যা একটি কোডিং এজেন্টকে Nexy এর একটি অংশ শেখায় ([কোডিং এজেন্ট](../guides/ai-agents.md)) |
| SSG | স্ট্যাটিক সাইট জেনারেশন; **নেক্সি মোড নয়**: সময়ের আগে তৈরি করা এইচটিএমএল সর্বদা সার্ভার দ্বারা পড়া হয় ([রেন্ডারিং](../rendering/README.md)) |
| SSR | সার্ভার-সাইড রেন্ডারিং: সার্ভার তার অনুরোধের জন্য প্রতিটি পৃষ্ঠা রেন্ডার করে এবং এটি ডিফল্ট ([SSR](../rendering/ssr.md)) |
| দেখুন | একটি পৃষ্ঠার জন্য প্রতিক্রিয়া বডি তৈরির প্রক্রিয়া ([দর্শন](../views/README.md)) |

## ফাইল এবং ফোল্ডার

| নাম | এক লাইনে |
|---|---|
| `__nexy__/` | উৎপন্ন আউটপুট: সংকলিত পৃষ্ঠা, ক্লায়েন্ট এন্ট্রি এবং অ্যাকশন ক্লায়েন্ট; কখনও সম্পাদনা করা হয়নি, কখনও প্রতিশ্রুতিবদ্ধ নয় |
| `nexyconfig.py` | প্রকল্পের কনফিগারেশন, `use*` ফিল্ডের একটি ক্লাস ([কনফিগার](config.md)) |
| `public/` | ফাইলগুলি রুটে পরিবেশিত হয়, যেমন `public/logo.svg` → `/logo.svg` ([ফাইল কনভেনশনগুলি](file-conventions.md)) |
| `src/apps/` | মডুলার রাউটারের কন্ট্রোলার এবং মডিউল ([মডুলার](../routing/modular/README.md)) |
| `src/components/` | পৃষ্ঠা দ্বারা আমদানি করা উপাদান; কখনই রুট করে না ([ফাইল কনভেনশন](file-conventions.md)) |
| `src/routes/` | অ্যাপ্লিকেশনের রুট ([ফাইল কনভেনশনগুলি](file-conventions.md)]) |
