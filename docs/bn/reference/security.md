# নিরাপত্তা

কিভাবে Nexy তার নিজস্ব আক্রমণের পৃষ্ঠকে ছোট রাখে, কোন সংস্করণগুলির প্রয়োজন হয় এবং কীভাবে একটি প্রকল্প পরীক্ষা করা যায়।

## সংস্করণ ফ্লোর

Nexy নির্ভর করে FastAPI, Starlette, Jinja2, Vite এবং React এর উপর। একটি তল হল সর্বনিম্ন সংস্করণ Nexy
অনুমতি দেয়; প্রত্যেকে একটি প্রকাশিত পরামর্শের উত্তর দেয়।

| প্যাকেজ | ফ্লোর | কেন |
|---|---|---|
| `starlette` | 1.0.1 | CVE-2026-48710 (BadHost): একটি কারুকাজ করা `Host` শিরোনাম স্টারলেট রিপোর্টের পথকে মিডলওয়্যারে পরিবর্তন করে, যা `request.url.path`-এ লেখা অনুমোদনকে বাইপাস করে। CISA দ্বারা শোষিত হিসাবে তালিকাভুক্ত. |
| `fastapi` | 0.133.0 | প্রথম রিলিজ যা একটি নির্দিষ্ট স্টারলেট গ্রহণ করে |
| `jinja2` | 3.1.6 | `attr` ফিল্টারের মাধ্যমে স্যান্ডবক্স এস্কেপ (CVE-2025-27516) |
| `vite` (স্ক্যাফোল্ডেড প্রজেক্ট) | 6.4.3 | `server.fs.deny` উইন্ডোজ বিকল্প পথে বাইপাস (CVE-2026-53571); আগের ক্যোয়ারী-স্ট্রিং বাইপাস (CVE-2026-39364) শুধুমাত্র Vite 7.1-7.3.1 এবং 8.0.0-8.0.4 | কে প্রভাবিত করে
| `react`, `react-dom` | 19.2.5 | 2026 প্রতিক্রিয়া পরামর্শগুলি `react-server-dom-*` প্যাকেজগুলির সাথে সম্পর্কিত, যা নেক্সি ব্যবহার করে না; মেঝে লাইন প্যাচ করে রাখে |

আপনার সমাধান করা সংস্করণ পরীক্ষা করুন:

```bash
uv pip list | grep -i -E "starlette|fastapi|jinja2"
npm ls vite
```

## নিয়ম Nexy অনুসরণ করে

- **এর জন্য হোস্ট হেডারকে কখনই বিশ্বাস করবেন না পথ** Nexy পড়ে `scope["path"]`, নয় `request.url.path`, in
  এর নিজস্ব মিডলওয়্যার (ডিরেক্টরি মিডলওয়্যার)। আপনার মধ্যে একই কাজ.
- **যা পৌঁছায় পালিয়ে যান এইচটিএমএল** প্রপস ক্লায়েন্ট উপাদান, `Link` বৈশিষ্ট্য, `Image` পাস করা হয়েছে,
  `Audio` এবং `Video` বৈশিষ্ট্য, বিষয়বস্তুর সারণী অ্যাঙ্কর এবং `HTTPException` বিবরণ সবই
  HTML-এস্কেপড। একটি টেমপ্লেটে `| safe` এটি বন্ধ করে দেয়: ব্যবহারকারীর ইনপুটে এটি কখনই ব্যবহার করবেন না।
- **ডেভেলপার এন্ডপয়েন্টগুলি শুধুমাত্র লুপব্যাক এবং সংকীর্ণ। ** ডেভ রেন্ডার এন্ডপয়েন্ট
  (`/__nexy__/render`) শুধুমাত্র `src/routes/` এর অধীনে একটি `.tsx` বা `.jsx` এক্সটেনশন সহ ফাইল গ্রহণ করে এবং
  শুধুমাত্র dev সার্ভারের মাধ্যমে পৌঁছানো যায়, যা বিদেশী `Host` শিরোনাম প্রত্যাখ্যান করে।
- **ত্রুটির বিবরণ নেই ফুটো** একটি ত্রুটি পৃষ্ঠা যা নিজেই ব্যর্থ হয় শুধুমাত্র স্থিতি কোড দেখায়।
- **উৎপাদন উত্তর নিরাপদ শিরোনাম বহন করে।** `X-Content-Type-Options: nosniff` এবং
  `Referrer-Policy: strict-origin-when-cross-origin`, যদি না আপনার কোড তার নিজস্ব সেট করে। এই `Server`
  হেডার পাঠানো হয় না। আপনার মধ্যে `Strict-Transport-Security` এবং একটি `Content-Security-Policy` যোগ করুন
  প্রক্সি বা মিডলওয়্যার: তারা আপনার ডোমেনের উপর নির্ভর করে।
- **একটি ক্র্যাশ একটি রেফারেন্স দেখায়, ত্রুটি নয়।** [ত্রুটির পৃষ্ঠাগুলি](../routing/fbr/errors/README.md#unhandled-exceptions) দেখুন।
- **নেক্সির পাইথনে না `eval` এবং না `shell=True` ** বহিরাগত প্রোগ্রাম একটি আর্গুমেন্ট তালিকার সাথে সঞ্চালিত হয়.

## অডিট চলমান

```bash
python scripts/audit_dependencies.py        # Python dependencies against the lock
npm audit                                    # in a scaffolded project
uv run bandit -r nexy -c .bandit             # static analysis of Nexy itself
```

Nexy এর নিজস্ব সংগ্রহস্থল তার চেকগুলিতে প্রথম এবং তৃতীয়টি চালায়। উপরে একটি মেঝে একটি নতুন পরামর্শ উত্থাপন দ্বারা পরিচালিত হয়
মেঝে `pyproject.toml` বা ভারা `package.json` মধ্যে, তারপর তালা পুনর্জন্ম।

## নিরাপদভাবে স্থাপন করা হচ্ছে

- আপনার ডোমেনে `useTrustedHost` সেট করুন: এটি যেকোনো রুটের আগে অপ্রত্যাশিত `Host` শিরোনাম প্রত্যাখ্যান করে।
- Vite dev সার্ভারটি প্রকাশ করবেন না: `nx dev` এটিকে নেক্সি মূলের পিছনে লুপব্যাকে রাখে।
- সেট `useDocs = False` যদি API স্কিমা সর্বজনীন না হয়।

[মিডলওয়্যার এবং নিরাপত্তা](../guides/middleware-and-security.md) দেখুন।
