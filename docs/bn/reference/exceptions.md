#  ব্যতিক্রম এবং ত্রুটি

একটি অনুরোধ চারটি জায়গায় ব্যর্থ হতে পারে এবং Nexy প্রতিটির ভিন্নভাবে উত্তর দেয়৷ এই পৃষ্ঠাটি হল সূচী:
আপনি যে স্ট্যাটাসটি দেখেন তা খুঁজুন, তারপর যে লাইনটি এটি তৈরি করেছে, তারপর ফাইলটি যা বডি নির্ধারণ করে।

> [!নোট]
> তিনটি জিনিস আলাদা এবং সহজেই মেশানো যায়: **HTTP উত্তর** (একটি স্ট্যাটাস এবং একটি বডি),
> **ত্রুটির পৃষ্ঠা** (`notfound.nexy`, `errors.nexy`), এবং **লগ লাইন** (আপনি যা পড়েন
> টার্মিনাল)। পৃষ্ঠা পরিবর্তন করলে স্থিতি পরিবর্তন হয় না, এবং পৃষ্ঠাটি কাস্টমাইজ করা লুকানো যায় না
> লগ।

## সংক্ষিপ্ত সংস্করণ

| কি হয়েছে | অবস্থা | ব্রাউজার দেখেছে | API ক্লায়েন্ট দেখেছে |
|---|---|---|---|
| কোনো রুট URL এর সাথে মেলে না | `404` | `notfound.nexy`, অন্যথায় অন্তর্নির্মিত পৃষ্ঠা | `{"detail": "Not Found"}` |
| একটি পাথ সেগমেন্ট তার টীকাটির সাথে খাপ খায় না | `404` | একই পৃষ্ঠা | `{"detail": "Not Found"}` |
| একটি ক্যোয়ারী, হেডার, কুকি বা বডি ফিল্ড অনুপস্থিত বা অবৈধ | `422` | FastAPI এর JSON বডি | FastAPI এর JSON বডি |
| `notFound()` | `404` | পৃষ্ঠা | `{"detail": ...}` |
| `unauthorized()` | `401` | অন্তর্নির্মিত পৃষ্ঠা | `{"detail": ...}` |
| `forbidden()` | `403` | অন্তর্নির্মিত পৃষ্ঠা | `{"detail": ...}` |
| `raise HTTPException(409, ...)` | `409` | অন্তর্নির্মিত পৃষ্ঠা | `{"detail": ...}` |
| একটি ব্যতিক্রম কিছুই ধরা পড়েনি | `500` | `errors.nexy`, অন্যথায় অন্তর্নির্মিত পৃষ্ঠা | `{"detail", "reference"}` |
| `redirect(url)` | `307` | গন্তব্য, পৃষ্ঠা নেই | গন্তব্য, শরীর নেই |
| `permanentRedirect(url)` | `308` | গন্তব্য, পৃষ্ঠা নেই | গন্তব্য |

একটি API ক্লায়েন্ট হল একটি অনুরোধ যার `Accept` শিরোনাম JSON-এর জন্য জিজ্ঞাসা করে এবং একটি পৃষ্ঠার জন্য নয়:

```bash
curl -H "Accept: application/json" http://localhost:3000/api/items/500
# {"detail":"Out of range"}
```

> [!সতর্কতা]
> `curl` ডিফল্টরূপে `Accept: */*` পাঠায়, যা HTML পৃষ্ঠা পায়। যোগ করুন
> `-H "Accept: application/json"` যখন আপনি JSON আকৃতি পরীক্ষা করেন। ব্রাউজার পেজ পেতে রাখা.
## যেখানে একটি ব্যর্থতা থেকে আসে

```diagram filename="একটি অনুরোধ, চারটি প্রস্থান"
Browser ──► Middleware ──► Router ──► Page or handler
                 │            │             │
                 │            │             ├─ return ───────────► 200
                 │            │             ├─ HTTPException ────► its status
                 │            │             └─ other exception ───► 500
                 │            └─ no match ────────────────────────► 404
                 └─ raises ──────────────────────────────────────► 500
```

| পর্যায় | কী ব্যর্থ হতে পারে | উত্তর |
|---|---|---|
| মিডলওয়্যার | আপনার `middleware.py`, CORS, সেশনগুলি | ব্যতিক্রমের অবস্থা, অন্যথায় `500` |
| রাউটার | URL কোনো ফাইলের সাথে মেলে না | `404` |
| বৈধতা | একটি পাথ সেগমেন্ট রূপান্তর করা যাবে না | `404` |
| বৈধতা | একটি প্রশ্ন, শিরোনাম, কুকি বা বডি ফিল্ড | `422` |
| পৃষ্ঠা, হ্যান্ডলার, অ্যাকশন, গার্ড | `HTTPException` | এর অবস্থা |
| পৃষ্ঠা, হ্যান্ডলার, অ্যাকশন, গার্ড | অন্য কিছু | `500` |

## যেকোন জায়গা থেকে চলে যান

`redirect`, `permanentRedirect`, `notFound`, `forbidden` এবং `unauthorized` একটি HTTP ব্যতিক্রম উত্থাপন,
তাই একই কল একটি `.nexy` পৃষ্ঠায় কাজ করে, একটি API হ্যান্ডলার, একটি মডুলার কন্ট্রোলার, একটি গার্ড, একটি
`dependencies.py` এবং একটি কর্ম.

```python filename="src/routes/posts/[slug].py"
from nexy import notFound, redirect

from src.posts import find


async def GET(slug: str):
    post = find(slug)
    if post is None:
        notFound("No such post")
    if post.moved_to:
        redirect(post.moved_to)
    return post
```

| কল | উত্তর | যখন |
|---|---|---|
| `notFound(detail=None)` | `404` | সম্পদের অস্তিত্ব নেই |
| `unauthorized(detail=None, scheme=None)` | `401` | ভিজিটরকে প্রথমে সাইন ইন করতে হবে |
| `forbidden(detail=None)` | `403` | দর্শনার্থী পরিচিত তবে এটি দেখতে পান না |
| `redirect(url, status=307)` | `307` | পদ্ধতি বজায় রেখে অন্যত্র পাঠান |
| `redirect(url, status=303)` | `303` | একটি ফর্মের পরে: পরবর্তী অনুরোধটি একটি `GET` |
| `permanentRedirect(url)` | `308` | একটি সরানো পৃষ্ঠা যা সার্চ ইঞ্জিনের মনে রাখা উচিত |

আপনার বিশ্বাসযোগ্য মানগুলি থেকে গন্তব্য তৈরি করুন। `redirect(request.query_params["next"])` দর্শক পাঠায়
যেখানেই লিঙ্ক বলে; এটি একটি খোলা পুনঃনির্দেশ। একটি লাইন বিরতি ধারণ করে এমন একটি গন্তব্য প্রত্যাখ্যান করা হয়েছে৷
## বৈধতা: 422, বা 404

হ্যান্ডলার প্যারামিটারগুলি তাদের টীকাগুলির বিপরীতে FastAPI দ্বারা যাচাই করা হয়৷

```python filename="src/routes/api/search.py"
from nexy.http import Header


async def GET(q: str, limit: int = 10, x_token: str = Header(...)):
    return {"q": q, "limit": limit}
```

| সমস্যা | স্থিতি | কেন |
|---|---|---|
| অনুপস্থিত বা অবৈধ ক্যোয়ারী, হেডার, কুকি বা বডি ফিল্ড | `422` | অনুরোধ হ্যান্ডলারের কাছে পৌঁছেছে, ডেটা ভুল |
| অবৈধ পাথ সেগমেন্ট (`/api/users/abc` জন্য `id: int`) | `404` | ফোল্ডারে একটি নন-সংখ্যার জন্য কোনো রুট নেই, তাই URLটি বিদ্যমান নেই |

`422` বডি হল ফাস্টএপিআই-এর আদর্শ আকৃতি, তাই ক্লায়েন্ট এবং জেনারেট করা SDK কাজ করতে থাকে:

```json
{"detail": [{"loc": ["query", "q"], "msg": "Field required", "type": "missing"}]}
```

একটি ফর্ম বা একটি কর্মের জন্য, ক্লায়েন্ট একটি `ActionError` `status` এবং `detail` সহ পায়; একটি `422`
এছাড়াও প্রতি ক্ষেত্রে একটি বার্তা দিয়ে `error.fields` পূরণ করে। [কর্ম](../guides/actions.md#errors-and-failures) দেখুন।

> [!টিপ]
> স্বাক্ষরে যাচাই করুন যখন নিয়মটি প্রায় একটি ক্ষেত্র (`limit: int = 10`)। মধ্যে বৈধতা
> শরীর যখন নিয়মের প্রয়োজন হয় ডাটাবেস বা অন্য একটি ক্ষেত্র ("এই ইমেলটি ইতিমধ্যেই ব্যবহার করা হয়েছে"): raise
> `HTTPException(409)` এবং ক্লায়েন্টের জন্য বার্তাটি রাখুন।

## কাস্টম ত্রুটি পৃষ্ঠা

```nexy filename="src/routes/notfound.nexy"
<h1>Page not found</h1>
<p>The link may be old. <a href="/">Start from the home page</a>.</p>
```

```nexy filename="src/routes/errors.nexy"
<h1>Something went wrong</h1>
<p>Try again in a moment.</p>
```

| ফাইল | স্থিতি | সুযোগ |
|---|---|---|
| `src/routes/notfound.nexy` | `404` | প্রকল্পের প্রতিটি রুট |
| `src/routes/errors.nexy` | `500` | প্রকল্পের প্রতিটি রুট |
| `src/routes/forbidden.nexy` | `403` | প্রকল্পের প্রতিটি রুট |
| `src/routes/unauthorized.nexy` | `401` | প্রকল্পের প্রতিটি রুট |
| `src/routes/blog/notfound.nexy` | `404` | `/blog` এবং নীচে |
| `src/routes/blog/errors.nexy` | `500` | `/blog` এবং নীচে |
| `src/routes/loading.nexy` | - | সংরক্ষিত, এখনও কোনো রানটাইম প্রভাব নেই |

রুটের কোথাও একটি ফাইল তার স্থিতির জন্য উত্তর ইনস্টল করে: রুটে একটি অনুলিপি উত্তর দেয়
পুরো প্রকল্প, একটি ফোল্ডারের একটি অনুলিপি সেই ফোল্ডারটির উত্তর দেয় এবং গভীরতম ফাইল যা URL এর সাথে মেলে
জয় প্রতিটি অনুলিপির বাইরে একটি URL, এবং কোনো ফাইল ছাড়াই একটি স্থিতি, অন্তর্নির্মিত স্টাইলযুক্ত পৃষ্ঠাগুলি পান৷
[ফোল্ডার প্রতি ত্রুটি পৃষ্ঠাগুলি](../routing/fbr/errors/folder-pages.md) দেখুন।

> [!গুরুত্বপূর্ণ]
> একটি `errors.nexy` পৃষ্ঠা `500` পৃষ্ঠাকে প্রতিস্থাপন করে; এটা ব্যতিক্রম ধরা না এবং এটা না
> লগ লাইন পরিবর্তন. উত্থাপিত হ্যান্ডলার যদি নিজেই পৃষ্ঠা হয়, তাহলে পৃষ্ঠাটি তার নিজস্ব দেখাতে পারে না
> ত্রুটির বিবরণ: `errors.nexy` সরল এবং স্বাধীন রাখুন।

## আনহ্যান্ডেল করা ব্যতিক্রম

একটি ব্যতিক্রম যে ধরা পড়া কিছুই একবার লগ করা হয় না, তার রেফারেন্স, এটি কোথা থেকে এসেছে এবং কোড সহ
এর চারপাশে অবস্থা হল `500`, এবং শরীর পরিবেশের উপর নির্ভর করে।

| | `nexy dev` | `nexy build` তারপর `nexy start` |
|---|---|---|
| ব্রাউজার | ত্রুটি, আপনার কোডের লাইন এবং ট্রেসব্যাক | `errors.nexy`, অন্যথায় বিল্ট-ইন পৃষ্ঠা, একটি রেফারেন্স সহ |
| API ক্লায়েন্ট | `{"detail", "reference", "error"}` | `{"detail", "reference"}` |
| টার্মিনাল | আপনার কোডের ব্যতিক্রম এবং লাইন | ব্যতিক্রম, পুরো ট্রেসব্যাক এবং রেফারেন্স |

```text
  x ZeroDivisionError: division by zero  GET /boom  ref fe6a5217
    at src/routes/boom.py:2 in GET
       1 | def GET():
       2 |     return {"a": 1 / 0}
```

রেফারেন্সটি আটটি অক্ষর, প্রতিটি ব্যর্থতার জন্য নতুন। একটি দর্শক এটি উদ্ধৃত করতে পারেন, এবং আপনি এটি খুঁজে
এটির জন্য লগ অনুসন্ধান করে ট্রেসব্যাক। কোনটিই ব্যতিক্রম বা কোড ভিজিটরের কাছে পৌঁছায় না
উত্পাদন

> [!সাবধান]
> উৎপাদনে কোনো দর্শকের কাছে ট্রেসব্যাক ফেরত দেবেন না এবং কোনো ভুলের মধ্যে গোপনীয়তা রাখবেন না
> বার্তা: একটি `HTTPException`-এর `detail` ক্লায়েন্টকে পাঠানো হয়, HTML-এস্কেপড। গোপন রাখুন
> লগ, উত্তরে নয়।
## কর্ম এবং ফর্ম

একটি ক্রিয়া হল একটি `POST` শেষ বিন্দু যার একটি উৎপন্ন পথ রয়েছে। এর ব্যর্থতা একই নিয়ম অনুসরণ করে:

| পরিস্থিতি | অবস্থা | ক্লায়েন্ট |
|---|---|---|
| একটি ক্ষেত্র অনুপস্থিত বা অবৈধ | `422` | `ActionError` `fields` | সহ
| `HTTPException(403)` কর্মে উত্থাপিত | `403` | `ActionError` `status` এবং `detail` |
| একটি আন-হ্যান্ডেল করা ব্যতিক্রম | `500` | `ActionError`; রেফারেন্সটি সার্ভার লগে রয়েছে |
| `Origin` শিরোনামটি অন্য একটি সাইট | `403` | অ্যাকশন চালানোর আগে প্রত্যাখ্যান |

অ্যাকশন পাথে জাভাস্ক্রিপ্ট পোস্ট ছাড়া একটি ফর্ম; একটি সফল উত্তর `303` পাতায় ফিরে, ক
ব্যর্থতা ত্রুটি পৃষ্ঠা দেখায়। [কর্ম](../guides/actions.md#forms-without-javascript) দেখুন।

## একটি চেকলিস্ট যখন একটি পৃষ্ঠা ভুল উত্তর দেয়

1. **স্ট্যাটাস দেখুন**, পেজ নয়। একটি কাস্টম `notfound.nexy` এখনও উত্তর দেয় `404`।
2. **টার্মিনাল পড়ুন।** একটি পৃষ্ঠা যা আমদানি করতে ব্যর্থ হয় তা নিবন্ধিত নয়, তাই এর URL উত্তর দেয় `404`
   যখন ফাইলটি বিদ্যমান থাকে। আমদানি ত্রুটি লগে আছে।
3. **চেক করুন এক্সটেনশন** `useCSR = True` সহ, `.nexy` পৃষ্ঠাগুলি সার্ভার মোডের অন্তর্গত; একটি পাতা
   ভুল মোড একটি রুট নয়।
4. **চেক করুন গভীরতা** একটি `notfound.nexy` বা `errors.nexy` শুধুমাত্র তখনই কাজ করে যখন রুট কপি বিদ্যমান থাকে।
5. **জেএসওএন**-এর জন্য জিজ্ঞাসা করুন `Accept: application/json` এর সাথে আপনার API ক্লায়েন্ট যে আকার পায় তা দেখতে।
6. **একটি `500` এর রেফারেন্স ** উদ্ধৃত করুন যখন আপনি একটি সমস্যা খুলবেন বা লগ অনুসন্ধান করুন।
