# CLI

বাইনারি হল `nx` (`nexy` হিসেবেও ইনস্টল করা হয়েছে)। `uvx nexy new` একটি প্রকল্প তৈরি করে (`uvx` এর সাথে আসে
uv)। প্রকল্পের ভার্চুয়াল পরিবেশের ভিতরে বা `uv run` এর মাধ্যমে অন্য প্রতিটি কমান্ড চালান
উদাহরণ `uv run nexy dev`: এখানেই আপনার নিজস্ব প্যাকেজ রয়েছে।

## কমান্ড

| কমান্ড | উপনাম | এটি কী করে |
|---|---|---|
| `nx dev` | `nx d` | ডেভেলপমেন্ট সার্ভার: কম্পাইল অন চেঞ্জ, ভিটে, এইচএমআর |
| `nx start` | `nx s` | সংকলিত আউটপুটে উৎপাদন সার্ভার |
| `nx build` | `nx b` | উত্পাদন নির্মাণ |
| `nx new` | `nx n` | একটি প্রকল্পের ভারা |
| `nx init` | `nx i` | একটি বিদ্যমান প্রকল্পে Nexy যোগ করুন |
| `nx add` | - | রেজিস্ট্রি থেকে একটি UI উপাদান বা একটি URL যোগ করুন `src/components/ui` |
| `nx migrate` | `nx m` | অ্যালেম্বিক বা এরিচের সাথে ডাটাবেস মাইগ্রেশন তৈরি বা প্রয়োগ করুন |
| `nx check` | `nx c` | টাইপ-চেক: পাইথনে mypy, টাইপস্ক্রিপ্টে `tsc` |
| `nx format` | `nx f` | বিন্যাস পাইথন (রাফ), JS/TS (সুন্দর), `.nexy` ফাইল |
| `nx test` | - | রান pytest; `--client` vitest যোগ করে |
| `nx skills` | - | দক্ষতা যোগ করুন বা রিফ্রেশ করুন, `AGENTS.md` এবং `CLAUDE.md` কোডিং এজেন্টের জন্য |

## আউটপুট

দীর্ঘ পদক্ষেপ (প্যাকেজ ইনস্টল করা, কম্পাইল করা, বান্ডলিং) অতিবাহিত সময়ের সাথে একটি স্পিনার দেখায়, তারপর
একটি লাইন পিছনে ছেড়ে দিন: `✔ uv sync .venv  1.4s`। ধাপগুলির একটি গ্রুপ ( `nx new` এর ইনস্টলেশনগুলি দেখায় a
সমাপ্ত পদক্ষেপের সংখ্যা সহ অগ্রগতি বার, `━━━━────  2/5`; একটি একক পদক্ষেপ (`nx add`) দেখায় a
বার যে ডাল যখন এটি রান. অনুরোধের জন্য দেব লগ পড়া `GET » /about 200 in 12ms` এবং
ভিটের জন্য `vite » ...`। একটি ব্যর্থ পদক্ষেপ শেষ মুদ্রণ
কমান্ডের আউটপুটের লাইনগুলি লুকিয়ে রাখার পরিবর্তে। যেসব টার্মিনাল ইউনিকোড রেন্ডার করতে পারে না সেগুলি পাবেন
`+` এবং `x`।

## যখন ত্রুটি `nx dev` রান

একটি ভাঙা ফাইল সংরক্ষণ করা সার্ভার বন্ধ করে না. একটি সিনট্যাক্স ত্রুটি সহ একটি `.py` ফাইল এর সাথে রিপোর্ট করা হয়েছে
ফাইল এবং লাইন, এবং আপনি এটি ঠিক না করা পর্যন্ত সার্ভারটি শেষ কার্যকরী সংস্করণটি পরিবেশন করে:

```text
  nexy » error  src/routes/users.py:3
  SyntaxError: invalid syntax

    1 | import json
    2 |
  > 3 | def GET(:
                ^
    4 |     x = 1
    5 |     return {"v": 2}

  Fix it and save: the server keeps its last working version.
```

একটি ফাইল যা পার্স করে কিন্তু ব্যর্থ হয় যখন অ্যাপ্লিকেশন লোড হয় (একটি অনুপস্থিত আমদানি, মডিউলে একটি ত্রুটি
স্তর) একইভাবে রিপোর্ট করা হয় এবং `nx dev` আপনার পরবর্তী সংরক্ষণের জন্য অপেক্ষা করে; পর্যন্ত কিছুই পরিবেশন করা হয় না
অ্যাপ্লিকেশন আবার লোড. সার্ভার পুনরায় লোড করার সময় একটি বৈধ সংরক্ষণ পড়ে `nexy » update <file>`। বাইরে মার্কডাউন ফাইল
`src/routes`, যেমন `README.md`, পৃষ্ঠা নয় এবং কিছু ট্রিগার করে না।
`nx start` আরও কঠোর: এটি কোড 1 দিয়ে প্রস্থান করে এবং রুট ফাইল লোড করতে না পারলে কিছুই শুরু হয় না।

##  `nx new` এর প্রশ্ন

`nx new` জিজ্ঞাসা করে, এই ক্রমে: ফাইল-ভিত্তিক রাউটার, প্রকল্পের ধরন (ওয়েব বা API), ক্লায়েন্ট-সাইড রাউটিং,
ক্লায়েন্ট ফ্রেমওয়ার্ক, অ্যাপটিকে কীভাবে স্টাইল করতে হয়, ইম্পোর্ট উপনাম, ORM, ডাটাবেস এবং ডাটাবেস URL। প্রতিটি বিকল্প একটি সংক্ষিপ্ত আছে
বর্ণনা এবং বর্তমান এক হাইলাইট করা হয়. যে প্রশ্নগুলি প্রযোজ্য নয় সেগুলি বাদ দেওয়া হয় (একটি API
প্রকল্পের কোন কাঠামো বা শৈলী নেই; ORM ডাটাবেস এবং URL এড়িয়ে যাওয়ার কারণে **কোনও ডাটাবেস** বেছে নেওয়া হয়নি)।
তীর কী (বা `j`/`k`, বা একটি সংখ্যা দিয়ে সরান, `enter` দিয়ে নিশ্চিত করুন, আগেরটিতে ফিরে যান
`←` অথবা `esc` দিয়ে প্রশ্ন, `ctrl+c` দিয়ে প্রস্থান করুন।

| প্রশ্ন | পছন্দ |
|---|---|
| ইম্পোর্ট উপনাম | `@` (`@/components/...` পয়েন্ট `src/`, বা অন্য উপসর্গ যেমন `~` বা `#app` |
| স্টাইল | টেইলউইন্ড সিএসএস, ইউনোসিএসএস, ভ্যানিলা সিএসএস, অন্যান্য (কোনও সিএসএস টুল নয়, ভ্যানিলার মতো একই প্লেইন স্টাইলশীট) |
| ORM | SQLModel, SQLAlchemy, Tortoise-ORM, কোন ডাটাবেস নেই |
| ডেটাবেস (একটি ORM সহ) | SQLite, PostgreSQL, Neon, MySQL / MariaDB, অন্যান্য (আপনি URL টাইপ করেন) |

নির্বাচিত ORM-এর জন্য ডাটাবেস ড্রাইভার এটির সাথে ইনস্টল করা আছে (`psycopg`, `pymysql`, `asyncpg` অথবা
`aiomysql`), এবং URLটি `.env`-এ লেখা হয়েছে।

প্যাকেজ ইনস্টল করার আগে, `nx new` সংযোগ পরীক্ষা করে। একটি ছাড়া, এটি ইনস্টল এড়িয়ে যায় এবং
আপনাকে `uv sync` চালাতে এবং আপনার প্যাকেজ ম্যানেজারের পরে ইনস্টল করতে বলে। এক সঙ্গে, এটা প্রিন্ট
লেটেন্সি এবং ডাউনলোডের গতি, এবং যখন সংযোগটি ধীর হয় তখন সতর্ক করে (400 ms এর বেশি, বা কম
100 KB/s)। প্রতিটি ইনস্টল লাইন টুলের নাম দেয় এবং এটি যে ফোল্ডারটি পূরণ করে, উদাহরণস্বরূপ
`pnpm install node_modules` বা `uv sync .venv`।

## কি `dev`, `build` এবং `start` তৈরি করে

তারা চালানোর আগে, তিনটি কমান্ড `src/` এবং প্রতিটি ফোল্ডারে একটি খালি `__init__.py` তৈরি করে
এটির অধীনে একটি `.py` বা `.nexy` ফাইল ধারণ করে, তাই একটি রুট যেমন `src/routes/users.py` আমদানি করে
তাদের সব একই ভাবে. বিদ্যমান ফাইলগুলিকে কখনই স্পর্শ করা হয় না এবং `nx dev` আবার একই কাজ করে যখন
আপনি একটি ফোল্ডার যোগ করুন। পাইথন বাইটকোড `__nexy__/__pycache__` এ যায়, তাই কোনো `__pycache__` ফোল্ডার নেই
আপনার উৎসের পাশে প্রদর্শিত হবে।

## ভাষা

কমান্ড লাইন ইংরেজি, চীনা, হিন্দি, স্প্যানিশ, পর্তুগিজ, ফরাসি, জার্মান, জাপানিজ,
রুশ, কোরিয়ান, ইন্দোনেশিয়ান এবং আরবি। এটি এইগুলির মধ্যে প্রথমটি ব্যবহার করে যা এটি সমর্থন করে:

1.  `NEXY_LANG` পরিবেশ পরিবর্তনশীল (`NEXY_LANG=ja nx dev`);
2. আপনার শেলের লোকেল ভেরিয়েবল (`LC_ALL`, `LC_MESSAGES`, `LANG`, তারপর `LANGUAGE`);
3. আপনার অপারেটিং সিস্টেমের ভাষা।

অন্য কিছু ইংরেজি, এবং তাই কোন বার্তা একটি ভাষা এখনও নেই. শুধু কি `nx`
প্রিন্টগুলি অনুবাদ করা হয়: কম্পাইলার ত্রুটি, ট্রেসব্যাক এবং এটি চালানোর সরঞ্জামগুলির আউটপুট যেমন থাকে
হয় অনুবাদগুলি এখনও স্থানীয় ভাষাভাষীদের দ্বারা পর্যালোচনা করা হয়নি:
সংশোধনগুলিকে `nexy/modules/i18n/<language>.json` করার অনুরোধ হিসাবে স্বাগত জানানো হয়।
## আচরণ তৈরি করুন

`nx build` রুটগুলি কম্পাইল করে, তারপর `useVite` চালু হলে ক্লায়েন্টকে বান্ডিল করে।

> [!নোট]
> কোন `--static` পতাকা নেই। স্ট্যাটিক হোস্টিং একটি স্থাপনার পছন্দ, বিল্ড নয়
> মোড - [ডিপ্লয়](../deployment/README.md) দেখুন।
