# গতিশীল রুট

বর্গাকার বন্ধনীতে লেখা একটি পাথ সেগমেন্ট যেকোন মানের সাথে মেলে এবং এটি পৃষ্ঠা বা হ্যান্ডলারের কাছে হস্তান্তর করে।

## গতিশীল সেগমেন্ট

`blog/[slug].nexy` পরিবেশন করে `/blog/{slug}`। একটি পৃষ্ঠায়, বিভাগটিকে একটি সম্পত্তি হিসাবে ঘোষণা করুন; একটি Python হ্যান্ডলারে, এটি একটি যুক্তি হিসাবে নিন।

```nexy filename="src/routes/blog/[slug].nexy"
---
slug: prop[str]
---
<h1>{{ slug }}</h1>
```

```python filename="src/routes/api/users/[id].py"
async def GET(id: int):
    return {"id": id}
```

## টাইপ করা অংশ

টীকা প্রকার নির্ধারণ করে।

| যেখানে | রূপান্তর |
|---|---|
| `.py` হ্যান্ডলার | যেকোনো FastAPI টাইপ টীকা (`int`, `UUID`, `Enum`...) |
| `.nexy` পৃষ্ঠা | `int` এবং `float` রূপান্তরিত হয়; বাকি সব কিছু একটা স্ট্রিং থাকে |

একটি মান যা টীকাটির সাথে মেলে না তা হল **পাওয়া যায় না**: `/api/users/abc` উত্তর দেয় `404`, কারণ একটি ডায়নামিক রুট যেকোনো URL ক্যাপচার করে এবং একটি URL যা রূপান্তরিত করা যায় না তার অস্তিত্ব নেই। দেখুন [বৈধকরণ এবং ত্রুটি](../handlers/validation-and-errors.md)।

## ক্যাচ-সব সেগমেন্ট

`docs/[...path].nexy` পরিবেশন করে `/docs/{path:path}`। অবশিষ্ট অংশগুলি একটি স্ট্রিং হিসাবে আসে, স্ল্যাশগুলি অন্তর্ভুক্ত।

```nexy filename="src/routes/docs/[...path].nexy"
---
path: prop[str]
---
<pre>{{ path }}</pre>
```

`/docs/a/b/c` দেয় `path == "a/b/c"`।

## রুট গ্রুপ

বন্ধনীতে থাকা একটি ডিরেক্টরি URL-এ উপস্থিত না হয়ে ফাইলগুলিকে সংগঠিত করে। এটি এখনও অংশ নেয় [উত্তরাধিকার](../inheritance.md): এর `layout.*` এবং `dependencies.py` ভিতরে যা আছে তার জন্য প্রযোজ্য।

```text
src/routes/
├─ (marketing)/
│  ├─ layout.nexy        applies to the pages in the group
│  ├─ pricing.nexy       /pricing
│  └─ about.nexy         /about
└─ (app)/
   └─ dashboard.nexy     /dashboard
```

বিভিন্ন বিভাগকে তাদের URL পরিবর্তন না করেই ভিন্ন ভিন্ন লেআউট দিতে গোষ্ঠী ব্যবহার করুন।

## অগ্রাধিকার

স্ট্যাটিক রুটগুলি গতিশীলগুলির উপর জয়লাভ করে এবং গতিশীলগুলি ক্যাচ-অলগুলির উপর জয়লাভ করে: `/blog/new` ম্যাচ `blog/new.nexy` `blog/[slug].nexy` এর আগে।

## URL প্রতি একটি ফাইল

একই ইউআরএলে সমাধান করা দুটি ফাইল উভয় নিবন্ধন করে। `blog/index.nexy` এর পাশে `blog.nexy` রাখবেন না, বা একই পথের জন্য `index.nexy` এবং `index.py` মিশ্রিত করবেন না।
