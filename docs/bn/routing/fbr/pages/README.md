# পাতা

একটি পৃষ্ঠা ফাইল HTML প্রদান করে। আপনি কোন ফাইল টাইপ ব্যবহার করেন তা কীভাবে উত্পাদিত হয় তা পরিবর্তন করে: [দর্শন](../../../views/README.md) দেখুন। এই বিভাগে রাউটিং নিয়মগুলি কভার করে যা প্রতিটি পৃষ্ঠা বিন্যাসে প্রযোজ্য।

| পৃষ্ঠা | এটি কি কভার করে |
|---|---|
| [ডাইনামিক রুট](dynamic-routes.md) | `[slug]`, `[...path]`, রুট গ্রুপ, টাইপ করা সেগমেন্ট |
| [ত্রুটি পৃষ্ঠাগুলি](../errors/README.md) | `notfound.nexy`, `errors.nexy`, API ক্লায়েন্টদের জন্য JSON |
| [লেআউটস](../layouts/README.md) | লেআউট ফাইল টাইপ প্রতি এক পৃষ্ঠা |
| [উত্তরাধিকার](../inheritance.md) | লেআউট এবং নির্ভরতা কীভাবে স্ট্যাক করে |

## একটি ন্যূনতম পৃষ্ঠা

```nexy filename="src/routes/about.nexy"
---
title: prop[str] = "About"
---
<h1>{{ title }}</h1>
```

এটি `/about` এ পরিবেশিত হয়। `---` লাইনের মধ্যবর্তী বিষয় হল Python; এর নিচের মার্কআপটি হল Jinja2। [.nexy ফাইল](../../../views/nexy/README.md) দেখুন।

## পৃষ্ঠা বিন্যাস

| মোড | ফাইল | উত্পাদন করে |
|---|---|---|
| সার্ভার | `.nexy` | Python এবং Jinja2 | থেকে সার্ভার-রেন্ডার করা HTML
| সার্ভার | `.md`, `.mdx` | বিষয়বস্তু পাতা |
| ক্লায়েন্ট | `.tsx`, `.jsx`, `.vue`, `.svelte` | ফ্রেমওয়ার্ক উপাদান, ব্রাউজারে রেন্ডার করা এবং নেভিগেট করা |

দুটি মোড এক প্রকল্পে মিশ্রিত করা যাবে না. [সার্ভার মোড এবং ক্লায়েন্ট মোড](../modes.md) দেখুন। ক্লায়েন্ট উপাদানগুলি এখনও সার্ভার মোডে প্রদর্শিত হতে পারে, একটি `.nexy` পৃষ্ঠার ভিতরে [দ্বীপগুলি](../../../rendering/islands.md) হিসাবে।

## ইনক্রিমেন্টাল ক্যাশিং

stale-while-revalidate দিয়ে ক্যাশে করার জন্য একটি `.nexy` পৃষ্ঠায় `revalidate = 60` যোগ করুন। [ISR](../../../rendering/isr.md) দেখুন।

## অনুরোধ পড়া

একটি পৃষ্ঠা হুকের মাধ্যমে পথ, ক্যোয়ারী স্ট্রিং, কুকিজ এবং সেশন পড়ে। [হুকস](../navigation/hooks.md) দেখুন।
