# পৃষ্ঠা রূপান্তর কিভাবে কাজ করে?

Nexy ক্লায়েন্ট নেভিগেশনের জন্য ব্রাউজারের ভিউ ট্রানজিশন এপিআই ব্যবহার করে, তাই একটি সমর্থিত ব্রাউজার পৃষ্ঠা অদলবদলকে অ্যানিমেট করে যদি না ভিজিটর কম গতিতে পছন্দ করে।

## যখন একটি ট্রানজিশন চলে

প্রথম দস্তাবেজটি একটি সাধারণ সার্ভারের প্রতিক্রিয়া এবং কোন রূপান্তর নেই। তারপর থেকে, ক্লায়েন্ট রাউটার দ্বারা পরিচালিত প্রতিটি নেভিগেশন পৃষ্ঠাটিকে `document.startViewTransition()` এর ভিতরে অদলবদল করে: একটি ক্লায়েন্ট রুটের একটি লিঙ্ক, `router.push()` বা `router.replace()`, এবং পিছনে এবং সামনের বোতামগুলি। রাউটারটি প্রথমে পরবর্তী পৃষ্ঠা এবং এর লেআউটগুলিকে রেন্ডার করে, তারপরে URLটি সরানো হয়, তাই নতুন পৃষ্ঠাটি দেখানোর আগে প্রস্তুত থাকে৷

React, Preact, Solid, Vue এবং Svelte একই রাউটার ভাগ করে, তাই পাঁচটি অ্যাডাপ্টারের আচরণ একই। ট্রানজিশন সক্ষম করার জন্য কোন সেটিং নেই।

## যখন পিছিয়ে পড়ে

- `startViewTransition()` ছাড়া একটি ব্রাউজার সরাসরি পৃষ্ঠাটিকে রেন্ডার করে।
- `prefers-reduced-motion: reduce` এর সাথে, রাউটার সরাসরি পৃষ্ঠাটি রেন্ডার করে।
- একটি নতুন নেভিগেশন দ্বারা এড়িয়ে যাওয়া একটি ট্রানজিশন একটি ত্রুটি লগ করে না: পৃষ্ঠাটি এখনও সঠিক।

URL, ইতিহাস, স্ক্রোল অবস্থান এবং `nexy:navigated` ইভেন্ট একটি রূপান্তরের সাথে বা ছাড়াই একইভাবে আচরণ করে।

## রূপান্তর শৈলী

Nexy শিপ কোন অ্যানিমেশন CSS. ব্রাউজারটি তার ডিফল্ট ক্রস-ফেড প্রয়োগ করে, যা আপনি নিজের স্টাইলশীটে প্রতিস্থাপন করতে পারেন:

```css
::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: 250ms;
}
```
