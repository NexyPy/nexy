# CSR (ক্লায়েন্ট-সাইড রেন্ডারিং)

## সংজ্ঞা

CSR ব্রাউজারে নেভিগেশন হস্তান্তর করে: প্রথম নথির পরে, পৃষ্ঠাগুলির মধ্যে সরানো আর জিজ্ঞাসা করে না
HTML এর জন্য সার্ভার। নেক্সিতে এটি একটি **প্রকল্প** সিদ্ধান্ত, একটি পৃষ্ঠা নয় - `useCSR = True` পরিবর্তন করে
সম্পূর্ণ অ্যাপ্লিকেশন ক্লায়েন্ট-রুটেড।

## এটি কিভাবে কাজ করে

```python filename="nexyconfig.py"
from nexy.core.models import NexyConfigModel
from nexy.frontend import react


class NexyConfig(NexyConfigModel):
    useFF = react()
    useCSR = True
```

প্রকল্প তারপর আকৃতি পরিবর্তন:

| | সার্ভার মোড (`False`) | ক্লায়েন্ট মোড (`True`) |
|---|---|---|
| রুট | `.nexy`, `.md`, `.mdx` | `.tsx`, `.jsx`, `.vue`, `.svelte` |
| নথি | `layout.nexy` | মূল `layout.tsx` / `.vue` / `.svelte` মালিকানা `<html>`, `<head>`, `<body>` |
| ক্লায়েন্ট উপাদানগুলি | একটি পৃষ্ঠার ভিতরে দ্বীপগুলি | পৃষ্ঠাগুলি নিজেই |
| `.nexy` `src/routes/` | পৃষ্ঠা বিন্যাসের অধীনে | `nx dev`, `nx start` এবং `nx build` | আগে প্রত্যাখ্যান করা হয়েছে
| নেভিগেশন | লিঙ্ক প্রতি একটি সম্পূর্ণ অনুরোধ | ক্লায়েন্ট রাউটার |

`.md` এবং `.mdx` বৈধ থাকে: Nexy সেগুলিকে ক্লায়েন্ট লেআউটের ভিতরে সার্ভারে রেন্ডার করে এবং
ক্লায়েন্ট রাউটার সেখান থেকে গ্রহণ করে। `.py` হ্যান্ডলাররা রুটের পাশে বসে এবং FastAPI দ্বারা পরিবেশিত হয়।

## রেন্ডারিং জীবনচক্র

1. অনুরোধটি ফাইল-ভিত্তিক রাউটারে পৌঁছায়, যা মিলিত রুট এবং এর লেআউটগুলি খুঁজে পায়।
2. রুট লেআউটটি নোডে **পুরো নথি** রেন্ডার করে - প্রথম প্রতিক্রিয়াটি ইতিমধ্যেই বহন করে
   বাস্তব `<html>`, খালি শেল নয়।
3. Nexy ক্লায়েন্ট সম্পদ এবং `</body>` এর আগে পৃষ্ঠার একটি JSON বিবরণ ইনজেক্ট করে।
4. ব্রাউজার সেই নথিটিকে হাইড্রেট করে। নেস্টেড লেআউটগুলি তখন থেকে তাদের অবস্থা বজায় রাখে।
5. অন্য রুটের একটি লিঙ্ক ক্লায়েন্ট রাউটার দ্বারা পরিচালিত হয়: কোনো নথির অনুরোধ নেই, পৃষ্ঠাটি
   ব্রাউজারে রেন্ডার করা হয়েছে।

বিকাশে ডকুমেন্টটি Vite dev সার্ভারের চাহিদা অনুযায়ী রেন্ডার করা হয়। উৎপাদনে এটা
বিল্ড করার সময় একবার রেন্ডার করা হয়: একটি স্ট্যাটিক রুট তার ডকুমেন্ট পায়, একটি ডাইনামিক রুট ঘোষিত প্রতি একটি পায়
স্ট্যাটিক প্যারাম, বা একটি শেল - একটি খালি পৃষ্ঠার চারপাশে লেআউট - যখন এটি কোনটি ঘোষণা করে না।

## কখন ব্যবহার করতে হবে

- ড্যাশবোর্ড, এডিটর, যে কোনো কিছু যা একটি অ্যাপ্লিকেশনের মতো আচরণ করে।
- উপরে একটি ক্লায়েন্ট অ্যাপ্লিকেশন সহ একটি পাইথন API।
- একটি পৃষ্ঠা যেখানে প্রতিটি মিথস্ক্রিয়া স্থানীয় এবং একটি রাউন্ড ট্রিপ অনুভূত হবে।

## কনফিগারেশন

| সেটিং | মান |
|---|---|
| `useFF` | আবশ্যক: ক্লায়েন্ট ফ্রেমওয়ার্ক ছাড়াই `useCSR` প্রত্যাখ্যান করা হয় |
| `useCSR` | `True` |
| `useRouter` | বন্ধ থাকতে হবে: মডুলার রাউটার ক্লায়েন্ট মোডে প্রত্যাখ্যান করা হয়েছে |

`_` বা `.` দিয়ে শুরু হওয়া ফাইল এবং ফোল্ডারগুলি এই চেকগুলির দ্বারা উপেক্ষা করা হয়।

## সীমাবদ্ধতা

- **সম্পূর্ণ প্রকল্প** আপনি একটি সার্ভার-মোড প্রকল্পে একটি CSR পৃষ্ঠা মিশ্রিত করতে পারবেন না: এর জন্য মোড বাছাই করুন৷
  অ্যাপ্লিকেশন, তারপর একটি সার্ভার-মোড পৃষ্ঠার ইন্টারেক্টিভ অংশগুলির জন্য [দ্বীপগুলি](islands.md) ব্যবহার করুন।
- **না `.nexy` রুট** আপনি `.nexy` এ যা কিছু লিখেছেন তা একটি কাঠামোর উপাদান হয়ে উঠতে হবে।
- **সার্ভার ডেটা যায় শেষ পয়েন্ট** একটি ক্লায়েন্ট রুট রেন্ডারের সময় ডাটাবেস পড়তে পারে না; এটা
  একটি `.py` হ্যান্ডলার বা একটি [অ্যাকশন](../guides/actions.md) কল করে।
- **একটি গতিশীল রুটের একটি ঘোষিত স্ট্যাটিক প্যারাম প্রয়োজন, অথবা এটি একটি শেল থেকে শুরু হয়।** রপ্তানি
  `getStaticParams()` পৃষ্ঠা থেকে - Next.js নাম `getStaticPaths` এবং `generateStaticParams`
  এছাড়াও গৃহীত হয় - প্রতি মান একটি নথি আছে. এটি ছাড়া, শেল লেআউট বহন করে এবং
  পৃষ্ঠাটি নয়: ব্রাউজারটি চালানোর পরে পৃষ্ঠাটি উপস্থিত হয়।
- **CSR একটি ফাঁকা পৃষ্ঠা নয়, এবং একটি SPAও নয়।** প্রথম নথিটি সার্ভার দ্বারা রেন্ডার করা হয়; এটা
  ব্রাউজারে ঘটে যাওয়া নেভিগেশন।
