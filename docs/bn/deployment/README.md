# নিয়োগ করুন

দুটি আদেশ: `nx build` শিল্পকর্ম তৈরি করে, `nx start` তাদের পরিবেশন করে।

**আপনি শুরু করার আগে:** একটি প্রকল্প যা স্থানীয়ভাবে তৈরি করে `nx build`, এবং - ক্লায়েন্ট পৃষ্ঠাগুলির জন্য -
ফ্রন্টএন্ড টুলচেন যা `nx new` ইনস্টল করা হয়েছে।

```bash
nx build
nx start --host 0.0.0.0 --port 8000
```

রানটাইম শুধুমাত্র পাইথন প্রয়োজন. Uvicorn কম্পাইল করা অ্যাপ এবং স্ট্যাটিক সম্পদ পরিবেশন করে; কোন নোড নেই
প্রক্রিয়া এবং কোন Vite প্রক্রিয়া জড়িত নেই.

## বিল্ড কি উত্পাদন করে

`__nexy__/` কম্পাইল করা রুট মডিউল, `__nexy__/client/` এর অধীনে ক্লায়েন্ট বান্ডিল এবং
ফ্রেমওয়ার্ক রুটের জন্য প্রাক-রেন্ডার করা HTML। প্রকল্পটি অনুলিপি করুন - উত্স প্লাস `__nexy__/` - বা ভিতরে তৈরি করুন
ছবিটি

## ডকার

বিল্ড স্টেজে Node (Vite এর জন্য) এবং Python (কম্পাইলারের জন্য) প্রয়োজন। রানটাইম পর্যায়ে পাইথন প্রয়োজন
শুধুমাত্র

```dockerfile filename="ডকারফাইল"
FROM node:22-bookworm-slim AS build
WORKDIR /app

COPY --from=ghcr.io/astral-sh/uv:latest /uv /usr/local/bin/uv
COPY pyproject.toml uv.lock ./
RUN uv sync --frozen --no-install-project

COPY . .
RUN uv sync --frozen && uv run nx build

FROM python:3.13-slim
WORKDIR /app
COPY --from=build /app /app
ENV PATH="/app/.venv/bin:$PATH"

EXPOSE 8000
CMD ["nx", "start", "--host", "0.0.0.0", "--port", "8000"]
```

`uv` একটি পরিচালিত পাইথন নিয়ে আসে যখন বেস ইমেজের কোনোটিই থাকে না, যার কারণে বিল্ড স্টেজ শুরু হতে পারে
একটি নোড ইমেজ থেকে।

## একটি বিপরীত প্রক্সির পিছনে

লোকালহোস্টে `nx start` চালান এবং Nginx, Caddy বা প্ল্যাটফর্ম প্রক্সিকে TLS বন্ধ করতে দিন:

```bash
nx start --host 127.0.0.1 --port 8000
```

আপনি যদি `SOCKET` হ্যান্ডলার ব্যবহার করেন তবে প্রক্সি ফরওয়ার্ড ওয়েবসকেট আপগ্রেড হয় এবং এটি ফরওয়ার্ড করে তা নিশ্চিত করুন
মূল হোস্ট - ফাস্টএপিআই এটি থেকে সম্পূর্ণ ইউআরএল তৈরি করে।

## স্বাস্থ্য পরীক্ষা

একটি হ্যান্ডলার ফাইল যোগ করুন, `src/routes/api/health.py`, এবং প্রোব `/api/health` - একটি পৃষ্ঠার পরিবর্তে যা হতে পারে
ধীরে ধীরে রেন্ডার করুন:

```python filename="src/routes/api/health.py"
async def GET():
    return {"status": "ok"}
```

## স্ট্যাটিক হোস্টিং

প্রতিটি পৃষ্ঠা এইচটিএমএল, কিন্তু নেক্সি রাউটিং এবং API হ্যান্ডলারের জন্য একটি সার্ভার ধরে নেয়।

> [!নোট]
> কোনও `--static` বিল্ড মোড নেই। একটি সম্পূর্ণরূপে স্থিতিশীল রপ্তানি তৈরি করতে হবে
> আপনার পাইপলাইন `nx build` আউটপুট থেকে।

## চেকলিস্ট

- [ ] `nx build` CI তে, আপনি সার্ভারে রেন্ডার করার আশা করা রুটের জন্য কোনো সতর্কতা নেই
- [ ] `nx start` কোড 1 দিয়ে প্রস্থান করে, এবং কিছুই শুরু করে না, যখন একটি রুট ফাইল লোড করতে পারে না
- [ ] `NEXY_ACTION_SECRET` সেট, বা `__nexy__/action.key` বিল্ডের সাথে রাখা
- [ ] `useDocs = False` উত্পাদনে যদি API স্কিমা সর্বজনীন হওয়া উচিত নয়
- [ ] `useTrustedHost` এবং `useHTTPSRedirect` পাবলিক স্থাপনার জন্য সেট
- [ ] `__nexy__/` প্রতিশ্রুতিবদ্ধ নয়
