# পারফরম্যান্স

ডিফল্টরূপে `nx start` কী করে, কী চালু করতে হবে এবং কী পরিমাপ করা হয়েছিল।

## ডিফল্ট

| উদ্বেগ | ডিফল্ট | এটি পরিবর্তন করুন |
|---|---|---|
| প্রক্রিয়া করে | লিনাক্স এবং ম্যাকওএস-এ সিপিইউ প্রতি একজন ইউভিকর্ন কর্মী, একজন উইন্ডোজ | `nx start` ইউভিকর্নের মাধ্যমে অ্যাপ চালায় |
| কম্প্রেশন | বন্ধ | `useGZip = {"minimum_size": 1000}` [কনফিগারে](../reference/config.md), অথবা বিপরীত প্রক্সিতে | কম্প্রেস করুন
| স্ট্যাটিক ফাইলগুলি | `ETag` এবং `Last-Modified` দিয়ে পরিবেশিত হয়, না `Cache-Control` | হ্যাশ করা বান্ডিলের জন্য বিপরীত প্রক্সি বা CDN এ দীর্ঘস্থায়ী ক্যাশিং সেট করে |
| HTML পৃষ্ঠাগুলি | অনুরোধ প্রতি রেন্ডার করা হয়েছে, কোন ক্যাশে নেই | [ISR](../rendering/isr.md) `revalidate = N` | সহ
| API ডক্স | | `useDocs = False` উৎপাদনে |
| রানটাইমে নোড | কোনোটিই | `nx build` ক্লায়েন্ট উপাদানগুলিকে প্রাক-রেন্ডার করে |

## মাপা

একটি স্থানীয় রান, একজন ইউভিকর্ন কর্মী, উইন্ডোজ, পাইথন 3.13, পাইথন লোড থেকে জীবিত সংযোগগুলি রাখুন
একই মেশিনে জেনারেটর। পরিবর্তনগুলি তুলনা করার জন্য সংখ্যাগুলিকে একটি বেসলাইন হিসাবে বিবেচনা করুন, a হিসাবে নয়
অন্যান্য কাঠামোর বিরুদ্ধে বেঞ্চমার্ক।

| রুট | সঙ্গতি | প্রতি সেকেন্ডে অনুরোধ | p50 | p99 |
|---|---|---|---|---|
| বেয়ার ফাস্টএপিআই JSON রুট | 16 | ~4,500 | 3.4 ms | 5.1 ms |
| Nexy JSON রুট (`src/routes/api/ping.py`) | 16 | ~2,900 | 5.2 ms | 9.8 ms |
| Nexy SSR পৃষ্ঠা (16 KB, 16 উপাদান) | 1 | ~500 | 1.9 ms | 3.0 ms |
| Nexy SSR পৃষ্ঠা (16 KB, 16 উপাদান) | 64 | ~670 | 94 ms | 126 ms |

টেবিল পড়া:

- Nexy-এর নিজস্ব স্তরগুলির (পথের প্রসঙ্গ, মিডলওয়্যার) একটি বেয়ারের থ্রুপুটের প্রায় এক তৃতীয়াংশ খরচ হয়
  ফাস্টএপিআই রুট।
- একটি সার্ভার-রেন্ডার করা পৃষ্ঠার জন্য প্রায় 2 ms CPU খরচ হয়, যা প্রায় 16টি টেমপ্লেট রেন্ডারে ছড়িয়ে পড়ে (প্রতিটি
  উপাদান)। কম উপাদান সহ পৃষ্ঠাগুলি আনুপাতিকভাবে সস্তা।
- শ্রমিকদের সাথে থ্রুপুট স্কেল। লিনাক্সে, `nx start` ইতিমধ্যেই প্রতি সিপিইউ একটি শুরু হয়।

## ব্যবহারিক পরামর্শ

1. Nginx, Caddy বা আপনার প্ল্যাটফর্মের প্রান্তকে সামনে রাখুন: TLS, HTTP/2, Brotli এবং এর জন্য দীর্ঘস্থায়ী ক্যাশিং
   `/__nexy__/client/` সম্পদ তাদের শক্তি। দেখুন [মোতায়েন](README.md)।
2. যে পৃষ্ঠাগুলি প্রতি মিনিটে একবারেরও কম পরিবর্তন হয় তাদের জন্য [ISR](../rendering/isr.md) ব্যবহার করুন।
3.  [দ্বীপগুলি](../rendering/islands.md) দিয়ে অলসভাবে হাইড্রেট করুন তাই প্রথম লোড কম জাভাস্ক্রিপ্ট পাঠায়।
4. প্রতি পৃষ্ঠায় `.nexy` উপাদানের সংখ্যা যুক্তিসঙ্গত রাখুন: প্রতিটি একটি পৃথক টেমপ্লেট
   রেন্ডার
5. আপনার নিজের রুট পরিমাপ করুন. একটি স্থানীয় লোড জেনারেটর যা সংযোগগুলিকে বাঁচিয়ে রাখে তুলনা করার জন্য যথেষ্ট
   একটি পৃষ্ঠার দুটি সংস্করণ।
