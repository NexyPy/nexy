# Nexy দিয়ে একটি নোট অ্যাপ তৈরি করুন, পার্ট 1: প্রোজেক্ট তৈরি করুন

টিউটোরিয়ালের পার্ট 1 প্রকল্পটি তৈরি করে যা আপনি একটি নোট অ্যাপে পরিণত হবেন এবং এটি প্রায় পাঁচ মিনিটের মধ্যে আপনার ব্রাউজারে চালান।

**আপনি শুরু করার আগে:** [uv](https://docs.astral.sh/uv/) এবং Node.js 20 বা নতুন। টিউটোরিয়ালটি মেনুর শীর্ষে নির্বাচিত রাউটার অনুসরণ করে: এটিকে সেখানে সুইচ করুন এবং প্রতিটি অংশ সেই রাউটারের ফাইলগুলি দেখায়।

## যা আপনি নির্মাণ করবেন

টিউটোরিয়ালের শেষে, অ্যাপটিতে নোট, একটি ডাটাবেস, অ্যাকাউন্ট, ইমেলের মাধ্যমে শেয়ার করা নোট, লাইভ আপডেট, পরীক্ষা এবং একটি প্রোডাকশন বিল্ডের জন্য পৃষ্ঠা এবং একটি JSON API রয়েছে। প্রতিটি অংশ একটি অ্যাপ দিয়ে শেষ হয় যা চলে, তাই আপনি তাদের যেকোনও পরে থামতে পারেন।

## প্রকল্প তৈরি করুন

```bash
uvx nexy new notes
```

এইভাবে প্রশ্নের উত্তর দিন:

| প্রশ্ন | উত্তর |
|---|---|
| ফাইল ভিত্তিক রাউটার? | ফাইল-ভিত্তিক এবং কাস্টম রাউটারগুলির জন্য `Yes`, মডুলারের জন্য `No` |
| প্রকল্পের ধরন | `Web` |
| ক্লায়েন্ট-সাইড রাউটিং | `No`: সার্ভার পেজ রেন্ডার করে |
| ক্লায়েন্ট ফ্রেমওয়ার্ক | `React`: এটি দ্বীপের জন্য ইউনিট 4 এ ফিরে আসে |
| শৈলী | `Tailwind CSS` |
| আমদানি উপনাম | `@` |
| ওআরএম | `No database`: অংশ 5 একটি যোগ করে |

## চালান

```bash
cd notes
source .venv/bin/activate    # Windows: .venv\Scripts\activate
nexy dev
```

খুলুন <http://localhost:3000>। আপনি স্বাগত পৃষ্ঠা দেখতে হবে. চলমান `nexy dev` ছেড়ে দিন: এখন থেকে, আপনার সংরক্ষণ করা প্রতিটি ফাইল ব্রাউজার পুনরায় লোড হবে।

## আপনি যা শিখেছেন

- `uvx nexy new` একটি প্রকল্প তৈরি করে এবং এর Python এবং JavaScript প্যাকেজ ইনস্টল করে।
- `nexy dev` এটি পরিবেশন করে এবং সংরক্ষণে পুনরায় লোড করে।

- পৃষ্ঠাগুলি বাস করে `src/routes/`: পরবর্তী অংশে একটি যোগ করা হয়েছে।
