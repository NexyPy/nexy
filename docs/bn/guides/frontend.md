# ফ্রন্টএন্ড

Nexy ক্লায়েন্টের জন্য নিজস্ব কম্পোনেন্ট সিস্টেম পাঠায় না। এটি ভিটে তৈরি করে: প্রতিক্রিয়া, ভিউ, স্বেল্ট,
সলিড এবং প্রেক্ট সবই সমর্থিত, এবং ভ্যানিলা পৃষ্ঠাগুলি কোনও ক্লায়েন্ট ফ্রেমওয়ার্ক ছাড়াই কাজ করে।

## একটি কাঠামো সক্ষম করুন৷

```python filename="nexyconfig.py"
from nexy.core.models import NexyConfigModel
from nexy.frontend import react


class NexyConfig(NexyConfigModel):
    useFF = react()   # vue(), svelte(), solid(), preact()
```

`useVite` ডিফল্ট `True`; একটি ফ্রেমওয়ার্ক কনফিগার করা হলে এটি চালু রাখুন।

## রুট ফাইল

| এক্সটেনশন | রেন্ডার করা হয়েছে |
|---|---|
অনুরোধের সময় নেক্সি দ্বারা | `.nexy`, `.md` | |
| `.mdx`, `.tsx`, `.jsx`, `.vue`, `.svelte` | ক্লায়েন্ট ফ্রেমওয়ার্ক দ্বারা; বিল্ড টাইমে এইচটিএমএল-এ প্রি-রেন্ডার করা হয়, তারপর ক্লায়েন্ট বান্ডিল দ্বারা নেওয়া হয় |

একটি ফ্রেমওয়ার্ক রুট একটি সাধারণ পৃষ্ঠা, একটি ক্লায়েন্ট-শুধু দ্বীপ নয়: বান্ডিল চালানোর আগে HTML বিদ্যমান,
তাই প্রথম পেইন্ট জাভাস্ক্রিপ্টের জন্য অপেক্ষা করে না।

প্রতি-ফ্রেমওয়ার্ক সেটআপ: [প্রতিক্রিয়া](../views/react/differences.md), [ভিউ](../views/vue/differences.md),
[Svelte](../views/svelte/differences.md), [সলিড](../views/solid/differences.md),
[প্র্যাক্ট](../views/preact/differences.md)।

## উন্নয়ন

`nx dev` একটি পোর্টে একটি সার্ভার শুরু করে:

1. অ্যাপটি আপনার পরিবর্তন করা রুট, সার্ভার এবং ক্লায়েন্টকে পুনরায় কম্পাইল করে;
2. Vite একটি অভ্যন্তরীণ পোর্টে চলে এবং ফ্রেমওয়ার্ক মডিউল পরিবেশন করে;
3. Nexy প্রক্সি Vite এর শেষ বিন্দু তার নিজস্ব উত্স মাধ্যমে.

ব্রাউজার শুধুমাত্র পোর্টের সাথে কথা বলে `3000`। খোলার জন্য কোন দ্বিতীয় URL নেই এবং কনফিগার করার জন্য কোন CORS নেই৷

## বিল্ড

`nx build` উত্পাদন করে:

-  ফ্রেমওয়ার্ক রুটের জন্য প্রাক-রেন্ডার করা HTML;
- ক্লায়েন্ট বান্ডিল, `__nexy__/client/` এর অধীনে সম্পদ সহ;
- সংকলিত পাইথন রুট।

Vite ক্লায়েন্ট বান্ডিল পরিচালনা করে; এসএসআর এইচটিএমএল প্রতি ফাইল esbuild দ্বারা উত্পাদিত হয়.

> [!নোট]
> একটি রুট যার সার্ভার রেন্ডার ব্যর্থ হয় তার পরিবর্তে একটি ক্লায়েন্ট-অনলি রুট হিসাবে রিপোর্ট করা হয়
> পুরো বিল্ড ব্যর্থ.

## স্টাইলিং

`nexy new` একটি স্টাইল মোডের জন্য জিজ্ঞাসা করে এবং আপনার বাছাই করা ক্লায়েন্ট ফ্রেমওয়ার্কের জন্য এটি সেট আপ করে: Tailwind,
UnoCSS বা প্লেইন CSS। ডিজাইন টোকেন (রঙ, ফন্ট, গাঢ় থিম) হল CSS ভেরিয়েবল
`src/globale.css`, স্ক্যাফোল্ড যে ফাইলটি তৈরি করে।

| মোড | স্টার্টার পৃষ্ঠাগুলি | দিয়ে লেখা হয়
|---|---|
| Tailwind, UnoCSS | মার্কআপে ইউটিলিটি ক্লাস, টোকেনগুলি ক্লাসের নামের সাথে ম্যাপ করা |
| প্লেইন CSS | শব্দার্থিক শ্রেণীর নাম এবং `src/globale.css` | এ CSS

আপনি একটি পৃষ্ঠা যোগ করার সময় আপনার প্রকল্পের মোড অনুসরণ করুন: একটি ইউটিলিটি প্রকল্পে ইউটিলিটি ক্লাস, একটিতে CSS
প্লেইন-সিএসএস এক। কম্পোনেন্ট সিএসএস রাখুন যা ইউটিলিটিগুলি কম্পোনেন্টের `<style>` ব্লকে প্রকাশ করতে পারে না।
একটি সার্ভার প্রকল্পে (`.nexy` পৃষ্ঠাগুলিতে) UnoCSS ক্লাসের জন্য `.nexy` ফাইলগুলি পড়ে; টেলউইন্ড তাদের খুঁজে বের করে
নিজে থেকে
