# আমি কিভাবে রেজিস্ট্রি থেকে একটি মডিউল ইনস্টল করব?

মডিউল রেজিস্ট্রি থেকে একটি রিলিজ ডাউনলোড করতে একটি Nexy প্রকল্পে `nx add @scope/name` চালান, এটি পরীক্ষা করুন এবং এর ঘোষিত পরিবর্তনগুলি প্রয়োগ করুন৷ একটি সঠিক সংস্করণ পিন করতে `@1.2.0` যোগ করুন।

## একটি মডিউল ইনস্টল করুন

একটি Nexy প্রকল্পের মূল থেকে:

```bash
nx add @acme/auth
nx add @acme/auth@1.2.0
```

`nx add` রিলিজ মেটাডেটা পড়ে এবং `useModuleRegistry` থেকে আর্কাইভ করে, SHA-256 চেকসাম চেক করে এবং মডিউলের `nexy` এবং `python` সামঞ্জস্যের রেঞ্জ চেক করে। এটি তারপর শুধুমাত্র ম্যানিফেস্ট ঘোষণা করা ফাইলগুলি লিখে, `uv add` এর সাথে ঘোষিত Python প্যাকেজ যোগ করে, প্রকল্পের প্যাকেজ ম্যানেজারের সাথে নোড প্যাকেজ যোগ করে এবং `nexyconfig.py` এবং `package.json`-এ কনফিগার হুকগুলি প্রয়োগ করে। বিদ্যমান সেটিংস এবং ফাইলগুলি যেমন আছে তেমনই থাকে: একটি ঘোষিত ফাইল যা ইতিমধ্যেই বিদ্যমান একটি `warning:` লাইন দিয়ে এড়িয়ে যায়।

প্রতিটি সফল ইনস্টল `.nexy/modules.json` এ রেকর্ড করা হয়। সেই ফাইলটি কমিট করুন যাতে একজন সতীর্থ একই মডিউল সংস্করণ পায়।

## একটি মডিউল আপগ্রেড করুন

আপগ্রেড করতে, রেজিস্ট্রিটি একটি নতুন রিলিজ হওয়ার পরে আবার `nx add @acme/auth` চালান, অথবা একটি নতুন পিন সেট করুন যেমন `@acme/auth@1.3.0`। একটি আনপিন করা নাম রেজিস্ট্রির `/versions` প্রতিক্রিয়া থেকে নতুন সংস্করণ নির্বাচন করে। একই সংস্করণ চালানো আবার মুদ্রণ `is already installed` এবং কিছুই পরিবর্তন করে না।

## একটি সংস্করণ পিন করুন

একটি পিন সঠিক: `nx add @acme/auth@1.2.0` ইনস্টল করে `1.2.0` এবং অন্য কোনো রিলিজ নেই। CI তে একটি পিন ব্যবহার করুন এবং একটি প্রতিশ্রুতিবদ্ধ `.nexy/modules.json` যাতে প্রতিটি চেকআউট একই কোড ইনস্টল করে। একটি পিন ছাড়াই, একটি নতুন রিলিজ পরবর্তী ইনস্টলে পরিবর্তন করে।

## মাইগ্রেশন চালান

মাইগ্রেশন ডিফল্টরূপে বন্ধ। আপনি যখন রিলিজের ঘোষিত কমান্ডগুলিকে ফাইল এবং নির্ভরতা স্থানান্তরিত করার পরে চালাতে চান তখন `--migrate` যোগ করুন:

```bash
nx add @acme/auth@1.2.0 --migrate
```

প্রতিটি কমান্ড চালানোর আগে প্রিন্ট করা হয়। একটি মডিউল ঘোষণা করার আগে প্রকল্পটির মাইগ্রেশন টুল ইনস্টল করা প্রয়োজন।

## রেজিস্ট্রি এবং এর ট্রাস্ট নিয়ম সেট করুন

ডিফল্টগুলি এখানে থাকে `nexyconfig.py`:

```python filename="nexyconfig.py"
class NexyConfig(NexyConfigModel):
    useModuleRegistry = "https://registry.nexypy.dev"
    useRequireSignedModules = False
```

`useModuleRegistry` হল বেস ইউআরএল যা CLI পড়ে। বিকাশের সময় স্থানীয় রেজিস্ট্রির জন্য লুপব্যাক http ব্যতীত শুধুমাত্র https URL গুলিই গ্রহণ করা হয়৷ `useRequireSignedModules = True` স্বাক্ষরবিহীন রিলিজ প্রত্যাখ্যান করে। একটি স্বাক্ষর বহনকারী একটি রিলিজ একটি যাচাইকারী উপলব্ধ না হওয়া পর্যন্ত প্রত্যাখ্যান করা হয়; একবার এটি যাচাই করার পরে, স্বাক্ষরকারীর পরিচয় সহ `nx add` প্রিন্ট করে `Verified by`। আপনি বিশ্বাস করেন শুধুমাত্র রেজিস্ট্রিগুলির জন্য ডিফল্ট `False` রাখুন।
