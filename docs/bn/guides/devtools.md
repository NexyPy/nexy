# দেব টুলবার

`nexy dev` প্রতিটি HTML পৃষ্ঠায় একটি টুলবার যোগ করে। এটি নীচে-বাম কোণায় বসে, আপনি যে রুটে আছেন এবং সার্ভারটি কতক্ষণ নিয়েছে তা দেখায় এবং একটি প্যানেলে খোলে৷ এটি একটি উত্পাদন প্রতিক্রিয়া অংশ না.

| ট্যাব | দেখায় |
|---|---|
| পৃষ্ঠা | URL, রুট, হ্যান্ডলার, এটি যে ফাইল থেকে এসেছে (একটি লিঙ্ক সহ যা এটি আপনার সম্পাদকে খোলে), অবস্থা, সার্ভারের সময়, প্রথম বাইট, প্রথম পেইন্ট, প্রধান বিষয়বস্তু, লেআউট শিফট (গ্রেডেড সবুজ, অ্যাম্বার বা লাল), DOM প্রস্তুত |
| রুটগুলি | অ্যাপের প্রতিটি রুট এর পদ্ধতি, একটি ফিল্টার এবং বর্তমান একটি চিহ্নিত; প্রতিটি তার ফাইলের সাথে লিঙ্ক করে |
| ত্রুটি | সার্ভারের ত্রুটি `nexy dev` শুরু হওয়ার পর থেকে এবং ব্রাউজার যে ত্রুটিগুলি উত্থাপন করেছে |
| সেটিংস | থিম (পৃষ্ঠার সাথে মেলে, অন্ধকার বা হালকা), অবস্থান, আকার, লুকান, পুনরায় সেট করুন |

## এটা সরান

বোতামটি টেনে আনুন: এটি পয়েন্টার অনুসরণ করে এবং আপনি যেতে দিলে নিকটতম কোণে স্ন্যাপ করে। বোতামটি যেখানেই থাকুক না কেন প্যানেলটি পর্দার মাঝখানে খোলে। এই ব্রাউজারে পজিশন রাখা হয়। এছাড়াও আপনি **সেটিংস** থেকে একটি কোণা বাছাই করতে পারেন।

`Shift` + `Alt` + `D` লুকিয়ে টুলবার দেখায়। `Esc` প্যানেল বন্ধ করে দেয়।

## ত্রুটি

ব্রাউজারে ধরা না পড়া ত্রুটি বার্তা এবং স্ট্যাকের সাথে পৃষ্ঠায় একটি ডায়ালগ খোলে; বেশ কয়েকটি ত্রুটি সহ, সেগুলি দিয়ে ধাপ করুন (3 এর মধ্যে 1)। একটি সার্ভার ত্রুটি একই ধরণের একটি পৃষ্ঠার সাথে উত্তর দেয়: ত্রুটি, যেখানে এটি উত্থাপিত হয়েছিল এবং এর চারপাশে কোড৷

## এটি বন্ধ করুন

```python filename="nexyconfig.py"
class NexyConfig(NexyConfigModel):
    useDevTools = False
```

টুলবার হল একটি স্টাইল ব্লক এবং একটি স্ক্রিপ্ট যা `</body>` এর আগে যোগ করা হয়েছে: কোনো বাহ্যিক অনুরোধ নেই, কোনো নির্ভরতা নেই। JSON, ফাইল এবং এইচটিএমএল নয় এমন প্রতিটি প্রতিক্রিয়া একা রেখে দেওয়া হয়।
