# দেব টুলবার

`nexy dev` প্রতিটি HTML পৃষ্ঠায় একটি টুলবার যোগ করে। এটি নীচে-বাম কোণায় বসে, আপনাকে যে রুটটি দেখায়
চালু আছে এবং সার্ভারটি কতক্ষণ নিয়েছে এবং একটি প্যানেলে খোলে। এটি কখনই উৎপাদনের অংশ নয়
প্রতিক্রিয়া

| ট্যাব | দেখায় |
|---|---|
| পৃষ্ঠা | URL, রুট, হ্যান্ডলার, এটি যে ফাইল থেকে এসেছে (একটি লিঙ্ক যা এটি আপনার সম্পাদকে খোলে), অবস্থা, সার্ভারের সময়, প্রথম বাইট, প্রথম রঙ, প্রধান বিষয়বস্তু, লেআউট শিফট (গ্রেডেড সবুজ, অ্যাম্বার বা লাল), DOM প্রস্তুত |
| রুটগুলি | অ্যাপের প্রতিটি রুট এর পদ্ধতি, একটি ফিল্টার এবং বর্তমান একটি চিহ্নিত; প্রতিটি তার ফাইলের সাথে লিঙ্ক করে |
| ত্রুটি | সার্ভারের ত্রুটি `nexy dev` শুরু হওয়ার পর থেকে এবং ব্রাউজার যে ত্রুটিগুলি উত্থাপন করেছে |
| সেটিংস | থিম (পৃষ্ঠার সাথে মিল করুন, অন্ধকার বা হালকা), অবস্থান, আকার, লুকান, পুনরায় সেট করুন |

## এটি সরান

বোতামটি টেনে আনুন: এটি পয়েন্টার অনুসরণ করে এবং আপনি যেতে দিলে নিকটতম কোণে স্ন্যাপ করে। প্যানেল
বোতামটি যেখানেই হোক না কেন পর্দার মাঝখানের দিকে খোলে। এতে পদ রাখা হয়
ব্রাউজার এছাড়াও আপনি **সেটিংস** থেকে একটি কোণা বাছাই করতে পারেন।

`Shift` + `Alt` + `D` লুকিয়ে টুলবার দেখায়। `Esc` প্যানেল বন্ধ করে দেয়।

## ত্রুটি

ব্রাউজারে ধরা না পড়া ত্রুটি বার্তা এবং স্ট্যাকের সাথে পৃষ্ঠায় একটি ডায়ালগ খোলে; সঙ্গে
বেশ কয়েকটি ত্রুটি, সেগুলির মাধ্যমে ধাপে ধাপে (3টির মধ্যে 1)। একটি সার্ভার ত্রুটি একই ধরনের একটি পৃষ্ঠার সাথে উত্তর দেয়:
ত্রুটি, যেখানে এটি উত্থাপিত হয়েছিল এবং এর চারপাশের কোড।

## এটি বন্ধ করুন

```python filename="nexyconfig.py"
class NexyConfig(NexyConfigModel):
    useDevTools = False
```

টুলবার হল একটি স্টাইল ব্লক এবং `</body>` এর আগে যোগ করা একটি স্ক্রিপ্ট: কোনো বহিরাগত অনুরোধ নেই, না
নির্ভরতা JSON, ফাইল এবং এইচটিএমএল নয় এমন প্রতিটি প্রতিক্রিয়া একা রেখে দেওয়া হয়।
