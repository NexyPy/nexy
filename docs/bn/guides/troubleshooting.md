# সমস্যা সমাধান

আপনি কি দেখতে এবং কি করতে হবে তা দিয়ে মানুষ প্রথমে যে সমস্যাগুলিকে আঘাত করে। প্রতিটি এক একটি বাস্তব রান থেকে আসে.

## একটি পৃষ্ঠা 404 উত্তর দেয় কিন্তু এর ফাইলটি বিদ্যমান

টার্মিনালটি দেখুন যা `nx dev` বা `nx start` চলে। যখন একটি পৃষ্ঠা আমদানি করা যায় না, Nexy তার ফাইল এবং লাইন সহ ত্রুটি রিপোর্ট করে এবং রুটটি নিবন্ধিত হয় না:

```text
nexy » error __nexy__/src/routes/index.py:18  ImportError: cannot import name 'FrameworkLogo' ...
```

সেখানে নামযুক্ত আমদানি ঠিক করুন। সাধারণ কারণগুলি হল একটি উপাদান যার ফাংশনের নাম আপনি যা আমদানি করেন তার সাথে মেলে না (পরবর্তী আইটেমটি দেখুন) এবং পথের একটি টাইপো।

## একটি `.nexy` পৃষ্ঠা কম্পাইল করে না: "লজিক পার্স ত্রুটি"

```text
src/components/live-panel.nexy - Logic Parse Error: invalid syntax
```

একটি `.nexy` উপাদান একটি Python মডিউল হিসাবে আমদানি করা হয়, তাই এর ফাইলের নাম অবশ্যই একটি বৈধ নাম হতে হবে। একটি হাইফেন নয়। এটিকে PascalCase এ নাম দিন, `LivePanel.nexy`, এবং একই নামে এটি আমদানি করুন:

```nexy
from "@/components/LivePanel.nexy" import LivePanel
```

## একটি উপাদান তার শিশুদের পাঠ্য হিসাবে রেন্ডার করে `<slot />`

একটি `.nexy` উপাদানটি তার শিশুদেরকে `<Slot />`, একটি বড় হাতের S দিয়ে রাখে। একটি ছোট হাতের অক্ষর `<slot />` পৃষ্ঠায় যেমন আছে তেমনই রেখে দেওয়া হয়। Vue, যার নিজস্ব `<slot />` আছে, প্রভাবিত হয় না।

## একটি প্রপ ভেরিয়েবলের নাম দেখায়

```nexy
<Icon path=icon />          renders: icon
<Icon path="{{ icon }}" />  renders: the value of icon
```

কোন ধনুর্বন্ধনী ছাড়া একটি বৈশিষ্ট্য পাঠ্য. একটি গণনা করা মান পাস করার জন্য অ্যাট্রিবিউটে Jinja এক্সপ্রেশনটি রাখুন।

## `{{ ... }}` এ একটি মান খালি রেন্ডার করে

Jinja2 একটি অনির্ধারিত পরিবর্তনশীল লুকিয়ে রাখে। আপনি ফ্রন্টম্যাটারে (`title: prop[str] = ""`) ব্যবহার করেন এমন প্রতিটি সম্পত্তি ঘোষণা করুন এবং বানান পরীক্ষা করুন।

## একটি `.nexy` পৃষ্ঠায় ইউটিলিটি ক্লাসের কোনো প্রভাব নেই (UnoCSS)

UnoCSS একটি ফাইল তখনই পড়ে যখন এর এক্সটেনশন তার বিষয়বস্তু পাইপলাইনে থাকে। `nx new` দ্বারা তৈরি করা একটি সার্ভার প্রকল্প UnoCSS ইতিমধ্যেই তালিকা `.nexy`; একজন বয়স্ক ব্যক্তির এটির প্রয়োজন `uno.config.ts`:

```ts
content: {
  filesystem: ['src/**/*.nexy'],
  pipeline: { include: [/\.(vue|svelte|[jt]sx|mdx?|astro|html|nexy)($|\?)/] },
},
```

Tailwind নিজে থেকেই `.nexy` ফাইল খুঁজে পায়।

## একটি `.mdx` পৃষ্ঠা প্যাকেজগুলির জন্য জিজ্ঞাসা করে

```text
[nexy] MDX support requires optional packages that are not installed.
```

এগুলিকে প্রকল্পে ইনস্টল করুন: `@mdx-js/rollup`, `remark-gfm` এবং `@mdx-js/react` (প্লাস `@mdx-js/esbuild` এর জন্য `nx build`)। MDX প্রয়োজন React বা Preact `useFF` এ। একটি ক্লায়েন্ট ফ্রেমওয়ার্ক ছাড়া, পৃষ্ঠাটি `.md` হিসাবে লিখুন। [Markdown এবং MDX](../views/nexy/markdown.md) দেখুন।

## `No module named 'sqlmodel'` (বা যেকোনো প্যাকেজ) যখন একটি কমান্ড শুরু হয়

```text
nexy » nexyconfig.py cannot be loaded: No module named 'sqlmodel'. If it is a package, install it
in this Python (...) or activate the project's virtual environment.
```

আদেশ ভুল Python দৌড়ে. আপনার প্রোজেক্টের প্যাকেজগুলি (আপনার ORM, আপনার লাইব্রেরিগুলি) তার `.venv`, এবং `uvx nexy` বা একটি বিশ্বব্যাপী `nexy` নিজস্ব পরিবেশে চলে যার কোনোটিই নেই।

প্রকল্প ফোল্ডার থেকে প্রকল্পের ভার্চুয়াল পরিবেশ সক্রিয় করুন, তারপর আবার কমান্ড চালান:

```bash
.venv\Scripts\activate    # Windows; on macOS and Linux: source .venv/bin/activate
nexy dev
```

প্রম্পটটি `(.venv)` দিয়ে শুরু হয় যখন এটি সক্রিয় থাকে। অথবা `uv run nexy dev` দিয়ে অ্যাক্টিভেশনটি এড়িয়ে যান। যদি প্যাকেজটি সত্যিই প্রকল্প থেকে অনুপস্থিত থাকে তবে এটি `uv add sqlmodel` এর সাথে যোগ করুন।

## `nx dev` একটি ত্রুটি দেখায় এবং অপেক্ষা করে

যখন আপনার আবেদন শুরু হতে পারে না, `nx dev` কেন রিপোর্ট করে এবং পরবর্তী ফাইল পরিবর্তনের জন্য অপেক্ষা করে; এটা প্রস্থান না. ফাইলটি ঠিক করুন এবং সংরক্ষণ করুন। শুধুমাত্র Ctrl+C এটি বন্ধ করে।

## বন্দর ব্যস্ত

`nx dev` পরবর্তী মুক্ত পোর্ট নেয় এবং এটি মুদ্রণ করে। একটি বেছে নিতে, `--port` ব্যবহার করুন বা `nexyconfig.py` এ `usePort` সেট করুন।

## থিম একটি অন্ধকার পৃষ্ঠায় সাদা ঝলকানি

সংরক্ষিত থিম প্রথম পেইন্ট আগে প্রয়োগ করা আবশ্যক. স্টার্টারের ছোট স্ক্রিপ্টটি রুট লেআউটের `<head>` এ রাখুন এবং React এ `<html>` এর উপর `suppressHydrationWarning` রাখুন।
