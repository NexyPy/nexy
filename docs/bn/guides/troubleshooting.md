# সমস্যা নিবারণ

আপনি কি দেখতে এবং কি করতে হবে তা দিয়ে মানুষ প্রথমে যে সমস্যাগুলিকে আঘাত করে। প্রতিটি এক একটি বাস্তব রান থেকে আসে.

## একটি পৃষ্ঠা 404 উত্তর দেয় কিন্তু এর ফাইল বিদ্যমান

টার্মিনালটি দেখুন যা `nx dev` বা `nx start` চলে। যখন একটি পৃষ্ঠা আমদানি করা যায় না, Nexy রিপোর্ট করে
এর ফাইল এবং লাইনের সাথে ত্রুটি, এবং রুটটি নিবন্ধিত নয়:

```text
nexy » error __nexy__/src/routes/index.py:18  ImportError: cannot import name 'FrameworkLogo' ...
```

সেখানে নামযুক্ত আমদানি ঠিক করুন। স্বাভাবিক কারণ হল একটি উপাদান যার ফাংশনের নাম মেলে না
আপনি কি আমদানি করেন (পরবর্তী আইটেমটি দেখুন) এবং পথে একটি টাইপো।

## একটি `.nexy` পৃষ্ঠা কম্পাইল করে না: "লজিক পার্স ত্রুটি"

```text
src/components/live-panel.nexy - Logic Parse Error: invalid syntax
```

একটি `.nexy` উপাদান একটি পাইথন মডিউল হিসাবে আমদানি করা হয়, তাই এর ফাইলের নাম অবশ্যই একটি বৈধ নাম হতে হবে। একটি হাইফেন
হয় না এটিকে PascalCase এ নাম দিন, `LivePanel.nexy`, এবং একই নামে এটি আমদানি করুন:

```nexy
from "@/components/LivePanel.nexy" import LivePanel
```

## একটি উপাদান তার সন্তানদের পাঠ্য হিসাবে রেন্ডার করে `<slot />`

একটি `.nexy` উপাদান তার শিশুদেরকে `<Slot />` দিয়ে রাখে, একটি ক্যাপিটাল S দিয়ে। একটি ছোট হাতের অক্ষর `<slot />` হল
এটি যেমন আছে পৃষ্ঠায় বাম। Vue, যার নিজস্ব `<slot />` আছে, প্রভাবিত হয় না।

## একটি প্রপ ভেরিয়েবলের নাম দেখায়

```nexy
<Icon path=icon />          renders: icon
<Icon path="{{ icon }}" />  renders: the value of icon
```

কোন ধনুর্বন্ধনী ছাড়া একটি বৈশিষ্ট্য পাঠ্য. একটি গণনা পাস করার জন্য অ্যাট্রিবিউটে জিনজা এক্সপ্রেশনটি রাখুন
মান

## একটি মান `{{ ... }}` খালি রেন্ডার করে

Jinja2 একটি অনির্ধারিত পরিবর্তনশীল লুকিয়ে রাখে। আপনি ফ্রন্ট ম্যাটারে ব্যবহার করেন এমন প্রতিটি সম্পত্তি ঘোষণা করুন
(`title: prop[str] = ""`), এবং বানান পরীক্ষা করুন।

##  একটি `.nexy` পৃষ্ঠায় ইউটিলিটি ক্লাসের কোনো প্রভাব নেই (UnoCSS)

UnoCSS একটি ফাইল তখনই পড়ে যখন এর এক্সটেনশন তার সামগ্রী পাইপলাইনে থাকে। একটি সার্ভার প্রকল্প তৈরি করা হয়েছে
দ্বারা `nx new` ইতিমধ্যেই UnoCSS তালিকা `.nexy`; একজন বয়স্ক ব্যক্তির এটির প্রয়োজন `uno.config.ts`:

```ts
content: {
  filesystem: ['src/**/*.nexy'],
  pipeline: { include: [/\.(vue|svelte|[jt]sx|mdx?|astro|html|nexy)($|\?)/] },
},
```

টেলউইন্ড নিজে থেকেই `.nexy` ফাইল খুঁজে বের করে।

## একটি `.mdx` পৃষ্ঠা প্যাকেজের জন্য জিজ্ঞাসা করে

```text
[nexy] MDX support requires optional packages that are not installed.
```

এগুলিকে প্রকল্পে ইনস্টল করুন: `@mdx-js/rollup`, `remark-gfm` এবং `@mdx-js/react` (প্লাস
`@mdx-js/esbuild` জন্য `nx build`)। MDX-এর `useFF` মধ্যে প্রতিক্রিয়া বা প্রেক্ট প্রয়োজন। ক্লায়েন্ট ফ্রেমওয়ার্ক ছাড়া,
পৃষ্ঠাটিকে `.md` হিসাবে লিখুন। [মার্কডাউন এবং MDX](../views/nexy/markdown.md) দেখুন।

## `No module named 'sqlmodel'` (বা যেকোনো প্যাকেজ) যখন একটি কমান্ড শুরু হয়

```text
nexy » nexyconfig.py cannot be loaded: No module named 'sqlmodel'. If it is a package, install it
in this Python (...) or activate the project's virtual environment.
```

কমান্ডটি ভুল পাইথনে চলেছিল। আপনার প্রকল্পের প্যাকেজ (আপনার ORM, আপনার লাইব্রেরি) আছে
এটি `.venv`, এবং `uvx nexy` বা একটি বিশ্বব্যাপী `nexy` চলে তার নিজস্ব পরিবেশে যার কোনোটি নেই
তাদের

প্রকল্প ফোল্ডার থেকে প্রকল্পের ভার্চুয়াল পরিবেশ সক্রিয় করুন, তারপর আবার কমান্ড চালান:

```bash
.venv\Scripts\activate    # Windows; on macOS and Linux: source .venv/bin/activate
nexy dev
```

যখন এটি সক্রিয় থাকে তখন প্রম্পটটি `(.venv)` দিয়ে শুরু হয়। অথবা এর সাথে সক্রিয়করণটি এড়িয়ে যান
`uv run nexy dev`। যদি প্যাকেজটি সত্যিই প্রকল্প থেকে অনুপস্থিত থাকে তবে এটি `uv add sqlmodel` এর সাথে যোগ করুন।

## `nx dev` একটি ত্রুটি দেখায় এবং অপেক্ষা করে

যখন আপনার আবেদন শুরু হতে পারে না, `nx dev` কেন রিপোর্ট করে এবং পরবর্তী ফাইল পরিবর্তনের জন্য অপেক্ষা করে; এটা করে
প্রস্থান না ফাইলটি ঠিক করুন এবং সংরক্ষণ করুন। শুধুমাত্র Ctrl+C এটি বন্ধ করে।

## বন্দরটি ব্যস্ত

`nx dev` পরবর্তী ফ্রি পোর্ট নেয় এবং এটি মুদ্রণ করে। একটি বেছে নিতে, `--port` ব্যবহার করুন বা `usePort` ইন সেট করুন
`nexyconfig.py`।

## থিমটি একটি অন্ধকার পৃষ্ঠায় সাদা হয়ে যায়

সংরক্ষিত থিম প্রথম পেইন্ট আগে প্রয়োগ করা আবশ্যক. স্টার্টারের ছোট স্ক্রিপ্টটি রাখুন
রুট লেআউটের `<head>`, এবং `suppressHydrationWarning`কে `<html>` রিঅ্যাক্টে রাখুন।
