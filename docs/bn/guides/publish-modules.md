# আমি কিভাবে Nexy রেজিস্ট্রিতে একটি মডিউল প্রকাশ করব?

একটি বৈধ `nx.toml`, একটি রেজিস্ট্রি টোকেন এবং ম্যানিফেস্ট ঘোষণা করা প্রতিটি ফাইল সহ একটি মডিউল ডিরেক্টরি থেকে `nx publish` চালান; কমান্ডটি রিলিজ পরীক্ষা করে, একটি সংরক্ষণাগার তৈরি করে এবং একটি অপরিবর্তনীয় সংস্করণ আপলোড করে।

## ম্যানিফেস্ট প্রস্তুত করুন

একটি উৎস মডিউল এটি পাঠানো প্রতিটি ফাইলের তালিকা করে। আর্কাইভ `nx.toml` এবং ঠিক সেই ফাইলগুলিকে ধারণ করে।

```toml filename="nx.toml"
name = "@acme/auth"
version = "1.2.0"
kind = "source"

[compatibility]
nexy = ">=2.0.0"
python = ">=3.12"

[dependencies]
python = []
node = []

[source]
files = ["src/auth.py", "src/helpers.py"]
```

`name` ক্ষেত্রটি অবশ্যই ছোট হাতের `@scope/name` হতে হবে। `version` ক্ষেত্রটি অবশ্যই বিন্দু দ্বারা পৃথক করা তিনটি সংখ্যা হতে হবে। ফাইলগুলি অবশ্যই মডিউলের মধ্যে আপেক্ষিক পাথ হতে হবে। একটি প্যাকেজ মডিউল `source.files` এর পরিবর্তে `source.package` ঘোষণা করে।

## আপলোড করার আগে চেক করুন

ম্যানিফেস্ট যাচাই করতে `--dry-run` ব্যবহার করুন, ঘোষিত ফাইল সংরক্ষণ করুন এবং আপলোড না করেই চেকসাম প্রিন্ট করুন:

```bash
nx publish --dry-run
```

একটি শুষ্ক রান একটি টোকেন প্রয়োজন হয় না. এটি প্রতিটি আপেক্ষিক আমদানির জন্য একটি `warning:` লাইন প্রিন্ট করে যা ম্যানিফেস্ট ঘোষণা করে না এমন একটি ফাইলের দিকে নির্দেশ করে। উদাহরণস্বরূপ, `from .helpers import token` `src/auth.py` এর মধ্যে `src/helpers.py` `source.files` প্রয়োজন, অন্যথায় একটি ইনস্টল একটি ভাঙা আমদানি পাবে।

## টোকেন সেট করুন

`nx publish` পড়ে `NEXY_REGISTRY_TOKEN`, তারপর `~/.config/nexy/registry-token`। টোকেনটি `Authorization` শিরোনামে পাঠানো হয় এবং মুদ্রিত হয় না।

```bash
export NEXY_REGISTRY_TOKEN="your-token"
nx publish
```

টোকেন ফাইলটি ভবিষ্যতে `nx login` একই শংসাপত্র লিখতে দেয়। কোনো উৎস ছাড়াই, কমান্ডটি প্রিন্ট করে `error: No registry token` এবং স্ট্যাটাস 1 দিয়ে প্রস্থান করে।

## প্রকাশ করুন

```bash
nx publish
```

কমান্ডটি প্রকাশিত রিলিজের নাম, সংস্করণ এবং SHA-256 চেকসাম প্রিন্ট করে। একটি নাম এবং সংস্করণ জোড়া অপরিবর্তনীয়: এটি আবার প্রকাশ করা একটি দ্বন্দ্ব ত্রুটি মুদ্রণ করে। পরিবর্তে একটি নতুন সংস্করণ প্রকাশ করুন.

## অন্য রেজিস্ট্রি ব্যবহার করুন

ডিফল্টরূপে কমান্ড পোস্ট করে `https://registry.nexypy.dev`। অন্য রেজিস্ট্রির জন্য `--registry` ব্যবহার করুন, উদাহরণস্বরূপ বিকাশের সময় একটি স্থানীয়:

```bash
nx publish --registry http://localhost:8000
```

শুধুমাত্র https URL গুলি গ্রহণ করা হয়, প্লাস http তে `localhost`, `127.0.0.1` এবং `::1`। ক্ষণস্থায়ী `429` এবং `5xx` উত্তর দুবার পুনরায় চেষ্টা করা হয়; একটি খারাপ ম্যানিফেস্ট, একটি অনুপস্থিত টোকেন বা একটি দ্বন্দ্ব পুনরায় চেষ্টা করা হয় না।

## রিলিজ যাচাই করুন

```bash
nx add @acme/auth@1.2.0
```

আপগ্রেড, পিন এবং ট্রাস্ট সেটিংসের জন্য [মডিউল ইনস্টল করুন](install-modules.md) দেখুন।
