# আন্তর্জাতিককরণ (i18n)

Nexy আপনার আবেদন অনুবাদ করে না. এটির কোন লোকেল মিডলওয়্যার নেই, কোন `trans` সাহায্যকারী নেই এবং নেই
লোকেল ফাইল: একটি অ্যাপ্লিকেশন i18n লাইব্রেরি বেছে নেয় যা এটির জন্য উপযুক্ত, কারণ এটি একটি ORM বাছাই করে।

কমান্ড লাইন (`nx`) অনুবাদ করা হয়; [CLI](../reference/cli.md) দেখুন।

## একজন হ্যান্ডলারে

একজন হ্যান্ডলার অনুরোধ থেকে যা প্রয়োজন তা পড়ে। এই এক এর ভাষায় উত্তর
`Accept-Language` শিরোনাম:

```python filename="src/routes/hello.py"
from nexy.http import Header

MESSAGES = {"en": "Hello", "fr": "Bonjour"}


async def GET(accept_language: str = Header("en")):
    language = accept_language.split(",")[0].split("-")[0].lower()
    return {"message": MESSAGES.get(language, MESSAGES["en"])}
```

## একটি পৃষ্ঠায়

ক্লায়েন্ট-রাউটেড পৃষ্ঠাগুলির জন্য আপনার ফ্রন্টএন্ডের লাইব্রেরি ব্যবহার করুন (উদাহরণস্বরূপ `i18next`, `vue-i18n` বা একটি
Svelte স্টোর), এবং আপনার পাইথন লাইব্রেরি (`gettext` স্ট্যান্ডার্ড লাইব্রেরি থেকে, বা ব্যাবেল) `.nexy` এর জন্য
পৃষ্ঠাগুলি রুট লেআউটে `<html lang>` সেট করুন।
