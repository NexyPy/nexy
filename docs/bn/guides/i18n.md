# আন্তর্জাতিকীকরণ (i18n)

Nexy আপনার আবেদন অনুবাদ করে না. এতে কোনো লোকেল মিডলওয়্যার নেই, কোনো `trans` সাহায্যকারী নেই এবং কোনো লোকেল ফাইল নেই: একটি অ্যাপ্লিকেশন i18n লাইব্রেরি বেছে নেয় যা এটির জন্য উপযুক্ত, কারণ এটি একটি ORM বেছে নেয়।

কমান্ড লাইন (`nx`) অনুবাদ করা হয়; [CLI](../reference/cli.md) দেখুন।

## একটি হ্যান্ডলার মধ্যে

একজন হ্যান্ডলার অনুরোধ থেকে যা প্রয়োজন তা পড়ে। এটি `Accept-Language` শিরোনামের ভাষায় উত্তর দেয়:

```python filename="src/routes/hello.py"
from nexy.http import Header

MESSAGES = {"en": "Hello", "fr": "Bonjour"}


async def GET(accept_language: str = Header("en")):
    language = accept_language.split(",")[0].split("-")[0].lower()
    return {"message": MESSAGES.get(language, MESSAGES["en"])}
```

## একটি পাতায়

ক্লায়েন্ট-রুটেড পৃষ্ঠাগুলির জন্য আপনার ফ্রন্টএন্ডের লাইব্রেরি ব্যবহার করুন (উদাহরণস্বরূপ `i18next`, `vue-i18n` বা একটি Svelte স্টোর), এবং `.nexy` পৃষ্ঠাগুলির জন্য আপনার Python লাইব্রেরি (`gettext` স্ট্যান্ডার্ড লাইব্রেরি থেকে, বা বেবেল)। রুট লেআউটে `<html lang>` সেট করুন।
