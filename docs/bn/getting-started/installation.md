# ইনস্টলেশন

## প্রয়োজনীয়তা

| প্রয়োজনীয়তা | কেন |
|---|---|
| পাইথন 3.12+ | `requires-python` `pyproject.toml` | এ
| [uv](https://docs.astral.sh/uv/) | প্রকল্প তৈরি করে, এর প্যাকেজ ইনস্টল করে এবং Nexy চালায় |
| Node.js 18+ | শুধুমাত্র একটি ক্লায়েন্ট ফ্রেমওয়ার্কের জন্য (React, Vue, Svelte, Solid, Preact) |

একটি ক্লায়েন্ট ফ্রেমওয়ার্ক ছাড়া একটি প্রকল্পের কোন Node.js প্রয়োজন নেই।

## প্রথমে ইউভি ইনস্টল করুন

`uvx` একটি পৃথক টুল নয়: এটি ইউভির সাথে আসে, তাই অন্য কিছুর আগে ইউভি ইনস্টল করুন।

```bash
# macOS and Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

এটি `uv --version` এবং `uvx --version` দিয়ে পরীক্ষা করুন।

## একটি প্রকল্প তৈরি করুন

```bash
uvx nexy new my-app
```

`uvx` একটি অস্থায়ী পরিবেশে Nexy চালায় এবং কিছুই ছেড়ে যায় না। এটি **সৃষ্টি করার** জন্য যথেষ্ট
প্রকল্প (`new`, `init`) এবং আর কিছুই নয়: অস্থায়ী পরিবেশ নেক্সিকে ধরে রাখে এবং অন্য কোনো
প্যাকেজ `nexy new` প্রকল্পের নিজস্ব ভার্চুয়াল পরিবেশ তৈরি করে, `.venv`, এবং এর প্যাকেজগুলি ইনস্টল করে
সেখানে

`nexy new my-app` চারটি প্রশ্ন জিজ্ঞাসা করে: রাউটার (ফাইল-ভিত্তিক বা মডুলার), প্রকল্পের ধরন (ওয়েব বা API),
ক্লায়েন্ট ফ্রেমওয়ার্ক, ORM। পাইথন এবং নোড নির্ভরতার ইনস্টলেশন তারপর প্রতি এক লাইনের সাথে চলে
পদক্ষেপ এবং এর সময়কাল। দেখুন [CLI](../reference/cli.md)।

একটি নিবন্ধিত টেমপ্লেট সহ প্রম্পটগুলি এড়িয়ে যান:

```bash
uvx nexy new my-app --template <name>
```

## প্রজেক্টের ভার্চুয়াল পরিবেশের ভিতরে কাজ করুন

অন্য প্রতিটি কমান্ড (`nexy dev`, `nexy build`, `nexy migrate`...) অবশ্যই প্রজেক্টের ভিতরে **চালনা করবে
ভার্চুয়াল পরিবেশ **। সেখানেই আপনার নিজস্ব প্যাকেজগুলি থাকে: আপনার ORM, আপনার লাইব্রেরি এবং Nexy৷
প্রকল্পটি দিয়ে নির্মিত হয়েছিল। এর বাইরে, একটি প্রকল্প যার প্রয়োজন `sqlmodel` ব্যর্থ হয়
`ModuleNotFoundError: No module named 'sqlmodel'`।

প্রকল্প ফোল্ডার থেকে প্রতি টার্মিনাল একবার এটি সক্রিয় করুন:

| শেল | কমান্ড |
|---|---|
| পাওয়ারশেল, cmd (উইন্ডোজ) | `.venv\Scripts\activate` |
| macOS, লিনাক্স | `source .venv/bin/activate` |

প্রম্পট তারপর শুরু হয় `(.venv)` দিয়ে। সেখান থেকে:

```bash
cd my-app
.venv\Scripts\activate    # Windows; on macOS and Linux: source .venv/bin/activate
nexy dev
```

খুলুন <http://localhost:3000>।

অ্যাক্টিভেশন এড়িয়ে যেতে, একটি কমান্ডের জন্য uv করতে দিন: `uv run nexy dev`।

> [!নোট]
> `nexy` এবং `nx` একই বাইনারি। একটি অনুলিপি `ইউভি টুল ইনস্টল সহ ইনস্টল করা হয়েছে
> nexy` lives in its own environment, like `uvx`, তাই প্রকল্প তৈরি করতে এবং সবকিছু চালানোর জন্য এটি ব্যবহার করুন
> অন্য প্রকল্পের পরিবেশ থেকে।

## একটি বিদ্যমান প্রকল্পে Nexy যোগ করুন

এটিকে প্রজেক্টের ভার্চুয়াল এনভায়রনমেন্ট থেকে চালান, এর প্যাকেজের মধ্যে Nexy সহ (`uv add nexy`):

```bash
nexy init
```
