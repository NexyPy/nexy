# 2.2-এ আপগ্রেড করা হচ্ছে

আপনি যখন 2.1 থেকে 2.2 এ যান তখন বিদ্যমান প্রকল্পের জন্য কী পরিবর্তন হয় এবং এটি সম্পর্কে কী করতে হবে। সম্পূর্ণ তালিকা [চেঞ্জলগ](../../CHANGELOG.md) এ রয়েছে।

```bash
uv add "nexy>=2.2"            # or: uv tool upgrade nexy
nx build
nx test
```

## আপনি কি পরিবর্তন করতে হতে পারে

| পরিবর্তন করুন | এটি করুন |
|---|---|
| **`.mdx` দ্বারা সংকলিত হয় Vite শুধুমাত্র** Python কম্পাইলার আর এটি রেন্ডার করে না | React বা Preact কে `useFF` এ রাখুন এবং `@mdx-js/rollup`, `remark-gfm` এবং `@mdx-js/react` ইনস্টল করুন। কোন উপাদান ছাড়া একটি পৃষ্ঠা পরিবর্তে একটি `.md` ফাইল হতে পারে |
| **`useBadge` হয় চলে গেছে** "Built with Nexy" ট্যাগটি আর বিদ্যমান নেই | `nexyconfig.py` থেকে লাইনটি মুছুন। একটি অবশিষ্ট লাইন উপেক্ষা করা হয় |
| **`nx check` আর সংকলন করে না `.mdx`[** | কিছুই নয়: Vite বিল্ডে MDX ত্রুটির রিপোর্ট করে |

## যা একই থাকে

- আপনার রুট, লেআউট, অ্যাকশন এবং কনফিগারেশন।
- বিদ্যমান প্রকল্পগুলি তাদের নিজস্ব স্টার্টার পেজ রাখে। নতুন স্টার্টার ডিজাইন শুধুমাত্র আপগ্রেডের পরে তৈরি করা প্রকল্পগুলিতে প্রযোজ্য।
- উন্নয়ন টুলবার এবং `useDevTools`.

## 2.2-এ নতুন

- **এজেন্ট ফাইল** `nx new` লিখেছেন `AGENTS.md`, `CLAUDE.md` এবং কোডিং এজেন্টের দক্ষতা। আপনার ইতিমধ্যে একটি প্রকল্পের জন্য, `nx skills` চালান। এটি কখনোই আপনার লেখা একটি ফাইল ওভাররাইট করে না। [কোডিং এজেন্ট](../guides/ai-agents.md) দেখুন।
- **একটি ডেভ সার্ভার যা রাখে চলমান** যখন আপনার আবেদন শুরু হতে পারে না, `nx dev` কেন রিপোর্ট করে এবং প্রস্থান করার পরিবর্তে পরবর্তী পরিবর্তনের জন্য অপেক্ষা করে।
- **একই পৃষ্ঠা এবং উপাদান সহ Tailwind বা UnoCSS-এর প্রতিটি কাঠামোর জন্য একটি নতুন স্টার্টার**।
- **UnoCSS একটি সার্ভার প্রকল্পে `.nexy` ফাইল** পড়ে। আপনি যদি `.nexy` পৃষ্ঠাগুলির সাথে UnoCSS ব্যবহার করেন, তাহলে যোগ করুন `content` ব্লক [সমস্যা সমাধান](../guides/troubleshooting.md) এ দেখানো হয়েছে।

## সঠিক ডকুমেন্টেশন

তিনটি পৃষ্ঠা এমন কিছু বলেছে যা কোডটি করে না। আপনি যদি তাদের অনুসরণ করেন তবে আপনার ফাইলগুলি পরীক্ষা করুন:

- একটি `.nexy` উপাদান তার শিশুদের `<Slot />` (ক্যাপিটাল এস) দিয়ে রাখে, `<slot />` নয়।
- একটি `.nexy` কম্পোনেন্ট ফাইলের নাম PascalCase এ রাখা হয়েছে: এটি একটি Python মডিউল হিসেবে আমদানি করা হয়, তাই একটি হাইফেন কম্পাইল করে না।
- `.mdx` এর জন্য, ফ্রেমওয়ার্ক হল Preact যখন ফাইলটি আমদানি করে `preact`, React অন্যথায়।
