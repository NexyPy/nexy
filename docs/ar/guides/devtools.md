# شريط أدوات التطوير

`nexy dev` يضيف شريط أدوات إلى كل صفحة HTML. إنه موجود في الزاوية السفلية اليسرى، ويظهر المسار الذي تسلكه والمدة التي استغرقها الخادم، ويفتح في لوحة. إنها ليست أبدًا جزءًا من استجابة الإنتاج.

| علامة التبويب | تظهر |
|---|---|
| الصفحة | عنوان URL، المسار، المعالج، الملف الذي تأتي منه (مع رابط يفتحه في المحرر الخاص بك)، الحالة، وقت الخادم، البايت الأول، الطلاء الأول، المحتوى الرئيسي، تغيير التخطيط (متدرج باللون الأخضر أو الكهرماني أو الأحمر)، DOM جاهز |
| توجيه | كل مسار للتطبيق مع طرقه ومرشحه ووضع علامة على المسار الحالي؛ كل رابط إلى ملفه |
| أخطاء | أخطاء الخادم منذ بدء `nexy dev` والأخطاء التي أثارها المتصفح |
| الإعدادات | السمة (مطابقة الصفحة، داكنة أو فاتحة)، الموضع، الحجم، الإخفاء، إعادة التعيين |

## حركه

اسحب الزر: فهو يتبع المؤشر ويستقر في أقرب زاوية عند تركه. تفتح اللوحة باتجاه منتصف الشاشة من أي مكان يوجد فيه الزر. يتم الاحتفاظ بالموقف في هذا المتصفح. يمكنك أيضًا اختيار زاوية في **الإعدادات**.

`Shift` + `Alt` + `D` يخفي ويظهر شريط الأدوات. `Esc` يغلق اللوحة.

## أخطاء

يؤدي خطأ لم يتم اكتشافه في المتصفح إلى فتح مربع حوار فوق الصفحة التي تحتوي على الرسالة والمكدس؛ مع وجود العديد من الأخطاء، انتقل إليها (1 من 3). خطأ في الخادم يجيب بصفحة من نفس النوع: الخطأ ومكان ظهوره والكود المحيط به.

## أطفئه

```python filename="nexyconfig.py"
class NexyConfig(NexyConfigModel):
    useDevTools = False
```

شريط الأدوات عبارة عن كتلة نمط ونص تمت إضافته قبل `</body>`: لا يوجد طلب خارجي ولا تبعية. يتم ترك JSON والملفات وكل استجابة ليست بتنسيق HTML بمفردها.
