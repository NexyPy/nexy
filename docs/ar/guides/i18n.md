# التدويل (i18n)

Nexy لا يترجم طلبك. لا يحتوي على برمجيات وسيطة محلية، ولا يوجد `trans` مساعد ولا ملفات محلية: يختار التطبيق مكتبة i18n التي تناسبه، كما يختار ORM.

تتم ترجمة سطر الأوامر (`nx`)؛ انظر [CLI](../reference/cli.md).

## في معالج

يقرأ المعالج ما يحتاجه من الطلب. هذا يجيب بلغة العنوان `Accept-Language`:

```python filename="src/routes/hello.py"
from nexy.http import Header

MESSAGES = {"en": "Hello", "fr": "Bonjour"}


async def GET(accept_language: str = Header("en")):
    language = accept_language.split(",")[0].split("-")[0].lower()
    return {"message": MESSAGES.get(language, MESSAGES["en"])}
```

## في صفحة

استخدم مكتبة الواجهة الأمامية الخاصة بك للصفحات الموجهة بواسطة العميل (على سبيل المثال `i18next` أو `vue-i18n` أو متجر Svelte)، ومكتبة Python (`gettext` من المكتبة القياسية، أو Babel) لصفحات `.nexy`. قم بتعيين `<html lang>` في تخطيط الجذر.
