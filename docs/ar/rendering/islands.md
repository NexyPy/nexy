# الجزر والترطيب

## التعريف

الجزيرة عبارة عن مكون عميل - React أو Vue أو Svelte أو Solid أو Preact - يتم استيرادها إلى `.nexy`
الصفحة. يعرض الخادم HTML الخاص به؛ يجعل المتصفح هذا المكون تفاعليًا. بقية
تبقى الصفحة HTML.

الجزر موجودة في وضع الخادم. في وضع العميل، المكونات *هي* الصفحات: راجع [CSR](csr.md).

## كيفية العمل

```nexy filename="src/routes/index.nexy"
---
from "@/components/Counter.tsx" import Counter
---
<h1>Static heading</h1>
<Counter directive="client:visible" />
```

يعرض Nexy المكون في وقت الإنشاء، ويخزن HTML الخاص به، ويضعه داخل الصفحة. الصفحة
تحمل الاستجابة HTML بالإضافة إلى الدعائم كسمة JSON. في المتصفح، وقت تشغيل الجزيرة
يقوم بتحميل المكون ويتولى الحاوية.

`directive` يقرر **متى** أن يحدث ذلك. وبدون ذلك، ترطب الجزيرة بمجرد تشغيلها
جاهز.

## دورة حياة العرض

1. عند الإنشاء، يتم تقديم كل مكون عميل إلى HTML وكتابته تحت `__nexy__/client/static/`.
2. يعرض الطلب صفحة `.nexy`؛ يتم إدراج HTML الخاص بالجزيرة بدلاً من العلامة.
3. تحمل الاستجابة HTML والدعائم والتوجيه كسمات.
4. في المتصفح، يقوم وقت التشغيل بجدولة عملية الترطيب وفقًا للتوجيهات.
5. يستبدل الترطيب HTML الثابت بالمكون المباشر؛ بقية الصفحة لم تمس.

لا توجد لقطة بناء أثناء التطوير: الحاوية فارغة ويتم عرض المكون في ملف
browser. تبدو الصفحة متشابهة، لكن الطلاء الأول يختلف عن الإنتاج.

## متى يستخدم

- صفحة تحتوي في الغالب على محتوى وتحتوي على نقطة تفاعلية واحدة أو اثنتين.
- أداة يجب أن تكون موجودة في HTML لبرامج الزحف ولا تزال تعمل.
- مكون يحتاج إلى المتصفح ولكن لا يجب أن يسحب الصفحة بأكملها إلى عرض العميل.

##  التكوين

| التوجيه | هيدرات |
|---|---|
| لا شيء، أو `client:load` | على الفور |
| `client:idle` | عندما يكون المتصفح خاملاً (`requestIdleCallback`، مهلة ثانيتين) |
| `client:visible` | عندما تدخل الجزيرة إلى منفذ العرض، 200 بكسل مبكرًا |
| `client:media` | عندما يتطابق استعلام الوسائط؛ اضبطه باستخدام الدعامة `media` |

```nexy
<Chart directive="client:media" media="(min-width: 768px)" />
```

`client:media` افتراضيًا إلى `(min-width: 768px)` عند غياب `media`، ويتم الترطيب مرة واحدة. على أ
المتصفح بدون `IntersectionObserver`، `client:visible` يعود إلى وضع الخمول.

يتم استهلاك `directive` و`media` بواسطة Nexy: ولا يتم تمريرهما إلى المكون الخاص بك.

## مثال

```tsx filename="src/components/Counter.tsx"
import { useState } from "react"

export default function Counter({ start = 0 }: { start?: number }) {
  const [count, setCount] = useState(start)
  return <button onClick={() => setCount(count + 1)}>{count}</button>
}
```

```nexy filename="src/routes/index.nexy"
---
from "@/components/Counter.tsx" import Counter
---
<h1>Count</h1>
<Counter start=3 directive="client:idle" />
```

## القيود

- **`client:only` لا يرطب أبدًا.** إنه مقبول، لكن وقت التشغيل يتخطى ذلك، لذلك يبقى HTML للخادم
  خامل. استخدم مسار العميل ([CSR](csr.md)) عندما لا يمكن عرض أحد المكونات على الخادم.
- **`client:manual` ليس له مشغل عام.** يتم تخطيه أيضًا تلقائيًا، والمقبض الذي
  يستأنف أنه داخلي.
- **الدعائم يجب أن تكون JSON.** وهي متسلسلة مع `json.dumps`؛ القيمة التي لا يمكن إجراء تسلسل لها هي
  أسقطت، وتستقبل الجزيرة `{}` - بصمت.
- **الجزيرة ليست مكون عميل ذو حالة مشتركة.** لا تشترك الجزيرتان في الحالة بدون
  آلية تضيفها بنفسك.
- **لا يتم إعادة عرض الجزيرة بواسطة الخادم.** HTML الخاص بها هو لقطة البناء، بالإضافة إلى أي شيء
  المكون لا رطب مرة واحدة.
- **صفحة الجزر هي صفحة CSR مقنعة.** إذا كانت كل كتلة بحاجة إلى التحدث مع بعضها البعض، فاختر
  وضع العميل بدلاً من ذلك.
