# تخفيض السعر وMDX

هناك تنسيقان لصفحات المحتوى: `.md` عندما تحتاج إلى Markdown فقط، `.mdx` عندما تحتاج إلى مكونات.

## `.md`: تخفيض السعر خالصًا

الملف `.md` هو محتوى خالص. يعرضه Nexy باستخدام `cmarkgfm` (GFM)، ويضيف معرفات العناوين، ويشتق a
جدول المحتويات، ويغلفه في أقرب `layout.*`.

```md filename="src/routes/about.md"
# About

Nexy is a fullstack Python meta-framework.
```

-  لا يتم استخدام Frontmatter في `.md` كمنطق بايثون. إذا كنت بحاجة إلى منطق الخادم، فاستخدم `.nexy`.
- يعمل التفاف التخطيط وصفحات الخطأ والشرائح الديناميكية بنفس الطريقة التي تعمل بها الصفحات الأخرى.

## `.mdx`: تخفيض السعر بالمكونات

`.mdx` يتم تجميع الملفات بواسطة **Vite**، من خلال مسار مسار الإطار (React أو Preact). بايثون
يكتب فقط الغلاف الرقيق الذي يخدم المسار؛ فهو لا يقوم أبدًا بتجميع أو عرض MDX نفسه.
يتم عرض المكونات بواسطة إطار العمل، ويتم عرضها بواسطة الخادم مثل مسارات المكونات الأخرى، و
تم تقديمه مسبقًا إلى HTML بواسطة `nx build`.

- يتطلب `useFF` أن يكون React أو Preact.
- يتطلب الحزم الاختيارية `@mdx-js/rollup`، `remark-gfm` و `@mdx-js/react` (و
  `@mdx-js/esbuild` للبناء). يخبرك Vite بالشخص المفقود.
- يتم اكتشاف إطار العمل تلقائيًا من عمليات الاستيراد: Preact عندما يقوم الملف باستيراد `preact`، React
  خلاف ذلك.

> [!ملاحظة]
> استخدم `.nexy` إذا كنت بحاجة إلى منطق Python في المادة الأمامية.
