# إنشاء تطبيق ملاحظات باستخدام Nexy، الجزء 1: إنشاء المشروع

يقوم الجزء الأول من البرنامج التعليمي بإنشاء المشروع الذي ستحوله إلى تطبيق ملاحظات، وتشغيله في متصفحك خلال خمس دقائق تقريبًا.

**قبل أن تبدأ:** [uv](https://docs.astral.sh/uv/) و Node.js 20 أو أحدث. يتبع البرنامج التعليمي جهاز التوجيه الذي تم اختياره في الجزء العلوي من القائمة: قم بتبديله هناك وسيظهر كل جزء ملفات جهاز التوجيه هذا.

## ماذا ستبني

بحلول نهاية البرنامج التعليمي، يحتوي التطبيق على صفحات وواجهة برمجة تطبيقات JSON للملاحظات وقاعدة بيانات وحسابات وملاحظات تتم مشاركتها عبر البريد الإلكتروني والتحديثات المباشرة والاختبارات وبناء الإنتاج. وينتهي كل جزء بتطبيق يعمل، بحيث يمكنك التوقف بعد أي جزء منه.

## إنشاء المشروع

```bash
uvx nexy new notes
```

أجب عن الأسئلة بهذه الطريقة:

| سؤال | الإجابة |
|---|---|
| جهاز التوجيه القائم على الملف؟ | `Yes` لأجهزة التوجيه المخصصة والقائمة على الملفات، `No` لأجهزة التوجيه المعيارية |
| نوع المشروع | `Web` |
| التوجيه من جانب العميل | `No`: يعرض الخادم الصفحات |
| إطار العميل | `React`: يعود في الوحدة الرابعة للجزر |
| النمط | `Tailwind CSS` |
| استيراد الاسم المستعار | `@` |
| ORM | `No database`: الجزء الخامس يضيف واحدة |

<!-- router:custom -->
جهاز التوجيه المخصص هو جهاز يعتمد على الملف بالإضافة إلى `APIRouter` لديك بالفعل. يقوم البرنامج التعليمي بإنشاء التطبيق باستخدام الملفات؛ [تضمين جهاز توجيه FastAPI موجود](../routing/custom/README.md) يوضح كيفية تركيب جهاز التوجيه الخاص بك بجانبه.

## تشغيله

```bash
cd notes
source .venv/bin/activate    # Windows: .venv\Scripts\activate
nexy dev
```

فتح <http://localhost:3000>. يجب أن تشاهد صفحة الترحيب. اترك `nexy dev` قيد التشغيل: من الآن فصاعدًا، كل ملف تحفظه يعيد تحميل المتصفح.

## ما تعلمته

- `uvx nexy new` يقوم بإنشاء مشروع وتثبيت الحزمتين Python و JavaScript الخاصتين به.
- `nexy dev` يخدمه ويعيد تحميله عند الحفظ.
<!-- router:fbr,custom -->
- الصفحات موجودة في `src/routes/`: الجزء التالي يضيف واحدة.
<!-- /router -->

- وحدات التحكم ووجهات نظرها موجودة في `src/apps/`: الجزء التالي يضيف واحدًا.
