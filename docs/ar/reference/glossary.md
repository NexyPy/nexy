# المسرد

الكلمات التي تستخدمها هذه المستندات، سطر واحد لكل منها، بالترتيب الأبجدي. مصطلح يحتاج إلى أكثر من سطر
لديه صفحة: اتبع الرابط. لمعرفة كيفية توافق المفاهيم معًا، اقرأ
[المفاهيم الأساسية](../getting-started/core-concepts.md).

## المصطلحات

| المصطلح | في سطر واحد |
|---|---|
| الإجراء | دالة بايثون تحمل علامة `@Action`، بمثابة `POST` وقابلة للاستدعاء من العميل ([actions](../guides/actions.md)) |
| ASGI | الواجهة التي يتحدث بها Uvicorn، والتي تم تنفيذها بواسطة FastAPI وStarlette |
| وضع العميل | `useCSR = True`: ملفات إطار العمل هي المسارات التي يتنقل بها المتصفح ([الأوضاع](../routing/fbr/modes.md)) |
| المكون | كتلة بناء لواجهة المستخدم قابلة لإعادة الاستخدام تُستخدم لإنشاء طريقة عرض ([المشاهدات](../views/README.md)) |
| CSR | العرض من جانب العميل: يعرض المتصفح الصفحات بعد المستند الأول ([CSR](../rendering/csr.md)) |
| التبعية | وظيفة يتم تشغيلها بواسطة FastAPI قبل المعالج، لكل مسار أو لكل مجلد ([التبعيات](../routing/fbr/dependencies/README.md)) |
| غلاف المستند | و `<html>` و `<head>` و `<body>` حول الصفحة، مملوك لأقرب تخطيط أو Nexy ([تخطيطات](../routing/fbr/layouts/README.md)) |
| نقطة النهاية | مزيج فريد من عنوان URL وطريقة HTTP ([المشاهدات](../views/README.md)) |
| FBR | التوجيه المستند إلى الملف: الملف الموجود ضمن `src/routes/` هو مسار ([توجيه](../routing/fbr/README.md)) |
| Frontmatter | كتلة Python بين السطرين `---` لملف `.nexy` أو `.md` ([.nexy files](../views/nexy/README.md)) |
| الحرس | تبعية ترفض الطلب برفع `HTTPException` ([guards](../routing/modular/guards-and-metadata.md)) |
| المعالج | دالة بايثون تتعامل مع طلب HTTP لطريقة معينة ([المشاهدات](../views/README.md)) |
| HMR | استبدال الوحدة الساخنة: يقوم خادم التطوير بتبديل الوحدات التي تم تغييرها، دون إعادة تحميل كاملة ([الواجهة الأمامية](../guides/frontend.md)) |
| الترطيب | المتصفح الذي يقوم بإرفاق إطار عمل بـ HTML الذي أرسله الخادم بالفعل ([الجزر](../rendering/islands.md)) |
| الجزيرة | مكون العميل المثبت داخل الصفحة المعروضة بواسطة الخادم ([الجزر](../rendering/islands.md)) |
| ISR | التجديد الثابت التزايدي: صفحة واحدة مخبأة لكل مسار، يتم تحديثها في الخلفية ([ISR](../rendering/isr.md)) |
| التخطيط | ملف `layout.*` يقوم بتغليف الصفحات الموجودة أسفل مجلده ([التخطيطات](../routing/fbr/layouts/README.md)) |
| تم الإعلان عن مسارات جهاز التوجيه المعياري | بـ `@Module` و `@Controller` ضمن `src/apps/` ([معياري](../routing/modular/README.md)) |
| الصفحة | مورد قابل للعنونة عبر URL محدد بواسطة ملف ضمن `src/routes/` ([المشاهدات](../views/README.md)) |
| الجلب المسبق | تحميل الصفحة خلف رابط قبل أن ينقر عليها القارئ ([ربط](../routing/fbr/navigation/linking-and-navigating.md)) |
| الدعائم | القيم التي يمررها أحد الوالدين إلى المكون ([.nexy files](../views/nexy/README.md)) |
| إعادة التحقق من | عدد الثواني التي يتم بعدها إعادة إنشاء صفحة ISR في الخلفية ([ISR](../rendering/isr.md)) |
| المسار | نمط URL، يتم إنتاجه بواسطة مسار ملف المسار ([routing](../routing/README.md)) |
| مجموعة المسار | مجلد بين قوسين يقوم بتجميع المسارات دون إضافة مقطع ([المسارات الديناميكية](../routing/fbr/pages/dynamic-routes.md)) |
| معالج المسار | وظيفة `GET`، `POST`، ... لملف المسار `.py` ([معالجات](../routing/fbr/handlers/README.md)) |
| وضع الخادم | `useCSR = False`، الافتراضي: يعرض الخادم `.nexy` و `.md` الصفحات ([الأوضاع](../routing/fbr/modes.md)) |
| المهارة | مجلد به `SKILL.md` يعلم وكيل الترميز جزءًا واحدًا من Nexy ([وكلاء الترميز](../guides/ai-agents.md)) |
| SSG | إنشاء موقع ثابت؛ **ليس وضع Nexy**: تتم دائمًا قراءة HTML الذي تم إنشاؤه مسبقًا بواسطة الخادم ([تقديم](../rendering/README.md)) |
| SSR | العرض من جانب الخادم: يعرض الخادم كل صفحة لطلبه، وهو الافتراضي ([SSR](../rendering/ssr.md)) |
| عرض | عملية إنتاج نص الرد لصفحة ([المشاهدات](../views/README.md)) |

## الملفات والمجلدات

| الاسم | في سطر واحد |
|---|---|
| `__nexy__/` | الإخراج الناتج: الصفحات المجمعة، وإدخال العميل وعميل الإجراء؛ لم يتم تحريره مطلقًا، ولم يتم الالتزام به مطلقًا |
| `nexyconfig.py` | تكوين المشروع، فئة من `use*` الحقول ([config](config.md)) |
| `public/` | الملفات المقدمة في الجذر، مثل `public/logo.svg` → `/logo.svg` ([اصطلاحات الملفات](file-conventions.md)) |
| `src/apps/` | وحدات التحكم والوحدات النمطية لجهاز التوجيه المعياري ([وحدات](../routing/modular/README.md)) |
| `src/components/` | المكونات المستوردة بالصفحات؛ لا يوجه أبدًا ([اصطلاحات الملف](file-conventions.md)) |
| `src/routes/` | مسارات التطبيق ([اصطلاحات الملف](file-conventions.md)) |
