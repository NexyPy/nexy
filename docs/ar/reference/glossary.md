# مسرد

الكلمات التي تستخدمها هذه المستندات، سطر واحد لكل منها، بالترتيب الأبجدي. مصطلح يحتاج إلى أكثر من سطر له صفحة: اتبع الرابط. للتعرف على كيفية توافق المفاهيم معًا، اقرأ [المفاهيم الأساسية](../getting-started/core-concepts.md).

## الشروط

| مصطلح | في سطر واحد |
|---|---|
| العمل | دالة Python تحمل علامة `@Action`، بمثابة `POST` وقابلة للاستدعاء من العميل ([الإجراءات](../guides/actions.md)) |
| ASGI | الواجهة Uvicorn تتحدث، ينفذها FastAPI و Starlette |
| وضع العميل | `useCSR = True`: ملفات الإطار هي المسارات التي يتنقل بها المتصفح ([الأوضاع](../routing/fbr/modes.md)) |
| مكون | كتلة بناء لواجهة المستخدم قابلة لإعادة الاستخدام تُستخدم لإنشاء طريقة عرض ([المشاهدات](../views/README.md)) |
| المسؤولية الاجتماعية للشركات | العرض من جانب العميل: يعرض المتصفح الصفحات بعد المستند الأول ([CSR](../rendering/csr.md)) |
| التبعية | يتم تشغيل الوظيفة FastAPI قبل المعالج، لكل مسار أو لكل مجلد ([التبعيات](../routing/fbr/dependencies/README.md)) |
| غلاف الوثيقة | `<html>`، `<head>` و `<body>` حول الصفحة، مملوكة لأقرب تخطيط أو بواسطة Nexy ([تخطيطات](../routing/fbr/layouts/README.md)) |
| نقطة النهاية | التركيبة الفريدة لعنوان URL وطريقة HTTP ([المشاهدات](../views/README.md)) |
| FBR | التوجيه المستند إلى الملف: الملف الموجود ضمن `src/routes/` هو مسار ([توجيه](../routing/fbr/README.md)) |
| فرونتماتر | الكتلة Python بين السطرين `---` لملف `.nexy` أو `.md` ([ملفات .nexy](../views/nexy/README.md)) |
| حارس | تبعية ترفض الطلب عن طريق رفع `HTTPException` ([الحراس](../routing/modular/guards-and-metadata.md)) |
| معالج | دالة Python تعالج طلب HTTP لطريقة معينة ([العروض](../views/README.md)) |
| HMR | استبدال الوحدة الساخنة: يقوم خادم التطوير بتبديل الوحدات التي تم تغييرها، دون إعادة تحميل كامل ([الواجهة الأمامية](../guides/frontend.md)) |
| الترطيب | المتصفح الذي يقوم بإرفاق إطار عمل بـ HTML الذي أرسله الخادم بالفعل ([الجزر](../rendering/islands.md)) |
| الجزيرة | مكون العميل المثبت داخل الصفحة المعروضة بواسطة الخادم ([الجزر](../rendering/islands.md)) |
| ISR | التجديد الثابت التزايدي: صفحة واحدة مخبأة لكل مسار، يتم تحديثها في الخلفية ([ISR](../rendering/isr.md)) |
| التخطيط | ملف `layout.*` يغلف الصفحات الموجودة أسفل المجلد الخاص به ([التخطيطات](../routing/fbr/layouts/README.md)) |
| جهاز التوجيه المعياري | الطرق المعلنة بـ `@Module` و `@Controller` ضمن `src/apps/` ([المعياري](../routing/modular/README.md)) |
| الصفحة | مورد يمكن عنونة عنوان URL محدد بواسطة ملف ضمن `src/routes/` ([المشاهدات](../views/README.md)) |
| الجلب المسبق | تحميل الصفحة خلف رابط قبل أن ينقر القارئ عليها ([الروابط](../routing/fbr/navigation/linking-and-navigating.md)) |
| Props | القيم التي يمررها أحد الوالدين إلى أحد المكونات ([ملفات .nexy](../views/nexy/README.md)) |
| إعادة التحقق | عدد الثواني التي يتم بعدها إعادة إنشاء صفحة ISR في الخلفية ([ISR](../rendering/isr.md)) |
| الطريق | نمط عنوان URL، يتم إنتاجه بواسطة مسار ملف المسار ([التوجيه](../routing/README.md)) |
| مجموعة الطريق | مجلد بين قوسين يقوم بتجميع المسارات دون إضافة مقطع ([المسارات الديناميكية](../routing/fbr/pages/dynamic-routes.md)) |
| معالج الطريق | وظيفة `GET`، `POST`، … لملف المسار `.py` ([معالجات](../routing/fbr/handlers/README.md)) |
| وضع الخادم | `useCSR = False`، الافتراضي: يعرض الخادم `.nexy` و `.md` الصفحات ([الأوضاع](../routing/fbr/modes.md)) |
| مهارة | مجلد يحتوي على `SKILL.md` يعلم وكيل الترميز جزءًا واحدًا من Nexy ([وكلاء الترميز](../guides/ai-agents.md)) |
| إس إس جي | إنشاء موقع ثابت؛ **ليس وضع Nexy**: تتم دائمًا قراءة HTML الذي تم إنشاؤه مسبقًا بواسطة الخادم ([تقديم](../rendering/README.md)) |
| إصلاحية القطاع الخاص | العرض من جانب الخادم: يعرض الخادم كل صفحة لطلبه، وهو الإعداد الافتراضي ([SSR](../rendering/ssr.md)) |
| عرض | عملية إنتاج نص الاستجابة للصفحة ([المشاهدات](../views/README.md)) |

## الملفات والمجلدات

| الاسم | في سطر واحد |
|---|---|
| `__nexy__/` | المخرجات التي تم إنشاؤها: الصفحات المجمعة، وإدخال العميل وعميل الإجراء؛ لم يتم تحريره مطلقًا، ولم يتم الالتزام به أبدًا |
| `nexyconfig.py` | تكوين المشروع، فئة من `use*` الحقول ([الإعداد](config.md)) |
| `public/` | الملفات المقدمة في الجذر، مثل `public/logo.svg` → `/logo.svg` ([اصطلاحات الملفات](file-conventions.md)) |
| `src/apps/` | وحدات التحكم والوحدات النمطية لجهاز التوجيه المعياري ([المعياري](../routing/modular/README.md)) |
| `src/components/` | المكونات المستوردة عن طريق الصفحات؛ لا يتم التوجيه مطلقًا ([اصطلاحات الملف](file-conventions.md)) |
| `src/routes/` | مسارات التطبيق ([اصطلاحات الملف](file-conventions.md)) |
