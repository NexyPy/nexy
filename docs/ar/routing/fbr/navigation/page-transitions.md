# كيف تعمل انتقالات الصفحة؟

يستخدم Nexy واجهة برمجة تطبيقات View Transitions الخاصة بالمتصفح لتنقلات العميل، لذا يقوم المتصفح المدعوم بتحريك عملية تبديل الصفحة ما لم يفضل الزائر تقليل الحركة.

## عند تشغيل عملية انتقالية

الوثيقة الأولى هي استجابة خادم عادية ولا تحتوي على أي انتقال. منذ ذلك الحين، يقوم كل تنقل يتم التعامل معه بواسطة جهاز توجيه العميل بتبديل الصفحة داخل `document.startViewTransition()`: رابط إلى مسار العميل، `router.push()` أو `router.replace()`، وزري الرجوع والأمام. يعرض جهاز التوجيه الصفحة التالية وتخطيطاتها أولاً، ثم ينقل عنوان URL، بحيث تكون الصفحة الجديدة جاهزة قبل عرضها.

React، Preact، Solid، Vue و Svelte يشتركون في نفس جهاز التوجيه، وبالتالي فإن السلوك هو نفسه في جميع المحولات الخمسة. لا يوجد إعداد لتمكين التحولات.

## عندما يتراجع

- المتصفح الذي لا يحتوي على `startViewTransition()` يعرض الصفحة مباشرة.
- باستخدام `prefers-reduced-motion: reduce`، يقوم جهاز التوجيه بعرض الصفحة مباشرة.
- لا يؤدي الانتقال الذي تم تخطيه بواسطة التنقل الأحدث إلى تسجيل خطأ: لا تزال الصفحة صحيحة.

يتصرف عنوان URL والسجل وموضع التمرير وحدث `nexy:navigated` بنفس الطريقة مع أو بدون انتقال.

## نمط الانتقال

Nexy لا يشحن أي رسوم متحركة CSS. يطبق المتصفح خاصية التداخل الافتراضي، والتي يمكنك استبدالها في ورقة الأنماط الخاصة بك:

```css
::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: 250ms;
}
```
