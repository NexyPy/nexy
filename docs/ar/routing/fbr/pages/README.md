# الصفحات

يقوم ملف الصفحة بإرجاع HTML. نوع الملف الذي تستخدمه يغير طريقة إنتاجه: راجع [طرق العرض](../../../views/README.md). يغطي هذا القسم قواعد التوجيه التي تنطبق على كل تنسيق صفحة.

| الصفحة | ما يغطيه |
|---|---|
| [المسارات الديناميكية](dynamic-routes.md) | `[slug]`، `[...path]`، مجموعات المسارات، المقاطع المكتوبة |
| [صفحات الخطأ](../errors/README.md) | `notfound.nexy`، `errors.nexy`، JSON لعملاء API |
| [التخطيطات](../layouts/README.md) | صفحة واحدة لكل نوع ملف تخطيط |
| [الميراث](../inheritance.md) | كيفية تكديس التخطيطات والتبعيات |

## صفحة الحد الأدنى

```nexy filename="src/routes/about.nexy"
---
title: prop[str] = "About"
---
<h1>{{ title }}</h1>
```

ويتم تقديمه في `/about`. الواجهة بين السطرين `---` هي Python؛ العلامة أدناه هي Jinja2. راجع [ملفات .nexy](../../../views/nexy/README.md).

## تنسيقات الصفحة

| الوضع | الملف | ينتج |
|---|---|---|
| الخادم | `.nexy` | HTML المقدم من الخادم من Python و Jinja2 |
| الخادم | `.md`، `.mdx` | صفحات المحتوى |
| العميل | `.tsx`، `.jsx`، `.vue`، `.svelte` | مكونات إطار العمل، المقدمة والتنقل في المتصفح |

ولا يمكن الجمع بين الوضعين في مشروع واحد. انظر [وضع الخادم ووضع العميل](../modes.md). لا يزال من الممكن أن تظهر مكونات العميل في وضع الخادم، مثل [الجزر](../../../rendering/islands.md) داخل صفحة `.nexy`.

## التخزين المؤقت المتزايد

أضف `revalidate = 60` إلى صفحة `.nexy` لتخزينها مؤقتًا مع إعادة التحقق من الصلاحية. انظر [ISR](../../../rendering/isr.md).

## قراءة الطلب

تقرأ الصفحة المسار وسلسلة الاستعلام وملفات تعريف الارتباط والجلسة من خلال الخطافات. انظر [الخطافات](../navigation/hooks.md).
