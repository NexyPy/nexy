# الصفحات

يقوم ملف الصفحة بإرجاع HTML. نوع الملف الذي تستخدمه يغير طريقة إنتاجه: انظر
[المشاهدات](../../../views/README.md). يغطي هذا القسم قواعد التوجيه التي تنطبق على كل صفحة
تنسيق.

| الصفحة | ما يغطيه |
|---|---|
| [المسارات الديناميكية](dynamic-routes.md) | `[slug]`، `[...path]`، مجموعات المسارات، المقاطع المكتوبة |
| [صفحات الخطأ](../errors/README.md) | `notfound.nexy`، `errors.nexy`، JSON لعملاء API |
| [التخطيطات](../layouts/README.md) | صفحة واحدة لكل نوع ملف تخطيط |
| [الميراث](../inheritance.md) | كيفية تكديس التخطيطات والتبعيات |

## صفحة صغيرة

```nexy filename="src/routes/about.nexy"
---
title: prop[str] = "About"
---
<h1>{{ title }}</h1>
```

ويتم تقديمه في `/about`. الواجهة بين السطور `---` هي بايثون؛ الترميز أدناه هو
جينجا2. راجع [ملفات .nexy](../../../views/nexy/README.md).

## تنسيقات الصفحات

| الوضع | الملف | ينتج |
|---|---|---|
| الخادم | `.nexy` | HTML المقدم من الخادم من Python وJinja2 |
| الخادم | `.md`، `.mdx` | صفحات المحتوى |
| مكونات إطار عمل العميل | `.tsx`، `.jsx`، `.vue`، `.svelte` |، يتم تقديمها والتنقل فيها في المتصفح |

ولا يمكن الجمع بين الوضعين في مشروع واحد. انظر [وضع الخادم ووضع العميل](../modes.md).
لا يزال من الممكن ظهور مكونات العميل في وضع الخادم، مثل [الجزر](../../../rendering/islands.md)
داخل صفحة `.nexy` .

## التخزين المؤقت المتزايد

أضف `revalidate = 60` إلى صفحة `.nexy` لتخزينها مؤقتًا مع إعادة التحقق من الصلاحية. انظر
[الاستخبارات](../../../rendering/isr.md).

## قراءة الطلب

تقرأ الصفحة المسار وسلسلة الاستعلام وملفات تعريف الارتباط والجلسة من خلال الخطافات. انظر
[الخطافات](../navigation/hooks.md).
