# Nexy وNestJS

جهاز التوجيه المعياري مستوحى من NestJS: وحدات التحكم والوحدات النمطية وحقن المنشئ. إنه أ
طبقة رقيقة فوق FastAPI، لذلك لا يحاول إعادة إنتاج NestJS بالكامل. هذه الصفحة تسرد كلا الجانبين.

## ما يطابق

| NestJS | نكسي |
|---|---|
| `@Controller('users')` | `@Controller(prefix="/users")` |
| `@Module({ controllers, providers, imports, exports })` | `@Module()` بنفس سمات الفئة الأربع |
| `@Injectable()` | `@Injectable()` |
| حقن المنشئ | `__init__` تم حل المعلمات من التعليقات التوضيحية للنوع |
| النطاق الفردي والطلب والنطاقات العابرة | `Scope.SINGLETON`، `Scope.REQUEST`، `Scope.TRANSIENT` |
| `@UseGuards(AuthGuard)` | `@UseGuard(guard)` (تبعية FastAPI) |
| `@ApiOperation`، `@ApiResponse` (Swagger) | `@UseRoute`، `@UseResponse` (OpenAPI، متوفر في `/docs`) |
| بوابات WebSocket | `async def SOCKET(...)` على وحدة التحكم |
| التحقق من صحة DTO (`class-validator`) | نماذج Pydantic، الأصلية في FastAPI |
| الكشف عن التبعية الدائرية | `RecursionError` تسمية الفئة |

## ما يختلف

- المعالجات هي طرق مسماة على اسم فعل HTTP (`get`، `post`...)، واحدة لكل وحدة تحكم.
- الحراسات ومصممو البرامج الوسيطة هم FastAPI `Depends`، وليس فئات ذات `canActivate`.
-  المعلمات (`@Body`، `@Param`، `@Query`) هي معلمات FastAPI: اكتب التعليقات التوضيحية، `Query`، `Path`،
  `Body`.
- الأنابيب هي التحقق من صحة Pydantic وتبعيات FastAPI.

## ما هو مفقود

| ميزة NestJS | الحالة في Nexy |
|---|---|
| موفرو الخدمة المخصصون (`useValue`، `useFactory`، `useClass`، رموز السلسلة) | غير متاحين: فقط `@Injectable()` الفئات |
| الحقن بالواجهة أو الفئة المجردة | غير متوفر |
| لم يتم فرض تغليف الوحدة النمطية |: الحاوية على مستوى العملية، `exports` تتحكم فقط في الدقة المتحمسة |
| الوحدات الديناميكية والعالمية (`forRoot`، `@Global`) | غير متوفرة |
| خطافات دورة الحياة (`onModuleInit`، `onApplicationShutdown`) | غير متوفرة |
| تستخدم المعترضات | برامج ASGI الوسيطة (`useMiddlewares`) أو التبعيات |
| تستخدم مرشحات الاستثناءات | معالجات الاستثناءات FastAPI |
| وحدة الاختبار مع تجاوزات الموفر | لا توجد واجهة برمجة تطبيقات عامة؛ استخدم FastAPI `dependency_overrides` و `TestClient` |
| وحدة التكوين، الجدولة، قوائم الانتظار، CQRS، الخدمات الصغيرة، التخزين المؤقت | ليست جزءًا من Nexy؛ استخدام نظام بايثون البيئي |

## متى يتم اختياره

اختر جهاز التوجيه المعياري عندما تريد بنية قائمة على الفئة مع حقن واجهة برمجة تطبيقات أكبر.
اختر جهاز التوجيه المستند إلى الملف عندما تكون بنية عنوان URL هي المبدأ التنظيمي. كلاهما سقالات
بواسطة `nx new`، يعمل على نفس تطبيق FastAPI، ويمكن أن يتواجد معًا.

> [!ملاحظة]
> العناصر المفقودة أعلاه هي الفجوة الصادقة. إذا كنت بحاجة إلى `useFactory` مقدمي الخدمة
> أو موفري الخدمة الذين يمكن تجاوزهم في الاختبارات اليوم، احتفظوا بالمنطق في الوظائف البسيطة وFastAPI
> `Depends`، والتي تؤلف وتتجاوز بشكل طبيعي.
