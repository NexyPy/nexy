# نكسي و NestJS

جهاز التوجيه المعياري مستوحى من NestJS: وحدات التحكم والوحدات النمطية وحقن المنشئ. إنها طبقة رقيقة فوق FastAPI، لذلك لا تحاول إعادة إنتاج كل NestJS. هذه الصفحة تسرد كلا الجانبين.

## ما يتطابق

| NestJS | نكسي |
|---|---|
| `@Controller('users')` | `@Controller(prefix="/users")` |
| `@Module({ controllers, providers, imports, exports })` | `@Module()` بنفس سمات الفئة الأربع |
| `@Injectable()` | `@Injectable()` |
| تم حل معلمات حقن المنشئ | `__init__` من التعليقات التوضيحية للنوع |
| نطاقات فردية وطلبية وعابرة | `Scope.SINGLETON`، `Scope.REQUEST`، `Scope.TRANSIENT` |
| `@UseGuards(AuthGuard)` | `@UseGuard(guard)` (تبعية FastAPI) |
| `@ApiOperation`، `@ApiResponse` (اختيال) | `@UseRoute`، `@UseResponse` (OpenAPI، خدم في `/docs`) |
| WebSocket بوابات | `async def SOCKET(...)` على وحدة التحكم |
| التحقق من صحة DTO (`class-validator`) | Pydantic، أصلي في FastAPI |
| كشف التبعية الدائرية | `RecursionError` تسمية الفئة |

## ما يختلف

- المعالجات هي طرق مسماة على اسم فعل HTTP (`get`، `post`...)، واحدة لكل وحدة تحكم.
- الحراس ومصممو البرمجيات الوسيطة هم FastAPI `Depends`، وليسوا فئات ذات `canActivate`.
- المعلمات (`@Body`، `@Param`، `@Query`) هي FastAPI معلمات: نوع التعليقات التوضيحية، `Query`، `Path`، `Body`.
- الأنابيب هي Pydantic التحقق من الصحة و FastAPI التبعيات.

## ما هو مفقود

| NestJS خاصية | الحالة في النكسي |
|---|---|
| موفري الخدمة المخصصون (`useValue`، `useFactory`، `useClass`، رموز السلسلة) | غير متاحين: فئات `@Injectable()` فقط |
| الحقن بالواجهة أو الفئة المجردة | غير متوفر |
| لم يتم فرض تغليف الوحدة النمطية |: الحاوية على مستوى العملية، `exports` تتحكم فقط في الدقة المتحمسة |
| الوحدات الديناميكية والعالمية (`forRoot`، `@Global`) | غير متوفرة |
| خطافات دورة الحياة (`onModuleInit`، `onApplicationShutdown`) | غير متوفرة |
| تستخدم المعترضات | برامج ASGI الوسيطة (`useMiddlewares`) أو التبعيات |
| تستخدم مرشحات الاستثناء | معالجات الاستثناء FastAPI |
| وحدة الاختبار مع الموفر تتجاوز | لا توجد واجهة برمجة تطبيقات عامة؛ استخدم FastAPI `dependency_overrides` و `TestClient` |
| وحدة التكوين، والجدولة، وقوائم الانتظار، وCQRS، والخدمات الصغيرة، والتخزين المؤقت | ليس جزءًا من Nexy؛ استخدام Python النظام البيئي |

## متى تختاره

اختر جهاز التوجيه المعياري عندما تريد بنية قائمة على الفئة مع حقن واجهة برمجة تطبيقات أكبر. اختر جهاز التوجيه المستند إلى الملف عندما تكون بنية عنوان URL هي المبدأ التنظيمي. كلاهما مدعوم بـ `nx new`، ويعملان على نفس التطبيق FastAPI، ويمكنهما التواجد معًا.

> [!ملاحظة]
> العناصر المفقودة أعلاه هي الفجوة الصادقة. إذا كنت بحاجة إلى موفري `useFactory` أو موفري خدمات يمكن تجاوزهم في الاختبارات اليوم، فاحتفظ بالمنطق في الوظائف البسيطة و FastAPI `Depends`، التي يتم تركيبها وتجاوزها بشكل طبيعي.
