# ما هو نيكسي؟

Nexy هو إطار عمل Python لتطبيقات الويب الكاملة: صفحاتك وواجهة برمجة التطبيقات (API) الخاصة بك موجودة في مشروع واحد ويتم تقديمها بواسطة خادم واحد.

## ما تحصل عليه

- **الصفحات في Python.** الملف `.nexy` هو ملف HTML مع بضعة أسطر من Python في الأعلى؛ الملف `.md` هو صفحة أيضًا. ليس هناك حاجة إلى JavaScript لعرض الصفحة.
- **واجهة برمجة تطبيقات في نفس المشروع.** ملف `.py` ضمن `src/routes/` يجيب على طلبات HTTP: دالة اسمها `GET` تجيب `GET`، وظيفة اسمها `POST` تجيب `POST`.
- **وثائق واجهة برمجة التطبيقات (API) مجانًا.** يظهر كل مسار واجهة برمجة التطبيقات (API) في مخطط OpenAPI، ويعرضه Scalar كمرجع تفاعلي في `/docs`.
- **النماذج التي تستدعي Python.** يصل النموذج، أو المكالمة المكتوبة من المتصفح، إلى نفس الوظيفة Python.
- **إطار عمل للواجهة الأمامية عندما تريد واحدًا.** React، Vue، Svelte، Solid أو Preact، لمكون واحد أو للموقع بأكمله.
- **أمر واحد للعمل، وواحد للشحن.** `nx dev` يُعاد التحميل أثناء الحفظ؛ `nx build` يجهز الإنتاج.

## ما بني عليه

يعتمد الإصدار الحالي، 2.2، على أدوات ربما تعرفها بالفعل:

| جزء | بنيت على | ماذا يعني بالنسبة لك |
|---|---|---|
| الخادم وواجهة برمجة التطبيقات | [FastAPI](https://fastapi.tiangolo.com/) | مسار واجهة برمجة التطبيقات (API) هو مسار FastAPI: يعمل التحقق من الصحة والتبعيات كالمعتاد Pydantic |
| مرجع واجهة برمجة التطبيقات | OpenAPI و [العددية](https://scalar.com/) | المخطط موجود في `/openapi.json`، المرجع في `/docs` |
| الصفحات | Jinja2 | تستخدم صفحة `.nexy` علامات Jinja2 مثل `{{ title }}` |
| الواجهة الأمامية (اختياري) | [Vite](https://vite.dev/) | فقط مع إطار عمل الواجهة الأمامية، والذي يحتاج أيضًا إلى Node.js |

## الصفحة الأولى ونقطة النهاية الأولى

صفحة، في `/hello`:

```nexy filename="src/routes/hello.nexy"
---
title: prop[str] = "Hello"
---
<h1>{{ title }}</h1>
```

نقطة النهاية، عند `GET /api/items`، مدرجة في `/docs` بدون أي كود إضافي:

```python filename="src/routes/api/items.py"
from nexy.http import Request


async def GET(request: Request):
    return {"items": []}
```

## ما يتركه لك Nexy

قاعدة البيانات وتسجيل الدخول والقواعد المتعلقة بمن يمكنه فعل ما ينتمي إلى تطبيقك، لذلك تختار المكتبات. تُظهر [قواعد البيانات](../guides/databases.md) و[البرامج الوسيطة والأمان](../guides/middleware-and-security.md) مكان توصيل كل منها.
