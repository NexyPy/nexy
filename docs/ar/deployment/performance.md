# الأداء

ما يفعله `nx start` افتراضيًا، وما الذي يجب تشغيله، وما الذي تم قياسه.

## الافتراضيات

| الاهتمام | الافتراضي | تغييره |
|---|---|---|
| العمليات | عامل Uvicorn واحد لكل وحدة معالجة مركزية على Linux وmacOS، وواحد على Windows | `nx start` يقوم بتشغيل التطبيق من خلال Uvicorn |
| إيقاف الضغط | | `useGZip = {"minimum_size": 1000}` في [التكوين](../reference/config.md)، أو الضغط في الوكيل العكسي |
| الملفات الثابتة | يتم تقديمها مع `ETag` و `Last-Modified`، لا يوجد `Cache-Control` | يقوم بتعيين تخزين مؤقت طويل الأمد في الوكيل العكسي أو CDN للحزم المجزأة |
| صفحات HTML | يتم تقديمها لكل طلب، لا توجد ذاكرة تخزين مؤقت | [ISR](../rendering/isr.md) مع `revalidate = N` |
| مستندات API | على | `useDocs = False` قيد الإنتاج |
| العقدة في وقت التشغيل | لا شيء | `nx build` تعرض مكونات العميل مسبقًا |

## قياس

تشغيل محلي، عامل Uvicorn واحد، Windows، Python 3.13، اتصالات مستمرة من تحميل Python
مولد على نفس الجهاز. تعامل مع الأرقام كخط أساس لمقارنة التغييرات، وليس كرقم
المعيار مقابل الأطر الأخرى.

| المسار | التزامن | الطلبات في الثانية | ص50 | ص99 |
|---|---|---|---|---|
| طريق FastAPI JSON المجرد | 16 | ~4,500 | 3.4 مللي ثانية | 5.1 مللي ثانية |
| مسار Nexy JSON (`src/routes/api/ping.py`) | 16 | ~2,900 | 5.2 مللي ثانية | 9.8 مللي ثانية |
| صفحة Nexy SSR (16 كيلوبايت، 16 مكونًا) | 1 | ~500 | 1.9 مللي ثانية | 3.0 مللي ثانية |
| صفحة Nexy SSR (16 كيلوبايت، 16 مكون) | 64 | ~670 | 94 مللي ثانية | 126 مللي ثانية |

قراءة الجدول:

-  تكلف طبقات Nexy الخاصة (سياق المسار، البرامج الوسيطة) حوالي ثلث إنتاجية الطبقة العارية
  مسار FastAPI.
- تكلف الصفحة المعروضة بواسطة الخادم حوالي 2 مللي ثانية من وحدة المعالجة المركزية، موزعة على ما يقرب من 16 عرض قالب (واحد لكل
  المكون). الصفحات التي تحتوي على مكونات أقل تكون أرخص نسبيًا.
- مقاييس الإنتاجية مع العمال. في Linux، `nx start` يبدأ بالفعل تشغيل واحد لكل وحدة معالجة مركزية.

## نصيحة عملية

1. ضع Nginx أو Caddy أو حافة النظام الأساسي الخاص بك في المقدمة: TLS وHTTP/2 وBrotli والتخزين المؤقت طويل الأمد لـ
   `/__nexy__/client/` الأصول هي نقاط قوتهم. انظر [نشر](README.md).
2. استخدم [ISR](../rendering/isr.md) للصفحات التي تتغير أقل من مرة في الدقيقة.
3.  قم بالترطيب بتكاسل باستخدام [الجزر](../rendering/islands.md) بحيث يتم شحن التحميل الأول بكمية أقل من JavaScript.
4. حافظ على عدد `.nexy` من المكونات لكل صفحة بشكل معقول: كل واحد عبارة عن قالب منفصل
   تقديم.
5. قياس المسارات الخاصة بك. يكفي مولد التحميل المحلي الذي يحافظ على الاتصالات حية للمقارنة
   نسختين من الصفحة.
