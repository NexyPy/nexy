# तैनाती

दो आदेश: `nx build` कलाकृतियों का उत्पादन करता है, `nx start` उनकी सेवा करता है।

**शुरू करने से पहले:** एक प्रोजेक्ट जो स्थानीय स्तर पर `nx build` के साथ बनता है, और - क्लाइंट पेजों के लिए -
फ्रंटएंड टूलचेन जो `nx new` स्थापित है।

```bash
nx build
nx start --host 0.0.0.0 --port 8000
```

रनटाइम के लिए केवल पायथन की आवश्यकता है। यूविकॉर्न संकलित ऐप और स्थिर परिसंपत्तियों की सेवा प्रदान करता है; कोई नोड नहीं
प्रक्रिया और कोई वीट प्रक्रिया शामिल नहीं है।

## बिल्ड क्या उत्पन्न करता है

`__nexy__/` में संकलित रूट मॉड्यूल, `__nexy__/client/` के अंतर्गत क्लाइंट बंडल और शामिल हैं
फ्रेमवर्क मार्गों के लिए पूर्व-रेंडर HTML। प्रोजेक्ट को कॉपी करें - स्रोत प्लस `__nexy__/` - या अंदर बनाएं
छवि.

## डॉकर

निर्माण चरण के लिए नोड (वाइट के लिए) और पायथन (कंपाइलर के लिए) की आवश्यकता होती है। रनटाइम चरण को पायथन की आवश्यकता है
केवल.

```dockerfile filename="Dockerfile"
FROM node:22-bookworm-slim AS build
WORKDIR /app

COPY --from=ghcr.io/astral-sh/uv:latest /uv /usr/local/bin/uv
COPY pyproject.toml uv.lock ./
RUN uv sync --frozen --no-install-project

COPY . .
RUN uv sync --frozen && uv run nx build

FROM python:3.13-slim
WORKDIR /app
COPY --from=build /app /app
ENV PATH="/app/.venv/bin:$PATH"

EXPOSE 8000
CMD ["nx", "start", "--host", "0.0.0.0", "--port", "8000"]
```

`uv` एक प्रबंधित पायथन लाता है जब आधार छवि में कोई नहीं होता है, यही कारण है कि निर्माण चरण शुरू हो सकता है
एक नोड छवि से.

## रिवर्स प्रॉक्सी के पीछे

लोकलहोस्ट पर `nx start` चलाएँ और Nginx, Caddy या प्लेटफ़ॉर्म प्रॉक्सी को TLS समाप्त करने दें:

```bash
nx start --host 127.0.0.1 --port 8000
```

सुनिश्चित करें कि यदि आप `SOCKET` हैंडलर का उपयोग करते हैं, तो प्रॉक्सी वेबसॉकेट अपग्रेड को आगे बढ़ाती है, और यह आगे बढ़ती है
मूल होस्ट - फास्टएपीआई इससे संपूर्ण यूआरएल बनाता है।

## स्वास्थ्य जांच

एक हैंडलर फ़ाइल जोड़ें, `src/routes/api/health.py`, और जांच करें `/api/health` - एक पेज के बजाय जो हो सकता है
धीरे-धीरे प्रस्तुत करें:

```python filename="src/routes/api/health.py"
async def GET():
    return {"status": "ok"}
```

## स्टेटिक होस्टिंग

प्रत्येक पृष्ठ HTML है, लेकिन नेक्सी रूटिंग और एपीआई हैंडलर के लिए एक सर्वर मानता है।

> [!नोट]
> कोई `--static` बिल्ड मोड नहीं है। एक विशुद्ध रूप से स्थैतिक निर्यात उत्पन्न करना होगा
> `nx build` आउटपुट से आपकी पाइपलाइन।

## चेकलिस्ट

- [ ] `nx build` सीआई में, उन मार्गों के लिए कोई चेतावनी नहीं है जिन्हें आप सर्वर पर प्रस्तुत करने की उम्मीद करते हैं
- [ ] `nx start` कोड 1 के साथ बाहर निकलता है, और कुछ भी शुरू नहीं करता है, जब रूट फ़ाइल लोड नहीं हो पाती है
- [ ] `NEXY_ACTION_SECRET` सेट, या `__nexy__/action.key` बिल्ड के साथ रखा गया
- [ ] `useDocs = False` उत्पादन में यदि एपीआई स्कीमा सार्वजनिक नहीं होनी चाहिए
- [ ] `useTrustedHost` और `useHTTPSRedirect` सार्वजनिक तैनाती के लिए निर्धारित
- [ ] `__nexy__/` प्रतिबद्ध नहीं है
