# .nexy फ़ाइलें

एक `.nexy` फ़ाइल एक घटक है: शीर्ष पर पायथन, बीच में HTML, नीचे सीएसएस।

**शुरू करने से पहले:** [त्वरित शुरुआत](../../getting-started/quick-start.md) द्वारा बनाया गया एक प्रोजेक्ट।
एक `.nexy` फ़ाइल को किसी बिल्ड कॉन्फ़िगरेशन की आवश्यकता नहीं है: `nx dev` इसे सहेजने पर संकलित करता है।

```nexy filename="src/routes/blog/[slug].nexy"
---
from nexy import usePathname

slug: prop[str] = "untitled"
pathname = usePathname()
---
<article class="post">
  <h1>{{ slug }}</h1>
  <p>You are on {{ pathname }}</p>
</article>

<style>
  .post { max-width: 60ch; }
</style>
```

## फ्रंटमैटर

दो `---` लाइनों के बीच सब कुछ पायथन है। घटक होने पर आयात का समाधान हो जाता है
संकलित; बाकी हर अनुरोध के लिए चलता है, इसलिए यह अनुरोध स्थिति को पढ़ सकता है।

| क्या | उदाहरण |
|---|---|
| एक मॉड्यूल आयात करें | `import json`, `from datetime import datetime` |
| एक घटक आयात करें | `from "@/components/card.nexy" import Card` |
| संपत्ति की घोषणा करें | `title: prop[str] = "Default"` |
| एक मान की गणना करें | `year = datetime.now().year` |
| अनुरोध पढ़ें | `pathname = usePathname()` |
| पेज को कैश करें (आईएसआर) | `revalidate = 60` |

## गुण

गुण घटक की एपीआई हैं। `prop[type]` प्रकार घोषित करता है, `= value` एक डिफ़ॉल्ट देता है। ए
बिना किसी डिफ़ॉल्ट के संपत्ति को माता-पिता द्वारा पारित किया जाना चाहिए।

उपनाम से शुरू होने वाले आयात का समाधान `useAliases` के माध्यम से किया जाता है। सेटअप `nx new` मानचित्र लिखता है
`@` से `src`, जिससे `@/components/card.nexy` का मतलब `src/components/card.nexy` हो जाता है।

## टेम्पलेट

फ्रंटमैटर के नीचे Jinja2 के साथ HTML है। फ्रंटमैटर और गुणों से चर अंदर हैं
दायरा.

```html
{% for item in items %}
  <li>{{ item.name }}</li>
{% endfor %}

{% if user %}
  <p>Welcome, {{ user.name }}</p>
{% endif %}
```

ऑटोएस्केपिंग **बंद है**: टेम्प्लेट प्रोजेक्ट का अपना HTML है, इसलिए `{{ value }}` को इस रूप में डाला गया है
लिखा हुआ. `{{ value | e }}` के साथ स्वयं अविश्वसनीय मूल्यों से बचें। `| safe` इसलिए कुछ भी नहीं बदलता।

> [!नोट]
> ऐसी जावास्क्रिप्ट को लपेटें जिसमें `{% raw %}...{% endraw %}` में `{{` या `{%` हो।
> व्यू और स्वेल्ट जैसे फ्रेमवर्क समान ब्रेसिज़ का उपयोग करते हैं।

## घटक

कोई भी आयातित कॉल करने योग्य जिसका नाम बड़े अक्षर से शुरू होता है, उसे टैग के रूप में उपयोग किया जा सकता है। संकलक
इसे जिंजा कॉल में फिर से लिखता है: विशेषताएँ कीवर्ड तर्क बन जाती हैं।

```nexy filename="src/routes/index.nexy"
---
from "@/components/card.nexy" import Card
from nexy import Audio
---
<Card title="Hello">
  <p>Child content</p>
</Card>

<Audio src="/theme.mp3" controls=True />
```

अंतिम पंक्ति बिलकुल `{{ Audio("/theme.mp3", controls=True) }}` है। दोनों वाक्यविन्यास इसके लिए मान्य हैं
अंतर्निहित `Image`, `Link`, `Audio` और `Video` सहायक - देखें
[घटक](components.md#two-syntaxes-one-function).

बच्चों को चाइल्ड घटक के अंदर `<Slot />` (पूंजी एस) के माध्यम से, और `{{ children }}` के माध्यम से प्रस्तुत किया जाता है।
एक लेआउट के अंदर.

विशेषता के अंदर जिंजा के साथ एक परिकलित मान पास करें: `<Icon path="{{ icon }}" size="{{ size }}" />`।
`path=icon` जैसा एक खाली नाम टेक्स्ट `icon` है, वेरिएबल नहीं। किसी घटक को CSS देने के लिए
क्लास, एक `class_name` प्रोप घोषित करें: `class` एक पायथन कीवर्ड है।

> [!नोट]
> एक सहायक टैग हमेशा स्वतः बंद हो जाता है। `Link` को सामग्री भेजना इसके माध्यम से होता है
> `children` तर्क (`<Link href="/about" children="About" />`), तत्व सामग्री के माध्यम से नहीं।

## शैलियाँ

`<style>` ब्लॉक उस पृष्ठ से उत्सर्जित होते हैं जो उन्हें घोषित करता है। उनका दायरा नहीं है: एक वर्ग का नाम
दो घटकों में प्रयुक्त एक वर्ग है। अपनी कक्षाओं को उपसर्ग या नामस्थान दें।

## समय बचाने वाले नियम

- प्रति फ़ाइल एक घटक। पास्कलकेस (`CopyChip.nexy`) में फ़ाइल नाम घटक नाम है। ए
  `.nexy` घटक को पायथन मॉड्यूल के रूप में आयात किया गया है: नाम में एक हाइफ़न (`copy-chip.nexy`) नहीं है
  संकलित करें.
- प्रॉप्स का उपयोग करने से पहले उन्हें घोषित करें: एक अघोषित वैरिएबल एक खाली स्ट्रिंग के रूप में प्रस्तुत होता है, क्योंकि
  Jinja2 की अपरिभाषित यहाँ चुप है।
- फ़ंक्शंस के अंदर साइड इफेक्ट्स रखें - फ्रंटमैटर हर अनुरोध पर फिर से चलता है।
