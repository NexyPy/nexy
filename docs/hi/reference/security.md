# सुरक्षा

नेक्सी अपनी हमले की सतह को कैसे छोटा रखती है, उसे किन संस्करणों की आवश्यकता है, और किसी प्रोजेक्ट की जांच कैसे करें।

## संस्करण फर्श

## नेक्सी नियमों का पालन करता है

- **पथों के लिए होस्ट हेडर पर कभी भरोसा न करें।** नेक्सी अपने स्वयं के मिडलवेयर (निर्देशिका मिडलवेयर) में `scope["path"]` पढ़ता है, न कि `request.url.path`। अपने में भी वैसा ही करो.
- **जो HTML तक पहुंचता है उससे बच जाएं।** Props क्लाइंट घटकों को भेज दिया गया है, `Link` विशेषताएँ, `Image`, `Audio` और `Video` विशेषताएँ, तालिका-सामग्री एंकर और `HTTPException` विवरण सभी HTML से बच गए हैं। एक `.nexy` टेम्प्लेट अपने आप नहीं बचता: विज़िटर या डेटाबेस से आने वाले किसी भी मूल्य के लिए `{{ value | e }}` लिखें, और उपयोगकर्ता इनपुट पर कभी भी `| safe` न लिखें।
- **डेवलपर एंडपॉइंट केवल लूपबैक और संकीर्ण हैं।** डेव रेंडर एंडपॉइंट (`/__nexy__/render`) केवल `src/routes/` के तहत `.tsx` या `.jsx` एक्सटेंशन वाली फाइलों को स्वीकार करता है, और केवल डेव सर्वर के माध्यम से पहुंच योग्य है, जो विदेशी `Host` हेडर को अस्वीकार करता है।
- **त्रुटि विवरण लीक नहीं होते हैं।** एक त्रुटि पृष्ठ जो स्वयं विफल रहता है वह केवल स्थिति कोड दिखाता है।
- **प्रोडक्शन उत्तरों में सुरक्षित हेडर होते हैं।** `X-Content-Type-Options: nosniff` और `Referrer-Policy: strict-origin-when-cross-origin`, जब तक कि आपका कोड स्वयं सेट न हो जाए। `Server` हेडर नहीं भेजा गया है। अपने प्रॉक्सी या मिडलवेयर में `Strict-Transport-Security` और एक `Content-Security-Policy` जोड़ें: वे आपके डोमेन पर निर्भर करते हैं।
- **क्रैश एक संदर्भ दिखाता है, त्रुटि नहीं।** देखें [त्रुटि पृष्ठ](../routing/fbr/errors/README.md#unhandled-exceptions)।
- **नेक्सी के Python कोड में कोई `eval` और कोई `shell=True` नहीं है।** बाहरी प्रोग्राम एक तर्क सूची के साथ चलते हैं।

## ऑडिट चला रहे हैं

```bash
python scripts/audit_dependencies.py        # Python dependencies against the lock
npm audit                                    # in a scaffolded project
uv run bandit -r nexy -c .bandit             # static analysis of Nexy itself
```

नेक्सी का अपना भंडार अपने चेक में पहला और तीसरा चलाता है। ऊपर की मंजिल पर एक नई सलाह को `pyproject.toml` या मचान में `package.json` फर्श को ऊपर उठाकर, फिर ताले को पुनर्जीवित करके नियंत्रित किया जाता है।

## सुरक्षित तैनाती

- `useTrustedHost` को अपने डोमेन पर सेट करें: यह किसी भी रूट से पहले अप्रत्याशित `Host` हेडर को अस्वीकार कर देता है।
- Vite डेव सर्वर को उजागर न करें: `nx dev` इसे नेक्सी मूल के पीछे लूपबैक पर रखता है।
- यदि एपीआई स्कीमा सार्वजनिक नहीं होनी चाहिए तो `useDocs = False` सेट करें।
