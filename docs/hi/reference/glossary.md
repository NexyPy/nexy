# शब्दावली

इन दस्तावेज़ों में जिन शब्दों का उपयोग किया गया है, वे वर्णमाला क्रम में एक-एक पंक्ति में हैं। जिस शब्द के लिए एक पंक्ति से अधिक की आवश्यकता होती है उसमें एक पृष्ठ होता है: लिंक का अनुसरण करें। यह जानने के लिए कि धारणाएँ एक साथ कैसे फिट होती हैं, [मुख्य अवधारणाएँ](../getting-started/core-concepts.md) पढ़ें।

## शर्तें

| पद | एक पंक्ति में |
|---|---|
| क्रिया | एक Python फ़ंक्शन को `@Action` के रूप में चिह्नित किया गया है, जो `POST` के रूप में कार्य करता है और क्लाइंट से कॉल करने योग्य है ([क्रियाएं ](../guides/actions.md)) |
| एएसजीआई | इंटरफ़ेस Uvicorn बोलता है, FastAPI और Starlette | द्वारा कार्यान्वित किया जाता है।
| क्लाइंट मोड | `useCSR = True`: फ्रेमवर्क फ़ाइलें मार्ग हैं और ब्राउज़र नेविगेट करता है ([मोड](../routing/fbr/modes.md)) |
| घटक | एक पुन: प्रयोज्य यूआई बिल्डिंग ब्लॉक जिसका उपयोग एक दृश्य बनाने के लिए किया जाता है ([दृश्य ](../views/README.md)) |
| सीएसआर | क्लाइंट-साइड रेंडरिंग: ब्राउज़र पहले दस्तावेज़ के बाद पेजों को रेंडर करता है ([सीएसआर](../rendering/csr.md)) |
| निर्भरता | एक फ़ंक्शन FastAPI एक हैंडलर से पहले चलता है, प्रति रूट या प्रति फ़ोल्डर ([निर्भरताएं ](../routing/fbr/dependencies/README.md)) |
| दस्तावेज़ शेल | `<html>`, `<head>` और `<body>` एक पृष्ठ के आसपास, निकटतम लेआउट के स्वामित्व में या नेक्सी ([लेआउट्स ](../routing/fbr/layouts/README.md)) के स्वामित्व में है |
| समापन बिंदु | एक यूआरएल और एक HTTP विधि का अद्वितीय संयोजन ([विचार](../views/README.md)) |
| एफबीआर | फ़ाइल-आधारित रूटिंग: `src/routes/` के अंतर्गत एक फ़ाइल एक रूट है ([रूटिंग](../routing/fbr/README.md)) |
| फ्रंटमैटर | Python एक `.nexy` या `.md` फ़ाइल ([.nexy फ़ाइलें](../views/nexy/README.md)) की दो `---` पंक्तियों के बीच का ब्लॉक |
| गार्ड | एक निर्भरता जो `HTTPException` ([गार्ड ](../routing/modular/guards-and-metadata.md)) | बढ़ाकर अनुरोध को अस्वीकार कर देती है
| हैंडलर | एक Python फ़ंक्शन जो एक विशिष्ट विधि के लिए HTTP अनुरोध को संभालता है ([दृश्य ](../views/README.md)) |
| एचएमआर | हॉट मॉड्यूल प्रतिस्थापन: डेव सर्वर पूर्ण पुनः लोड किए बिना, बदले गए मॉड्यूल को स्वैप करता है ([फ्रंटएंड ](../guides/frontend.md)) |
| हाइड्रेशन | ब्राउज़र HTML में एक फ्रेमवर्क संलग्न करता है जिसे सर्वर पहले ही भेज चुका है ([द्वीप](../rendering/islands.md)) |
| आइलैंड | एक क्लाइंट घटक जो सर्वर-रेंडर पेज के अंदर लगा होता है ([आइलैंड्स](../rendering/islands.md)) |
| आईएसआर | वृद्धिशील स्थैतिक पुनर्जनन: प्रति पथ एक कैश्ड पृष्ठ, पृष्ठभूमि में ताज़ा ([आईएसआर](../rendering/isr.md)) |
| लेआउट | एक `layout.*` फ़ाइल जो अपने फ़ोल्डर के नीचे पृष्ठों को लपेटती है ([लेआउट्स](../routing/fbr/layouts/README.md)) |
| मॉड्यूलर राउटर | मार्गों को `src/apps/` ([मॉड्यूलर](../routing/modular/README.md)) | के अंतर्गत `@Module` और `@Controller` के साथ घोषित किया गया है।
| पृष्ठ | `src/routes/` ([विचार](../views/README.md)) | के अंतर्गत एक फ़ाइल द्वारा परिभाषित एक यूआरएल-पता योग्य संसाधन
| प्रीफ़ेच | पाठक द्वारा लिंक पर क्लिक करने से पहले पेज को लिंक के पीछे लोड करना ([लिंकिंग](../routing/fbr/navigation/linking-and-navigating.md)) |
| प्रॉप्स | वे मान जो माता-पिता किसी घटक को देते हैं ([.nexy फ़ाइलें](../views/nexy/README.md)) |
| | उस सेकंड की संख्या को पुनः मान्य करें जिसके बाद पृष्ठभूमि में एक आईएसआर पृष्ठ को फिर से बनाया जाता है ([आईएसआर](../rendering/isr.md)) |
| रूट | एक यूआरएल पैटर्न, जो रूट फ़ाइल के पथ द्वारा निर्मित होता है ([रूटिंग](../routing/README.md)) |
| रूट समूह | कोष्ठक में एक फ़ोल्डर जो खंड जोड़े बिना मार्गों को समूहित करता है ([गतिशील मार्ग](../routing/fbr/pages/dynamic-routes.md)) |
| रूट हैंडलर | `GET`, `POST`, ... `.py` रूट फ़ाइल का फ़ंक्शन ([हैंडलर ](../routing/fbr/handlers/README.md)) |
| सर्वर मोड | `useCSR = False`, डिफ़ॉल्ट: सर्वर `.nexy` और `.md` पेज ([मोड ](../routing/fbr/modes.md)) | प्रस्तुत करता है
| कौशल | एक फ़ोल्डर जिसमें `SKILL.md` है जो एक कोडिंग एजेंट को नेक्सी का एक हिस्सा सिखाता है ([कोडिंग एजेंट ](../guides/ai-agents.md)) |
| एसएसजी | स्थिर साइट निर्माण; **नेक्सी मोड नहीं**: समय से पहले बनाया गया HTML हमेशा सर्वर द्वारा पढ़ा जाता है ([रेंडरिंग](../rendering/README.md)) |
| SSR | सर्वर-साइड रेंडरिंग: सर्वर अपने अनुरोध के लिए प्रत्येक पेज को रेंडर करता है, और यह डिफ़ॉल्ट है ([SSR](../rendering/ssr.md)) |
| | एक पृष्ठ के लिए प्रतिक्रिया निकाय तैयार करने की प्रक्रिया देखें ([विचार](../views/README.md)) |

## फ़ाइलें और फ़ोल्डर्स

| नाम | एक पंक्ति में |
|---|---|
| `__nexy__/` | उत्पन्न आउटपुट: संकलित पृष्ठ, क्लाइंट प्रविष्टि और एक्शन क्लाइंट; कभी संपादित नहीं, कभी प्रतिबद्ध नहीं |
| `nexyconfig.py` | प्रोजेक्ट कॉन्फ़िगरेशन, `use*` फ़ील्ड्स का एक वर्ग ([कॉन्फिग](config.md)) |
| `public/` | फ़ाइलें रूट पर परोसी जाती हैं, जैसे कि `public/logo.svg` → `/logo.svg` ([फ़ाइल कन्वेंशन](file-conventions.md)) |
| `src/apps/` | मॉड्यूलर राउटर के नियंत्रक और मॉड्यूल ([मॉड्यूलर](../routing/modular/README.md)) |
| `src/components/` | पृष्ठों द्वारा आयातित घटक; कभी रूट नहीं ([फ़ाइल कन्वेंशन](file-conventions.md)) |
| `src/routes/` | आवेदन के मार्ग ([फ़ाइल कन्वेंशन](file-conventions.md)) |
