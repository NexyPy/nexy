# दूसरे ढांचे से आ रहा है

नेक्सी फास्टएपीआई प्लस फ़ाइल-आधारित रूटिंग, सर्वर-रेंडर पेज और वैकल्पिक रिएक्ट, वीयू, स्वेल्ट है।
ठोस या प्रीएक्ट द्वीप। यह पृष्ठ वही दर्शाता है जो आप पहले से जानते हैं।

## फास्टएपीआई से

| फास्टएपीआई | नेक्सी |
|---|---|
| `@app.get("/users")` एक मॉड्यूल में आप | `GET` फ़ंक्शन को `src/routes/users.py` | में आयात करते हैं
| `app.include_router(router)` | फ़ाइल पथ यूआरएल है; पंजीकरण के लिए कुछ भी नहीं |
| पथ परम `/users/{id}` | `src/routes/users/[id].py` |
| `Depends(...)` | अभी भी `Depends(...)`: हैंडलर फास्टएपीआई हैंडलर हैं |
| जिंजा2 `TemplateResponse` | समापन बिंदु के बगल में एक `.nexy` पृष्ठ |
| `uvicorn main:app` | `nx dev` के साथ चलाएँ, फिर `nx build && nx start` |

`src/routes/*.py` के अंतर्गत सब कुछ सामान्य फास्टएपीआई है: निर्भरताएं, पाइडेंटिक मॉडल, मिडलवेयर
और `/docs` काम करते रहें।

## नेक्स्ट.जेएस से

| Next.js | नेक्सी |
|---|---|
| `app/page.tsx` | `src/routes/index.tsx` या `index.nexy` |
| `app/blog/[slug]/page.tsx` | `src/routes/blog/[slug].tsx` |
| `app/layout.tsx` (`<html>` का मालिक है) | `src/routes/layout.tsx` के साथ `useCSR = True` (रिएक्ट), या `src/routes/layout.nexy` सर्वर मोड में |
| नेस्टेड `layout.tsx` | नेस्टेड `layout.tsx` / `layout.vue` / `layout.svelte` क्लाइंट मोड में, नेस्टेड `layout.nexy` सर्वर मोड में |
| `use client` सर्वर पेज में घटक | [द्वीप](../rendering/islands.md) सर्वर मोड में |
| रूट हैंडलर `route.ts` | `src/routes/api/x.py`, पायथन में लिखा गया है |
| `(group)` फ़ोल्डर्स | वही: `(group)/` |
| सर्वर क्रियाएं | [`@Action`](../guides/actions.md) फ़ंक्शन को किसी फॉर्म से या टाइप किए गए क्लाइंट फ़ंक्शन के रूप में बुलाया जाता है |
| `next dev` / `next build` / `next start` | `nx dev` / `nx build` / `nx start` |

बैकएंड पायथन है, इसलिए आपका एपीआई आपके डेटा और एमएल कार्य के साथ कोड साझा करता है। ग्राहक घटक
संपूर्ण पृष्ठ रिएक्ट वृक्ष के बजाय द्वीपों के रूप में हाइड्रेट करें।

## एक्सप्रेस या नोड बैकएंड से

| एक्सप्रेस | नेक्सी |
|---|---|
| `app.get("/users/:id", handler)` | `src/routes/users/[id].py` के साथ `async def GET(id)` |
| `app.use(middleware)` | फास्टएपीआई मिडलवेयर, `nexyconfig.py` | से पंजीकृत
| `res.json(obj)` | एक तानाशाही या पाइडेंटिक मॉडल लौटाएं |
| ईजेएस / पग दृश्य | `.nexy` (जिंजा2) पृष्ठ |
| `npm run dev` | `nx dev` |

## राउटर चुनना

| उपयोग करें | जब |
|---|---|
| फ़ाइल-आधारित राउटर | पृष्ठों और समापन बिंदुओं को फ़ाइलों से मैप किया गया; डिफ़ॉल्ट |
| मॉड्यूलर राउटर | नियंत्रक, मॉड्यूल और निर्भरता इंजेक्शन, नेस्टजेएस-शैली |

दोनों को `nx new` द्वारा तैयार किया गया है और एक ही एंड-टू-एंड परीक्षणों द्वारा कवर किया गया है। देखिये
[रूटिंग](../routing/README.md) और [मॉड्यूलर रूटिंग](../routing/modular/README.md)।
