# नेक्सी के साथ एक नोट्स ऐप बनाएं, भाग 1: प्रोजेक्ट बनाएं

ट्यूटोरियल का भाग 1 वह प्रोजेक्ट बनाता है जिसे आप एक नोट्स ऐप के रूप में विकसित करेंगे, और इसे लगभग पांच मिनट में आपके ब्राउज़र में चलाता है।

**शुरू करने से पहले:** [uv](https://docs.astral.sh/uv/) और Node.js 20 या नया। ट्यूटोरियल मेनू के शीर्ष पर चुने गए राउटर का अनुसरण करता है: इसे वहां स्विच करें और प्रत्येक भाग उस राउटर की फ़ाइलों को दिखाता है।

## आप क्या बनाएंगे

ट्यूटोरियल के अंत तक, ऐप में नोट्स के लिए पेज और एक JSON एपीआई, एक डेटाबेस, खाते, ईमेल द्वारा साझा किए गए नोट्स, लाइव अपडेट, परीक्षण और एक प्रोडक्शन बिल्ड होता है। प्रत्येक भाग एक ऐप के साथ समाप्त होता है जो चलता है, इसलिए आप उनमें से किसी के बाद रुक सकते हैं।

## प्रोजेक्ट बनाएं

```bash
uvx nexy new notes
```

प्रश्नों का उत्तर इस प्रकार दें:

| प्रश्न | उत्तर |
|---|---|
| फ़ाइल-आधारित राउटर? | `Yes` फ़ाइल-आधारित और कस्टम राउटर के लिए, `No` मॉड्यूलर के लिए |
| प्रोजेक्ट का प्रकार | `Web` |
| क्लाइंट-साइड रूटिंग | `No`: सर्वर पेजों को प्रस्तुत करता है |
| ग्राहक ढाँचा | `React`: यह द्वीपों के लिए इकाई 4 में वापस आता है |
| अंदाज | `Tailwind CSS` |
| उपनाम आयात करें | `@` |
| ओआरएम | `No database`: भाग 5 में एक जोड़ा गया है |

कस्टम राउटर फ़ाइल-आधारित वन प्लस एक `APIRouter` है जो आपके पास पहले से मौजूद है। ट्यूटोरियल फ़ाइलों के साथ ऐप बनाता है; [एक मौजूदा FastAPI राउटर शामिल करें](../routing/custom/README.md) दिखाता है कि उनके बगल में अपना राउटर कैसे लगाया जाए।

## इसे चलाओ

```bash
cd notes
source .venv/bin/activate    # Windows: .venv\Scripts\activate
nexy dev
```

<http://localhost:3000> खोलें। आपको स्वागत पृष्ठ देखना चाहिए. `nexy dev` को चालू रखें: अब से, आपके द्वारा सहेजी गई प्रत्येक फ़ाइल ब्राउज़र को पुनः लोड करती है।

## आपने क्या सीखा

- `uvx nexy new` एक प्रोजेक्ट बनाता है और उसके Python और JavaScript पैकेज स्थापित करता है।
- `nexy dev` इसे परोसता है और सेव करने पर पुनः लोड करता है।

- पेज `src/routes/` में रहते हैं: अगला भाग एक जोड़ता है।
