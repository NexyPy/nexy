# अंतर्राष्ट्रीयकरण (i18n)

नेक्सी आपके एप्लिकेशन का अनुवाद नहीं करता है। इसमें कोई लोकेल मिडलवेयर नहीं है, कोई `trans` हेल्पर नहीं है और कोई लोकेल फाइल नहीं है: एक एप्लिकेशन i18n लाइब्रेरी चुनता है जो उसके लिए उपयुक्त है, जैसे वह एक ORM चुनता है।

कमांड लाइन (`nx`) का अनुवाद किया गया है; [सीएलआई](../reference/cli.md) देखें।

## एक हैंडलर में

एक हैंडलर पढ़ता है कि उसे अनुरोध से क्या चाहिए। यह `Accept-Language` हेडर की भाषा में उत्तर देता है:

```python filename="src/routes/hello.py"
from nexy.http import Header

MESSAGES = {"en": "Hello", "fr": "Bonjour"}


async def GET(accept_language: str = Header("en")):
    language = accept_language.split(",")[0].split("-")[0].lower()
    return {"message": MESSAGES.get(language, MESSAGES["en"])}
```

## एक पेज में

क्लाइंट-रूटेड पृष्ठों के लिए अपने फ्रंटएंड की लाइब्रेरी का उपयोग करें (उदाहरण के लिए `i18next`, `vue-i18n` या Svelte स्टोर), और अपनी Python लाइब्रेरी (`gettext` मानक लाइब्रेरी से, या बैबेल) `.nexy` पृष्ठों के लिए। रूट लेआउट में `<html lang>` सेट करें।
