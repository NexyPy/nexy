# डेटाबेस

`nx new` SQLModel, SQLAlchemy या Tortoise-ORM के साथ एक मॉडल परत तैयार कर सकता है। नेक्सी लपेटता नहीं है
ओआरएम: आप इसे सीधे हैंडलर और पेज से उपयोग करते हैं।

##  मचान क्या जोड़ता है

| फ़ाइल | उद्देश्य |
|---|---|
| `src/configs/db.py` | इंजन (एसक्यूएलमॉडल, एसक्यूएलकेमी) या `TORTOISE_ORM` सेटिंग्स |
| `src/models/` | मॉडल कक्षाएं |
| `src/services/` | फ़ंक्शन जो मॉडलों को क्वेरी करते हैं |
| `.env` | `DATABASE_URL`, जब आप `nx new` | के दौरान डेटाबेस यूआरएल देते हैं तो लिखा जाता है

कनेक्शन स्ट्रिंग `DATABASE_URL` पर्यावरण चर से आती है। जब यह अस्त न हो, तो
मचान इंजन एक स्थानीय SQLite फ़ाइल में वापस आ जाता है, `dev.db`।

## किसी पृष्ठ में किसी सेवा का उपयोग करें

```nexy filename="src/routes/users/index.nexy"
---
from src.services.user_service import UserService
users = UserService.get_all()
---
<ul>
  {% for user in users %}
  <li>{{ user.name }}</li>
  {% endfor %}
</ul>
```

## एपीआई हैंडलर में एक सेवा का उपयोग करें

```python filename="src/routes/api/users.py"
from src.services.user_service import UserService


async def GET():
    return UserService.get_all()
```

## टोर्टोइज़-ओआरएम एसिंक्स है

एक पेज सर्वर के इवेंट लूप में चलता है और उस पर प्रतीक्षा नहीं कर सकता, इसलिए `asyncio.run(...)` वहां विफल हो जाता है
"चल रहे इवेंट लूप से कॉल नहीं किया जा सकता"। मचान `src/configs/db.py` कछुए को एक देता है
स्वयं का लूप, एक धागे में, और दो सहायक जो इसे एक कोरटाइन भेजते हैं:

| आप कहां हैं | कॉल करें | करता है |
|---|---|---|
| सिंक कोड, जैसे कि एक पेज | `run(UserService.get_all())` | इसे चलाता है और परिणाम देता है |
| एसिंक कोड, जैसे हैंडलर या कंट्रोलर | `await arun(UserService.get_all())` | सर्वर को ब्लॉक किए बिना वही है |

```nexy filename="src/routes/users/index.nexy"
---
from src.configs.db import run
from src.services.user_service import UserService
users = run(UserService.get_all())
---
```

जब पहली बार उनमें से किसी एक को बुलाया जाता है तो कछुआ जुड़ जाता है। `async def` से मॉडल को कॉल करें
(`await UserModel.all()` एक सेवा के अंदर), मॉड्यूल स्तर पर नहीं: कोरआउटिन के बाहर एक कॉल चलती है
कछुआ जुड़ने से पहले.

प्रत्येक मॉड्यूल को सूचीबद्ध करें जो `TORTOISE_ORM` (`models` की `src/configs/db.py` प्रविष्टि) में मॉडल रखता है।
मचान उपयोगकर्ता मॉडल को सूचीबद्ध करता है और `aerich.models`; मॉड्यूल में एक मॉडल जो सूचीबद्ध नहीं है वह नहीं है
मिला.

## प्रवास

`nx migrate` आपके ओआरएम के लिए उपकरण चुनता है: एसक्यूएलमॉडल और एसक्यूएलकेमी के लिए एलेम्बिक, एरीच के लिए
कछुआ-ओआरएम।

| कमांड | करता है |
|---|---|
| `nx migrate --init` | परियोजना के लिए माइग्रेशन टूल प्रारंभ करें |
| `nx migrate -m "add users"` | अपने मॉडल परिवर्तनों से माइग्रेशन बनाएं |
| `nx migrate --upgrade` | लंबित माइग्रेशन लागू करें |

एरीच के साथ, पहला `nx migrate` चलता है `aerich init-db`, जो पहला माइग्रेशन बनाता है और
टेबल एक साथ; अगले वाले चलते हैं `aerich migrate --name "..."`, और `--upgrade` चलते हैं
`aerich upgrade`.

`nx migrate` एक स्पष्ट संदेश के साथ रुकता है जब `DATABASE_URL` गायब होता है या डेटाबेस नहीं हो पाता है
पहुंच गया (केवल एलेम्बिक: एरीच अपनी त्रुटियों की रिपोर्ट करता है)।

### पहला माइग्रेशन आपके लिए बनाया गया है

जब आप एक ORM चुनते हैं और एक डेटाबेस URL देते हैं, तो `nx new` माइग्रेशन टूल सेट करता है, बनाता है
पहला माइग्रेशन और इसे लागू करता है, इसलिए उपयोगकर्ता पृष्ठ पहले `nexy dev` पर उत्तर देता है। प्रवास
टूल (`alembic` या `aerich`) ORM के साथ प्रोजेक्ट में स्थापित है।

यदि डेटाबेस उत्तर नहीं देता है (एक PostgreSQL सर्वर जो नहीं चल रहा है, एक लापता ड्राइवर), `nx new`
क्यों कहता है, माइग्रेशन छोड़ देता है और तैयार होने पर चलाने के लिए दो कमांड सूचीबद्ध करता है:

```bash
nexy migrate -m "create tables"
nexy migrate --upgrade
```

जब तक तालिकाएँ मौजूद नहीं होतीं, डेटाबेस को पढ़ने वाला पृष्ठ "ऐसी कोई तालिका नहीं" के साथ विफल हो जाता है।

### एक मॉडल जोड़ें

एलेम्बिक डेटाबेस की तुलना उन मॉडलों से करता है जो `alembic/env.py` आयात करते हैं। एक नए में एक मॉडल
मॉड्यूल तब तक दिखाई नहीं देता जब तक वह मॉड्यूल उपयोगकर्ता मॉडल के बगल में आयात नहीं किया जाता है:

```python filename="एलेम्बिक/env.py"
import src.models.user_model  # noqa: F401
import src.models.post_model  # noqa: F401
```

टोर्टोइज़-ओआरएम के लिए, मॉड्यूल को इसके बजाय `TORTOISE_ORM` में सूचीबद्ध करें (ऊपर देखें)।
