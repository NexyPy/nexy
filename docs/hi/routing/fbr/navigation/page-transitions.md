# पेज ट्रांज़िशन कैसे काम करते हैं?

नेक्सी क्लाइंट नेविगेशन के लिए ब्राउज़र के व्यू ट्रांज़िशन एपीआई का उपयोग करता है, इसलिए एक समर्थित ब्राउज़र पेज स्वैप को एनिमेट करता है जब तक कि विज़िटर कम गति को प्राथमिकता नहीं देता।

## जब कोई संक्रमण चलता है

पहला दस्तावेज़ एक सामान्य सर्वर प्रतिक्रिया है और इसमें कोई संक्रमण नहीं है। तब से, क्लाइंट राउटर द्वारा नियंत्रित प्रत्येक नेविगेशन पृष्ठ को `document.startViewTransition()` के अंदर स्वैप करता है: क्लाइंट रूट के लिए एक लिंक, `router.push()` या `router.replace()`, और पीछे और आगे के बटन। राउटर पहले अगले पृष्ठ और उसके लेआउट को प्रस्तुत करता है, फिर यूआरएल को स्थानांतरित करता है, इसलिए नया पृष्ठ दिखाए जाने से पहले तैयार होता है।

React, Preact, Solid, Vue और Svelte एक ही राउटर साझा करते हैं, इसलिए सभी पांच एडेप्टर में व्यवहार समान है। ट्रांज़िशन सक्षम करने के लिए कोई सेटिंग नहीं है.

## जब यह वापस गिर जाता है

- `startViewTransition()` के बिना एक ब्राउज़र सीधे पेज को प्रस्तुत करता है।
- `prefers-reduced-motion: reduce` के साथ, राउटर सीधे पेज को रेंडर करता है।
- नए नेविगेशन द्वारा छोड़ा गया संक्रमण कोई त्रुटि लॉग नहीं करता है: पृष्ठ अभी भी सही है।

यूआरएल, इतिहास, स्क्रॉल स्थिति और `nexy:navigated` घटना संक्रमण के साथ या उसके बिना एक ही तरह से व्यवहार करती है।

## परिवर्तन को शैलीबद्ध करें

Nexy कोई एनिमेशन CSS शिप नहीं करता। ब्राउज़र अपना डिफ़ॉल्ट क्रॉस-फ़ेड लागू करता है, जिसे आप अपनी स्टाइलशीट में बदल सकते हैं:

```css
::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: 250ms;
}
```
