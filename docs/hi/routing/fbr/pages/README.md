# पन्ने

एक पेज फ़ाइल HTML लौटाती है। आप किस फ़ाइल प्रकार का उपयोग करते हैं, यह उसके उत्पादन के तरीके को बदल देता है: [विचार](../../../views/README.md) देखें। यह अनुभाग उन रूटिंग नियमों को शामिल करता है जो प्रत्येक पृष्ठ प्रारूप पर लागू होते हैं।

| पेज | इसमें क्या शामिल है |
|---|---|
| [गतिशील मार्ग](dynamic-routes.md) | `[slug]`, `[...path]`, मार्ग समूह, टाइप किए गए खंड |
| [त्रुटि पृष्ठ](../errors/README.md) | `notfound.nexy`, `errors.nexy`, एपीआई क्लाइंट के लिए JSON |
| [लेआउट](../layouts/README.md) | प्रति लेआउट फ़ाइल प्रकार एक पृष्ठ |
| [विरासत](../inheritance.md) | लेआउट और निर्भरताएँ कैसे एकत्रित होती हैं |

## एक न्यूनतम पृष्ठ

```nexy filename="src/routes/about.nexy"
---
title: prop[str] = "About"
---
<h1>{{ title }}</h1>
```

इसे `/about` पर परोसा जाता है। `---` रेखाओं के बीच का फ्रंटमैटर Python है; इसके नीचे मार्कअप Jinja2 है। [.nexy फ़ाइलें](../../../views/nexy/README.md) देखें।

## पृष्ठ प्रारूप

| मोड | फ़ाइल | पैदा करता है |
|---|---|---|
| सर्वर | `.nexy` | Python और Jinja2 से सर्वर-रेंडर HTML |
| सर्वर | `.md`, `.mdx` | सामग्री पृष्ठ |
| ग्राहक | `.tsx`, `.jsx`, `.vue`, `.svelte` | फ़्रेमवर्क घटक, ब्राउज़र में प्रस्तुत और नेविगेट किए गए |

दो मोड को एक प्रोजेक्ट में मिश्रित नहीं किया जा सकता। [सर्वर मोड और क्लाइंट मोड](../modes.md) देखें। क्लाइंट घटक अभी भी सर्वर मोड में, `.nexy` पृष्ठ के अंदर [द्वीप](../../../rendering/islands.md) के रूप में दिखाई दे सकते हैं।

## वृद्धिशील कैशिंग

जोड़ें `revalidate = 60` को `.nexy` पेज पर बासी-जबकि-पुनर्वैधीकरण के साथ कैश करने के लिए। [आईएसआर](../../../rendering/isr.md) देखें।

## अनुरोध पढ़ना

एक पेज हुक के माध्यम से पथ, क्वेरी स्ट्रिंग, कुकीज़ और सत्र को पढ़ता है। [हुक](../navigation/hooks.md) देखें।
