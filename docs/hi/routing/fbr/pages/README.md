# पेज

एक पेज फ़ाइल HTML लौटाती है। आप किस फ़ाइल प्रकार का उपयोग करते हैं यह उसके उत्पादन के तरीके को बदल देता है: देखें
[विचार](../../../views/README.md). यह अनुभाग प्रत्येक पृष्ठ पर लागू होने वाले रूटिंग नियमों को शामिल करता है
प्रारूप.

| पेज | इसमें क्या शामिल है |
|---|---|
| [गतिशील मार्ग](dynamic-routes.md) | `[slug]`, `[...path]`, मार्ग समूह, टाइप किए गए खंड |
| [त्रुटि पृष्ठ](../errors/README.md) | `notfound.nexy`, `errors.nexy`, एपीआई क्लाइंट के लिए JSON |
| [लेआउट](../layouts/README.md) | प्रति लेआउट फ़ाइल प्रकार एक पृष्ठ |
| [विरासत](../inheritance.md) | लेआउट और निर्भरताएँ कैसे एकत्रित होती हैं |

## एक न्यूनतम पृष्ठ

```nexy filename="src/routes/about.nexy"
---
title: prop[str] = "About"
---
<h1>{{ title }}</h1>
```

इसे `/about` पर परोसा जाता है। `---` रेखाओं के बीच का फ्रंटमैटर पायथन है; इसके नीचे मार्कअप है
जिंजा2. [.nexy फ़ाइलें](../../../views/nexy/README.md) देखें।

## पेज प्रारूप

| मोड | फ़ाइल | उत्पन्न करता है |
|---|---|---|
| सर्वर | `.nexy` | पायथन और जिंजा2 से सर्वर-रेंडर HTML |
| सर्वर | `.md`, `.mdx` | सामग्री पृष्ठ |
| क्लाइंट | `.tsx`, `.jsx`, `.vue`, `.svelte` | फ्रेमवर्क घटक, ब्राउज़र में प्रस्तुत और नेविगेट किए गए |

दो मोड को एक प्रोजेक्ट में मिश्रित नहीं किया जा सकता। [सर्वर मोड और क्लाइंट मोड](../modes.md) देखें।
क्लाइंट घटक अभी भी सर्वर मोड में दिखाई दे सकते हैं, जैसे [द्वीप](../../../rendering/islands.md)
`.nexy` पेज के अंदर।

## वृद्धिशील कैशिंग

`.nexy` पेज को बासी-जबकि-पुनर्वैधीकरण के साथ कैश करने के लिए इसमें `revalidate = 60` जोड़ें। देखिये
[आईएसआर](../../../rendering/isr.md)।

## अनुरोध पढ़ रहा हूं

एक पेज हुक के माध्यम से पथ, क्वेरी स्ट्रिंग, कुकीज़ और सत्र को पढ़ता है। देखिये
[हुक](../navigation/hooks.md).
