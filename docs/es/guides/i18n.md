# Internacionalización (i18n)

Nexy no traduce su aplicación. No tiene middleware local, ni ayudante `trans` ni archivos locales: una aplicación elige la biblioteca i18n que más le convenga, al igual que elige un ORM.

La línea de comando (`nx`) está traducida; consulte [la CLI](../reference/cli.md).

## en un manejador

Un controlador lee lo que necesita de la solicitud. Éste responde en el idioma del encabezado `Accept-Language`:

```python filename="src/rutas/hola.py"
from nexy.http import Header

MESSAGES = {"en": "Hello", "fr": "Bonjour"}


async def GET(accept_language: str = Header("en")):
    language = accept_language.split(",")[0].split("-")[0].lower()
    return {"message": MESSAGES.get(language, MESSAGES["en"])}
```

## en una pagina

Utilice la biblioteca de su interfaz para páginas enrutadas por el cliente (por ejemplo `i18next`, `vue-i18n` o una tienda Svelte), y su biblioteca Python (`gettext` de la biblioteca estándar, o Babel) para `.nexy` páginas. Establezca `<html lang>` en el diseño raíz.
