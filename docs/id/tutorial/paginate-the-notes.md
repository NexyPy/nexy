# Membangun aplikasi catatan dengan Nexy, bagian 9: memberi nomor halaman pada catatan

Bagian 9 menunjukkan catatan lima sekaligus, dengan link ke halaman berikutnya dan sebelumnya, dibaca dari `page` URL: `/notes?page=2`.

**Sebelum Anda memulai:** aplikasi [bagian 8](edit-and-delete.md).

## Minta database untuk satu halaman

`OFFSET` melewatkan catatan halaman sebelumnya, `LIMIT` menyimpan lima. Meminta satu lebih dari lima akan memberi tahu, secara gratis, apakah ada halaman berikutnya:

<!-- router:fbr,custom -->
```python filename="src/catatan.py"
from sqlmodel import Session, select

from src.configs.db import engine
from src.models.note_model import Note


def all_notes() -> list[Note]:
    with Session(engine) as session:
        return list(session.exec(select(Note).order_by(Note.id)))


def find(note_id: int) -> Note | None:
    with Session(engine) as session:
        return session.get(Note, note_id)


def add_note(text: str) -> Note:
    note = Note(text=text)
    with Session(engine) as session:
        session.add(note)
        session.commit()
        session.refresh(note)
    return note


def change_note(note_id: int, text: str) -> bool:
    with Session(engine) as session:
        note = session.get(Note, note_id)
        if note is None:
            return False
        note.text = text
        session.commit()
    return True


def remove_note(note_id: int) -> bool:
    with Session(engine) as session:
        note = session.get(Note, note_id)
        if note is None:
            return False
        session.delete(note)
        session.commit()
    return True


PAGE_SIZE = 5


def notes_page(number: int) -> tuple[list[Note], bool]:
    """One page of notes, oldest first, and whether a page comes after it."""
    with Session(engine) as session:
        query = select(Note).order_by(Note.id).offset((number - 1) * PAGE_SIZE).limit(PAGE_SIZE + 1)
        found = list(session.exec(query))
    return found[:PAGE_SIZE], len(found) > PAGE_SIZE
```

## Baca nomor halaman dari URL

`page` dari string kueri adalah teks yang dikirim oleh pengunjung: apa pun yang bukan bilangan positif akan dikembalikan ke halaman pertama, jadi `/notes?page=abc` tetap menjawab.

<!-- router:fbr,custom -->
```nexy filename="src/rute/catatan/index.nexy"
---
from "@/components/NoteCard.nexy" import NoteCard
from nexy import useSearchParams
from src.notes import notes_page

params = useSearchParams()
error = params.get("error", "")
asked = params.get("page", "1")
number = max(int(asked), 1) if asked.isdigit() else 1
found = notes_page(number)
notes = found[0]
more = found[1]
---
<section class="app-page">
  <h1>Notes</h1>

  {% if error %}
  <p class="note-error" role="alert">{{ error | e }}</p>
  {% endif %}

  <form method="post" action="{{ __actions_path['create_note'] }}">
    <input name="text" placeholder="A new note" maxlength="200" required>
    <button type="submit">Add</button>
  </form>

  {% for note in notes %}
  <NoteCard id="{{ note.id }}" text="{{ note.text }}" />
  {% endfor %}

  <nav class="note-pages" aria-label="Pages of notes">
    {% if number > 1 %}<a href="/notes?page={{ number - 1 }}" rel="prev">Newer</a>{% endif %}
    {% if more %}<a href="/notes?page={{ number + 1 }}" rel="next">Older</a>{% endif %}
  </nav>
</section>
```

`rel="prev"` dan `rel="next"` memberi tahu browser dan mesin telusur bagaimana laman saling mengikuti, dan `aria-label` memberi nama tautan untuk pembaca layar.

Tambahkan catatan hingga jumlahnya lebih dari lima: daftar berhenti di lima, dengan tautan **Lebih Lama** . Ini mengarah ke `/notes?page=2`, yang memiliki tautan kembali **Lebih Baru**.

## Apa yang Anda pelajari

- `offset` dan `limit` membaca satu halaman; meminta satu baris lagi menunjukkan apakah halaman lain mengikuti.
- `useSearchParams()` berbunyi `?page=`; suatu nilai dari pengunjung diperiksa sebelum digunakan.
- `rel="prev"` dan `rel="next"` menghubungkan halaman untuk browser, crawler, dan pembaca layar.
