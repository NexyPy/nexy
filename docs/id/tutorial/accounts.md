# Bangun aplikasi catatan dengan Nexy, bagian 10: buat akun dan masuk

Bagian 10 memungkinkan pengunjung membuat akun dengan email dan kata sandi, masuk dan keluar, dan mengingat siapa yang masuk dengan cookie sesi.

**Sebelum Anda memulai:** aplikasi [bagian 9](paginate-the-notes.md).

## Aktifkan sesi

Sesi adalah cookie yang ditandatangani: server memasukkan id pengguna yang masuk ke dalamnya, dan membacanya kembali pada setiap permintaan. Starlette menandatanganinya dengan `itsdangerous`:

```bash
uv add itsdangerous
```

Rahasia yang ditandatanganinya disimpan di `.env`, di sebelah alamat database:

```bash filename=".env"
DATABASE_URL=sqlite:///dev.db
SESSION_SECRET=change-me-to-a-long-random-string
```

Buatlah rahasia nyata dengan `python -c "import secrets; print(secrets.token_urlsafe(32))"`. Siapa pun yang mengetahuinya dapat menandatangani cookie sebagai pengguna mana pun.

`useSession` mengaktifkan sesi, dengan rahasia yang dibaca dari lingkungan:

## Hash dan periksa kata sandi

`hashlib.scrypt`, dari perpustakaan standar, adalah hash yang sengaja dibuat lambat, jadi menebak kata sandi satu per satu membutuhkan waktu bertahun-tahun bagi penyerang. Setiap kata sandi mendapatkan garam acaknya sendiri:

<!-- router:fbr,custom -->
```python filename="src/akun.py"
import hashlib
import hmac
import secrets

from sqlalchemy.exc import IntegrityError
from sqlmodel import Session, select

from src.configs.db import engine
from src.models.user_model import User


def hash_password(password: str) -> str:
    salt = secrets.token_bytes(16)
    digest = hashlib.scrypt(password.encode(), salt=salt, n=2**14, r=8, p=1)
    return f"{salt.hex()}:{digest.hex()}"


def password_matches(password: str, stored: str) -> bool:
    salt, digest = stored.split(":")
    found = hashlib.scrypt(password.encode(), salt=bytes.fromhex(salt), n=2**14, r=8, p=1)
    return hmac.compare_digest(found.hex(), digest)


def create_user(email: str, password: str) -> User | None:
    """The new user, or None when the email already has an account."""
    user = User(email=email, password_hash=hash_password(password))
    with Session(engine) as session:
        session.add(user)
        try:
            session.commit()
        except IntegrityError:
            return None
        session.refresh(user)
    return user


def authenticate(email: str, password: str) -> User | None:
    with Session(engine) as session:
        user = session.exec(select(User).where(User.email == email)).first()
    if user is None or not password_matches(password, user.password_hash):
        return None
    return user
```

## Daftar, masuk, keluar

Tiga Tindakan. Masing-masing yang berhasil menulis sesi tersebut, atau mengosongkannya:

```python filename="src/aksi/akun.py"
from urllib.parse import urlencode

from nexy import useSession
from nexy.decorators import Action
from nexy.http import RedirectResponse
from src.accounts import authenticate, create_user

MIN_PASSWORD = 8


def go(path: str, error: str = "") -> RedirectResponse:
    query = f"?{urlencode({'error': error})}" if error else ""
    return RedirectResponse(f"{path}{query}", status_code=303)


@Action
async def sign_up(email: str, password: str) -> RedirectResponse:
    email = email.strip().lower()
    if len(password) < MIN_PASSWORD:
        return go("/signup", f"A password has at least {MIN_PASSWORD} characters.")
    user = create_user(email, password)
    if user is None:
        return go("/signup", "This email already has an account.")
    useSession()["user_id"] = user.id
    return go("/notes")


@Action
async def sign_in(email: str, password: str) -> RedirectResponse:
    user = authenticate(email.strip().lower(), password)
    if user is None:
        return go("/signin", "Wrong email or password.")
    useSession()["user_id"] = user.id
    return go("/notes")


@Action
async def sign_out() -> RedirectResponse:
    useSession().clear()
    return go("/")
```

*Email atau kata sandi salah*, tidak pernah yang mana: pesan yang mengatakan "tidak ada akun dengan email ini" akan memberi tahu siapa pun email mana yang memiliki akun.

## Tunjukkan siapa yang masuk

Halaman catatan menyambut pengguna dan menampilkan tombol keluar; pengunjung malah melihat tautan ke dua formulir:

from "@/components/NoteCard.nexy" import NoteCard
from nexy import useSearchParams, useSession

params = useSearchParams()

asked = params.get("page", "1")

## Apa yang Anda pelajari

- `useSession` di `nexyconfig.py` mengaktifkan cookie sesi yang ditandatangani; rahasianya ada di `.env`.
- Basis data menyimpan hash kata sandi yang lambat dan asin, diperiksa dengan `hmac.compare_digest`.
- Suatu Tindakan menulis sesi dengan `useSession()`; sebuah halaman membacanya dengan cara yang sama.
