# Internasionalisasi (i18n)

Nexy tidak menerjemahkan aplikasi Anda. Ia tidak memiliki middleware lokal, tidak ada pembantu `trans` dan tidak ada file lokal: aplikasi memilih perpustakaan i18n yang sesuai, saat ia memilih ORM.

Baris perintah (`nx`) diterjemahkan; lihat [CLI](../reference/cli.md).

## Dalam seorang pawang

Penangan membaca apa yang dibutuhkannya dari permintaan. Yang ini menjawab dalam bahasa header `Accept-Language`:

```python filename="src/rute/halo.py"
from nexy.http import Header

MESSAGES = {"en": "Hello", "fr": "Bonjour"}


async def GET(accept_language: str = Header("en")):
    language = accept_language.split(",")[0].split("-")[0].lower()
    return {"message": MESSAGES.get(language, MESSAGES["en"])}
```

## Dalam satu halaman

Gunakan perpustakaan frontend Anda untuk halaman yang dirutekan klien (misalnya `i18next`, `vue-i18n` atau toko Svelte), dan perpustakaan Python Anda (`gettext` dari perpustakaan standar, atau Babel) untuk halaman `.nexy`. Atur `<html lang>` di tata letak root.
