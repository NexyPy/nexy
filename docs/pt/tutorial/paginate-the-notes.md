# Crie um aplicativo de notas com Nexy, parte 9: paginar as notas

A parte 9 mostra as notas cinco de cada vez, com links para as páginas seguintes e anteriores, lidas a partir do `page` da URL: `/notes?page=2`.

**Antes de começar:** o aplicativo da [parte 8](edit-and-delete.md).

## Peça ao banco de dados uma página

`OFFSET` pula as notas das páginas anteriores, `LIMIT` mantém cinco. Pedir mais de cinco informa, gratuitamente, se existe uma próxima página:

<!-- router:fbr,custom -->
```python filename="src/notes.py"
from sqlmodel import Session, select

from src.configs.db import engine
from src.models.note_model import Note


def all_notes() -> list[Note]:
    with Session(engine) as session:
        return list(session.exec(select(Note).order_by(Note.id)))


def find(note_id: int) -> Note | None:
    with Session(engine) as session:
        return session.get(Note, note_id)


def add_note(text: str) -> Note:
    note = Note(text=text)
    with Session(engine) as session:
        session.add(note)
        session.commit()
        session.refresh(note)
    return note


def change_note(note_id: int, text: str) -> bool:
    with Session(engine) as session:
        note = session.get(Note, note_id)
        if note is None:
            return False
        note.text = text
        session.commit()
    return True


def remove_note(note_id: int) -> bool:
    with Session(engine) as session:
        note = session.get(Note, note_id)
        if note is None:
            return False
        session.delete(note)
        session.commit()
    return True


PAGE_SIZE = 5


def notes_page(number: int) -> tuple[list[Note], bool]:
    """One page of notes, oldest first, and whether a page comes after it."""
    with Session(engine) as session:
        query = select(Note).order_by(Note.id).offset((number - 1) * PAGE_SIZE).limit(PAGE_SIZE + 1)
        found = list(session.exec(query))
    return found[:PAGE_SIZE], len(found) > PAGE_SIZE
```

## Leia o número da página do URL

O `page` da string de consulta é o texto enviado pelo visitante: qualquer coisa que não seja um número positivo volta para a primeira página, então `/notes?page=abc` ainda responde.

<!-- router:fbr,custom -->
```nexy filename="src/rotas/notes/index.nexy"
---
from "@/components/NoteCard.nexy" import NoteCard
from nexy import useSearchParams
from src.notes import notes_page

params = useSearchParams()
error = params.get("error", "")
asked = params.get("page", "1")
number = max(int(asked), 1) if asked.isdigit() else 1
found = notes_page(number)
notes = found[0]
more = found[1]
---
<section class="app-page">
  <h1>Notes</h1>

  {% if error %}
  <p class="note-error" role="alert">{{ error | e }}</p>
  {% endif %}

  <form method="post" action="{{ __actions_path['create_note'] }}">
    <input name="text" placeholder="A new note" maxlength="200" required>
    <button type="submit">Add</button>
  </form>

  {% for note in notes %}
  <NoteCard id="{{ note.id }}" text="{{ note.text }}" />
  {% endfor %}

  <nav class="note-pages" aria-label="Pages of notes">
    {% if number > 1 %}<a href="/notes?page={{ number - 1 }}" rel="prev">Newer</a>{% endif %}
    {% if more %}<a href="/notes?page={{ number + 1 }}" rel="next">Older</a>{% endif %}
  </nav>
</section>
```

`rel="prev"` e `rel="next"` informam aos navegadores e mecanismos de busca como as páginas se sucedem e `aria-label` nomeia os links para um leitor de tela.

Adicione notas até que haja mais de cinco: a lista termina em cinco, com um link **Mais antigo**. Isso leva a `/notes?page=2`, que tem um link **Mais recente** de volta.

## O que você aprendeu

- `offset` e `limit` leram uma página; pedir mais uma linha indica se outra página segue.
- `useSearchParams()` lê `?page=`; um valor do visitante é verificado antes de ser usado.
- `rel="prev"` e `rel="next"` vinculam as páginas para navegadores, crawlers e leitores de tela.
