# Crie um aplicativo de notas com Nexy, parte 10: crie uma conta e faça login

A Parte 10 permite que um visitante crie uma conta com um e-mail e uma senha, faça login e logout e lembre quem está conectado com um cookie de sessão.

**Antes de começar:** o aplicativo da [parte 9](paginate-the-notes.md).

## Ativar sessões

Uma sessão é um cookie assinado: o servidor coloca nele o ID do usuário conectado e o lê de volta em cada solicitação. Starlette assina com `itsdangerous`:

```bash
uv add itsdangerous
```

O segredo com o qual ele assina é mantido em `.env`, próximo ao endereço do banco de dados:

```bash filename=".env"
DATABASE_URL=sqlite:///dev.db
SESSION_SECRET=change-me-to-a-long-random-string
```

Faça um verdadeiro segredo com `python -c "import secrets; print(secrets.token_urlsafe(32))"`. Qualquer pessoa que saiba disso pode assinar um cookie como qualquer usuário.

`useSession` ativa sessões, com o segredo lido do ambiente:

## Hash e verifique uma senha

`hashlib.scrypt`, da biblioteca padrão, é um hash lento propositalmente, portanto, adivinhar as senhas uma por uma custa anos ao invasor. Cada senha recebe seu próprio sal aleatório:

<!-- router:fbr,custom -->
```python filename="src/contas.py"
import hashlib
import hmac
import secrets

from sqlalchemy.exc import IntegrityError
from sqlmodel import Session, select

from src.configs.db import engine
from src.models.user_model import User


def hash_password(password: str) -> str:
    salt = secrets.token_bytes(16)
    digest = hashlib.scrypt(password.encode(), salt=salt, n=2**14, r=8, p=1)
    return f"{salt.hex()}:{digest.hex()}"


def password_matches(password: str, stored: str) -> bool:
    salt, digest = stored.split(":")
    found = hashlib.scrypt(password.encode(), salt=bytes.fromhex(salt), n=2**14, r=8, p=1)
    return hmac.compare_digest(found.hex(), digest)


def create_user(email: str, password: str) -> User | None:
    """The new user, or None when the email already has an account."""
    user = User(email=email, password_hash=hash_password(password))
    with Session(engine) as session:
        session.add(user)
        try:
            session.commit()
        except IntegrityError:
            return None
        session.refresh(user)
    return user


def authenticate(email: str, password: str) -> User | None:
    with Session(engine) as session:
        user = session.exec(select(User).where(User.email == email)).first()
    if user is None or not password_matches(password, user.password_hash):
        return None
    return user
```

`hmac.compare_digest` compara em um tempo que não depende de onde os dois hashes diferem, então o tempo de resposta não diz nada ao invasor.

## Inscreva-se, faça login, saia

Três ações. Cada um que tiver sucesso grava a sessão ou a esvazia:

```python filename="src/actions/accounts.py"
from urllib.parse import urlencode

from nexy import useSession
from nexy.decorators import Action
from nexy.http import RedirectResponse
from src.accounts import authenticate, create_user

MIN_PASSWORD = 8


def go(path: str, error: str = "") -> RedirectResponse:
    query = f"?{urlencode({'error': error})}" if error else ""
    return RedirectResponse(f"{path}{query}", status_code=303)


@Action
async def sign_up(email: str, password: str) -> RedirectResponse:
    email = email.strip().lower()
    if len(password) < MIN_PASSWORD:
        return go("/signup", f"A password has at least {MIN_PASSWORD} characters.")
    user = create_user(email, password)
    if user is None:
        return go("/signup", "This email already has an account.")
    useSession()["user_id"] = user.id
    return go("/notes")


@Action
async def sign_in(email: str, password: str) -> RedirectResponse:
    user = authenticate(email.strip().lower(), password)
    if user is None:
        return go("/signin", "Wrong email or password.")
    useSession()["user_id"] = user.id
    return go("/notes")


@Action
async def sign_out() -> RedirectResponse:
    useSession().clear()
    return go("/")
```

*E-mail ou senha errada*, nunca qual: uma mensagem que dizia “nenhuma conta com este e-mail” informaria a qualquer pessoa quais e-mails possuem uma conta.

## Mostrar quem está conectado

A página de notas cumprimenta o usuário e mostra o botão de sair; em vez disso, um visitante vê os links para os dois formulários:

<!-- router:fbr,custom -->
```nexy filename="src/rotas/notes/index.nexy"
---
from "@/components/NoteCard.nexy" import NoteCard
from nexy import useSearchParams, useSession
from src.notes import notes_page

params = useSearchParams()
error = params.get("error", "")
asked = params.get("page", "1")
number = max(int(asked), 1) if asked.isdigit() else 1
found = notes_page(number)
notes = found[0]
more = found[1]
signed_in = "user_id" in useSession()
---
<section class="app-page">
  <h1>Notes</h1>

  {% if signed_in %}
  <form method="post" action="{{ __actions_path['sign_out'] }}">
    <button type="submit">Sign out</button>
  </form>
  {% else %}
  <p><a href="/signin">Sign in</a> or <a href="/signup">create an account</a>.</p>
  {% endif %}

  {% if error %}
  <p class="note-error" role="alert">{{ error | e }}</p>
  {% endif %}

  <form method="post" action="{{ __actions_path['create_note'] }}">
    <input name="text" placeholder="A new note" maxlength="200" required>
    <button type="submit">Add</button>
  </form>

  {% for note in notes %}
  <NoteCard id="{{ note.id }}" text="{{ note.text }}" />
  {% endfor %}

  <nav class="note-pages" aria-label="Pages of notes">
    {% if number > 1 %}<a href="/notes?page={{ number - 1 }}" rel="prev">Newer</a>{% endif %}
    {% if more %}<a href="/notes?page={{ number + 1 }}" rel="next">Older</a>{% endif %}
  </nav>
</section>
```

## O que você aprendeu

- `useSession` em `nexyconfig.py` ativa um cookie de sessão assinado; seu segredo mora em `.env`.
- O banco de dados mantém um hash lento e salgado da senha, verificado com `hmac.compare_digest`.
- Uma Action grava a sessão com `useSession()`; uma página lê da mesma maneira.
