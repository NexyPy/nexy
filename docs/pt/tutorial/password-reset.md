# Crie um aplicativo de notas com Nexy, parte 12: redefina uma senha esquecida por e-mail

A Parte 12 envia um link por email para um usuário que esqueceu sua senha. O link abre um formulário para nova senha, funciona por uma hora e apenas uma vez.

**Antes de começar:** o aplicativo da [parte 11](own-notes.md).

## Envie um e-mail

`smtplib`, da biblioteca padrão, se comunica com qualquer servidor de e-mail: o do seu provedor, ou um serviço como Postmark, Resend ou Amazon SES, todos aceitando SMTP. Sem servidor, o email é impresso no terminal do `nexy dev`, que é tudo que você precisa no seu computador:

```python filename="src/mail.py"
import os
import smtplib
from email.message import EmailMessage


def send_email(to: str, subject: str, body: str) -> None:
    """Send through the SMTP server named in `.env`; without one, print the email instead."""
    host = os.getenv("SMTP_HOST")
    if not host:
        print(f"To: {to}\nSubject: {subject}\n\n{body}", flush=True)
        return
    message = EmailMessage()
    message["From"] = os.getenv("MAIL_FROM", "notes@localhost")
    message["To"] = to
    message["Subject"] = subject
    message.set_content(body)
    with smtplib.SMTP(host, int(os.getenv("SMTP_PORT", "587"))) as smtp:
        smtp.starttls()
        smtp.login(os.environ["SMTP_USER"], os.environ["SMTP_PASSWORD"])
        smtp.send_message(message)
```

Para enviar de verdade, adicione o servidor em `.env`:

```text
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=notes@example.com
SMTP_PASSWORD=the-password-of-the-mailbox
MAIL_FROM=notes@example.com
APP_URL=https://notes.example.com
```

`starttls()` criptografa a conexão antes que a senha seja enviada.

## Faça um link que funcione uma vez, por uma hora

O link carrega um token assinado com o segredo da sessão, para que ninguém possa fazer um manualmente. `itsdangerous` escreve a hora nele e `max_age` recusa depois de uma hora. O token também contém o final do hash da senha: quando a senha muda, o hash muda e o link para de funcionar.

<!-- router:fbr,custom -->
```python filename="src/password_reset.py"
import os

from itsdangerous import BadSignature, URLSafeTimedSerializer
from sqlmodel import Session, select

from src.accounts import hash_password
from src.configs.db import engine
from src.models.user_model import User

ONE_HOUR = 3600


def signer() -> URLSafeTimedSerializer:
    return URLSafeTimedSerializer(os.environ["SESSION_SECRET"], salt="password-reset")


def find_by_email(email: str) -> User | None:
    with Session(engine) as session:
        return session.exec(select(User).where(User.email == email)).first()


def reset_token(user: User) -> str:
    """A token that names the user and the end of their current password hash."""
    return signer().dumps([user.id, user.password_hash[-16:]])


def user_of(token: str) -> User | None:
    """The user of a token less than an hour old, whose password has not changed since."""
    try:
        user_id, fingerprint = signer().loads(token, max_age=ONE_HOUR)
    except BadSignature:
        return None
    with Session(engine) as session:
        user = session.get(User, user_id)
    if user is None or user.password_hash[-16:] != fingerprint:
        return None
    return user


def set_password(user_id: int, password: str) -> None:
    with Session(engine) as session:
        user = session.get(User, user_id)
        user.password_hash = hash_password(password)
        session.commit()
```

## Peça o link e use-o

```python filename="src/actions/password_reset.py"
import os
from urllib.parse import urlencode

from nexy.decorators import Action
from nexy.http import RedirectResponse
from src.mail import send_email
from src.password_reset import find_by_email, reset_token, set_password, user_of

MIN_PASSWORD = 8


def go(path: str, **query: str) -> RedirectResponse:
    return RedirectResponse(f"{path}?{urlencode(query)}" if query else path, status_code=303)


@Action
async def request_reset(email: str) -> RedirectResponse:
    user = find_by_email(email.strip().lower())
    if user is not None:
        link = f"{os.getenv('APP_URL', 'http://localhost:3000')}/reset?token={reset_token(user)}"
        body = f"Open this link within an hour to choose a new password:\n\n{link}\n"
        send_email(user.email, "Reset your password", body)
    return go("/forgot", sent="1")


@Action
async def reset_password(token: str, password: str) -> RedirectResponse:
    user = user_of(token)
    if user is None:
        return go("/forgot", error="This link has expired or was used. Ask for a new one.")
    if len(password) < MIN_PASSWORD:
        return go("/reset", token=token, error=f"A password has at least {MIN_PASSWORD} characters.")
    set_password(user.id, password)
    return go("/signin", reset="1")
```

`request_reset` responde da mesma forma se o e-mail tem conta ou não: a página diz que um link *pode* estar a caminho, então não informa a ninguém quais e-mails estão registrados.

`role="status"` faz um leitor de tela ler a mensagem sem interromper, onde `role="alert"` interrompe: uma confirmação não é um erro.

Abra <http://localhost:3000/forgot>, digite o email da sua conta e envie. O terminal de `nexy dev` imprime o e-mail: abra seu link, escolha uma nova senha e faça login com ela. Abra o link uma segunda vez: ele é recusado.

## O que você aprendeu

- `smtplib` envia um email através de qualquer servidor SMTP; no desenvolvimento, imprimir é suficiente.
- Um token assinado e cronometrado de `itsdangerous` cria um link que ninguém pode falsificar, válido por uma hora.
- Colocar parte do hash da senha no token faz com que o link funcione apenas uma vez.
