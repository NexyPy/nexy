What is Nexy ?

Nexy is a Python web framework optimized for building fast, content-driven websites, API services, and more.

Server-First

Nexy improves performance by rendering components on the server, sending lightweight HTML to the browser.

Customizable

Extend Nexy with your favorite tools - JavaScript UI components, CSS libraries, themes, and more.

Content-Driven

Nexy works with your content wherever it lives: your file system, an API, or your favorite CMS.

What's in Nexy ?

File-Based Router

Auto-discovers routes from src/routes/. Dynamic params, nested layouts, guards and locale dispatch.

Multi-Framework

React, Preact, Solid, Vue and Svelte - bring your own components. CSR, SSR and fast refresh.

Jinja2 + MDX

Server-side Markdown rendering with auto heading IDs and table-of-contents extraction.

i18n Built-In

Locale auto-detection, RTL support and the @i18n() decorator for class-level translation.

Dependency Injection

@Injectable with singleton, request and transient scopes. Thread-safe container.

CLI Toolchain

new, init, dev, start, build… 8 commands with Typer + Rich terminal output.

8 Request Hooks

usePathname, useRouter, useQuery, useSession, useCookies, useSearchParams, useToc, useViews.

FastAPI Foundation

HTTP, WebSocket and async support with middleware stack and OpenAPI docs.

Vite + HMR

WebSocket-based fast refresh and optional CSS/JS inlining.

Built on a foundation of fast, production-grade tooling

Nexy combines a modern compiler, a powerful template engine, and a fast asset builder.

FastAPI

Foundation for routers with HTTP, WebSocket and async support.

Maximum Flexibility

Bring your existing React, Preact, Solid, Vue or Svelte components - SSR and fast refresh included.
