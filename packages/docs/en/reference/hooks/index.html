Hooks reference

Every Nexy hook, its signature and what it returns. Hooks are the way your pages speak to the request context. Request hooks tip

Every Nexy hook, its signature and what it returns. Hooks are the way your pages speak to the request context.

Request hooks

hookusePathname

usePathname() -> str

Returns the current path of the request.

usePathname.py python 
from nexy import hooks

path = hooks.use_pathname()

hookuseRouter

useRouter() -> Router

Returns the active router for the current request.

hookuseQuery

useQuery() -> dict[str, str]

Returns the URL query string parsed into a dictionary.

hookuseSession

useSession() -> Session

Returns the current request session object.

ArgumentTypeDescription
sessionSessionThe persisted session tied to this request.

hookuseCookies

useCookies() -> dict[str, str]

Returns the request cookies as a plain mapping.

hookuseSearchParams

useSearchParams() -> SearchParams

Typed access to search parameters with serialization helpers.

hookuseToc

useToc() -> TableOfContents

Returns the extracted table of contents of the rendered page.

hookuseViews

useViews() -> Views

Tracks and returns view counters for the current page.

?
Hooks are the server-side answer to "data in the template". Pair them with frontmatter Python to render dynamic __props__.
