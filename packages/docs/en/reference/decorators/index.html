Dependency injection

decorator@Injectable

@Injectable(scope: Scope = Singleton)

Marks a class as injectable into other components through the container.

ArgumentTypeDescription
scopeSingleton | Request | TransientLifetime of the injected instance.

Internationalization

decorator@i18n

@i18n(default_locale: str)

Binds class-level string translations to the active locale.

default_localestrFallback locale when none is detected.
