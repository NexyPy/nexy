CLI reference

Every nexy command at a glance. Scaffolding Development

Every nexy command at a glance.

Scaffolding

commandnexy new

nexy new <name> [--template]

Creates a new project in a fresh folder.

ArgumentTypeDescription
namestrProject directory name.
templatestrStarter template (web-fbr, web-modular, api-fbr, api-modular).

commandnexy init

nexy init [--template]

Initializes Nexy in the current directory.

Development

commandnexy dev

nexy dev [--port]

Starts the dev server with hot reload.

commandnexy start

nexy start [--port]

Runs the built app in production mode.

commandnexy build

nexy build

Compiles the site and bundles the frontend for production.
