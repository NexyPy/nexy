Every Nexy release, from the latest to the first. Follow along with each new version.

2.1.1

Current stable release.

  • Fixed TemplateFormatter.format_attributes edge cases for empty attribute values.
  • Updated docs landing to a full app-style hero.
  • Client-only rendering guards for Vue, Svelte and Preact SSR.

2.1.0

  • Added the useViews hook.
  • Improved Vite HMR reliability under Windows.
  • SSG builds now run per-file esbuild builds in parallel.

2.0.0

The two-router release.

  • Introduced Modular Routing alongside File-Based Routing.
  • @Injectable with singleton / request / transient scopes.
  • @i18n class-level translations.
