Nexy is multilingual by design. Strings live in locale files, and your pages pull them with t().

How it works

  • A locale is a language code like en, fr, ar, zh…
  • Translated strings are stored per locale.
  • t(key) returns the string for the active locale.
  • trans() and useLocale give you more control.

Example

index.nexy python 
---
from nexy import t, useLocale

hello = t("hello")
lang = useLocale()
---

<p>{ { hello } } - locale: { { lang } }</p>
?
Strings are organized in keys per domain. Keep them in nexy/i18n/<locale>/ and reuse them across pages.
